## 二、Lecture 1：Introduction to Quantitative Data Analysis

### 1. 讲授了什么

第一讲主要介绍课程目标和社会科学定量研究的基本逻辑，而非 R 编程。课程以英国性别工资差异（Gender Pay Gap）为贯穿案例，说明怎样从现实问题出发，提出可以用统计数据检验的研究问题。

重要概念包括：

- **Deductive Research（演绎研究）**：从理论和文献提出假设，再使用数据支持或反驳它。
- **Inductive Research（归纳研究）**：从数据与观察中总结规律。
- **Hypothesis（研究假设）**：研究开始前提出的可检验判断。
- **Confounder（混杂因素）**和 **Omitted Variable（遗漏变量）**：解释为什么直接比较两个群体，不必然获得有效的因果结论。
- **Causality vs Association（因果与关联）**：统计相关并不自动证明因果关系。
- **DAG（有向无环图）**：辅助思考变量之间可能存在的因果结构。

### 2. 变量测量尺度

| 类型 | 英文 | 解释 | 示例 |
|---|---|---|---|
| 名义尺度 | Nominal | 只有类别，不存在天然顺序 | 性别、地区 |
| 顺序尺度 | Ordinal | 类别间存在排序关系 | 学历等级、满意度 |
| 区间尺度 | Interval | 差值有意义，但零点并非绝对 | 摄氏温度 |
| 比率尺度 | Ratio | 存在绝对零点，可比较倍数 | 工资、距离 |

### 3. 实际进行了哪些操作

主要是学习如何设计研究问题、识别变量、认识真实数据的复杂性以及理解课程要求。**没有成体系的 R 实操。**

### 4. 对作业的作用

形成 Research Question、Hypotheses、Dependent Variable、Independent Variables 和理论/文献依据。应避免仅仅因为数据中有两个字段就提出缺乏理论意义的关联问题。

## 三、Lecture 2：Data Preparation and R Fundamentals

### 1. 本讲目标

从英国 Labour Force Survey 的原始调查数据开始，学习 RStudio、基础 R 语法、包的使用、读取文件、筛选样本以及把变量转换为适合统计分析的形式。

### 2. R 基本语法

```r
result <- 3 + 2
numbers <- c(1, 2, 3, 4, 5)
numbers + 1
```

- `<-`：赋值；
- `c()`：创建向量；
- `library()`：加载软件包；
- `install.packages()`：安装软件包；
- `%>%`：管道，将前一步的结果传入下一步。

### 3. 导入文件

```r
library(tidyverse)

lfs <- read_tsv(
  "../UKDA-9388-tab/tab/lfsp_jm25_eul_pwt24.tab"
)
```

`read_tsv()` 用于读取 Tab 分隔的数据文件；路径必须按自己的文件夹结构修改。

### 4. 选择分析变量

```r
lfs <- select(
  lfs,
  SEX, HOURPAY, AGE, GOR9D,
  EMPLEN, FLEX22W6, FTPT,
  HIQUL22D, INDE07M, JOBTYP,
  MPNR02, MARSTA, NSECMJ20, BUSHR
)
```

课件强调：真实调查数据字段可能很多，应根据研究问题决定保留什么，而非盲目保留所有变量。

### 5. 筛选样本与清理不合理值

```r
lfs <- filter(lfs, HOURPAY >= 6.4)
lfs <- filter(lfs, HOURPAY <= 100)
lfs <- filter(lfs, AGE >= 16, AGE <= 64)
lfs <- filter(lfs, BUSHR >= 7)
lfs <- filter(lfs, BUSHR < 97)
```

实际研究中必须解释筛选阈值的依据及其对样本代表性的影响。

### 6. 处理分类变量

```r
lfs <- mutate(
  lfs,
  SEX = factor(
    SEX,
    levels = 1:2,
    labels = c("Male", "Female")
  )
)
```

`factor()` 用于将类别编号转换为分类变量，否则 R 可能把数字编码误当作连续数据。课件还处理地区、学历、行业、婚姻状态、合同和职业相关变量。

### 7. 核验清洗结果

```r
dim(lfs)
glimpse(lfs)
```

课件教学案例的最终样本为约 **7,347 个观测值**。此外，调查中可能用负数表示缺失、拒答或不适用；不能不查数据字典就直接把它们当作真实数值。

**作业对应：** Data and Methods：数据来源、变量定义、缺失值及异常值处理、样本筛选规则、最终样本量。

## 四、Lecture 3：Descriptive Statistics

### 1. 本讲目标

使用统计摘要和频数分布描述数据，了解均值、分位数、分布形态和不同群体之间的差异。

### 2. 连续变量的统计摘要

| 指标 | 函数 | 作用 |
|---|---|---|
| 平均数 | `mean()` | 描述平均水平 |
| 中位数 | `median()` | 描述中心位置，较不受极端值影响 |
| 最小/最大值 | `min()`, `max()` | 描述观测范围 |
| 方差 | `var()` | 描述数据离散程度 |
| 标准差 | `sd()` | 以变量原单位反映离散程度 |
| 分位数 | `quantile()` | 描述分布中指定百分位的位置 |
| 综合摘要 | `summary()` | 输出一组常用摘要 |

```r
lfs %>%
  summarise(
    mean_pay = mean(HOURPAY),
    median_pay = median(HOURPAY),
    minimum = min(HOURPAY),
    maximum = max(HOURPAY),
    sd_pay = sd(HOURPAY)
  )
```

### 3. 计算分位数

```r
reframe(
  lfs,
  quartiles = quantile(
    HOURPAY,
    probs = c(0.25, 0.5, 0.75)
  ),
  q = c(
    "First quartile",
    "Second Quartile",
    "Third Quartile"
  )
)
```

这里 `probs` 为 0.25、0.50、0.75 时分别计算第 25、50、75 百分位点；也可以取其他介于 0 和 1 的概率值。

### 4. 频数与百分比

```r
lfs %>%
  count(SEX) %>%
  mutate(percent = n / sum(n) * 100)
```

### 5. 分组统计

```r
lfs %>%
  group_by(SEX) %>%
  summarise(
    mean_wage = mean(HOURPAY),
    median_wage = median(HOURPAY)
  )
```

### 6. 交叉表与比例

```r
table(lfs$HIQUL22D, lfs$SEX)
prop.table(table(lfs$HIQUL22D, lfs$SEX), margin = 1)
prop.table(table(lfs$HIQUL22D, lfs$SEX), margin = 2)
```

注意行比例和列比例具有不同的分母，不应混淆。

本讲还使用 `head()`、`tail()`、`arrange()`、`pull()` 等函数检查数据。

**作业对应：** Summary Statistics；11 月的 Formative Proposal 也需要因变量的描述性统计以及结果解释。

## 七、Lecture 6：Statistical Inference and Hypothesis Testing

### 1. 本讲目标

从样本描述扩展到总体推断，学习抽样分布、标准误、置信区间、P 值以及两组均值比较。

### 2. 基本概念

- Sampling Error（抽样误差）
- Sampling Distribution（抽样分布）
- Central Limit Theorem（中心极限定理）
- Standard Error（标准误）
- Null/Alternative Hypothesis（原假设/备择假设）
- Statistical Significance（统计显著性）
- Type I / Type II Error（第一类/第二类错误）
- Confidence Interval（置信区间）

### 3. 正态分布概率

```r
1 - pnorm(11.26)
```

### 4. 两独立组均值的 t 检验

```r
t.test(HOURPAY ~ SEX, data = lfs)
```

举例：

\[
H_0: \mu_{Male} = \mu_{Female}
\]

\[
H_A: \mu_{Male} \neq \mu_{Female}
\]

### 5. 用回归分析同一组间差异

```r
lm(HOURPAY ~ SEX, data = lfs) %>%

```

当 X 为二元变量时，回归系数代表两组平均值的差异；截距对应参考组均值。

**作业对应：** 明确研究假设、正确解释显著性、估计不确定性与置信区间。

## 八、Lecture 7：ANOVA, Correlation and Simple Linear Regression

### 1. 本讲目标

从两组比较拓展到多组比较，并开始系统建立连续型结果变量的简单线性回归。

### 2. 方差分析（ANOVA）

```r
aov(HOURPAY ~ HIQUL22D, data = lfs) %>%
  summary()
```

主要讨论组间与组内变异、均方、F 统计量、多组均值检验。

### 3. 分类变量回归

```r
lm(HOURPAY ~ HIQUL22D, data = lfs) %>%
  summary()
```

分类自变量的系数是相对于参考组的差异。

### 4. 相关分析

```r
cor(lfs$HOURPAY, lfs$AGE)
cor.test(lfs$HOURPAY, lfs$AGE)
```

`cor()` 给出相关系数，`cor.test()` 提供统计检验及相关输出。

### 5. 简单 OLS 回归

```r
lm(HOURPAY ~ AGE, data = lfs) %>%
  summary()
```

基本模型：

\[
Y_i = \beta_0 + \beta_1 X_i + \epsilon_i
\]

学习了截距、斜率、残差、最小二乘法、\(R^2\) 及模型解释。

**作业对应：** 作为回归建模的起点，可先建立只有核心自变量的模型，再逐步加入其他因素。

## 九、Lecture 8：Multiple Linear Regression

> 本讲应同时阅读 `lecture8_notes.html` 与 `lecture8_regressions.html`。

### 1. 从简单模型扩展到多元模型

```r
# 只有重点自变量
lm(HOURPAY ~ SEX, data = lfs) %>%
  summary()

# 加入控制变量
lm(HOURPAY ~ SEX + HIQUL22D, data = lfs) %>%
  summary()
```

补充课件依次加入学历、工作状态、合同特征、工龄、企业规模、婚姻状况、行业、职业等级、年龄和地区等因素。

### 2. 重点观察什么

- 重点变量系数方向是否变化？
- 加入控制变量后，系数大小如何改变？
- P 值和标准误是否变化？
- \(R^2\) 和 Adjusted \(R^2\) 如何变化？
- 新增变量是否有理论依据？

补充课件中包含较多控制变量的模型解释了大约 **39% 的工资变异**（该数值只属于课堂示例，不可用于其他研究）。

### 3. R² 与 Adjusted R²

普通 \(R^2\) 不会因为新增自变量而降低；调整后的 \(R^2\) 会对模型复杂度作一定修正。研究不能简单地以最大化 \(R^2\) 代替研究设计。

### 4. 模型变量选择

强调不能仅凭显著性机械删减变量，理论依据、潜在混杂、解释目标同样重要。

### 5. 检查异常值和高影响点

```r
fake_data <- data.frame(
  age = c(20, 23, 25, 26, 28, 30, 32, 33, 65),
  wage = c(10, 11, 15, 9, 8, 20, 22, 25, 200)
)

fake_data %>%
  lm(wage ~ age, data = .) %>%
  plot(which = 5)
```

`which = 5` 绘制 Residuals vs Leverage 图，以发现对模型拟合影响特别大的观测值。

**作业对应：** 论文最重要的部分之一。需要展示递进模型的理由和结果，而不只展示单个最终回归表。

## 十、Lecture 9：Model Specification and Heteroscedasticity

### 1. 本讲目标

验证模型的函数形式和残差特征是否符合适当的回归假设；学习如何通过诊断调整模型设定。

### 2. 函数形式对照

课程使用 R 内置 `mtcars` 数据，比较汽车重量与燃油效率。

```r
lm(mpg ~ wt, data = mtcars)
lm(log(mpg) ~ wt, data = mtcars)
lm(log(mpg) ~ log(wt), data = mtcars)
```

分别对应线性、半对数、双对数形式。变换改变了系数的解释方式，不能直接用原始单位解释所有模型。

### 3. 残差与拟合值

```r
model <- lm(mpg ~ wt, data = mtcars)
plot(model, which = 1)
```

Residuals vs Fitted 图用于观察系统性趋势、非线性线索和残差方差的变化。

### 4. Ramsey RESET 检验

```r
lm(mpg ~ wt, data = mtcars) %>%
  lmtest::resettest()
```

RESET 检验用于检查某些模型设定问题，但不能直接指定正确模型形式。

### 5. Breusch–Pagan 异方差检验

```r
model <- lm(
  HOURPAY ~ SEX + AGE + HIQUL22D,
  data = lfs
)

lmtest::bptest(model)
```

原假设通常为同方差；拒绝原假设说明存在异方差的统计证据。

### 6. 残差正态性检查

```r
plot(model, which = 2)
```

`which = 2` 为 Normal Q-Q 图。

### 7. 对数工资变换

```r
lfs <- lfs %>%
  mutate(log_wage = log(HOURPAY))
```

注意工资需大于零。对数变换不是万能修复，仍应重新绘图并进行诊断。

**作业对应：** Model Specification Tests 与 Regression Assumptions Discussion。

## 十一、Lecture 10：Refining the Linear Regression Model

### 1. 本讲目标

进一步识别多重共线性、内生性风险和变量编码问题，并使用稳健标准误提高统计推断的可靠性。

### 2. VIF 检查

```r
model <- lm(
  log(HOURPAY) ~ SEX + AGE + HIQUL22D +
    FLEX22W6 + FTPT + EMPLEN +
    JOBTYP + MPNR02 + MARSTA +
    INDE07M + NSECMJ20 + GOR9D,
  data = lfs
)

car::vif(model)
```

多重共线性可能造成系数估计不稳定、标准误增大。对于有多水平分类变量的结果，解释 VIF 时需注意广义 VIF 的输出形式。

### 3. 内生性与双向关系

课程讨论外生性假设，以及例如工龄与工资可能互相影响的问题。结合理论重新思考模型，必要时调整变量集合，而不能认为一个简单诊断函数就可以解决内生性。

### 4. 合并分类变量

```r
lfs <- lfs %>%
  mutate(
    new_MARSTA = case_when(
      MARSTA == "Married, living with spouse" ~ "Married",
      MARSTA == "Divorced" ~ "Divorced",
      TRUE ~ "Other"
    ) %>%
      factor() %>%
      relevel(ref = "Other")
  )
```

### 5. 更改参考类别

```r
lfs <- lfs %>%
  mutate(
    INDE07M = relevel(
      INDE07M,
      ref = "Public admin, education and health"
    )
  )
```

### 6. 稳健标准误

```r
lmtest::coeftest(
  model,
  vcov = sandwich::vcovHC(model)
)
```

异方差稳健标准误主要修正标准误和对应的推断，并不能消除遗漏变量偏误或错误函数形式。

**作业对应：** 模型优化、变量设计依据、诊断后的结果修正、推断稳健性。

## 十二、Lecture 11：Building a Robust Regression Model

### 1. 本讲目标

解决或讨论误差项非独立的问题，使用聚类稳健标准误，总结如何构建有理论依据且稳健的最终线性回归模型。

### 2. 家庭内部相关性

Labour Force Survey 中，同一家庭的多名受访者可能共享影响工资的未观测因素，因此不应总是假定家庭内观测完全独立。

### 3. 聚类稳健标准误

```r
lfs %>%
  mutate(log_wage = log(HOURPAY)) %>%
  miceadds::lm.cluster(
    data = .,
    log_wage ~ SEX + AGE + HIQUL22D +
      FTPT + JOBTYP + MPNR02 +
      new_MARSTA + INDE07M +
      NSECMJ20 + GOR9D,
    cluster = "HSERIALP"
  ) %>%
  summary()
```

这里 `HSERIALP` 是课堂案例中使用的家庭聚类识别字段。若复现此代码，需要确保数据清洗时保留了它。

### 4. 两类建模策略

- **General-to-specific**：从较完整的模型出发，诊断并有依据地精简。
- **Specific-to-general**：从简单模型开始，逐步加入理论相关变量。

两种方式都可以，重点在于每一步的依据与结果解读。

### 5. 最终模型与研究局限

报告最终模型的核心系数、方向、大小、统计不确定性及实际含义，并讨论模型假设的满足程度和仍未解决的限制。

### 6. Beyond OLS：非常重要的课程界限

本讲末尾介绍了其他回归方法，包括用于计数、二元或多类别结果的模型，以及面板、时间序列和空间计量等方法。但课件明确表示：

> 不要求在本次作业中使用这些方法；不会因为使用它们而额外加分，也不希望它们出现在本次作业中。

因此，**不能因个人对高级算法或神经网络感兴趣，就把它们直接作为 URBAN5127 正式作业的主体。** 如需拓展，应先征询老师意见，或在课程作业之外另做独立研究。

**作业对应：** Final Regression Model、Robustness Discussion、Limitations、Critical Interpretation。

## 十四、Formative 与 Summative 两个阶段如何准备

### Formative Research Proposal（1,000 词）

按照此前上传的 `URBAN5127_-_Formative_1_-_Draft_Research_Proposal_-_Analysing_Quantitative_Data.html`：

- 提出研究问题、背景、理论依据和相关文献；
- 介绍选用的数据集、因变量、自变量，突出一个重点自变量；
- 提供因变量的描述性统计；
- 绘制因变量分布图；
- 绘制因变量与重点自变量之间的关系图；
- 每个统计输出与图表都要有文字解释；
- 给出简短反思。

草稿清单并未要求完成最终回归模型。

### Summative Research Paper（最多 4,000 词）

应在以上基础上开展递进式回归分析及模型诊断，并完成研究讨论和反思声明。使用 RStudio 及 R Markdown 或 Quarto 提交可复现的源文件和成功生成的论文文件。

**高优先级操作：**

1. `read_tsv()` / `select()` / `filter()` / `mutate()`：建立可解释的分析样本。
2. `summarise()` / `group_by()` / `quantile()`：完成描述性分析。
3. `ggplot2`：绘制合理的单变量和双变量图。
4. `lm()` / `summary()`：递进式建立简单与多元回归。
5. `plot()` / `resettest()` / `bptest()` / `vif()`：诊断模型。
6. `coeftest()` / `vcovHC()` / `lm.cluster()`：视具体数据结构采用稳健推断。
7. 将统计结果与社会科学问题连接起来，批判性解释而非机械粘贴输出。

## 十五、对选题和机器学习扩展的启示

结合全部课程内容，可以将学习目标概括为：

**研究问题 → 数据准备 → 描述性统计 → 可视化 → 假设检验 → 多元 OLS → 模型诊断 → 模型修正 → 批判性解释。**

课程并未将 Random Forest、XGBoost、LSTM、Transformer、MLP 神经网络等列为实际教学内容。对最终作业而言，更重要的是：

- 研究问题明确、数据与理论匹配；
- 使用合规的横截面数据，因变量适合线性回归；
- 完整说明变量处理及样本筛选；
- OLS 模型逻辑清楚，能够正确解释系数；
- 认真检查并讨论回归模型的假设；
- 清晰地回答研究问题并反思局限。

即便选择规模很大的城市交通、城市能源、住房或其他城市社会经济数据，也不代表必须引入深度学习。规模越大，越要注意数据是否真正代表独立的横截面观测以及变量的有效性。
