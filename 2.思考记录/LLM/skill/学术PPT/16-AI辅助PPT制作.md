## Gamma

### 核心功能
- **一键生成**：输入主题，自动生成完整幻灯片
- **智能设计**：自动配色、排版、配图
- **多种导出**：在线分享、PDF、PPTX
- **实时协作**：多人同时编辑

### 使用流程
```
1. 输入主题或粘贴文本
2. 选择风格和页数
3. AI生成初稿
4. 人工精修内容
5. 导出或分享
```

### 优缺点
```
优点:
├── 生成速度快 (30秒)
├── 设计质量高
├── 操作简单
└── 支持中文

缺点:
├── 内容深度有限
├── 定制化受限
├── 学术规范需人工调整
└── 高级功能付费
```

### 学术场景优化
```
1. 先用Gamma生成框架
2. 替换AI生成的泛泛内容为专业内容
3. 调整配色为学术风格
4. 添加专业图表替换通用图片
5. 检查学术用语规范
```

## AI图像生成

### Midjourney
```
提示词模板：
"academic presentation slide background, 
minimalist design, blue and white color scheme,
[具体主题], clean, professional, 16:9 aspect ratio"

示例：
"academic presentation slide background,
neural network visualization, blue nodes and connections,
minimalist, clean white background, professional"
```

### DALL-E / Stable Diffusion
```python
# 使用API批量生成配图
import openai

def generate_slide_image(prompt, style="academic"):
    """生成幻灯片配图"""
    full_prompt = f"{prompt}, {style} style, minimalist, clean background, professional"
    
    response = openai.Image.create(
        prompt=full_prompt,
        n=1,
        size="1792x1024"  # 16:9
    )
    
    return response.data[0].url
```

### 图片使用建议
```
适合AI生成的图片:
├── 概念性插图
├── 背景装饰
├── 抽象图形
└── 场景示意图

不适合AI生成的图片:
├── 数据图表 (用matplotlib)
├── 流程图 (用draw.io)
├── 截图 (用真实截图)
└── 照片 (用真实照片或学术图库)
```

## 工作流建议

### 快速出稿流程（1小时）
```
1. [5分钟] 用Gamma生成初稿
2. [10分钟] 审阅并标记需修改的地方
3. [20分钟] 用Claude生成专业内容
4. [15分钟] 替换内容、调整布局
5. [10分钟] 添加图表、检查细节
```

### 精细制作流程（半天）
```
1. [30分钟] 用ChatGPT/Claude生成大纲
2. [1小时] 用Beamer/Typst编写内容
3. [1小时] 用matplotlib生成图表
4. [30分钟] 用draw.io绘制流程图
5. [30分钟] 整体排版和动画
6. [30分钟] 演讲备注和排练
```

### AI辅助检查清单
```
内容检查:
□ 标题是否准确反映内容
□ 每页是否只有一个核心观点
□ 逻辑是否连贯
□ 术语是否一致

设计检查:
□ 字体是否统一
□ 配色是否一致
□ 图表是否清晰
□ 留白是否充足

技术检查:
□ 公式是否正确
□ 引用是否完整
□ 动画是否流畅
□ 导出是否正常
```

## 常见问题

### AI生成内容的局限
```
问题:
├── 内容泛泛，缺乏深度
├── 可能存在事实错误
├── 学术规范不符合
├── 数据可能编造
└── 缺少领域专业知识

解决方案:
├── 人工审核所有内容
├── 核对关键数据和引用
├── 补充专业细节
├── 使用真实数据替换
└── 请同行审阅
```

### 学术诚信
```
使用AI的原则:
├── AI作为辅助工具，非替代
├── 所有内容需人工审核
├── 关键数据必须真实
├── 引用必须准确
├── 适当声明AI辅助
└── 遵守会议/期刊政策
```
