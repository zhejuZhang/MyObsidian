## GitHub核心技能

### 仓库管理
```bash
# 创建仓库
gh repo create my-research --public --description "Research project"

# 克隆仓库
git clone https://github.com/username/my-research.git

# Fork并同步
gh repo fork upstream/repo
git remote add upstream https://github.com/upstream/repo.git
git fetch upstream
git merge upstream/main
```

### Issue管理
```bash
# 创建Issue
gh issue create --title "Bug: 数据加载失败" --body "详细描述..."

# 列出Issues
gh issue list --label "bug"

# 关联提交
git commit -m "fix: 修复数据加载问题

Closes #42"
```

### Pull Request流程
```bash
# 创建分支
git checkout -b feature/new-analysis

# 提交更改
git add .
git commit -m "feat: 添加新的分析方法"

# 推送并创建PR
git push origin feature/new-analysis
gh pr create --title "新增分析方法" --body "描述变更内容"

# 代码审查
gh pr review 123 --approve --body "LGTM!"
```

### GitHub Actions
```yaml
# .github/workflows/test.yml
name: Python Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: [3.9, 3.10, 3.11]
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: ${{ matrix.python-version }}
    
    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install pytest
    
    - name: Run tests
      run: pytest tests/
```

### GitHub Projects看板
```
列设置:
├── 📥 Inbox (新任务)
├── 📋 To Do (待办)
├── 🔄 In Progress (进行中)
├── 👀 In Review (审查中)
└── ✅ Done (完成)

自动化规则:
- 新Issue自动添加到Inbox
- PR关联Issue自动移动到In Review
- PR合并自动移动到Done
```

## 学术协作

### 研究组协作规范
```markdown
## 代码规范
1. 使用Git进行版本控制
2. 每个功能一个分支
3. 提交前必须通过测试
4. PR必须至少一人审查

## 文档规范
1. README必须包含：项目描述、安装步骤、使用方法
2. 复杂函数必须有docstring
3. 变更必须记录CHANGELOG

## 数据规范
1. 原始数据只读不改
2. 处理后数据保存在新目录
3. 大文件使用Git LFS
4. 敏感数据不上传
```

## 学术影响力管理

### ORCID
```
注册ORCID:
1. 访问 orcid.org
2. 注册账号
3. 关联论文、基金、机构
4. 在投稿时使用ORCID

好处:
├── 唯一标识符
├── 自动更新发表记录
├── 跨平台关联
└── 学术履历管理
```

### Google Scholar Profile
```
设置步骤:
1. 访问 scholar.google.com
2. 点击"我的引用"
3. 创建个人资料
4. 添加论文
5. 设置引用提醒

优化:
├── 确认所有论文已添加
├── 合并重复条目
├── 设置引用通知
└── 定期更新
```

### 海报设计
```
尺寸: 通常 A0 (841×1189mm) 或 36×48 inches

结构:
├── 标题和作者
├── 摘要
├── 背景/引言
├── 方法
├── 结果 (图表)
├── 结论
├── 参考文献
└── 联系方式

设计原则:
├── 字体大小: 标题>72pt, 正文>24pt
├── 高对比度配色
├── 图表为主，文字为辅
├── 留白充足
└── 从左到右、从上到下阅读流
```

### 口头报告
```
结构 (15分钟报告):
├── 背景介绍 (2分钟)
├── 研究问题 (1分钟)
├── 方法 (3分钟)
├── 结果 (5分钟)
├── 讨论 (2分钟)
└── 总结和Q&A (2分钟)

技巧:
├── 每页幻灯片一个要点
├── 使用图表而非文字
├── 练习计时
├── 准备常见问题答案
└── 保持眼神交流
```
