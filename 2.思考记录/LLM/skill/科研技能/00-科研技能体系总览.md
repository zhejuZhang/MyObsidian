# 科研技能体系总览

## 体系架构

```
科研技能体系
├── 文献检索与管理 [[01-文献检索与管理]]
│   ├── 检索工具 (Semantic Scholar, Connected Papers, Elicit)
│   ├── 文献管理 (Zotero, Mendeley, EndNote)
│   └── AI辅助阅读 (SciSpace, ChatPDF, NotebookLM)
├── 数据分析与可视化 [[02-数据分析与可视化]]
│   ├── 统计分析 (R, SPSS, Stata)
│   ├── 编程分析 (Python/Pandas, Julia)
│   └── 可视化 (Matplotlib, Plotly, Tableau)
├── 学术写作与出版 [[03-学术写作与出版]]
│   ├── 写作工具 (LaTeX, Overleaf, Typst)
│   ├── AI写作辅助 (Grammarly, Writefull, Consensus)
│   └── 投稿与同行评审
├── 实验设计与方法论 [[04-实验设计与方法论]]
│   ├── 实验设计框架
│   ├── 数据采集工具
│   └── 可复现性实践
├── 机器学习与深度学习 [[05-机器学习与深度学习]]
│   ├── 框架 (PyTorch, TensorFlow, JAX)
│   ├── 训练平台 (Colab, Kaggle, HuggingFace)
│   └── MLOps (Weights & Biases, MLflow)
├── 科研工作流自动化 [[06-科研工作流自动化]]
│   ├── 笔记与知识管理 (Obsidian, Notion, Logseq)
│   ├── 自动化脚本 (n8n, Make, Zapier)
│   └── AI Agent工作流
├── 协作与项目管理 [[07-协作与项目管理]]
│   ├── 代码协作 (GitHub, GitLab)
│   ├── 项目管理 (Trello, Linear, Notion)
│   └── 学术社交 (ResearchGate, ORCID)
└── 版本控制与代码管理 [[08-版本控制与代码管理]]
    ├── Git核心技能
    ├── 代码质量工具
    └── 容器化与环境管理
```

## 技能优先级矩阵

| 技能领域  | 入门必备                    | 进阶推荐                                | 专业深耕                         |
| ----- | ----------------------- | ----------------------------------- | ---------------------------- |
| 文献管理  | Zotero + Google Scholar | Semantic Scholar + Connected Papers | Elicit + Systematic Review工具 |
| 数据分析  | Python + Pandas         | R + 统计检验                            | 贝叶斯方法 + 因果推断                 |
| 学术写作  | LaTeX/Overleaf          | Grammarly + Writefull               | AI辅助综述写作                     |
| 实验设计  | 基础统计学                   | 功效分析 + 预注册                          | 自适应实验设计                      |
| ML/DL | Scikit-learn基础          | PyTorch + HuggingFace               | 分布式训练 + MLOps                |
| 工作流   | 文件夹+笔记                  | Obsidian+Zotero联动                   | 全链路自动化                       |
| 版本控制  | Git基本操作                 | GitHub协作流程                          | CI/CD + 容器化                  |
