## Semantic Scholar

### 核心优势
- **语义搜索**：理解论文含义而非仅关键词匹配
- **影响力指标**：Citation Velocity, Influential Citation
- **TLDR**：AI自动生成一句话摘要
- **Research Feeds**：个性化推荐

### 使用技巧
```
搜索语法:
- 精确匹配: "deep learning"
- 作者搜索: author:"Yann LeCun"
- 年份过滤: year:2023-2025
- 领域过滤: venue:NeurIPS
```

### API使用
```python
# Semantic Scholar API
import requests

def search_papers(query, limit=10):
    url = "https://api.semanticscholar.org/graph/v1/paper/search"
    params = {
        "query": query,
        "limit": limit,
        "fields": "title,authors,year,citationCount,tldr"
    }
    response = requests.get(url, params=params)
    return response.json()
```

## Connected Papers

### 核心功能
- **图谱可视化**：展示论文间的引用关系网络
- **相似度计算**：基于共同引用的相似性
- **Prior Works**：该领域的重要前置工作
- **Derivative Works**：基于该论文的后续研究

### 使用场景
1. **领域调研**：快速了解一个领域的核心论文
2. **文献发现**：找到遗漏的重要文献
3. **脉络梳理**：理解研究发展脉络

## AI辅助文献阅读

### Elicit
- **自动综述**：输入研究问题，自动整理相关论文
- **数据提取**：自动提取方法、结果、样本量等
- **局限性分析**：识别研究的局限和gap

### Consensus
- **证据综合**：基于多篇论文给出共识结论
- **证据强度**：标注结论的证据支持程度
- **适用场景**：快速了解某结论的证据基础

### SciSpace (原Typeset)
- **论文对话**：对论文内容提问
- **公式解释**：解释论文中的数学公式
- **表格解析**：解析论文中的数据表格

### ChatPDF / NotebookLM
- **PDF问答**：上传PDF进行对话式阅读
- **批量处理**：同时处理多篇论文
- **知识整合**：跨论文信息整合

## 系统综述流程

```
1. 定义研究问题 (PICO框架)
   ├── Population: 研究对象
   ├── Intervention: 干预措施
   ├── Comparison: 对照
   └── Outcome: 结果指标

2. 检索策略
   ├── 数据库选择 (至少3个)
   ├── 检索词构建
   └── 检索式验证

3. 筛选流程
   ├── 初筛 (标题+摘要)
   ├── 全文筛选
   └── PRISMA流程图

4. 数据提取
   ├── 标准化表格
   ├── 双人独立提取
   └── 质量评估

5. 数据综合
   ├── 定性综合
   ├── 定量Meta分析
   └── 敏感性分析
```
