## LaTeX写作

### 基础模板
```latex
\documentclass[12pt,a4paper]{article}
\usepackage[utf8]{inputenc}
\usepackage{amsmath,amssymb}
\usepackage{graphicx}
\usepackage{natbib}
\usepackage{hyperref}
\usepackage[margin=1in]{geometry}

\title{论文标题}
\author{作者姓名\\ \small{机构名称}}
\date{\today}

\begin{document}
\maketitle

\begin{abstract}
摘要内容...
\end{abstract}

\section{引言}
正文内容...

\bibliographystyle{apalike}
\bibliography{references}
\end{document}
```

### 常用包速查
| 包 | 功能 |
|---|------|
| `amsmath` | 数学公式 |
| `graphicx` | 图片插入 |
| `natbib` | 引用管理 |
| `booktabs` | 专业表格 |
| `algorithm2e` | 算法伪代码 |
| `listings` | 代码高亮 |
| `siunitx` | 单位格式化 |
| `tikz` | 绘图 |

### 表格技巧
```latex
% 专业三线表
\begin{table}[htbp]
\centering
\caption{实验结果对比}
\begin{tabular}{lccc}
\toprule
方法 & 准确率 & 精确率 & 召回率 \\
\midrule
方法A & 0.85 & 0.82 & 0.88 \\
方法B & 0.91 & 0.89 & 0.93 \\
\bottomrule
\end{tabular}
\label{tab:results}
\end{table}
```

### 图片插入
```latex
\begin{figure}[htbp]
\centering
\includegraphics[width=0.8\textwidth]{figure.pdf}
\caption{实验结果可视化。图中展示了...}
\label{fig:results}
\end{figure}
```

## 论文结构模板

### IMRaD结构
```
1. Introduction (引言)
   ├── 研究背景
   ├── 文献综述
   ├── 研究空白
   └── 研究目的/问题

2. Methods (方法)
   ├── 研究设计
   ├── 数据收集
   ├── 分析方法
   └── 伦理声明

3. Results (结果)
   ├── 描述性统计
   ├── 主要发现
   └── 图表展示

4. Discussion (讨论)
   ├── 结果解释
   ├── 与已有研究对比
   ├── 局限性
   └── 未来方向

5. Conclusion (结论)
   └── 核心发现总结
```

### 写作顺序建议
```
1. Methods (最熟悉，先写)
2. Results (数据说话)
3. Introduction (基于文献)
4. Discussion (最难，最后)
5. Abstract (全文浓缩)
```

## 学术写作常见问题

### 避免的表达
| 避免 | 替换为 |
|------|--------|
| "It is well known that..." | 直接引用文献 |
| "Obviously..." | 删除或提供证据 |
| "Very significant" | "significant (p < 0.01)" |
| "Proves that" | "Suggests/indicates that" |
| "Unique" | "Novel" 或 "Distinctive" |

### 学术英语技巧
```
1. 使用主动语态 (We conducted... 而非 It was conducted...)
2. 避免缩写首次出现时未展开
3. 数字：1-9拼写，10以上用数字
4. 单位：SI单位制
5. 时态：方法用过去时，普遍事实用现在时
```
