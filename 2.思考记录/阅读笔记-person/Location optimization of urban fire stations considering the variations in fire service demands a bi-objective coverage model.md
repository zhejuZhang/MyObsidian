## 论文整理：Location optimization of urban fire stations considering the variations in fire service demands: a bi_objective coverage model

### 一、解决什么问题

1. **传统覆盖模型的局限性**：传统覆盖模型将需求区域的服务等级简单划分为"覆盖"或"未覆盖"两种状态，忽略了覆盖半径内不同需求区域的服务满意度差异

2. **单目标规划的不足**：传统覆盖模型属于单目标规划问题，仅关注问题的某一方面，无法直接应用于具有复杂目标的城市消防站选址问题

3. **未考虑火灾风险差异**：现有研究往往忽略了将火灾风险变化和需求满足程度整合到优化过程中，不同功能区（工业区、商业区、住宅区、医院、学校）有不同的消防保护需求

4. **资源配置不合理**：传统方法定义责任区时未充分考虑区域间火灾风险差异，导致责任区过大、消防资源配置效率低下

---

### 二、解决问题思路

1. **基于火灾风险等级分析需求差异**：根据各区域的火灾风险等级（高、中、低），确定不同的期望覆盖半径（高风险1.5km、中风险2km、低风险2.5km）

2. **构建消防服务满意度函数**：借鉴渐进覆盖方法，建立分段函数fij(dij)描述不同需求区域对消防救援服务的满意度

3. **建立双目标覆盖(BOC)模型**：
   - 目标1：最小化消防站数量（集合覆盖模型改进）
   - 目标2：最大化需求区域的总消防救援满意度（最大覆盖模型改进）

4. **采用ε-约束方法求解**：将双目标模型转化为单目标模型，通过改变消防站数量p获得Pareto最优前沿

5. **实证验证**：以郑州市中心城区为案例，与传统双目标空间优化(BSO)模型进行对比分析

### 四、结论

1. **BOC模型优于BSO模型**：
   - 有效服务率（服务满意度>1的需求区域比例）显著更高
   - 多重覆盖率（可被多个消防站覆盖的需求区域比例）显著更高

2. **资源配置更均衡**：
   - BSO模型导致消防站过度集中在中心区域，造成资源浪费
   - BOC模型实现了中心区域与周边区域消防资源的均衡分配

3. **满意度分布更合理**：
   - BOC模型结果中需求区域的服务满意度分布更集中，离群值更少
   - 当消防站数量较多时（p=70,75），BOC模型的中位服务满意度明显高于BSO模型

4. **政策建议**：
   - 应在确保高风险区域充足消防资源的同时，兼顾中心与周边区域的公平分配
   - 扩大服务不足的周边区域覆盖范围

## 四、双目标覆盖模型（Proposed BOC Model，第6-9页）

这是论文的**核心方法论部分**，包含三个子节。

### 4.1 模型构建（Model Formulation，§3.1）

#### 核心思想

本研究**用居民对响应时间的期望来衡量消防救援满意度**，而非简单地判断住宅区是否被消防站覆盖。核心假设是：

- 不同位置的家庭对火灾风险的感知不同
- 大型商业市场附近或人口密集城区的家庭**需要更快的响应时间**
- 同样的规则适用于划分城市的网格单元

#### 服务满意度函数 fij(dij)

受**渐进覆盖方法**（Karasakal and Karasakal 2004）启发，建立了**分段函数**：

$$f_{ij}(d_{ij}) = \begin{cases} 1 & d_{ij} \leq R_{ik} \\ \frac{1}{1+\exp\left(5\frac{d_{ij}-\frac{R_{ik}+D}{2}}{R_{ik}}\right)} & R_{ik} < d_{ij} \leq D \\ 0 & d_{ij} > D \end{cases}$$

**三种情景详解**（见论文 Figure 1）：

| 需求区域 | 距离条件 | 满意度 | 含义 |
|----------|----------|--------|------|
| I₁ | 在期望覆盖半径 R 内 | **1** | 已获得满意的消防服务 |
| I₃ | 在 R 和 D 之间 | **0~1**（Sigmoid递减） | 满意度随距离增加而降低 |
| I₂ | 超过最大覆盖半径 D | **0** | 无法获得消防服务 |

**关键参数说明**：
- **Rᵢₖ**：需求区域 i 在火灾风险等级 k 下的**期望覆盖半径**
- **D**：消防站的**最大覆盖半径**（统一设定）
- **Sigmoid 函数**：描述中间过渡区间的满意度递减

论文特别说明：虽然分段函数在边界处（dij=Rik 和 dij=D）存在数学不连续性，但这种设计**反映了实际消防响应要求中的突变**，如果用连续函数平滑化则会模糊需求区域之间的关键区别，可能损害模型的实际决策效用。

#### 模型参数定义

| 参数 | 含义 |
|------|------|
| i, j | 需求区域和潜在消防站位置的索引 |
| I, J | 需求区域和潜在消防站位置的集合 |
| k | 需求区域 i 的火灾风险等级（高、中、低） |
| dij | 需求区域 i 到消防站 j 的距离 |
| D | 消防站最大覆盖半径 |
| N | 在期望覆盖半径内可为需求区域提供服务的消防站最大数量 |
| Rᵢₖ | 火灾风险等级 k 下需求区域 i 的期望覆盖半径 |
| fij(dij) | 需求区域 i 对消防站 j 的满意度 |

**决策变量**：
- yij = 1（需求区域 i 由站点 j 服务），0（否则）
- xj = 1（在位置 j 设立消防站），0（否则）

#### BOC 模型数学表达

**目标函数**：

- **目标(1)**：Number = Min Σⱼ xⱼ → 尽可能少的消防站覆盖所有需求区域
- **目标(2)**：Satisfaction = Max Σᵢ Σⱼ fij(dij)·yij → 最大化所有需求区域的总消防救援满意度

**约束条件**：

| 约束 | 含义 |
|------|------|
| (3) Σⱼ yij ≤ N, ∀i∈I | 每个需求区域在其期望覆盖半径内**最多接收 N 个消防站的服务**，防止新消防站过度集中 |
| (4) Σⱼ yij ≥ 1, ∀i∈I | 每个需求区域**至少被一个消防站覆盖**（在最大覆盖半径内） |
| (5) xⱼ ≥ yij | 站点 j 只有在设立了消防站时才能服务需求区域 i |
| (6) xⱼ ∈ {0,1} | 消防站存在与否的二元决策变量 |
| (7) yij ∈ {0,1} | 服务关系的二元决策变量 |

### 4.2 对比模型——BSO 模型（Comparison Scenarios，§3.2）

为了验证 BOC 模型的优越性，论文构建了 **BSO 模型**（整合覆盖和中值目标）作为对比基准：

**BSO 模型目标函数**：
- **目标(8)**：Number = Min Σⱼ xⱼ → 与 BOC 相同
- **目标(9)**：Travel = Min Σᵢ Σⱼ Lᵢ·dij·yij → **最小化所有需求区域到对应消防站的总加权距离**

其中 Lᵢ 代表需求区域 i 的火灾风险等级（作为权重）。

**关键区别**：BSO 的目标(9)通过最小化加权距离来确保消防站尽可能布局在高风险区域附近，而 BOC 的目标(2)通过最大化满意度来实现类似目标，但考虑了不同风险等级的**差异化覆盖半径**。

---

### 4.3 求解方法（Solution Approach，§3.3）

#### ε-约束方法

由于目标(1)要求消防站数量为整数，论文采用 **ε-约束方法** 求解双目标模型：

**步骤详解**：

| 步骤 | 操作 | 工具 |
|------|------|------|
| **步骤1** | 忽略目标(2)，仅保留目标(1)求解集合覆盖模型，计算覆盖所有需求区域所需的**最少消防站数 pmin** | GAMS + CPLEX |
| **步骤2** | 忽略目标(1)，仅保留目标(2)，最大消防站数 pmax = |J|（候选位置总数） | — |
| **步骤3** | 逐步增加 p 值（从 pmin 到 |J|），每次解目标(2)的单目标优化模型，获得 **Pareto 最优解集** | GAMS + CPLEX |

**计算环境**：
- 处理器：Intel Core i7-8565U（1.8 GHz）
- 内存：16 GB DDR4 RAM
- 存储：512 GB SSD
- 操作系统：Windows 10 Pro（64位）
- 软件：GAMS 24.8.2 + CPLEX 求解器

#### 火灾风险评估方法

与传统依赖历史灾害记录、人口密度、建筑密度等数据的风险评估不同，本文采用 **POI（兴趣点）数据** 构建风险评估体系，具有更强的**时效性**。

**数据来源**：2023年6月从**高德地图**爬取的郑州市主城区共 **185,700** 个 POI 数据点。

#### POI 分类为五大火灾风险因素

| 风险因素 | 包含的 POI 类型 |
|----------|-----------------|
| **易燃易爆** | 加气站、加油站、化工厂、工业园区等 |
| **脆弱群体** | 学校（幼儿园、小学、中学）、医院、婴幼儿看护机构等 |
| **人群密集** | 商业场所（商场、商业街、娱乐场所）、交通枢纽（机场、火车站、地铁/公交站）、政府机关等 |
| **重点保护** | 政府机关、外交机构、公安检察司法机构、科研机构、档案馆、图书馆、博物馆、历史遗迹、金融保险机构等 |
| **一般防火** | 住宅区、办公楼、公司、各类餐厅、公共设施、酒店、便利店、体育休闲场所、公园广场等 |

#### 风险评估流程

```
POI数据 → 分类为5大火灾风险因素
    → 核密度分析（ArcGIS可视化各因素空间分布）
        → SAVEE模型标准化各因素
            → 叠加分析 → 综合火灾风险分布图
```

#### 参数设定

根据《郑州市城市消防专项规划（2016-2030）》设定：

| 参数 | 设定值 | 含义 |
|------|--------|------|
| **Rᵢ₃**（高风险） | **1.5 km** | 期望覆盖半径最短（要求最高） |
| **Rᵢ₂**（中风险） | **2 km** | 期望覆盖半径中等 |
| **Rᵢ₁**（低风险） | **2.5 km** | 期望覆盖半径最长 |
| **D** | **3 km** | 最大覆盖半径（统一） |
| **N** | **2** | 在期望覆盖半径内每个需求区域最多接收2个消防站的服务 |

**直线距离替代说明**：先前研究表明直线距离可以较好地替代道路网络救援时间（Yao, Zhang, and Murray 2019）。

#### 火灾风险空间分布结果

- **中心区域**（郑州火车站附近）：火灾风险**最高**
- **西北、东北和西南角**（惠济区、金水区大部分区域）：火灾风险**相对较低**
- **总体特征**：火灾风险值从中心向外围递减，中心与外围区域之间存在**显著差异**

### 5.2 结果（Results，§4.2）

#### 下界计算

使用集合覆盖模型计算得到 **pmin = 50**，即在最大覆盖半径（3 km）内**至少需要 50 个消防站**才能实现研究区域的完全覆盖。

#### Pareto 最优前沿

通过逐步增加 p 值获得两个双目标模型的 Pareto 最优解：

| 模型 | 观察趋势 |
|------|----------|
| **BSO** | 加权距离总和（目标9）随 p 增加而**递减** |
| **BOC** | 总救援满意度（目标2）随 p 增加而**递增** |

#### 空间布局对比（p=65, 70, 75）

论文选取 p=65、70、75 三组解进行详细对比（见 Figure 6）：

| 模型 | 空间分布特征 |
|------|-------------|
| **BSO** | 消防站**过度集中在中心区域**，导致中心区消防资源过剩、外围区资源不足 |
| **BOC** | 消防站**空间分布更均衡**，既确保高风险区域充足供应，又兼顾中心与外围的公平分配 |

**原因分析**：BSO 模型的目标(9)（最小化加权距离总和）导致优化结果将资源过度分配给高风险区域（位于中心），造成中心与外围的资源分配不均。

#### 指标对比

**① 有效服务率（Effective Service Rate）**

定义：消防救援服务满意度 > 1 的需求区域比例。

| 特征 | 说明 |
|------|------|
| **BOC > BSO** | BOC 模型的有效服务率**显著高于** BSO 模型 |
| **边际递减** | 两个模型的有效服务率都随消防站数量增加而趋于稳定 |
| **具体数据** | p 从50增至55时，BOC 增长12.18%，BSO 增长10.81%；p 从70增至75时，BOC 增长8.06%，BSO 仅增长3.24% |

**② 多重覆盖率（Multiple Coverage Rate）**

定义：可被多个消防站覆盖的需求区域比例。

- BOC 模型的多重覆盖率**也显著高于** BSO 模型
- 两个模型的多重覆盖率均随消防站数量增加而递增并趋于稳定

#### 满意度分布对比（Boxplot，Figure 8）

| 对比维度 | BOC vs BSO |
|----------|------------|
| **分布集中度** | BOC 的满意度分布**更集中**，BSO 存在更多**离群值** |
| **资源均衡性** | BOC 避免了"某些区域资源过剩、其他区域严重短缺"的情况 |
| **中位满意度** | p=60,65 时两模型接近；p=70,75 时 BOC **明显高于** BSO |

#### 服务距离对比（Boxplot，Figure 9）

| 对比维度 | BOC vs BSO |
|----------|------------|
| **p=60, 65** | BOC 的中位服务距离**略高于** BSO |
| **p=70, 75** | BOC 的中位服务距离**接近** BSO 的水平 |

**解读**：当消防站数量较少时，BOC 模型可能牺牲部分距离优化来实现更均衡的覆盖；但当消防站数量增加后，两者的服务距离趋于一致，同时 BOC 在满意度方面仍保持优势。

## 六、讨论与结论（Discussion and Conclusions，第16-17页）

### 6.1 研究总结

论文重申了传统覆盖模型的三个核心缺陷：
1. 单目标规划，仅关注某一方面
2. 固定覆盖半径，仅有覆盖/未覆盖二元状态
3. 忽略覆盖半径内的服务满意度差异

本文通过构建 BOC 模型，成功解决了上述问题，并在郑州案例中验证了模型的有效性。

### 6.2 分段函数的讨论

论文对分段函数 fij(dij) 的不连续性进行了专门讨论：

| 观点 | 内容 |
|------|------|
| **设计合理性** | 不连续性反映了实际消防响应要求中的**突变**，与实际政策（期望覆盖半径、最大覆盖半径）一致 |
| **实用价值** | 这些阈值允许对高风险需求区域进行**明确的优先级排序** |
| **潜在问题** | 可能给某些计算方法或分析带来困难 |
| **未来方向** | 可探索结合分段函数的**操作可解释性**与连续模型的**分析灵活性**的混合方法 |

### 6.3 实际应用价值

- 为城市管理和应急决策提供**结构化框架**
- 帮助制定更**科学化**的消防设施分布政策
- 确保资源配置与**风险等级需求相匹配**
- 为决策者提供**循证建议**

### 6.4 模型局限性

| 局限 | 具体描述 |
|------|----------|
| **静态假设** | 模型假设需求区域静态，未纳入实时土地利用特征 |
| **动态因素缺失** | 未考虑道路拥堵、季节性天气变化等影响响应时间的动态条件 |
| **现有设施忽略** | 新增消防站选址未考虑现有消防站的分布情况 |

### 6.5 未来研究方向

1. 模型纳入**实时土地利用特征**
2. 考虑**道路拥堵、季节性天气**等动态因素
3. 整合**现有消防站分布**信息
4. 增强模型对不同城市或情境的**适用性和响应性**
