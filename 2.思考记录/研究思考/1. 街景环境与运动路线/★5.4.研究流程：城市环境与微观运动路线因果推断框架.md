## 阶段一：多源空间数据采集

### 1.1 微观运动轨迹数据

| 数据源 | 内容 | 获取方式 |
|--------|------|----------|
| 共享单车GPS | 骑行轨迹坐标序列 | 平台API/开放数据申请 |
| Strava Metro | 步行/跑步/骑行聚合轨迹 | Strava Metro数据合作 |
| 移动终端信令 | 人群移动OD数据 | 运营商脱敏数据接口 |

**数据要求**：
- 时间粒度：秒级采样频率（≥1Hz）
- 空间精度：原始GPS定位误差需记录（用于后续HMM概率建模）
- 属性字段：时间戳、用户ID（脱敏）、出行方式标签

### 1.2 Google街景影像（SVI）

**采集策略**：
- 沿OSM路网节点等间距采样（建议间距50-100m）
- 每个采样点获取四方向（0°/90°/180°/270°）水平视角影像
- 时间窗口：优先选择夏季晴天影像（植被完整、光照一致）

**API调用**：
```
Google Street View Static API
Endpoint: https://maps.googleapis.com/maps/api/streetview
Parameters: location, size=640x640, heading, fov=90, pitch=0
```

### 1.3 OpenStreetMap路网与POI

**数据提取工具**：OSMnx（Python）

**路网数据**：
- 节点（Nodes）：交叉口、端点坐标
- 路径（Ways）：路段几何、等级属性、限速、铺装类型
- 范围：研究区域bounding box或行政边界多边形

**POI数据类别**：
- 餐饮服务、零售商务
- 文体休闲、公园绿地
- 公交站点、地铁枢纽
- 教育医疗、公共服务

## 阶段二：特征工程与数据预处理

### 2.1 HMM快速地图匹配（FMM）

**目标**：将原始GPS坐标序列精确绑定至OSM路网有向边。

**算法步骤**：

```
Step 1: 路网预处理
  - 构建OSM路网有向图 G = (V, E)
  - 计算UBODT预计算表（上限起点-终点最短路径表）
  - 存储结构：R(n_o, n_d) = (n_o, n_d, next_n, next_e, dist)

Step 2: 候选路段搜索
  - 对每个GPS观测点 o_t，搜索半径 r 内的所有候选路段
  - 计算正交投影点 x_{t,i} 及投影距离

Step 3: 概率计算
  - 观测概率：P(o_t | r_i) = (1/√(2π)σ) × exp(-||o_t - x_{t,i}||² / 2σ²)
  - 转移概率：P(r_i→r_j) = [min(T_exp, T_act) / max(T_exp, T_act)] × exp(-λ|d_net - d_euc|)

Step 4: Viterbi解码
  - 在候选路段状态空间中，求解全局联合概率最大的隐状态序列
  - 输出：GPS点 → 路段ID的最优匹配序列

Step 5: 流量聚合
  - 按路段ID统计：步行通过频次、骑行通过频次、跑步通过频次
  - 形成路段级别人流流量向量（结果变量 Y）
```

**关键参数设置**：
- GPS误差标准差 σ：通常设为20-50m（视设备精度调整）
- 搜索半径 r：3σ = 60-150m
- UBODT阈值距离：3-5km

### 2.2 街景语义分割与环境指标提取

**模型选择**：
- DeepLabV3+（语义分割SOTA）
- SegFormer / Mask2Former（Transformer架构，精度更高）
- CLIP-based零样本分割（类别灵活扩展）

**像素级语义类别**：植被、天空、建筑外立面、道路铺装、行人、车辆、交通标志等

**核心环境指标计算**：

| 指标 | 定义 | 公式 |
|------|------|------|
| 绿视率 GVI | 植像像素占视野比例 | GVI = N_vegetation / N_total × 100% |
| 天空开阔度 SVF | 天空像素占视野比例 | SVF = N_sky / N_total × 100% |
| 建筑围合度 BVI | 建筑像素占视野比例 | BVI = N_building / N_total × 100% |
| 道路可见度 RVI | 道路铺装像素占比 | RVI = N_road / N_total × 100% |

**四方向聚合**：对每个采样点的四张影像取均值，消除朝向偏差

**路段级聚合**：将采样点指标沿路网有向边进行空间聚合（均值/中位数）

### 2.3 微气候热舒适度量化（PET）

**非线性建模要点**：
- SVF对PET存在显著正向因果效应（高温与凉爽季节均成立）
- GVI存在阈值效应：当GVI > 22.08%时，降温边际效用断崖下跌
  - 原因：极端热应力下硬化地表辐射压垮植被蒸发冷却上限
  - 原因：过高绿植密度阻碍自然通风，低空热量淤积
- 采用分段线性回归（Piecewise Linear Regression）识别断点

### 2.4 OSM路网拓扑特征

**OSMnx图构建与中心性计算**：

```python
import osmnx as ox

# 构建多重有向图
G = ox.graph_from_place("研究区域", network_type="walk")

# 计算图中心性
G = ox.add_edge_centrality(G)  # 介数中心性 Betweenness
# 接近中心性 Closeness 需手动计算
```

**宏观路网特征**：

| 特征 | 说明 | 计算方法 |
|------|------|----------|
| 介数中心性 | 路段在网络中的"桥梁"地位 | NetworkX betweenness_centrality |
| 接近中心性 | 路段到其他节点的平均可达性 | NetworkX closeness_centrality |
| 偏航率 | 网络距离 / 欧氏距离 | d_net / d_euc |
| 交叉口密度 | 单位面积内交叉口数量 | 交叉口数 / 缓冲区面积 |
| 道路坡度 | 纵向坡度（地形阻力） | DEM高程差 / 路段长度 |

**POI空间语义特征**：

| 特征 | 说明 | 计算方法 |
|------|------|----------|
| POI密度 | 各类POI在缓冲区内的数量 | 空间连接 + 分组计数 |
| 最近设施距离 | 到最近特定类别POI的网络距离 | shortest_path_length |
| 土地利用混合度 | 用地多样性（香农熵） | H = -Σ(p_i × ln(p_i)) |
| 沿街活力指数 | POI沿街道分布密度 | POI数 / 路段长度 |

### 2.5 联合观测矩阵构建

**矩阵结构**：

```
观测矩阵 X [n路段 × p变量]

│   ├── x_5: 介数中心性
│   ├── x_6: 接近中心性
```

**数据质量检查**：

## 阶段三：空间自相关消除（ESF前置处理）

### 3.1 空间权重矩阵构建

**基于路网拓扑的邻接矩阵**：

```python
# 方法一：路网连通性邻接矩阵
# 若路段 i 与路段 j 共享端点节点，则 C[i,j] = 1
C = np.zeros((n, n))
for edge_i in edges:
    for edge_j in edges:
        if share_node(edge_i, edge_j):
            C[i, j] = 1

# 方法二：距离衰减权重矩阵
# W[i,j] = exp(-d_ij / d_threshold)  若 d_ij < d_threshold
```

**标准化**：
```
W = D^{-1} × C    （行标准化）
其中 D = diag(C × 1)  为度矩阵
```

### 3.2 中心化投影与特征分解

**四步代数操作**：

```
Step 1: 输入空间权重矩阵 W [n×n]

Step 2: 构造中心化投影矩阵
        M = I - (1/n) × 11^T

Step 3: 双重中心化变换
        MWM (对称化处理)

Step 4: 特征分解
        MWM = E Λ E^T
        输出：
        - E [n×n]: 特征向量矩阵（n个正交空间模式）
        - Λ [n×n]: 特征值对角矩阵
        - 每个特征向量 E_i 对应一个独立的空间模式
        - 特征值 λ_i 与该模式的 Moran's I 正相关
```

### 3.3 空间过滤器裁剪

**筛选策略**：

```
Step 1: 计算每个特征向量的 Moran's I 值
        Moran's I(E_i) = (n / S_0) × [Σ_j w_ij × E_i × E_j / Σ_i E_i²]

Step 2: 筛选显著空间自相关的特征向量
        条件：p-value < 0.05 的 Moran's I 对应向量

Step 3: 特征选择（二选一）
        选项A: 逐步回归法（Stepwise Regression）
        选项B: Mi-Lasso（L1正则化特征选择）

Step 4: 输出空间过滤器矩阵 S_f [n×k]
        k 为筛选出的特征向量个数
```

### 3.4 空间去依赖过滤（Spatial Prewhitening）

**对原始变量执行空间漂白**：

```
对每个变量 x_j (j = 1, ..., p)：
    x_j_filtered = x_j - S_f × (S_f^T × S_f)^{-1} × S_f^T × x_j

对结果变量 y：
    y_filtered = y - S_f × (S_f^T × S_f)^{-1} × S_f^T × y
```

**效果**：
- 消除因地理邻近导致的伪高斯均值漂移
- 恢复数据的真实偏度与非高斯长尾形态
- 为后续LvLiNGAM提供更纯粹的非高斯信号

## 阶段四：因果骨架构建（GFCI算法）

### 4.1 第一阶段：FGES贪婪等价类搜索

**目标**：快速收敛无向数据骨架（Skeleton）

```
输入：ESF过滤后的变量矩阵 X_filtered [n×p]

Step 1: 初始化空图 G = (V, ∅)
        V = {x_1, x_2, ..., x_p}

Step 2: 前向加边（Forward Stepping）
        - 遍历所有未连接的节点对 (x_i, x_j)
        - 计算贝叶斯评分增益 ΔScore = Score(G ∪ (x_i→x_j)) - Score(G)
        - 选择 ΔScore 最大的边加入
        - 评分函数：BDeu分数 或 BIC分数
        - 重复直到无正增益边

Step 3: 后向删边（Backward Stepping）
        - 遍历所有已连接的边 (x_i, x_j)
        - 对每条边，搜索使 Score(G \ (x_i, x_j)) 最大的分离集 S
        - 若 Score(G \ (x_i→x_j)) > Score(G)，则删除该边
        - 重复直到无负增益边

输出：无向数据骨架（边集 E_skeleton）
```

### 4.2 第二阶段：FCI条件独立性检验与规则重构

**目标**：在骨架基础上，进行严格CI检验并识别V-结构

```
输入：骨架图 G_skeleton

Step 1: 条件独立性检验
        对骨架中每条边 (x_i, x_j)：
        - 搜索分离集 S ⊆ V \ {x_i, x_j}
        - 检验 H_0: x_i ⊥ x_j | S
        - 检验方法：
          · 连续非高斯变量：Fisher Z-test / 偏相关检验
          · 条件集 S 中强制包含 ESF 空间过滤向量 S_f
        - 若拒绝 H_0 失败（p > α），删除边 (x_i, x_j)
        - 记录分离集 sep(x_i, x_j) = S

Step 2: V-结构识别
        - 搜索碰撞节点模式：x_i → x_k ← x_j
        - 条件：x_i 与 x_j 在骨架中无直接边，但均连接 x_k
        - 且 x_k ∉ sep(x_i, x_j)
        - 标记为不可否认的碰撞结构

Step 3: Meek规则定向
        - 规则1: 若 x_i → x_j - x_k 且 x_i, x_k 不相邻 → x_j → x_k
        - 规则2: 若 x_i → x_j → x_k 且 x_i - x_k → x_j → x_k
        - 规则3: 若 x_i - x_j ← x_k 且存在 x_i → x_m → x_j ← x_k
        - 规则4: 若 x_i - x_j ← x_k 且存在 x_i → x_m → x_k
        - 重复应用直到无新定向产生

输出：部分祖先图（PAG）PAG [p×p]
```

### 4.3 PAG图谱解读

**四种边型及因果含义**：

| 边型 | 图形 | 含义 | 政策指示 |
|------|------|------|----------|
| 直接因果 | A → B | A是B的祖先原因 | 强推荐干预：改造A可获得B的响应 |
| 隐变量混杂 | A ↔ B | 存在未观测公共原因 | 停止干预：改动A不会影响B |
| 方向存疑 | A o→ B | 关系方向不确定 | 需进阶分析（LvLiNGAM） |
| 完全不确定 | A o-o B | 统计效力不足 | 需更多数据或进阶模型 |

**典型输出示例**：
```
GVI → 步行流量        （直接因果：绿视率提升促进步行）
POI密度 ↔ 骑行流量    （隐变量混杂：可能存在地价/商圈历史等混杂）
SVF o→ 跑步流量       （方向存疑：待LvLiNGAM裁定）
```

## 阶段五：因果定向裁定（LvLiNGAM算法）

### 5.1 非高斯性检验

**前提验证**：确认数据满足非高斯分布假设

```
对每个变量 x_j：
- 偏度检验：|Skew(x_j)| > 阈值（如0.5）
- 峰度检验：|Kurt(x_j) - 3| > 阈值（如1.0）
- 正态性检验：Jarque-Bera检验 或 Shapiro-Wilk检验
  · 若 p < 0.05，拒绝正态假设，满足LiNGAM前提

若变量近似高斯 → 考虑数据变换（Box-Cox/Yeo-Johnson）增强非高斯性
```

**空间数据的天然优势**：
- 人群流量密度：偏态分布、长尾分布、幂律分布
- GVI/SVF像素占比：截断型分布（[0, 1]区间）
- POI密度：高度右偏分布
- 这些特性天然满足LiNGAM的非高斯要求

### 5.2 LvLiNGAM模型求解

**模型设定**：

```
观测变量方程：V = B V + Λ L + E

其中：
- V [p×n]: 观测变量矩阵（p个变量，n个路段）
- B [p×p]: 观测变量间的因果系数矩阵（对角线为0）
- L [q×n]: 隐变量矩阵（q个未观测混杂因素）
- Λ [p×q]: 隐变量对观测变量的效应系数
- E [p×n]: 外生扰动项（非高斯分布）
```

**核心求解步骤**：

```
Step 1: 计算高阶累积量
        - 三阶累积量：cum(x_i, x_j, x_k) （反映偏斜）
        - 四阶累积量：cum(x_i, x_j, x_k, x_l) （反映尾部厚度）

Step 2: 构造非高斯混合累积量比率
        ratio = cum(x_i, x_i, x_i, x_j) / cum(x_i, x_i, x_j, x_j)

Step 3: 独立成分分析（ICA）
        - 基于Darmois-Skitovich定理
        - 当且仅当扰动项非高斯时，回归残差与输入变量独立
        - 顺向回归（X→Y）：残差 ⊥ X ✓
        - 逆向回归（Y→X）：残差 ⊗ X ✗（高阶矩耦合）

Step 4: 因果方向判定
        - 对PAG中每个 o-o 边，分别执行两个方向的回归
        - 检验残差-输入独立性
        - 选择残差独立性更好的方向作为因果方向

Step 5: 隐变量效应分离
        - 利用高阶累积量矩阵的秩约束
        - 推算 Λ 矩阵，分离出隐变量的投影效应
        - 输出纯粹的定向因果边（不受隐变量干扰）

Step 6: 效应规模量化
        - 估计 B 矩阵中的非标准化因果系数 β_ij
        - 解释：x_j 每增加1单位，x_i 的因果效应为 β_ij
```

### 5.3 PAG精化与最终因果图谱

```
输入：GFCI输出的PAG + LvLiNGAM定向结果

操作：
1. 将PAG中所有 o-o 边替换为LvLiNGAM确定的方向
2. 将 o→ 边确认为 → 或保留 o→
3. 保留 ↔ 边不变（隐变量混杂已确认）

输出：精化因果图谱
- 包含全部定向因果边：x_i → x_j (β = 0.35)
- 包含隐变量混杂边：x_i ↔ x_j
- 包含效应规模标注
```

**最终因果图谱示例**：

```
                ┌──────────┐
                │ 隐变量 L  │
                │ (地价/SES)│
                └──┬───┬───┘
                   │   │  Λ 系数
          ┌────────┘   └────────┐
          ▼                     ▼
┌─────────────┐         ┌─────────────┐
│   GVI (x_1) │         │ POI密度(x_2)│
└──────┬──────┘         └──────┬──────┘
       │ β=0.42                │ β=0.38
       ▼                       ▼

```

## 阶段六：结果解释与政策输出

### 6.1 因果效应解读框架

| 输出内容 | 解释方式 | 示例 |
|----------|----------|------|
| 直接因果边 | X每增加1单位，Y的因果变化量 | GVI每提升10%，步行流量因果增加4.2% |
| 隐变量混杂边 | 两者关联非因果，由深层因素共同驱动 | POI密度↔骑行流量：受地价/商圈历史混杂 |
| 效应规模排序 | 按β系数绝对值排列环境因子重要性 | GVI(0.42) > SVF(0.31) > POI密度(0.28) |
| 非线性阈值 | 识别边际效用突变点 | GVI>22.08%后降温效用断崖下跌 |

### 6.2 政策干预评估矩阵

| 干预类型 | 因果支撑强度 | 预期效应 | 实施建议 |
|----------|-------------|----------|----------|
| 提升GVI（行道树加密） | 强（直接因果） | 每10%提升→步行+4.2% | 优先在低GVI路段实施 |
| 增加POI密度 | 弱（混杂相关） | 无法确定因果效应 | 不建议单独作为干预手段 |
| 提升SVF（拓宽街道） | 中等（方向待确认） | 可能正向 | 需结合微气候分析 |
| 拓宽非机动车道 | 强（直接因果） | 骑行流量显著提升 | 与GVI提升协同实施 |

### 6.3 识别伪因果陷阱

**GFCI ↔ 标记的关键警示**：
- 若 `POI密度 ↔ 骑行流量`，说明两者同步增长可能是被城市地价/商圈历史共同驱动
- 盲目增加商铺POI以拉动骑行活力 → 缺乏因果支撑 → 决策破产
- 正确做法：寻找 ↔ 背后的隐变量（如区域经济发展水平），从根源干预

### 6.4 研究局限性声明

| 局限 | 影响 | 缓解策略 |
|------|------|----------|
| 横截面数据 | 无法捕捉动态因果演化 | 未来引入时空动态因果图模型 |
| 隐变量假设 | LvLiNGAM假设线性关系 | 结合非线性扩展模型验证 |
| GPS采样偏差 | 特定人群可能被过度代表 | 分层抽样校正 |
| 街景时效性 | 影像可能滞后于实际环境 | 定期更新SVI采集 |
