# 遥感大数据 — 实验研究

## 常用数据集

| 数据集 | 内容 | 规模 | 来源 |
|--------|------|------|------|
| ImageNet | 自然图像分类 | 14M 图像 | Stanford |
| EuroSAT | 欧洲卫星土地利用 | 27K 图像 | TU Munich |
| WHU Building | 武汉建筑物分割 | 187K 建筑 | WHU |
| DeepGlobe | 道路/建筑/土地覆盖 | 1500+ 图像 | CVPR 2018 |
| xView | 卫星目标检测 | 1M 目标 | DIUx |

## 评估指标

| 指标 | 适用场景 | 说明 |
|------|----------|------|
| OA (Overall Accuracy) | 分类 | 总体精度 |
| mIoU | 语义分割 | 平均交并比 |
| F1 Score | 目标检测 | 精确率与召回率调和 |
| Kappa | 分类 | 一致性系数 |
