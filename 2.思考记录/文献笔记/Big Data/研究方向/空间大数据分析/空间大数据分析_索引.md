# 空间大数据分析

> Spatial Big Data Analysis — 对大规模空间数据进行存储、索引、查询、挖掘与可视化的研究领域。

## 核心主题

- 空间聚类与热点分析（DBSCAN、OPTICS、核密度估计）
- 空间自相关与空间统计（Moran's I、Getis-Ord Gi*）
- 空间索引与查询优化（R-tree、Quadtree、GeoHash）
- 分布式空间计算（Apache Sedona、GeoMesa）
- 空间数据挖掘与模式发现
