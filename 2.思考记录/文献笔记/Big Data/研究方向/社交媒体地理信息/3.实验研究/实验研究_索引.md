# 社交媒体地理信息 — 实验研究

## 常用数据集

| 数据集 | 内容 | 规模 | 来源 |
|--------|------|------|------|
| Twitter API | 带地理标签的推文 | 流式 | X/Twitter |
| Flickr | 带地理标签的照片 | 亿级 | Yahoo |
| Weibo API | 微博签到数据 | 百万级 | 新浪 |
| Yelp Dataset | 商业评论 + 位置 | 6M+ | Yelp |
| GeoText | 地理标注文本 | - | 学术 |

| 指标 | 适用场景 | 说明 |
