# 地理空间数据基础设施 — 应用

## 典型应用场景

- Web 地图服务（天地图、Google Maps、高德）
- 空间数据共享平台（国家地理信息公共服务平台）
- 智慧城市空间信息平台
- 自动驾驶高精地图
- 应急指挥空间决策支持
- 全球环境监测数据基础设施
- 开放政府数据与空间数据融合
