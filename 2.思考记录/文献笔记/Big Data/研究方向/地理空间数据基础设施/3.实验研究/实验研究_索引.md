# 地理空间数据基础设施 — 实验研究

## 常用基准

| 基准 | 内容 | 说明 |
|------|------|------|
| Chicago Taxi | 出租车空间查询 | 1 亿+ 记录 |
| OSM Planet | 全球地图数据 | TB 级 |
| TPC-H (spatial) | 空间扩展 OLAP | 性能测试 |
| NYC Taxi | 时空查询基准 | 亿级记录 |

## 评估指标

| 指标 | 适用场景 | 说明 |
|------|----------|------|
| Query Latency | 查询性能 | 毫秒级 |
| Throughput | 吞吐量 | 查询/秒 |
| Index Build Time | 索引构建 | 构建耗时 |
| Storage Overhead | 存储开销 | 索引空间占比 |
| Completeness | 数据完整性 | 覆盖率百分比 |
| Accuracy/F1 | 数据质量 | 分类精度 |
