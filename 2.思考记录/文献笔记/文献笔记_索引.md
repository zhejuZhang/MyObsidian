# 文献笔记主索引

## 如何使用

**笔记流程：**
1. 阅读论文 → 用 `template/论文阅读笔记.md` 模板创建笔记
2. 将笔记放入对应学科 → 对应分类的文件夹下
3. 在该分类的 `_索引.md` 和学科的 `_主题索引.md` 中登记
4. 定期回顾本索引，梳理研究脉络

**命名规则：** `作者年份_关键词.md`，如 `Mai2024_GeoAI基础模型.md`
