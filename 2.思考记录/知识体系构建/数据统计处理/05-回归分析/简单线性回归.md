# 简单线性回归

> 用一条直线描述两个变量之间的线性关系。

---

## 模型

### 方程

$$Y = \beta_0 + \beta_1 X + \varepsilon$$

- $\beta_0$：截距（X=0时Y的期望值）
- $\beta_1$：斜率（X每增加1单位，Y的平均变化）
- $\varepsilon$：随机误差，$\varepsilon \sim N(0, \sigma^2)$

### 最小二乘估计

$$\hat{\beta}_1 = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2} = \frac{S_{xy}}{S_{xx}}$$

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}$$

---

## 回归方程

$$\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X$$

### 预测

给定 $X = x_0$：
- **点预测**：$\hat{y}_0 = \hat{\beta}_0 + \hat{\beta}_1 x_0$
- **均值的置信区间**：$\hat{y}_0 \pm t_{\alpha/2,n-2} \cdot SE(\hat{y}_0)$
- **个体的预测区间**：$\hat{y}_0 \pm t_{\alpha/2,n-2} \cdot SE(\text{pred})$

预测区间比置信区间更宽（包含个体变异）。

---

## 模型评估

### 决定系数 R²

$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

其中：
- $SST = \sum(y_i-\bar{y})^2$（总平方和）
- $SSR = \sum(\hat{y}_i-\bar{y})^2$（回归平方和）
- $SSE = \sum(y_i-\hat{y}_i)^2$（残差平方和）

**含义**：Y的变异中被X解释的比例。

| R²范围 | 解释 |
|--------|------|
| 0.0 - 0.3 | 弱相关 |
| 0.3 - 0.7 | 中等相关 |
| 0.7 - 1.0 | 强相关 |

### 相关系数 r

$$r = \frac{S_{xy}}{\sqrt{S_{xx} \cdot S_{yy}}}$$

- $r = \sqrt{R^2}$（简单线性回归中）
- $-1 \leq r \leq 1$
- 正值表示正相关，负值表示负相关

### 回归的F检验

$$F = \frac{MSR}{MSE} = \frac{SSR/1}{SSE/(n-2)}$$

检验 $H_0: \beta_1 = 0$（X与Y无线性关系）

---

## 模型假设

### 四大假设（LINE）

| 假设 | 含义 | 检验方法 |
|------|------|----------|
| **L**inear | X与Y线性关系 | 残差图 |
| **I**ndependent | 误差独立 | DW检验、ACF图 |
| **N**ormal | 误差正态分布 | Q-Q图、Shapiro-Wilk |
| **E**qual variance | 误差方差齐性 | 残差图、Breusch-Pagan |

### 残差分析

```
残差
  │   · ·    ·
  │ ·  ·  · · ·
  ├─────────────────  0
  │  ·  · ·  ·
  │    ·    ·
  └───────────────── 拟合值

理想：随机分布在0附近，无模式
```

**常见问题**：
- 残差有曲线模式 → 非线性
- 残差呈喇叭形 → 方差不齐
- 残差有异常点 → 异常值影响

---

## 回归系数的推断

### 斜率的假设检验

$$H_0: \beta_1 = 0 \quad vs \quad H_1: \beta_1 \neq 0$$

$$t = \frac{\hat{\beta}_1}{SE(\hat{\beta}_1)}, \quad df = n-2$$

### 斜率的置信区间

$$\hat{\beta}_1 \pm t_{\alpha/2,n-2} \cdot SE(\hat{\beta}_1)$$

---

## 注意事项

### 相关不等于因果

回归只能说明关联，不能证明因果关系。

### 外推的风险

在数据范围外的预测不可靠。

### 异常值的影响

单个异常值可能严重影响回归结果。

## 常见误区

1. **相关=因果**：回归只说明关联
2. **忽视残差分析**：假设不满足时结论不可靠
3. **外推预测**：在数据范围外预测风险大
4. **只看R²**：应结合残差分析和假设检验
