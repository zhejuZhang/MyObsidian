# 总体与样本

> 统计学的核心任务：通过样本推断总体。

---

## 基本概念

### 总体（Population）

- **定义**：研究对象的全部个体集合
- **特征**：通常未知，是我们想要了解的目标
- **参数（Parameter）**：描述总体的数值特征，用希腊字母表示

| 参数 | 符号 | 含义 |
|------|------|------|
| 总体均值 | $\mu$ | 总体的平均水平 |
| 总体方差 | $\sigma^2$ | 总体的离散程度 |
| 总体比例 | $\pi$ 或 $p$ | 总体中某类别的占比 |
| 总体大小 | $N$ | 总体中的个体数 |

### 样本（Sample）

- **定义**：从总体中抽取的一部分个体
- **特征**：可观测，用于推断总体
- **统计量（Statistic）**：描述样本的数值特征，用拉丁字母表示

| 统计量 | 符号 | 含义 |
|------|------|------|
| 样本均值 | $\bar{x}$ | 样本的平均水平 |
| 样本方差 | $s^2$ | 样本的离散程度 |
| 样本比例 | $\hat{p}$ | 样本中某类别的占比 |
| 样本大小 | $n$ | 样本中的个体数 |

## 总体与样本的关系

```
总体 (N, μ, σ²)        样本 (n, x̄, s²)
┌─────────────────┐    ┌─────────────┐
│ ● ● ● ● ● ● ● │    │   ● ● ●    │
│ ● ● ● ● ● ● ● │ →  │   ● ● ●    │
│ ● ● ● ● ● ● ● │    │   ● ●      │
│ ● ● ● ● ● ● ● │    │             │
└─────────────────┘    └─────────────┘
     未知真相               可观测推断
```

**核心思想**：统计量是参数的估计，但存在抽样误差。

## 抽样方法

### 概率抽样（Probability Sampling）

每个个体被抽中的概率已知且非零。

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| **简单随机抽样** | 每个个体等概率被抽中 | 总体同质性高 |
| **系统抽样** | 按固定间隔抽取 | 有名单的总体 |
| **分层抽样** | 先分层，再从各层抽样 | 总体有明显分组 |
| **整群抽样** | 随机抽取若干群，调查群内全部 | 地理分散的总体 |
| **多阶段抽样** | 分多个阶段逐步抽取 | 大规模调查 |

### 非概率抽样（Non-probability Sampling）

抽样概率未知，可能存在偏差。

| 方法 | 描述 | 风险 |
|------|------|------|
| **便利抽样** | 找最容易获取的样本 | 选择偏差大 |
| **判断抽样** | 研究者主观选择 | 依赖研究者判断 |
| **配额抽样** | 按比例分配各类别 | 组内选择仍有偏差 |
| **滚雪球抽样** | 通过已有样本推荐 | 网络效应偏差 |

## 抽样误差与非抽样误差

### 抽样误差（Sampling Error）

- **定义**：仅因抽样而导致的样本统计量与总体参数的差异
- **特征**：不可避免，但可通过增大样本量减小
- **公式**：$SE = \frac{\sigma}{\sqrt{n}}$（均值的标准误差）

### 非抽样误差（Non-sampling Error）

| 类型 | 来源 | 示例 |
|------|------|------|
| 覆盖误差 | 抽样框不完整 | 电话调查遗漏无电话人群 |
| 无响应误差 | 被调查者未回复 | 邮件调查回收率低 |
| 测量误差 | 数据收集不准确 | 问卷理解偏差、记录错误 |
| 处理误差 | 数据处理出错 | 编码错误、录入错误 |

> [!important] 样本量不是万能的
> 增大样本量可以减小抽样误差，但无法减小非抽样误差。一个有偏差的抽样框，即使样本量再大，结果也是有偏的。

---

## 样本量的影响

```
标准误差 SE = σ/√n

n = 25  →  SE = σ/5
n = 100 →  SE = σ/10  (减小50%)
n = 400 →  SE = σ/20  (再减小50%)
```

**规律**：标准误差与样本量的平方根成反比。要将误差减半，需要4倍的样本量。

---

## 统计量的性质

| 性质 | 说明 |
|------|------|
| **无偏性** | $E(\bar{x}) = \mu$，统计量的期望等于参数 |
| **有效性** | 方差越小越有效 |
| **一致性** | $n \to \infty$ 时，统计量收敛于参数 |
| **充分性** | 包含样本中关于参数的全部信息 |

## 常见误区

1. **混淆参数和统计量**：$\mu$ 是总体参数（通常未知），$\bar{x}$ 是样本统计量（可计算）
2. **样本量越大越好？**：大样本可能引入更多非抽样误差，且成本更高
3. **随机抽样≠随便抽样**：随机抽样有严格的概率要求，"随便找人"不是随机抽样
4. **忽略抽样框质量**：抽样框不完整会导致系统性偏差
