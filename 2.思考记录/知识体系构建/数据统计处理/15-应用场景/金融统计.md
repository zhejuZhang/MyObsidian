# 金融统计

> 统计学在金融领域的应用，是风险管理的基础。

---

## 收益率

### 简单收益率

$$R_t = \frac{P_t - P_{t-1}}{P_{t-1}}$$

### 对数收益率

$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(1 + R_t)$$

### 选择

| 收益率 | 优点 | 缺点 |
|--------|------|------|
| 简单收益率 | 直观 | 不可加 |
| 对数收益率 | 可加 | 不直观 |

## 风险度量

### 波动率

$$\sigma = \sqrt{\frac{1}{n-1}\sum_{t=1}^{n}(r_t - \bar{r})^2}$$

### VaR（在险价值）

$$P(Loss > VaR) = \alpha$$

**含义**：在给定置信水平下，最大可能损失。

| 方法 | 描述 |
|------|------|
| 历史模拟法 | 用历史分布 |
| 参数法 | 假设正态分布 |
| Monte Carlo | 模拟方法 |

### CVaR（条件在险价值）

$$CVaR = E[Loss | Loss > VaR]$$

**含义**：超过VaR时的平均损失。

## 资产组合

### 收益率

$$R_p = \sum_{i=1}^{n} w_i R_i$$

### 方差

$$\sigma_p^2 = \sum_{i=1}^{n}\sum_{j=1}^{n} w_i w_j \sigma_{ij}$$

### 有效前沿

```
收益
  │      ●
  │    ●   ●
  │  ●       ●
  │ ●         ●
  │●           ●
  └─────────────── 风险
```

## CAPM模型

### 公式

$$E(R_i) = R_f + \beta_i (E(R_m) - R_f)$$

- $R_f$：无风险利率
- $\beta_i$：资产i的系统风险
- $E(R_m)$：市场期望收益率

### Beta

$$\beta_i = \frac{Cov(R_i, R_m)}{Var(R_m)}$$

| Beta | 含义 |
|------|------|
| β = 1 | 与市场同步 |
| β > 1 | 比市场波动大 |
| β < 1 | 比市场波动小 |

## 常见误区

1. **假设正态分布**：金融数据常有厚尾
2. **忽视风险度量**：只关注收益不关注风险
3. **过度拟合**：历史表现不代表未来
4. **忽视行为因素**：市场不是完全理性的
