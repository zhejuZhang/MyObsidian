# 质量控制与SPC

> 统计过程控制是质量管理的核心方法。

---

## 基本概念

### SPC定义

**统计过程控制**（Statistical Process Control, SPC）用统计方法监控和控制过程。

### 目标

- 监控过程稳定性
- 发现异常波动
- 减少变异
- 提高质量

---

## 控制图

### 基本原理

```
UCL ─────────────────  上控制限
      · ·   · ·
    ·   · · ·   ·
CL  ─────────────────  中心线
    ·   · · ·   ·
      · ·   · ·
LCL ─────────────────  下控制限
```

### 控制限

$$UCL = \bar{\bar{X}} + A_2 \bar{R}$$
$$LCL = \bar{\bar{X}} - A_2 \bar{R}$$

### 常用控制图

| 图表 | 适用 | 数据类型 |
|------|------|----------|
| X̄-R图 | 均值和极差 | 计量数据，n<10 |
| X̄-S图 | 均值和标准差 | 计量数据，n≥10 |
| p图 | 不良率 | 计件数据 |
| np图 | 不良数 | 计件数据 |
| c图 | 缺陷数 | 计点数据 |
| u图 | 单位缺陷数 | 计点数据 |

---

## 过程能力

### 过程能力指数

$$C_p = \frac{USL - LSL}{6\sigma}$$

$$C_{pk} = \min\left(\frac{USL - \mu}{3\sigma}, \frac{\mu - LSL}{3\sigma}\right)$$

### 解读

| Cp/Cpk | 含义 |
|--------|------|
| ≥ 1.67 | 优秀 |
| 1.33-1.67 | 良好 |
| 1.0-1.33 | 可接受 |
| < 1.0 | 不可接受 |

---

## 变异来源

### 普通原因变异

- 过程固有变异
- 随机波动
- 无法完全消除

### 特殊原因变异

- 异常事件导致
- 可识别和消除
- 控制图的目标

## 失控规则

### Western Electric规则

| 规则 | 描述 |
|------|------|
| 规则1 | 1点超出3σ |
| 规则2 | 连续9点在中心线同侧 |
| 规则3 | 连续6点递增或递减 |
| 规则4 | 连续14点交替升降 |

### Nelson规则

扩展了Western Electric规则，共8条。

## 测量系统分析（MSA）

### GR&R（重复性和再现性）

$$GR\&R = \sqrt{\sigma_{重复性}^2 + \sigma_{再现性}^2}$$

### 可接受标准

| %GR&R | 含义 |
|--------|------|
| < 10% | 可接受 |
| 10-30% | 有条件接受 |
| > 30% | 不可接受 |

## 常见误区

1. **混淆控制限和规格限**：控制限是过程的，规格限是客户的
2. **忽视测量系统**：测量误差会影响控制图
3. **过度调整**：对普通原因变异过度干预
4. **不做持续改进**：SPC是持续改进的工具
