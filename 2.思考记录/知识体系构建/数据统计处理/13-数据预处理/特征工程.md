# 特征工程

> 将原始数据转换为更适合建模的特征，是机器学习成功的关键。

---

## 基本概念

### 定义

**特征工程**是从原始数据中提取、转换和创建特征的过程。

### 重要性

> "Applied machine learning is basically feature engineering." — Andrew Ng

---

## 数值特征处理

### 标准化（Standardization）

$$z = \frac{x - \mu}{\sigma}$$

- 均值为0，标准差为1
- 适用：正态分布数据

### 归一化（Normalization）

$$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$

- 缩放到[0,1]
- 适用：有界数据

### 对数变换

$$x' = \ln(x + 1)$$

- 处理右偏数据
- 减少异常值影响

### 分箱（Binning）

将连续变量离散化。

```
年龄：{18, 25, 35, 45, 60}
分箱：{青年, 中年, 中老年, 老年}
```

**方法**：等宽分箱、等频分箱、自定义分箱

## 分类特征处理

### 独热编码（One-Hot Encoding）

```
颜色：{红, 蓝, 绿}
编码：红→[1,0,0], 蓝→[0,1,0], 绿→[0,0,1]
```

### 标签编码（Label Encoding）

```
颜色：{红, 蓝, 绿}
编码：红→0, 蓝→1, 绿→2
```

### 目标编码（Target Encoding）

用目标变量的统计量编码。

```
类别A的平均目标值 = 0.8
类别B的平均目标值 = 0.3
```

### 频率编码

用类别出现频率编码。

## 时间特征

| 特征 | 提取方法 |
|------|----------|
| 年、月、日 | dt.year, dt.month, dt.day |
| 星期 | dt.weekday |
| 小时 | dt.hour |
| 是否周末 | dt.weekday >= 5 |
| 是否节假日 | 日历匹配 |
| 时间差 | 两个日期之差 |
| 周期性编码 | sin/cos变换 |

## 交互特征

### 多项式特征

$$x_1, x_2 \rightarrow x_1, x_2, x_1^2, x_1 x_2, x_2^2$$

### 交叉特征

```
颜色=红, 尺寸=大 → 红_大
```

### 比率特征

```
点击次数/展示次数 = 点击率
```

## 特征工程流程

```
原始数据
    │
    ▼
数据清洗
    │
    ▼
数值特征处理
├── 标准化/归一化
├── 变换
└── 分箱
    │
    ▼
分类特征处理
├── 编码
└── 目标编码
    │
    ▼
时间/文本特征
    │
    ▼
交互特征
    │
    ▼
特征选择
    │
    ▼
建模
```

## 常见误区

1. **不做特征工程**：特征工程往往比算法更重要
2. **过度特征**：特征太多可能导致过拟合
3. **数据泄露**：特征工程不应使用测试集信息
4. **忽视领域知识**：领域知识可以指导特征创建
