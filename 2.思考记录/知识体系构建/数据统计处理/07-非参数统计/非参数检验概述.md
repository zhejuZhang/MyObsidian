# 非参数检验概述

> 不依赖总体分布假设的统计方法，适用于分布未知或非正态数据。

---

## 参数 vs 非参数

| 维度 | 参数方法 | 非参数方法 |
|------|----------|-----------|
| 分布假设 | 需要（如正态） | 不需要 |
| 数据类型 | 定距/定比 | 定类/定序也可 |
| 统计功效 | 较高 | 较低（约95%效率） |
| 稳健性 | 对假设敏感 | 稳健 |
| 样本量 | 小样本时依赖假设 | 适合小样本 |

---

## 何时使用非参数方法

| 场景 | 推荐方法 |
|------|----------|
| 数据明显非正态 | 非参数检验 |
| 样本量很小（n < 15） | 非参数检验 |
| 定序数据 | 非参数检验 |
| 有异常值 | 非参数检验 |
| 分布未知 | 非参数检验 |
| 数据正态、样本量足够 | 参数方法（功效更高） |

---

## 参数方法与非参数方法的对应

| 参数方法 | 非参数替代 | 适用场景 |
|----------|-----------|----------|
| 单样本t检验 | Wilcoxon符号秩检验 | 单样本中位数 |
| 独立样本t检验 | Mann-Whitney U检验 | 两组比较 |
| 配对样本t检验 | Wilcoxon符号秩检验 | 配对数据 |
| 单因素ANOVA | Kruskal-Wallis检验 | 多组比较 |
| 重复测量ANOVA | Friedman检验 | 重复测量 |
| Pearson相关 | Spearman秩相关 | 变量关系 |

## 秩次方法

### 核心思想

用数据的**秩次**（排序位置）代替原始值，消除分布假设。

### 秩次的计算

原始数据：{3, 7, 1, 5, 9}
排序：{1, 3, 5, 7, 9}
秩次：{2, 4, 1, 3, 5}

**结（Ties）**：相同值取平均秩次
原始数据：{3, 7, 3, 5, 9}
排序：{3, 3, 5, 7, 9}
秩次：{1.5, 1.5, 3, 4, 5}

## 置换检验

### 思想

在零假设下，通过重新排列数据标签来构建检验统计量的分布。

### 步骤

```
1. 计算观测数据的检验统计量
2. 随机重新排列组标签
3. 计算重新排列后的统计量
4. 重复多次（如10000次）
5. 计算p值 = 极端值的比例
```

### 优点

- 不依赖分布假设
- 精确（可计算精确p值）
- 适用于复杂统计量

## Bootstrap方法

### 思想

通过有放回重抽样来估计统计量的分布。

### 步骤

```
1. 从原始样本中有放回地抽取n个观测值
2. 计算统计量（如均值、中位数）
3. 重复B次（B ≥ 1000）
4. 用B个统计量构建置信区间
```

### Bootstrap置信区间

| 方法 | 描述 | 特点 |
|------|------|------|
| 百分位法 | 取分位数 | 简单 |
| BCa法 | 校正偏差和偏斜 | 更准确 |
| 基本法 | 基于pivot | 对称 |

---

## 非参数方法的优缺点

### 优点

- 不依赖分布假设
- 对异常值稳健
- 适用于小样本
- 可用于定序数据

### 缺点

- 统计功效略低于参数方法
- 大样本时计算量大
- 某些方法不如参数方法灵活
- 对结的处理可能影响结果

---

## 大样本近似

许多非参数检验在大样本时近似正态分布。

**示例**：Mann-Whitney U检验

$$Z = \frac{U - n_1 n_2/2}{\sqrt{n_1 n_2(n_1+n_2+1)/12}}$$

大样本时Z近似标准正态。

## 常见误区

1. **非参数=无分布假设**：某些方法仍有假设（如独立性）
2. **非参数总是更好**：参数方法在假设满足时功效更高
3. **大样本用非参数**：大样本时参数方法更高效
4. **忽视结的处理**：结会影响秩次和检验结果
