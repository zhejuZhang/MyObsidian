# 多重比较方法

> ANOVA显著后，需要确定哪些组之间存在差异。

---

## 为什么需要多重比较？

ANOVA只告诉你"至少有两组不同"，但不告诉你哪些组不同。

---

## 方法分类

### 参数方法

| 方法 | 适用场景 | 特点 |
|------|----------|------|
| **LSD（最小显著差异）** | ANOVA显著后的两两比较 | 最不保守 |
| **Bonferroni** | 任意两两比较 | 保守 |
| **Tukey HSD** | 所有两两比较（等样本量） | 最常用 |
| **Scheffé** | 所有可能的比较（包括复合比较） | 最保守 |
| **Dunnett** | 各组与对照组比较 | 专用 |
| **Holm** | 逐步校正 | 比Bonferroni强 |
| **Games-Howell** | 方差不齐时 | 不假设方差齐性 |

### 非参数方法

| 方法 | 适用场景 |
|------|----------|
| **Dunn检验** | Kruskal-Wallis后的两两比较 |
| **Conover检验** | 非参数两两比较 |
| **Nemenyi检验** | 非参数所有两两比较 |

---

## 事后检验 vs 计划对比

### 事后检验（Post-hoc）

- 在看到数据后决定比较哪些组
- 需要更严格的校正
- 如Tukey、Bonferroni

### 计划对比（Planned/ A Priori）

- 在收集数据前就确定比较
- 不需要多重比较校正
- 如Dunnett（与对照组比较）

---

## 常用方法详解

### Tukey HSD（Honestly Significant Difference）

**适用**：所有两两比较，各组样本量相等

$$q = \frac{\bar{X}_i - \bar{X}_j}{\sqrt{MSW/n}}$$

**判断**：$q > q_{\alpha, k, df}$ 则显著

**优点**：控制整体错误率，功效较高

### Bonferroni校正

**方法**：将α除以比较次数m

$$\alpha' = \alpha/m$$

**优点**：简单、通用
**缺点**：过于保守

### Holm-Bonferroni（逐步校正）

**步骤**：
1. 将p值从小到大排序
2. 最小的p值与 $\alpha/m$ 比较
3. 第i个p值与 $\alpha/(m-i+1)$ 比较
4. 直到不显著为止

**优点**：比Bonferroni更强

### Dunnett检验

**适用**：各处理组与一个对照组比较

**优点**：比Tukey更高效（比较次数少）

### Games-Howell

**适用**：方差不齐或样本量不等

**不假设**：方差齐性

## 效应大小

### Cohen's d（两组比较）

$$d = \frac{\bar{X}_1 - \bar{X}_2}{s_p}$$

| d值 | 效应大小 |
|-----|----------|
| 0.2 | 小 |
| 0.5 | 中 |
| 0.8 | 大 |

## 方法选择指南

```
假设条件满足？
├── 是
│   ├── 比较类型？
│   │   ├── 所有两两比较 → Tukey HSD
│   │   ├── 与对照组比较 → Dunnett
│   │   └── 特定对比 → 计划对比
│   └── 样本量相等？
│       ├── 是 → Tukey HSD
│       └── 否 → Tukey-Kramer
└── 否（方差不齐）
    └── Games-Howell
```

## 多重比较校正

### 家族错误率（FWER）

至少犯一个第一类错误的概率。

- Bonferroni控制FWER
- Tukey控制FWER

### 错误发现率（FDR）

错误拒绝的比例。

- Benjamini-Hochberg（BH）方法
- 适用于大量比较（如基因组学）

## 常见误区

1. **ANOVA显著后不做多重比较**：不知道哪些组不同
2. **用t检验做所有两两比较**：不校正会导致错误率膨胀
3. **选择最不保守的方法**：应根据研究设计选择
4. **忽视方差不齐**：应使用Games-Howell等方法
