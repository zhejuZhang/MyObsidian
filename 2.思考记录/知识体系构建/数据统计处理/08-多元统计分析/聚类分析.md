# 聚类分析

> 将数据分成若干组，使组内相似、组间不同。

---

## 基本概念

### 目的

- 发现数据中的自然分组
- 数据压缩
- 异常检测
- 探索性分析

### 类型

| 类型 | 方法 | 特点 |
|------|------|------|
| 划分方法 | K-means | 需要指定k |
| 层次方法 | 凝聚/分裂 | 树状图 |
| 密度方法 | DBSCAN | 发现任意形状 |
| 模型方法 | 高斯混合 | 概率框架 |

---

## 距离度量

### 连续变量

| 距离 | 公式 | 适用 |
|------|------|------|
| 欧氏距离 | $d = \sqrt{\sum(x_i-y_i)^2}$ | 最常用 |
| 曼哈顿距离 | $d = \sum|x_i-y_i|$ | 高维数据 |
| 马氏距离 | 考虑相关性 | 相关变量 |
| 余弦距离 | $1 - \cos(\theta)$ | 文本数据 |

### 分类变量

| 距离 | 公式 |
|------|------|
| Jaccard距离 | $1 - \frac{|A \cap B|}{|A \cup B|}$ |
| 汉明距离 | 不同属性的个数 |

## K-means聚类

### 算法

```
1. 随机选择k个初始中心
2. 将每个点分配到最近的中心
3. 重新计算各簇的中心
4. 重复2-3直到收敛
```

### 优点

- 简单高效
- 适用于大数据

### 缺点

- 需要指定k
- 对初始中心敏感
- 假设簇是球形的
- 对异常值敏感

### k的选择

| 方法 | 描述 |
|------|------|
| 肘部法则 | 簇内平方和 vs k |
| 轮廓系数 | 衡量聚类质量 |
| Gap统计量 | 与随机数据比较 |
| 领域知识 | 实际应用考虑 |

### 肘部法则

```
SSE
  │ ●
  │   ●
  │     ●
  │       ● ● ● ●
  └────────────────── k
       拐点处选择
```

## 层次聚类

### 凝聚方法（自底向上）

```
1. 每个点作为一个簇
2. 合并最近的两个簇
3. 重复2直到达到目标
```

### 分裂方法（自顶向下）

```
1. 所有点作为一个簇
2. 分裂最不相似的簇
3. 重复2直到达到目标
```

### 簇间距离

| 方法 | 公式 | 特点 |
|------|------|------|
| 单链接 | 最近点距离 | 链式效应 |
| 完全链接 | 最远点距离 | 紧凑簇 |
| 平均链接 | 平均距离 | 平衡 |
| Ward方法 | 簇内方差增量 | 最常用 |

### 树状图

```
       ┌─────────┐
       │         │
    ┌──┴──┐   ┌──┴──┐
    │     │   │     │
  ┌─┴─┐ ┌┴─┐ │   ┌─┴─┐
  │   │ │  │ │   │   │
  A   B C  D E   F   G
```

## DBSCAN

### 核心概念

| 概念 | 定义 |
|------|------|
| 核心点 | 邻域内有足够多点 |
| 边界点 | 在核心点邻域内但本身不是核心点 |
| 噪声点 | 既不是核心点也不是边界点 |

### 参数

- ε（eps）：邻域半径
- MinPts：最小点数

### 优点

- 不需要指定簇数
- 可以发现任意形状的簇
- 可以识别噪声点

### 缺点

- 对参数敏感
- 密度不均匀时效果差

## 聚类评估

### 内部评估

| 指标 | 公式 | 含义 |
|------|------|------|
| SSE | $\sum_{i}\sum_{x \in C_i}||x-\mu_i||^2$ | 簇内紧密度 |
| 轮廓系数 | $\frac{b-a}{\max(a,b)}$ | 簇内紧密+簇间分离 |
| Calinski-Harabasz | 组间方差/组内方差 | 综合评估 |

### 外部评估

当有真实标签时：

| 指标 | 含义 |
|------|------|
| ARI（调整兰德指数） | 衡量聚类与真实标签的一致性 |
| NMI（标准化互信息） | 信息论视角 |
| Fowlkes-Mallows | 精确率和召回率的几何平均 |

## 常见误区

1. **不标准化**：变量量纲不同时必须标准化
2. **忽视k的选择**：k的选择对结果影响很大
3. **假设簇是球形**：K-means假设可能不成立
4. **过度解释聚类结果**：聚类结果需要领域知识验证
