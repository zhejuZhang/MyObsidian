# 因子分析

> 用少数几个潜在因子解释多个观测变量之间的相关性。

---

## 基本概念

### 目的

- 发现潜在的结构
- 用少数因子概括多个变量
- 验证理论结构

### 模型

$$X_i = \mu + l_{i1}F_1 + l_{i2}F_2 + \cdots + l_{im}F_m + \varepsilon_i$$

- $F_j$：公共因子（潜变量）
- $l_{ij}$：因子载荷
- $\varepsilon_i$：特殊因子（误差）

---

## PCA vs 因子分析

| 维度 | PCA | 因子分析 |
|------|-----|----------|
| 目的 | 降维、数据概括 | 发现潜在结构 |
| 模型 | 数学变换 | 统计模型 |
| 误差 | 无 | 有特殊因子 |
| 假设 | 无 | 有潜变量假设 |
| 适用 | 数据概括 | 理论验证 |

---

## 因子分析的步骤

```
1. 确定是否适合因子分析
   ├── KMO测度 > 0.6
   └── Bartlett球形检验显著
        │
2. 提取因子
   ├── 主成分法
   ├── 主轴因子法
   ├── 最大似然法
   └── 其他方法
        │
3. 确定因子数量
   ├── 特征值 > 1
   ├── 碎石图
   └── 平行分析
        │
4. 因子旋转
   ├── 正交旋转（Varimax）
   └── 斜交旋转（Promax）
        │
5. 解释因子
   └── 根据载荷解释因子含义
```

## 因子提取方法

| 方法 | 特点 | 适用 |
|------|------|------|
| 主成分法 | 最常用 | 数据概括 |
| 主轴因子法 | 考虑误差 | 测量模型 |
| 最大似然法 | 有统计检验 | 正态数据 |
| Alpha法 | 最大化信度 | 量表开发 |

## 因子数量的确定

### 特征值准则

保留特征值 > 1 的因子（Kaiser准则）。

### 碎石图

```
特征值
  │ ●
  │   ●
  │     ●
  │       ● ● ● ●
  └────────────────── 因子序号
       拐点处选择
```

### 平行分析

比较实际特征值与随机数据的特征值。

### 累积解释率

保留足够的因子使累积解释率 > 70-80%。

---

## 因子旋转

### 正交旋转（Orthogonal）

因子之间不相关。

**Varimax旋转**：最大化因子载荷的方差。

### 斜交旋转（Oblique）

因子之间可以相关。

**Promax旋转**：先做正交旋转，再允许相关。

### 选择

| 旋转 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| Varimax | 因子不相关 | 简单易解释 | 可能不符合实际 |
| Promax | 因子可能相关 | 更符合实际 | 更复杂 |

## 因子载荷

### 含义

因子载荷 $l_{ij}$ 是变量 $X_i$ 与因子 $F_j$ 的相关系数。

### 解读

| 载荷绝对值 | 含义 |
|-----------|------|
| > 0.7 | 强载荷 |
| 0.4 - 0.7 | 中等载荷 |
| < 0.4 | 弱载荷（通常忽略） |

### 载荷矩阵

```
         F1    F2
X₁      0.8   0.1
X₂      0.7   0.2
X₃      0.1   0.8
X₄      0.2   0.7
```

解读：X₁, X₂ 主要由 F₁ 解释；X₃, X₄ 主要由 F₂ 解释。

### 定义

### 计算方法

| 方法 | 特点 |
|------|------|
| 回归法 | 最常用 |
| Bartlett法 | 无偏 |
| Anderson-Rubin | 正交因子 |

## 评估指标

### KMO测度

采样充分性，KMO > 0.6 适合因子分析。

| KMO值 | 含义 |
|-------|------|
| > 0.9 | 极好 |
| 0.8-0.9 | 好 |
| 0.7-0.8 | 中等 |
| 0.6-0.7 | 差 |
| < 0.6 | 不适合 |

### Bartlett球形检验

检验变量间是否有足够的相关性。

### 共同度

变量被公共因子解释的比例。

$$h_i^2 = \sum_{j=1}^{m} l_{ij}^2$$

### Cronbach's α

量表的内部一致性信度。

$$\alpha = \frac{k}{k-1}\left(1 - \frac{\sum s_i^2}{s_T^2}\right)$$

## 探索性 vs 验证性因子分析

| | 探索性因子分析（EFA） | 验证性因子分析（CFA） |
|---|---|---|
| 目的 | 发现结构 | 验证结构 |
| 假设 | 无先验假设 | 有先验假设 |
| 方法 | 数据驱动 | 理论驱动 |
| 适用 | 探索阶段 | 验证阶段 |

## 常见误区

1. **PCA=因子分析**：两者目标和方法不同
2. **不旋转因子**：未旋转的因子难以解释
3. **忽视假设检验**：KMO和Bartlett检验很重要
4. **样本量不足**：通常需要 n ≥ 5p 或 n ≥ 100
