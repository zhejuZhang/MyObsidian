# 主成分分析（PCA）

> 将多个相关变量转化为少数几个不相关的综合变量，实现降维。

---

## 基本概念

### 目的

- 降维：用较少的变量概括大部分信息
- 去除多重共线性
- 数据可视化
- 特征提取

### 核心思想

找到数据变异最大的方向，依次找到正交方向。

```
原始空间（2D）        主成分空间
    Y │  · ·           PC2 │
      │ · · · ·            │
      │· · · ·             │
      │ · ·                │
      └──────── X          └──────── PC1
                           最大方差方向
```

---

## 数学原理

### 步骤

1. **标准化数据**（均值为0，标准差为1）
2. **计算协方差矩阵**（或相关矩阵）
3. **特征值分解**
4. **选择主成分**

### 协方差矩阵

$$\mathbf{C} = \frac{1}{n-1}\mathbf{X}^T\mathbf{X}$$

### 特征值分解

$$\mathbf{C}\mathbf{v}_i = \lambda_i \mathbf{v}_i$$

- $\lambda_i$：特征值（第i个主成分的方差）
- $\mathbf{v}_i$：特征向量（第i个主成分的方向）

### 主成分

$$PC_i = \mathbf{X}\mathbf{v}_i = v_{1i}X_1 + v_{2i}X_2 + \cdots + v_{pi}X_p$$

---

## 主成分的选择

### 方差解释率

$$\text{解释率}_i = \frac{\lambda_i}{\sum_{j=1}^{p}\lambda_j}$$

### 累积解释率

$$\text{累积解释率}_k = \frac{\sum_{i=1}^{k}\lambda_i}{\sum_{j=1}^{p}\lambda_j}$$

### 选择标准

| 标准 | 方法 |
|------|------|
| 特征值 > 1 | Kaiser准则 |
| 累积解释率 > 80% | 经验准则 |
| 碎石图拐点 | 图形方法 |
| 平行分析 | 统计方法 |

### 碎石图

```
特征值
  │ ●
  │   ●
  │     ●
  │       ●
  │         ● ● ● ●
  └────────────────── 主成分序号
       拐点处选择
```

---

## 结果解读

### 载荷（Loadings）

主成分与原始变量的相关系数。

$$\text{loading}_{ij} = v_{ij} \times \sqrt{\lambda_i}$$

### 载荷图

```
PC2 │
    │    X₂
    │   ╱
    │  ╱
    │ X₃
    └──────── PC1
         X₁
```

- 同侧的变量正相关
- 对侧的变量负相关
- 夹角小的变量相关性强

### 得分（Scores）

每个观测在主成分上的取值。

$$\text{score}_i = \mathbf{X}\mathbf{v}_i$$

---

## 标准化问题

### 何时标准化

| 情况 | 是否标准化 | 原因 |
|------|-----------|------|
| 变量单位不同 | 是 | 消除量纲影响 |
| 变量单位相同 | 否 | 保留原始信息 |
| 方差差异大 | 是 | 避免大方差主导 |

### 相关矩阵 vs 协方差矩阵

- **相关矩阵**：标准化后的数据
- **协方差矩阵**：原始数据

---

## PCA的假设

| 假设 | 含义 | 检验 |
|------|------|------|
| 线性关系 | 变量间线性相关 | 散点图 |
| 足够的样本量 | n ≥ 5p 或 n ≥ 100 | 经验规则 |
| Bartlett球形检验 | 变量间有相关 | 检验 |
| KMO测度 | 采样充分性 | KMO > 0.6 |

---

## PCA的应用

### 数据降维

用前k个主成分代替原始p个变量。

### 数据可视化

用前2-3个主成分绘制散点图。

### 去除噪声

丢弃方差小的主成分。

### 处理多重共线性

主成分回归（PCR）。

---

## PCA的局限

| 局限 | 说明 |
|------|------|
| 仅线性关系 | 无法捕捉非线性结构 |
| 对异常值敏感 | 异常值可能影响主成分方向 |
| 解释性差 | 主成分是原始变量的线性组合 |
| 信息损失 | 降维必然损失信息 |

---

## 扩展方法

| 方法 | 特点 |
|------|------|
| 核PCA | 处理非线性关系 |
| 稀疏PCA | 产生稀疏载荷，更易解释 |
| 增量PCA | 适用于大数据 |
| 因子分析 | 有潜变量模型 |

## 常见误区

1. **PCA=因子分析**：PCA是数学变换，因子分析是统计模型
2. **不标准化**：变量单位不同时必须标准化
3. **过度降维**：保留太少主成分会损失重要信息
4. **忽视解释性**：主成分可能难以解释
