# 贝叶斯推断基础

> 用新证据更新信念的统计框架，将参数视为随机变量。

---

## 核心思想

### 贝叶斯定理

$$P(\theta|D) = \frac{P(D|\theta) \cdot P(\theta)}{P(D)}$$

- $P(\theta)$：先验分布（Prior）
- $P(D|\theta)$：似然（Likelihood）
- $P(\theta|D)$：后验分布（Posterior）
- $P(D)$：边际似然（Marginal Likelihood）

### 直观理解

```
后验 ∝ 先验 × 似然

旧信念 × 新证据 = 新信念
```

## 频率学派 vs 贝叶斯学派

| 维度 | 频率学派 | 贝叶斯学派 |
|------|----------|-----------|
| 参数 | 固定的 | 随机变量 |
| 概率 | 长期频率 | 信念程度 |
| 推断 | 假设检验、置信区间 | 后验分布、可信区间 |
| 先验 | 不使用 | 使用 |
| 重复 | 假设重复实验 | 基于当前数据 |

## 先验分布

### 类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 无信息先验 | 尽量不影响后验 | 均匀分布 |
| 弱信息先验 | 弱约束 | 正态(0, 100²) |
| 信息先验 | 利用已有知识 | 专家意见 |
| 共轭先验 | 数学方便 | Beta-Binomial |

### 常见共轭先验

| 似然 | 共轭先验 | 后验 |
|------|----------|------|
| 二项 | Beta | Beta |
| 正态（已知方差） | 正态 | 正态 |
| 泊松 | Gamma | Gamma |
| 指数 | Gamma | Gamma |

### Beta-Binomial示例

- 先验：$p \sim \text{Beta}(\alpha, \beta)$
- 数据：$x \sim \text{Binomial}(n, p)$
- 后验：$p|x \sim \text{Beta}(\alpha+x, \beta+n-x)$

## 后验分布

### 定义

$$P(\theta|D) = \frac{P(D|\theta) \cdot P(\theta)}{\int P(D|\theta) \cdot P(\theta) d\theta}$$

### 后验统计量

| 统计量 | 公式 | 用途 |
|--------|------|------|
| 后验均值 | $E[\theta|D]$ | 点估计 |
| 后验中位数 | $\text{Median}[\theta|D]$ | 稳健估计 |
| 后验众数 | $\text{Mode}[\theta|D]$ | MAP估计 |
| 后验方差 | $\text{Var}[\theta|D]$ | 不确定性 |

### 可信区间

$$P(\theta \in [a,b]|D) = 1-\alpha$$

可以直接说"参数有95%的概率在区间内"。

## 贝叶斯假设检验

### 贝叶斯因子

$$BF_{10} = \frac{P(D|H_1)}{P(D|H_0)}$$

| BF值 | 含义 |
|------|------|
| > 100 | 极强证据支持H₁ |
| 30-100 | 很强证据 |
| 10-30 | 强证据 |
| 3-10 | 中等证据 |
| 1-3 | 弱证据 |
| 1 | 无证据 |

### 后验概率

$$P(H_1|D) = \frac{P(D|H_1)P(H_1)}{P(D|H_1)P(H_1)+P(D|H_0)P(H_0)}$$

## 贝叶斯线性回归

### 模型

$$Y = X\beta + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$

$$\beta \sim N(\mu_0, \Sigma_0)$$

### 后验

$$\beta|Y \sim N(\mu_n, \Sigma_n)$$

$$\Sigma_n = (\Sigma_0^{-1} + \frac{1}{\sigma^2}X^TX)^{-1}$$

$$\mu_n = \Sigma_n(\Sigma_0^{-1}\mu_0 + \frac{1}{\sigma^2}X^TY)$$

## 先验的影响

### 数据量与先验

- 小样本：先验影响大
- 大样本：数据主导后验

```
先验         后验         似然
  │           │            │
  ▼           ▼            ▼
┌─────┐    ┌─────┐      ┌─────┐
│     │ +  │     │  →   │     │
└─────┘    └─────┘      └─────┘
先验       数据         后验=两者折中
```

### 敏感性分析

检查不同先验对后验的影响。

## 与频率学派的比较

| 方面 | 频率学派 | 贝叶斯学派 |
|------|----------|-----------|
| 优点 | 客观、标准 | 直观、灵活 |
| 缺点 | 解释困难 | 主观性 |
| 小样本 | 困难 | 利用先验信息 |
| 计算 | 简单 | 复杂（MCMC） |
| 解释 | 长期频率 | 直接概率 |

## 常见误区

1. **先验是主观的**：可以用弱信息先验减少主观性
2. **贝叶斯=主观**：大样本时后验主要由数据决定
3. **混淆可信区间和置信区间**：解释不同
4. **忽视先验敏感性**：应检查不同先验的影响
