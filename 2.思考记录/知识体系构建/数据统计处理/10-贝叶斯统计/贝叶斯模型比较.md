# 贝叶斯模型比较

> 用贝叶斯方法比较不同模型的优劣。

---

## 贝叶斯因子

### 定义

$$BF_{10} = \frac{P(D|M_1)}{P(D|M_0)}$$

- $P(D|M)$：模型M的边际似然
- $BF_{10} > 1$：支持M₁
- $BF_{10} < 1$：支持M₀

### 解读

| BF值 | 含义 |
|------|------|
| > 100 | 极强证据支持M₁ |
| 30-100 | 很强证据 |
| 10-30 | 强证据 |
| 3-10 | 中等证据 |
| 1-3 | 弱证据 |
| 1 | 无证据 |
| 1/3-1 | 弱证据支持M₀ |
| 1/10-1/3 | 中等证据支持M₀ |
| < 1/10 | 强证据支持M₀ |

---

## 边际似然

### 定义

$$P(D|M) = \int P(D|\theta, M) P(\theta|M) d\theta$$

### 计算方法

| 方法 | 描述 | 适用 |
|------|------|------|
| 解析 | 共轭先验 | 简单模型 |
| 拉普拉斯近似 | 正态近似 | 大样本 |
| 调和均值 | MCMC采样 | 通用 |
| 桥接采样 | MCMC采样 | 通用 |
| 重要性采样 | 重采样 | 通用 |

---

## 信息准则

### 适用于模型比较

| 准则 | 公式 | 特点 |
|------|------|------|
| DIC | $-2\ln L + 2p_D$ | 贝叶斯AIC |
| WAIC | 广义信息准则 | 更稳健 |
| LOO-CV | 留一交叉验证 | 最可靠 |

### LOO-CV

$$\text{LOO} = \sum_{i=1}^{n} \ln P(y_i | y_{-i})$$

用PSIS近似计算。

---

## 后验模型概率

### 定义

$$P(M_k|D) = \frac{P(D|M_k)P(M_k)}{\sum_j P(D|M_j)P(M_j)}$$

### 假设等先验

$$P(M_k|D) = \frac{P(D|M_k)}{\sum_j P(D|M_j)}$$

---

## 模型平均

### 定义

$$P(\theta|D) = \sum_k P(\theta|M_k, D) P(M_k|D)$$

### 优点

- 考虑模型不确定性
- 更稳健的预测

---

## 模型检查

### 后验预测检查

```
1. 从后验中抽取参数
2. 用参数生成模拟数据
3. 比较模拟数据与观测数据
```

### PPC图

```
观测数据  · · · · · · ·
模拟数据  ─────────────
          应该重叠
```

---

## 实际应用

### 步骤

```
1. 定义候选模型
2. 为每个模型设定先验
3. 计算后验
4. 计算模型比较指标
5. 选择最佳模型或模型平均
```

## 常见误区

1. **只看贝叶斯因子**：应结合后验预测检查
2. **不做模型检查**：模型可能拟合不好
3. **忽视计算误差**：边际似然计算可能不稳定
4. **过度依赖自动化**：应结合领域知识
