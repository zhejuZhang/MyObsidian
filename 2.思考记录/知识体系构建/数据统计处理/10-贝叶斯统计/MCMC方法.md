# MCMC方法

> 马尔可夫链蒙特卡洛方法，用于从复杂后验分布中采样。

---

## 基本概念

### 问题

后验分布 $P(\theta|D)$ 通常没有解析形式，需要数值方法。

### 思想

构建一个马尔可夫链，其平稳分布就是目标后验分布。

### 蒙特卡洛

用随机采样来近似积分。

$$E[\theta|D] \approx \frac{1}{S}\sum_{s=1}^{S}\theta^{(s)}$$

---

## 主要算法

### Metropolis-Hastings算法

#### 步骤

```
1. 初始化 θ⁰
2. 对于 s = 1, 2, ..., S:
   a. 从提议分布 q(θ*|θ^(s-1)) 生成候选 θ*
   b. 计算接受概率：
      α = min(1, [P(θ*|D)q(θ^(s-1)|θ*)] / [P(θ^(s-1)|D)q(θ*|θ^(s-1))])
   c. 以概率 α 接受 θ*：
      θ^(s) = θ*  (以概率 α)
      θ^(s) = θ^(s-1)  (以概率 1-α)
```

#### 特点

- 通用，适用于任何分布
- 需要选择提议分布
- 可能混合缓慢

### Gibbs采样

#### 步骤

```
1. 初始化所有参数
2. 对于 s = 1, 2, ..., S:
   对于每个参数 θ_j:
     从条件分布 P(θ_j|θ_{-j}, D) 采样
```

#### 特点

- 使用条件分布
- 接受率为1
- 需要知道条件分布
- 适用于多参数模型

### Hamiltonian Monte Carlo（HMC）

#### 思想

引入辅助动量变量，用哈密顿动力学指导采样。

#### 优点

- 高维空间效率高
- 相关性低

#### 缺点

- 需要调参
- 计算梯度

## 诊断

### 收敛诊断

| 方法 | 描述 | 标准 |
|------|------|------|
| 迹图 | 参数值随迭代变化 | 应平稳 |
| Gelman-Rubin | 多链比较 | R̂ < 1.1 |
| 有效样本量 | 独立样本数 | ESS > 100 |
| Geweke | 前后比较 | p > 0.05 |

### 迹图

```
θ
  │  ╱╲  ╱╲╱╲  ╱╲  ╱╲╱╲
  │ ╱  ╲╱      ╲╱  ╲╱    ╲╱
  └────────────────────────── 迭代
   预热期    采样期
```

### 混合

- 快速混合：链快速探索参数空间
- 慢速混合：链在局部徘徊

---

## 预热（Burn-in）

### 目的

丢弃初始样本，让链达到平稳分布。

### 预热期

- 通常丢弃前10-50%的样本
- 通过迹图判断

---

## 稀释（Thinning）

### 目的

减少样本间的相关性。

### 方法

每隔k个样本保留一个。

### 注意

- 稀释会减少有效样本量
- 现代观点：不稀释更好，保留所有样本

## 实际应用

### 步骤

```
1. 建立模型
   └── 指定似然和先验
        │
2. 选择算法
   └── Metropolis, Gibbs, HMC
        │
3. 运行MCMC
   └── 多条链，足够迭代
        │
4. 诊断
   └── 检查收敛
        │
5. 推断
   └── 后验统计量和区间
```

---

## 常见问题

### 高相关性

参数高度相关时混合缓慢。

**解决**：重新参数化、HMC

### 多峰分布

链可能被困在局部模式。

**解决**：并行回火、多次运行

### 维度灾难

高维空间效率低。

**解决**：HMC、有效参数化

## 常见误区

1. **链太短**：需要足够的迭代才能收敛
2. **不检查收敛**：未收敛的结果不可靠
3. **过度稀释**：保留所有样本通常更好
4. **单条链**：应该运行多条链检查收敛
