# 先验分布选择

> 先验分布是贝叶斯统计的核心，选择合适的先验是建模的关键。

---

## 先验的类型

### 无信息先验（Non-informative Prior）

尽量不影响后验，让数据说话。

| 类型 | 描述 | 示例 |
|------|------|------|
| 均匀先验 | 所有值等概率 | $\theta \sim U(0,1)$ |
| Jeffreys先验 | 参数化不变 | $\theta^{-1/2}(1-\theta)^{-1/2}$ |
| 参考先验 | 最大化信息增益 | 依赖模型 |

### 弱信息先验（Weakly Informative Prior）

施加弱约束，排除不合理值。

| 示例 | 含义 |
|------|------|
| $\theta \sim N(0, 100^2)$ | 均值附近，但很宽 |
| $\sigma \sim \text{Half-Cauchy}(0, 5)$ | 正数，但允许大值 |

### 信息先验（Informative Prior）

基于已有知识或专家意见。

| 来源 | 示例 |
|------|------|
| 先前研究 | 使用meta分析结果 |
| 专家意见 | 专家提供的分布 |
| 理论约束 | 物理定律约束 |

## 共轭先验

### 定义

先验和后验属于同一分布族。

### 常见共轭对

| 似然 | 共轭先验 | 后验 |
|------|----------|------|
| 二项 $Bin(n,p)$ | $Beta(\alpha,\beta)$ | $Beta(\alpha+x, \beta+n-x)$ |
| 泊松 $Pois(\lambda)$ | $Gamma(\alpha,\beta)$ | $Gamma(\alpha+\sum x_i, \beta+n)$ |
| 正态（已知方差） | $N(\mu_0, \sigma_0^2)$ | 正态 |
| 指数 $Exp(\lambda)$ | $Gamma(\alpha,\beta)$ | $Gamma(\alpha+n, \beta+\sum x_i)$ |
| 多项 | Dirichlet | Dirichlet |

### Beta先验示例

$$p \sim Beta(\alpha, \beta)$$

- $\alpha = \beta = 1$：均匀先验
- $\alpha = \beta > 1$：集中在0.5附近
- $\alpha > \beta$：偏向1
- $\alpha < \beta$：偏向0

## 先验敏感性分析

### 为什么做

检查先验选择对后验的影响。

### 方法

| 方法 | 描述 |
|------|------|
| 多先验比较 | 用不同先验拟合 |
| 先验预测检查 | 从先验模拟数据 |
| 后验稳健性 | 后验是否随先验变化 |

### 先验预测检查

```
1. 从先验中抽取参数
2. 用参数生成模拟数据
3. 检查模拟数据是否合理
```

## 实用建议

### 选择流程

```
有先前信息？
├── 是 → 信息先验
└── 否
      │
      ▼
需要约束？
├── 是 → 弱信息先验
└── 否 → 无信息先验
```

### 常见场景

| 场景 | 推荐先验 |
|------|----------|
| 比例参数 | Beta |
| 正数参数 | Half-Normal, Half-Cauchy |
| 均值参数 | Normal |
| 方差参数 | Half-Cauchy, Inverse-Gamma |
| 回归系数 | Normal, Laplace |

---

## 常见误区

1. **总是用无信息先验**：有时信息先验更好
2. **先验太强**：数据量小时先验影响大
3. **不做敏感性分析**：应检查先验的影响
4. **先验不合理**：先验预测检查很重要
