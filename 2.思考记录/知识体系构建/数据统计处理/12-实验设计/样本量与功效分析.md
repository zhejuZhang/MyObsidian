# 样本量与功效分析

> 确定合适的样本量是实验设计的关键步骤。

---

## 基本概念

### 统计功效

$$\text{Power} = 1 - \beta = P(\text{拒绝} H_0 | H_1 \text{为真})$$

- 通常要求 ≥ 0.80
- 功效越高，检测真实效应的能力越强

### 四个关键参数

| 参数 | 含义 | 通常设定 |
|------|------|----------|
| α | 第一类错误率 | 0.05 |
| β | 第二类错误率 | 0.20 |
| 效应大小 δ | 最小可检测效应 | 领域知识 |
| n | 样本量 | 待计算 |

**关系**：知道其中三个，可以计算第四个。

---

## 样本量计算

### 单样本均值检验

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \sigma^2}{\delta^2}$$

- δ：最小可检测差异
- σ：标准差

### 双样本均值检验

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot 2\sigma^2}{\delta^2}$$

每组需要n个样本。

### 单样本比例检验

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 p_0(1-p_0)}{(p_1-p_0)^2}$$

### 双样本比例检验

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 [p_1(1-p_1)+p_2(1-p_2)]}{(p_1-p_2)^2}$$

## 效应大小

### Cohen's效应大小

| 检验 | 小 | 中 | 大 |
|------|-----|-----|-----|
| 均值检验（d） | 0.2 | 0.5 | 0.8 |
| 相关（r） | 0.1 | 0.3 | 0.5 |
| 方差分析（f） | 0.1 | 0.25 | 0.4 |
| 卡方（w） | 0.1 | 0.3 | 0.5 |

### 如何确定效应大小

| 方法 | 描述 |
|------|------|
| 领域知识 | 有实际意义的最小差异 |
| 先前研究 | 参考已有研究 |
| 预实验 | 小规模预实验 |
| Cohen's标准 | 通用参考标准 |

## 实际考虑

### 调整因素

| 因素 | 调整 |
|------|------|
| 脱落率 | 增加10-20%样本量 |
| 多重比较 | 校正α或增加样本量 |
| 协变量 | 可减少所需样本量 |
| 分层 | 每层需要足够样本 |

## 功效不足的后果

| 后果 | 影响 |
|------|------|
| 假阴性 | 真实效应检测不到 |
| 资源浪费 | 实验无法得出结论 |
| 伦理问题 | 受试者承受风险但无收益 |

## 常见误区

1. **不做功效分析**：样本量随意确定
2. **效应大小不合理**：太小需要巨大样本，太大可能不现实
3. **忽视脱落率**：实际样本量会减少
4. **过度追求功效**：样本量过大会浪费资源
