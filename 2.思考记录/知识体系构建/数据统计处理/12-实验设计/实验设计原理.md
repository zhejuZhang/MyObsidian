# 实验设计原理

> 良好的实验设计是获得可靠结论的基础。

---

## 基本原则

### Fisher三原则

| 原则 | 含义 | 目的 |
|------|------|------|
| **重复** | 每个处理多次观测 | 估计误差 |
| **随机化** | 随机分配处理 | 消除偏差 |
| **局部控制** | 区组设计 | 减少误差 |

### 重复

- 估计实验误差
- 提高估计精度
- 增加统计功效

### 随机化

- 消除系统性偏差
- 使统计推断有效
- 平衡已知和未知混杂因素

### 局部控制

- 通过区组减少误差
- 提高处理效应的检测能力

## 实验设计类型

### 完全随机设计（CRD）

```
处理A: ● ● ● ●
处理B: ○ ○ ○ ○
处理C: △ △ △ △

随机分配
```

- 最简单的设计
- 无区组效应
- 适用于同质实验单元

### 随机化区组设计（RCBD）

```
区组1: A B C
区组2: B C A
区组3: C A B

每个区组包含所有处理
```

- 控制区组效应
- 减少误差
- 适用于异质实验单元

### 拉丁方设计

```
    列1  列2  列3
行1  A    B    C
行2  B    C    A
行3  C    A    B

同时控制行和列效应
```

### 因子设计

同时研究多个因素。

| 设计 | 因素 | 水平组合 |
|------|------|----------|
| 2²设计 | 2因素，各2水平 | 4种组合 |
| 2³设计 | 3因素，各2水平 | 8种组合 |
| 3²设计 | 2因素，各3水平 | 9种组合 |

## 处理与因素

### 术语

| 术语 | 定义 | 示例 |
|------|------|------|
| 因素 | 影响响应的变量 | 药物、温度 |
| 水平 | 因素的不同取值 | 药物A/B、高温/低温 |
| 处理 | 因素水平的组合 | 药物A+高温 |
| 响应 | 观测的结果 | 治愈率 |

## 样本量确定

### 影响因素

| 因素 | 影响 |
|------|------|
| 效应大小 | 效应越小，需要样本越大 |
| 显著性水平α | α越小，需要样本越大 |
| 统计功效1-β | 功效越高，需要样本越大 |
| 变异性 | 变异越大，需要样本越大 |

### 功效分析

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot 2\sigma^2}{\delta^2}$$

- δ：最小可检测效应
- σ：标准差
- α：显著性水平
- β：第二类错误概率

---

## 混杂与交互

### 混杂因素

与处理因素相关的影响响应的变量。

**控制方法**：
- 随机化
- 区组设计
- 协方差分析

### 交互效应

一个因素的效应取决于另一个因素的水平。

**示例**：药物A对男性更有效，药物B对女性更有效。

## 盲法

| 类型 | 描述 | 目的 |
|------|------|------|
| 单盲 | 受试者不知道处理 | 减少安慰剂效应 |
| 双盲 | 受试者和研究者都不知道 | 减少主观偏差 |
| 三盲 | 受试者、研究者、分析者都不知道 | 最严格 |

## 伦理考虑

| 原则 | 含义 |
|------|------|
| 知情同意 | 受试者了解并同意 |
| 风险最小化 | 最小化受试者风险 |
| 公平选择 | 公平选择受试者 |
| 独立审查 | 伦理委员会审查 |

## 实验 vs 观察研究

| 维度 | 实验 | 观察研究 |
|------|------|----------|
| 干预 | 研究者施加 | 无干预 |
| 因果 | 可推断因果 | 只能推断关联 |
| 随机化 | 有 | 无 |
| 控制 | 高 | 低 |

## 常见误区

1. **不做功效分析**：样本量不足导致功效低
2. **忽视混杂因素**：导致因果推断无效
3. **不做随机化**：引入系统性偏差
4. **忽视伦理**：必须考虑受试者权益
