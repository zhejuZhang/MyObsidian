# 置信区间

> 置信区间是参数估计的核心工具，它量化了估计的不确定性。

---

## 置信区间的核心思想

### 点估计的局限

```
点估计：μ ≈ 50
问题：这个50有多可靠？
```

### 置信区间的优势

```
置信区间：μ ∈ [45.87, 54.13]（95%置信）
信息：估计值 + 不确定性范围
```

---

## 置信区间的构造

### 通用公式

$$\text{CI} = \text{点估计} \pm \text{临界值} \times \text{标准误差}$$

### 各参数的置信区间

| 参数 | 点估计 | 标准误差 | 临界值 | 条件 |
|------|--------|----------|--------|------|
| 均值μ（σ已知） | $\bar{x}$ | $\sigma/\sqrt{n}$ | $z_{\alpha/2}$ | 正态或大样本 |
| 均值μ（σ未知） | $\bar{x}$ | $s/\sqrt{n}$ | $t_{\alpha/2,n-1}$ | 正态或大样本 |
| 比例p | $\hat{p}$ | $\sqrt{\hat{p}(1-\hat{p})/n}$ | $z_{\alpha/2}$ | $np≥5, n(1-p)≥5$ |
| 方差σ² | $s^2$ | — | $\chi^2$ | 正态总体 |
| 均值差μ₁-μ₂ | $\bar{x}_1-\bar{x}_2$ | $\sqrt{s_1^2/n_1+s_2^2/n_2}$ | $t_{\alpha/2,df}$ | 独立样本 |
| 比例差p₁-p₂ | $\hat{p}_1-\hat{p}_2$ | $\sqrt{\hat{p}_1(1-\hat{p}_1)/n_1+\hat{p}_2(1-\hat{p}_2)/n_2}$ | $z_{\alpha/2}$ | 大样本 |

## 置信水平的含义

### 正确理解

```
95%置信水平 = 如果重复抽样100次，
             约95个置信区间会包含真实参数
```

```
第1次抽样:  ├────[45.87, 54.13]────┤  ✓ 包含μ
第2次抽样:  ├──[43.2, 51.8]──┤        ✓ 包含μ
第3次抽样:    ├──[48.1, 56.7]──┤      ✓ 包含μ
...
第96次:      ├──[52.3, 60.9]──┤       ✗ 不包含
...
100次中约95次包含，约5次不包含
```

### 错误理解

- "μ有95%的概率在[45.87, 54.13]中" — 错误
- μ是固定的，要么在区间内，要么不在

## 置信区间的宽度

### 影响因素

$$\text{宽度} = 2 \times \text{临界值} \times \frac{s}{\sqrt{n}}$$

| 因素 | 变化 | 对宽度的影响 |
|------|------|-------------|
| 样本量n | 增大 | 变窄（精确度提高） |
| 置信水平 | 增大 | 变宽（需要更大范围） |
| 标准差s | 增大 | 变宽（数据更分散） |

### 样本量与宽度的关系

```
宽度 ∝ 1/√n

n=25  → 宽度 = W
n=100 → 宽度 = W/2
n=400 → 宽度 = W/4
```

要将宽度减半，需要4倍的样本量。

## 置信区间与假设检验

### 等价关系

对于双尾检验 $H_0: \mu = \mu_0$：

$$\mu_0 \notin \text{CI}_{1-\alpha} \iff \text{拒绝} H_0 \text{ at level } \alpha$$

### 置信区间的优势

| 只用假设检验 | 用置信区间 |
|-------------|-----------|
| 只知道是否显著 | 知道效应大小和精度 |
| p值大小难以解释 | 区间范围直观 |
| 样本量影响p值 | 区间直接反映不确定性 |

## 置信区间的类型

### 参数置信区间

对总体参数（均值、比例、方差等）的区间估计。

### 预测区间

对单个未来观测值的区间估计：

$$\hat{y}_0 \pm t_{\alpha/2,n-2} \cdot s\sqrt{1 + \frac{1}{n} + \frac{(x_0-\bar{x})^2}{\sum(x_i-\bar{x})^2}}$$

比置信区间更宽（包含个体变异）。

### 容忍区间

包含总体中指定比例数据的区间。

## Bootstrap置信区间

当分布假设不满足时，用重抽样方法构造置信区间。

### 步骤

```
1. 从样本中有放回地抽取n个观测值
2. 计算统计量（如均值）
3. 重复B次（B ≥ 1000）
4. 用B个统计量的分布构造区间
```

### 方法

| 方法 | 公式 | 特点 |
|------|------|------|
| 百分位法 | [θ*_(α/2), θ*_(1-α/2)] | 简单 |
| BCa法 | 校正偏差和偏斜 | 更准确 |
| 基本法 | $2\hat{\theta} - \theta^*_{(1-\alpha/2)}$ | 基于pivot |

## 贝叶斯可信区间

### 与频率学派置信区间的区别

| | 频率学派置信区间 | 贝叶斯可信区间 |
|---|---|---|
| 解释 | 区间包含参数的概率（长期频率） | 参数在区间内的概率 |
| 参数 | 固定的 | 随机变量 |
| 依赖 | 抽样分布 | 先验 + 数据 |

### 贝叶斯可信区间

$$P(\theta \in [a,b] | \text{data}) = 1-\alpha$$

可以直接说"参数有95%的概率在区间内"。

## 常见误区

1. **误解置信水平**：不是"参数在区间内的概率"
2. **只看点估计**：应同时报告置信区间
3. **忽视假设条件**：t区间需要正态性或大样本
4. **混淆置信区间和预测区间**：预测区间包含个体变异，更宽
5. **认为窄区间一定好**：可能只是样本量大，不代表估计准确
