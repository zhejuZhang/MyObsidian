# 抽样分布与中心极限定理

> 中心极限定理是统计推断的基石，它解释了为什么正态分布如此重要。

---

## 抽样分布

### 定义

**抽样分布**（Sampling Distribution）是某个统计量在所有可能样本中的概率分布。

```
总体 (μ, σ²)
    │
    ├──→ 样本1 → x̄₁
    ├──→ 样本2 → x̄₂
    ├──→ 样本3 → x̄₃
    │    ...
    └──→ 样本k → x̄ₖ

x̄₁, x̄₂, ..., x̄ₖ 的分布 = 样本均值的抽样分布
```

### 样本均值的抽样分布

如果从总体中抽取所有大小为n的样本：

- **期望**：$E(\bar{X}) = \mu$（无偏）
- **标准误差**：$SE = \frac{\sigma}{\sqrt{n}}$
- **分布形状**：取决于总体分布和样本量

---

## 中心极限定理（Central Limit Theorem, CLT）

### 定理内容

无论总体分布是什么形状，当样本量 $n$ 足够大时，样本均值 $\bar{X}$ 的分布近似正态：

$$\bar{X} \xrightarrow{d} N\left(\mu, \frac{\sigma^2}{n}\right)$$

即：

$$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} N(0,1)$$

### "足够大"的标准

| 总体分布 | 建议最小样本量 |
|----------|---------------|
| 正态分布 | 任意n |
| 轻度偏斜 | n ≥ 15-20 |
| 中度偏斜 | n ≥ 30 |
| 严重偏斜 | n ≥ 40-50 |
| 极端分布 | n ≥ 100+ |

> [!tip] 经验法则
> n ≥ 30 是常用的"大样本"标准，但这只是粗略指南。

### 直观理解

```
总体分布（任意形状）    样本均值的分布（n足够大）
    ┌──┐                  ╱╲
    │  │                 ╱  ╲
  ┌─┤  ├──┐             ╱    ╲
  │ │  │  │            ╱      ╲
──┴─┴──┴──┴──         ───────────
                    近似正态！
```

### 为什么重要？

1. **不需要知道总体分布**：只要n足够大，就能用正态分布做推断
2. **适用于任何统计量**：均值、比例、方差等
3. **奠定了假设检验和置信区间的基础**

## 其他统计量的抽样分布

### 样本比例的抽样分布

$$\hat{p} \sim N\left(p, \frac{p(1-p)}{n}\right)$$

条件：$np \geq 5$ 且 $n(1-p) \geq 5$

### 样本方差的抽样分布

$$\frac{(n-1)s^2}{\sigma^2} \sim \chi^2(n-1)$$

### 两个样本均值之差的抽样分布

$$\bar{X}_1 - \bar{X}_2 \sim N\left(\mu_1 - \mu_2, \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}\right)$$

---

## 标准误差

### 定义

统计量的抽样分布的标准差称为**标准误差**（Standard Error）。

| 统计量 | 标准误差公式 |
|--------|-------------|
| 均值 | $SE = \frac{\sigma}{\sqrt{n}} \approx \frac{s}{\sqrt{n}}$ |
| 比例 | $SE = \sqrt{\frac{p(1-p)}{n}}$ |
| 均值之差 | $SE = \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$ |

### 标准差 vs 标准误差

| | 标准差（SD） | 标准误差（SE） |
|---|---|---|
| 描述对象 | 数据的离散程度 | 统计量的离散程度 |
| 含义 | 个体间的变异 | 估计的精度 |
| 公式 | $s = \sqrt{\frac{\sum(x_i-\bar{x})^2}{n-1}}$ | $SE = \frac{s}{\sqrt{n}}$ |
| 样本量增大 | 不变 | 减小 |

---

## 大数定律（LLN）

### 定义

当 $n \to \infty$ 时，样本均值收敛于总体均值：

$$\bar{X}_n \xrightarrow{P} \mu$$

### 与CLT的关系

| | 大数定律 | 中心极限定理 |
|---|---|---|
| 回答什么 | 样本均值收敛到哪里？ | 样本均值的分布形状？ |
| 结论 | $\bar{X} \to \mu$ | $\bar{X} \sim N(\mu, \sigma^2/n)$ |
| 提供信息 | 收敛性 | 分布形状和精度 |

---

## 有限总体校正

当抽样比 $n/N > 0.05$（抽样比例超过5%）时：

$$SE = \frac{\sigma}{\sqrt{n}} \times \sqrt{\frac{N-n}{N-1}}$$

校正因子 $\sqrt{\frac{N-n}{N-1}} < 1$，说明从有限总体抽样时误差更小。

## 常见误区

1. **混淆总体分布和抽样分布**：总体可以是任何形状，但样本均值的分布趋向正态
2. **忽视样本量要求**：小样本时CLT不适用，需要总体正态性假设
3. **混淆标准差和标准误差**：两者描述不同的东西
4. **认为CLT意味着总体变正态**：CLT只说均值的分布变正态，总体不变
