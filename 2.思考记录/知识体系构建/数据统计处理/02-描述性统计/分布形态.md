# 分布形态

> 数据分布的"形状"决定了哪些统计方法适用。

---

## 为什么关注分布形态？

- 决定使用哪些描述统计量
- 影响假设检验方法的选择
- 判断正态性假设是否成立
- 发现数据中的模式和异常

---

## 偏度（Skewness）

衡量分布的**不对称程度**。

$$g_1 = \frac{\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^3}{\left[\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2\right]^{3/2}}$$

| 偏度值 | 含义 | 形态 | 典型数据 |
|--------|------|------|----------|
| = 0 | 完全对称 | 对称钟形 | 身高、考试分数 |
| > 0 | 右偏（正偏） | 右尾长 | 收入、房价、等待时间 |
| < 0 | 左偏（负偏） | 左尾长 | 考试满分限制、死亡年龄 |

**经验判断**：
- |偏度| < 0.5：近似对称
- 0.5 ≤ |偏度| < 1：中等偏斜
- |偏度| ≥ 1：严重偏斜

---

## 峰度（Kurtosis）

衡量分布的**尖锐程度和尾部厚度**。

$$g_2 = \frac{\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^4}{\left[\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2\right]^{2}} - 3$$

> [!note] 超额峰度
> 上面公式减去了3，称为**超额峰度**（Excess Kurtosis）。正态分布的超额峰度 = 0。

| 峰度值 | 含义 | 形态 | 特征 |
|--------|------|------|------|
| = 0 | 正态峰度 | 标准钟形 | 标准正态分布 |
| > 0 | 尖峰（Leptokurtic） | 尖而瘦 | 尾部厚，极端值多 |
| < 0 | 平峰（Platykurtic） | 平而宽 | 尾部薄，极端值少 |

```
        ▲ 尖峰
       ╱╲
      ╱  ╲
     ╱    ╲
────╱──────╲────  正态
──╱──────────╲──  平峰
```

## 正态性检验

### 图形方法

| 方法 | 描述 | 判断标准 |
|------|------|----------|
| **直方图** | 频次分布图 | 是否呈钟形 |
| **Q-Q图** | 分位数 vs 理论分位数 | 点是否在对角线上 |
| **箱线图** | 五数概括可视化 | 是否对称，有无异常值 |
| **P-P图** | 累积概率 vs 理论概率 | 点是否在对角线上 |

### 统计检验方法

| 检验 | 适用样本量 | 优点 | 缺点 |
|------|-----------|------|------|
| **Shapiro-Wilk** | n < 5000 | 小样本功效高 | 大样本不适用 |
| **Kolmogorov-Smirnov** | 通用 | 适用范围广 | 对中间敏感 |
| **Anderson-Darling** | 通用 | 对尾部敏感 | 计算复杂 |
| **Jarque-Bera** | 大样本 | 基于偏度峰度 | 大样本才准确 |
| **D'Agostino-Pearson** | n ≥ 20 | 综合偏度峰度 | 需要一定样本量 |

> [!tip] 实用建议
> - 小样本（n < 50）：用 Shapiro-Wilk + Q-Q图
> - 大样本（n > 100）：图形方法为主（大样本检验过于敏感）
> - 中等样本：多种方法结合使用

### Q-Q图的解读

```
理论分位数
    │      ╱╱
    │    ╱╱
    │  ╱╱     ← 点在直线上 = 正态
    │╱╱
    └──────── 样本分位数

    │    ╱╱╱  ← 右端上翘 = 右偏
    │  ╱╱
    │╱╱

    │ ╱╱      ← S形曲线 = 尾部异常
    │╱
    │╲
    │ ╲╲
    └────────
```

## 常见分布形态

### 对称分布
- 正态分布
- t分布
- 均匀分布

### 右偏分布
- 指数分布
- 卡方分布
- 对数正态分布
- 泊松分布（小λ）

### 多峰分布
- 混合分布
- 可能暗示存在子群体

## 偏斜数据的处理

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| **对数变换** | $y = \ln(x)$ | 右偏数据 |
| **平方根变换** | $y = \sqrt{x}$ | 轻度右偏 |
| **Box-Cox变换** | 自动选择最佳变换 | 一般偏斜 |
| **使用稳健统计量** | 中位数、IQR | 任何偏斜 |
| **非参数方法** | 不假设分布 | 严重偏斜 |

## 常见误区

1. **忽视偏度选错方法**：严重偏斜数据使用均值±标准差描述是不恰当的
2. **过度依赖正态性检验**：大样本时几乎所有检验都显著，应结合图形判断
3. **混淆峰度和方差**：峰度描述形状，方差描述尺度，两者不同
4. **多峰分布用单一指标**：多峰分布的均值和中位数可能都不在峰上
