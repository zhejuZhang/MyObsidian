# 地理加权回归 GWR 与 MGWR

> 上位概念：[[00-空间分析知识体系总索引]] > 理论基石
> 前置知识：[[地理学第二定律与空间异质性]]
> 相关概念：[[地理探测器Geodetector]]、[[地理加权随机森林GWRF]]

---

## 1. 概述

**地理加权回归（Geographically Weighted Regression, GWR）** 由 Alexander Fotheringham 等人发展，旨在克服传统全局回归模型（如OLS）对**参数空间恒定假设**的局限。GWR通过引入空间权重矩阵，允许回归系数随空间位置坐标 $(u_i, v_i)$ 的改变而动态变化，从而有效捕获**空间局域非平稳性**。

## 2. GWR模型

### 2.1 数学表达式

$$y_i = \beta_0(u_i, v_i) + \sum_{k=1}^{p} \beta_k(u_i, v_i) x_{ik} + \epsilon_i$$

| 参数 | 含义 |
|------|------|
| $y_i$ | 位置 $i$ 的因变量值 |
| $\beta_0(u_i, v_i)$ | 位置 $i$ 的局域截距 |
| $\beta_k(u_i, v_i)$ | 位置 $i$ 的第 $k$ 个变量的局域回归系数 |
| $x_{ik}$ | 位置 $i$ 的第 $k$ 个自变量值 |
| $\epsilon_i$ | 误差项 |

### 2.2 参数估计

GWR使用**加权最小二乘法（WLS）** 进行参数估计：

$$\hat{\beta}(u_i, v_i) = (X^T W(u_i, v_i) X)^{-1} X^T W(u_i, v_i) Y$$

其中 $W(u_i, v_i)$ 是以位置 $(u_i, v_i)$ 为中心的空间权重对角矩阵。

### 2.3 空间权重函数

| 核函数 | 公式 | 特点 |
|--------|------|------|
| **高斯核** | $w_{ij} = \exp\left(-\frac{d_{ij}^2}{2h^2}\right)$ | 平滑衰减 |
| **双平方核** | $w_{ij} = \left[1 - \left(\frac{d_{ij}}{h}\right)^2\right]^2$ (当 $d_{ij} < h$) | 带宽外权重为0 |
| **指数核** | $w_{ij} = \exp\left(-\frac{d_{ij}}{h}\right)$ | 指数衰减 |

### 2.4 带宽选择

**带宽（Bandwidth）** $h$ 控制局域估计的空间范围：

| 带宽类型 | 说明 |
|----------|------|
| **固定带宽** | 所有位置使用相同的带宽值 |
| **自适应带宽** | 数据密集区带宽小，稀疏区带宽带宽大 |

**选择准则：**
- **AICc（修正赤池信息准则）**：最常用
- **交叉验证（CV）**：最小化预测误差
- **BIC（贝叶斯信息准则）**

## 3. GWR的局限性

| 局限性 | 说明 |
|--------|------|
| **单一带宽假设** | 所有变量在同一空间尺度下运作 |
| **多重共线性** | 局部参数间可能存在共线性 |
| **过度拟合** | 带宽过小导致过拟合 |
| **推断困难** | 局部参数的标准误和假设检验不完善 |
| **计算复杂度** | 大样本时计算量大 |

## 4. 多尺度地理加权回归（MGWR）

### 4.1 核心改进

**MGWR（Multiscale Geographically Weighted Regression）** 的核心创新：

> 允许模型中的**每一个协变量拥有独立优化的带宽**

这意味着：
- 宏观全局过程 → 大带宽
- 微观局域过程 → 小带宽
- 不同变量可以在不同空间尺度上运作

### 4.2 数学表达式

$$y_i = \beta_{bw_0}(u_i, v_i) + \sum_{k=1}^{p} \beta_{bw_k}(u_i, v_i) x_{ik} + \epsilon_i$$

其中 $bw_k$ 表示第 $k$ 个变量的独立带宽。

### 4.3 MGWR的理论框架

通过将GWR重构为**广义相加模型（GAM）**，MGWR完善了：
- 局部参数估计的**标准误**
- **假设检验**统计推断框架
- 参数显著性的局域评估

### 4.4 MGWR vs GWR

| 特性 | GWR | MGWR |
|------|-----|------|
| 带宽数量 | 1个（所有变量共享） | p+1个（每个变量独立） |
| 空间尺度 | 单一尺度 | 多尺度 |
| 全局vs局域 | 仅局域 | 全局+局域 |
| 推断能力 | 有限 | 完善的统计推断 |
| 计算复杂度 | 较低 | 较高（迭代优化） |

## 5. 实证应用

### 5.1 房价评估

- **问题**：房价影响因素在不同区域的作用不同
- **方法**：MGWR分析交通、学区、环境等因素的局域效应
- **发现**：核心区与郊区的房价驱动机制存在显著差异

### 5.2 电动汽车普及率

- **问题**：EV普及率的时空演变规律
- **方法**：时空MGWR分析政策、基础设施、收入等因素
- **发现**：不同因素在不同地区的影响力存在尺度差异

## 6. PySAL中的实现

在 [[PySAL空间分析Python生态]] 中，`mgwr` 模块提供GWR和MGWR实现：

```python
from mgwr.gwr import GWR
from mgwr.sel_bw import Sel_BW

# 带宽选择
selector = Sel_BW(coords, y, X)
bw = selector.search(criterion='AICc')

# GWR拟合
model = GWR(coords, y, X, bw)
results = model.fit()

# 结果
results.params  # 局部参数估计
results.bse     # 局部标准误
results.tvalues # 局部t值
```

## 7. GWR与其他局部模型的关系

| 方法 | 类型 | 特点 |
|------|------|------|
| GWR | 参数局部回归 | 线性、单尺度 |
| MGWR | 参数局部回归 | 线性、多尺度 |
| GWRF | 非参数局部模型 | 非线性、集成学习 |
| LISA | 局部空间关联 | 描述性、无回归 |
