## 1. 概述

空间自相关指标是量化[[地理学第一定律与空间依赖性]]的核心工具，用于评估空间数据中属性值的集聚、离散或随机分布趋势。分为**全局指标**和**局部指标**两大类。

## 2. 全局空间自相关指标

全局指标评估整个研究区域内属性值的**总体空间模式**。

### 2.1 Moran's I 莫兰指数

**最广泛使用的全局空间自相关指标**。

$$I = \frac{n}{\sum_{i}\sum_{j} w_{ij}} \cdot \frac{\sum_{i}\sum_{j} w_{ij}(x_i - \bar{x})(x_j - \bar{x})}{\sum_{i}(x_i - \bar{x})^2}$$

| 参数         | 含义             |
| ---------- | -------------- |
| $n$        | 空间单元数量         |
| $x_i, x_j$ | 单元 $i, j$ 的属性值 |
| $\bar{x}$  | 属性均值           |
| $w_{ij}$   | 空间权重矩阵元素       |

**取值范围与解释：**

| 取值范围          | 空间模式 | 含义             |
| ------------- | ---- | -------------- |
| $I > 0$       | 正自相关 | 相似值聚集（高-高、低-低） |
| $I \approx 0$ | 随机分布 | 无显著空间模式        |
| $I < 0$       | 负自相关 | 相异值聚集（高-低、低-高） |

**假设检验：**
- 原假设 $H_0$：空间随机分布
- 通过Z检验或置换检验评估显著性
- $Z_I = \frac{I - E[I]}{\sqrt{Var(I)}}$

### 2.2 Geary's C

**对局部差异更敏感的全局指标**。

$$C = \frac{(n-1)}{2\sum_{i}\sum_{j} w_{ij}} \cdot \frac{\sum_{i}\sum_{j} w_{ij}(x_i - x_j)^2}{\sum_{i}(x_i - \bar{x})^2}$$

**与Moran's I的区别：**

| 特性 | Moran's I | Geary's C |
|------|-----------|-----------|
| 分子 | 协方差 $(x_i - \bar{x})(x_j - \bar{x})$ | 平方差 $(x_i - x_j)^2$ |
| 取值范围 | [-1, 1] | [0, 2] |
| 正自相关 | $I > 0$ | $C < 1$ |
| 负自相关 | $I < 0$ | $C > 1$ |
| 局部敏感性 | 对全局模式更敏感 | 对局部差异更敏感 |

### 2.3 Getis-Ord General G 高低聚类

- 专门用于检测**高值聚集**还是**低值聚集**
- 不像Moran's I只能检测"相似值聚集"
- $G = \frac{\sum_{i}\sum_{j} w_{ij} x_i x_j}{\sum_{i}\sum_{j} x_i x_j}$

## 3. 局部空间自相关指标（LISA）

**Local Indicators of Spatial Association**，由 Luc Anselin 创立，是探索性空间数据分析（ESDA）的核心工具。

### 3.1 局部Moran's I（Local Moran's I）

$$I_i = \frac{(x_i - \bar{x})}{S^2} \sum_{j} w_{ij}(x_j - \bar{x})$$

其中 $S^2 = \frac{1}{n}\sum_{i}(x_i - \bar{x})^2$

**性质：**
- 全局Moran's I是局部Moran's I的加权平均：$I = \frac{\sum_i I_i}{n}$
- 每个空间单元都有一个局部指标值
- 可以进行逐单元的显著性检验

### 3.2 局部Getis-Ord Gi*

$$G_i^* = \frac{\sum_{j} w_{ij} x_j - \bar{x} \sum_{j} w_{ij}}{S \sqrt{\frac{n \sum_{j} w_{ij}^2 - (\sum_{j} w_{ij})^2}{n-1}}}$$

**与局部Moran's I的区别：**
- Gi* 包含单元自身值，局部Moran's I不包含
- Gi* 更适合检测**热点/冷点**，局部Moran's I更适合检测空间异常值

### 3.3 Moran散点图（Moran Scatterplot）

**四象限分类：**

```
        空间滞后 (Lag)
             ↑
    LH       |       HH
  (低-高异常) |  (高-高聚类/热点)
             |
 ────────────┼────────────→ 属性值
    LL       |       HL
  (低-低聚类/冷点) | (高-低异常)
             |
```

| 象限 | 含义 | 空间模式 |
|------|------|----------|
| **HH（高-高）** | 高值被高值包围 | 热点（Hot Spot） |
| **LL（低-低）** | 低值被低值包围 | 冷点（Cold Spot） |
| **HL（高-低）** | 高值被低值包围 | 空间异常值 |
| **LH（低-高）** | 低值被高值包围 | 空间异常值 |

**Moran散点图的回归线斜率 = 全局Moran's I系数**

### 3.4 LISA显著性检验

- 通过**置换检验（Permutation Test）** 评估局部指标的显著性
- 常用显著性水平：$\alpha = 0.05, 0.01, 0.001$
- **多重检验问题**：同时检验多个单元时需要校正
  - Bonferroni校正
  - FDR（False Discovery Rate）校正

## 4. 探索性空间数据分析（ESDA）

ESDA是一组用于**发现空间数据中模式和关系**的技术集合。

### 4.1 ESDA的核心工具

| 工具 | 功能 | 输出 |
|------|------|------|
| Moran散点图 | 可视化全局/局部空间关联 | 四象限分类 |
| LISA聚类图 | 显著性空间聚类/异常 | 显著性地图 |
| 热点分析（Hot Spot） | 检测热点和冷点 | Gi* 统计量地图 |
| 半变异函数 | 空间依赖性随距离变化 | 变异函数图 |
| 协方差函数 | 空间协方差结构 | 协方差图 |

### 4.2 ESDA工作流程

```
数据探索
├── 1. 构建空间权重矩阵
├── 2. 计算全局空间自相关（Moran's I / Geary's C）
│   └── 判断是否存在整体空间模式
├── 3. 计算局部空间自相关（LISA）
│   ├── Moran散点图
│   └── LISA聚类图
├── 4. 热点分析（Gi*）
└── 5. 空间回归建模（如需要）
    ├── 空间滞后模型（SLM）
    └── 空间误差模型（SEM）
```

## 5. PySAL中的实现

在 [[PySAL空间分析Python生态]] 中，`esda` 模块提供了完整的ESDA工具：

```python
from pysal.lib import weights
from pysal.explore import esda

# 构建空间权重矩阵
w = weights.Queen.from_dataframe(gdf)  # 邻接矩阵
w.transform = 'r'  # 行标准化

# 全局Moran's I
moran = esda.Moran(gdf['variable'], w)
print(f"Moran's I: {moran.I}, p-value: {moran.p_sim}")

# 局部Moran's I (LISA)
lisa = esda.Moran_Local(gdf['variable'], w)
lisa.q  # 四象限分类
lisa.p_sim  # 显著性
```

## 6. 空间自相关的检验前提

| 前置检验 | 目的 |
|----------|------|
| **空间随机性检验** | 确认数据存在空间模式 |
| **正态性检验** | Moran's I的推断基于正态假设 |
| **权重矩阵选择** | 不同权重矩阵产生不同结果 |
| **尺度敏感性分析** | 检查结果是否随尺度变化 |
