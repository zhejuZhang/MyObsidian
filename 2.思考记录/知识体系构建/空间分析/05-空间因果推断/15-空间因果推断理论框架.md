# 空间因果推断理论框架

> 上位概念：[[00-空间分析知识体系总索引]] > 空间因果推断
> 相关概念：[[SUTVA假设与空间溢出效应]]、[[空间混杂与去混杂方法]]、[[空间因果发现算法]]

## 1. 概述

尽管GeoAI大幅提升了地理现象的预测精度，但在政策评估、流行病溯源与环境治理中，**"为什么（Why）"** 远比**"预测什么（What）"** 更为重要。机器学习长于捕捉相关性特征，但在面对**反事实推断**时往往无能为力。

空间分析知识体系正经历一场**"因果革命"**，向**空间因果推断（Spatial Causal Inference）** 与**空间因果发现（Spatial Causal Discovery）** 的纵深挺进。

## 2. 两大理论框架

### 2.1 Rubin潜在结果框架（Potential Outcomes Framework）

**核心概念：**

| 概念 | 定义 | 符号 |
|------|------|------|
| **潜在结果** | 个体在不同处理状态下的结果 | $Y_i(1), Y_i(0)$ |
| **处理效应** | 两种潜在结果之差 | $\tau_i = Y_i(1) - Y_i(0)$ |
| **平均处理效应（ATE）** | 所有个体处理效应的期望 | $\tau = E[Y_i(1) - Y_i(0)]$ |
| **因果推断根本问题** | 每个个体只能观测到一种潜在结果 | 反事实不可观测 |

**因果效应估计：**

$$\hat{\tau} = E[Y|A=1] - E[Y|A=0]$$

需要满足：**可忽略性假设（Ignorability）**——给定协变量X，处理分配A与潜在结果独立。

### 2.2 Pearl因果有向无环图（Causal DAGs）

**核心概念：**

| 概念 | 定义 |
|------|------|
| **有向无环图（DAG）** | 表示因果关系的有向图，无环 |
| **do算子** | 干预操作，$do(A=a)$ 表示强制设置A=a |
| **因果效应** | $P(Y|do(A=a))$，干预后的结果分布 |
| **后门准则** | 识别混杂变量的条件集 |
| **前门准则** | 通过中介变量识别因果效应 |

**因果效应识别：**

$$P(Y|do(A=a)) = \sum_c P(Y|A=a, C=c) P(C=c)$$

其中C是满足后门准则的混杂变量集。

## 3. 空间因果推断的独特挑战

### 3.1 空间数据的特殊性

| 挑战 | 说明 | 传统因果推断的假设 |
|------|------|-------------------|
| **空间溢出** | 干预通过空间传播影响邻近单元 | SUTVA假设独立性 |
| **空间混杂** | 未观测的空间结构变量同时影响干预和结果 | 可忽略性假设 |
| **空间自相关** | 观测值不独立 | IID假设 |
| **尺度依赖** | 因果关系可能随尺度变化 | 尺度无关 |

### 3.2 传统方法的失效

- **随机实验**：空间溢出导致处理污染
- **倾向得分匹配**：空间混杂导致匹配偏误
- **工具变量**：空间依赖性影响排除限制
- **断点回归**：空间边界效应

## 4. 空间因果推断的方法体系

### 4.1 应对空间溢出

- **重新定义分析单元**：考虑邻域干预状态
- **分离直接效应与溢出效应**
- 详见 [[SUTVA假设与空间溢出效应]]

### 4.2 应对空间混杂

- **Spatial+**：残差分离方法
- **谱调整**：频域滤波方法
- **空间去混杂器**：深度学习方法
- 详见 [[空间混杂与去混杂方法]]

### 4.3 因果发现

- **FCI算法**：处理隐变量的因果发现
- **currentFCI**：融合物理先验的因果发现
- 详见 [[空间因果发现算法]]

## 5. 空间因果推断的应用

| 应用领域 | 研究问题 | 方法 |
|----------|----------|------|
| **政策评估** | 交通设施对房价的因果效应 | 空间RDD |
| **流行病学** | 疫苗接种的区域保护效应 | 空间溢出效应模型 |
| **环境科学** | 污染排放对健康的影响 | 空间去混杂器 |
| **犯罪学** | 警力部署对犯罪率的因果效应 | 空间断点回归 |
| **选举研究** | 媒体覆盖对投票行为的影响 | 空间因果发现 |

## 6. 与传统空间分析的关系

| 传统空间分析 | 空间因果推断 |
|-------------|-------------|
| 描述空间模式 | 揭示因果机制 |
| 相关性分析 | 因果效应估计 |
| 预测建模 | 反事实推理 |
| Moran's I、GWR | ATE、因果DAG |

**从"是什么"到"为什么"的范式转变。**
