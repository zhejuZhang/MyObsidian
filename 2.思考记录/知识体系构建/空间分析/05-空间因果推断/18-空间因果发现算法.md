# 空间因果发现算法

> 上位概念：[[00-空间分析知识体系总索引]] > 空间因果推断
> 前置知识：[[空间因果推断理论框架]]
> 相关概念：[[空间混杂与去混杂方法]]

## 1. 概述

如果因果推断是估计已有假说下的效应规模，那么**因果发现（Causal Discovery）** 则是从观测性时空大数据中直接**"挖掘"出因果有向无环图（DAG）**，寻找自然界与社会的底层运行框架。

## 2. 经典因果发现算法

### 2.1 PC算法

- **假设**：因果充分性（所有相关变量已被观测）
- **方法**：条件独立性检验 + 图搜索
- **输出**：因果DAG（部分有向）
- **局限**：在面对复杂地球系统时常常给出错误的有向边

### 2.2 FCI算法（Fast Causal Inference）

- **适用**：存在隐变量的环境
- **核心优势**：不强行得出结论
- **输出**：**部分祖先图（PAG）**

#### PAG的边类型

| 边类型 | 含义 |
|--------|------|
| $\rightarrow$ | 确定的因果方向 |
| $\leftrightarrow$ | 存在未观测共因 |
| $\circ \rightarrow$ | 方向不确定 |
| $\circ - \circ$ | 关系不确定 |

#### FCI的局限

- 地球系统数据存在极强的**时间自相关**与**空间邻接依赖**
- 不加控制地运行标准FCI，极易因过度条件独立检验导致因果边的**大面积丢失（低召回率）**

## 3. 融合物理先验的衍生算法

### 3.1 currentFCI算法（河流网络背景因果发现）

#### 核心思想

由 Mielke 等人提出，将系统**物理属性**直接编入因果骨架提取流程。

#### 算法流程

```
1. 数据分区
   ├── 上游 U
   ├── 下游 I
   ├── 局部 R
   └── 外生变量 O

2. 引入物理先验
   └── "原因不可能逆流而上"的定向先验

3. 屏蔽无物理意义的边缘测试
   └── 大幅减少独立性检验次数

4. 运行FCI
   └── 在物理约束下进行因果发现
```

#### 核心优势

| 优势 | 说明 |
|------|------|
| **计算效率** | 屏蔽无意义检验，计算成倍提升 |
| **避免假阴性** | 物理约束防止因果边丢失 |
| **逻辑严密性** | 因果结构符合物理规律 |

#### 适用场景

- 具有明确**平流方向**的空间网络
- 河流汇流系统
- 风系输送系统
- 交通流网络

### 3.2 其他衍生算法

| 算法 | 特点 | 适用场景 |
|------|------|----------|
| **FCI+** | 改进的条件独立性检验 | 一般隐变量环境 |
| **CD-NOD** | 处理非稳态数据 | 时空变化环境 |
| **PCMCI** | 时间序列因果发现 | 时间因果关系 |
| **PCMCI+** | 扩展到空间数据 | 时空因果关系 |

## 4. 开源软件生态

### 4.1 causal-learn（Python）

- **功能**：PC、FCI、GES等算法的行业标准级实现
- **特点**：API调用接口、可视化工具
- **维护**：CMU CLeaR团队

```python
from causallearn.search.ConstraintBased.FCI import fci
from causallearn.utils.GraphUtils import GraphUtils

# FCI因果发现
g, edges = fci(data, alpha=0.05)

# 可视化
pdy = GraphUtils.to_pydot(g)
pdy.write_png('causal_graph.png')
```

### 4.2 SpEDM（R语言）

- **功能**：基于经验动态建模的因果发现
- **适用**：气象波动、生物种群交互
- **特点**：非线性动态系统

### 4.3 SVAR-FM

- **功能**：流匹配结合模拟器物理干预机制
- **适用**：时序因果发现框架
- **特点**：融合物理模拟器

### 4.4 SpaCE评估工具包

- **功能**：空间混杂评估基准环境
- **特点**：内建真实健康、气象反事实数据集
- **用途**：新算法鲁棒性测评

## 5. 空间因果发现的挑战

| 挑战 | 说明 | 应对策略 |
|------|------|----------|
| **隐变量** | 未观测变量影响因果结构 | FCI、PAG |
| **空间依赖** | 样本不独立 | 物理先验约束 |
| **时间自相关** | 时序数据的自相关 | PCMCI |
| **计算复杂度** | 高阶条件独立检验 | 物理约束减少检验 |
| **评估困难** | 真实因果结构未知 | SpaCE基准测试 |

## 6. 应用案例

### 6.1 河流网络因果发现

- **问题**：河流水质变量间的因果关系
- **方法**：currentFCI
- **先验**：水从上游流向下游
- **发现**：揭示污染物传播的因果路径

### 6.2 气候系统因果发现

- **问题**：气候变量间的因果网络
- **方法**：PCMCI+
- **挑战**：强时间自相关
- **发现**：ENSO与区域气候的因果链

### 6.3 生态系统因果发现

- **问题**：物种-环境因果关系
- **方法**：FCI + 生态先验
- **挑战**：隐变量（未观测环境因素）
- **发现**：物种共存的因果机制
