# SUTVA假设与空间溢出效应

> 上位概念：[[00-空间分析知识体系总索引]] > 空间因果推断
> 前置知识：[[空间因果推断理论框架]]
> 相关概念：[[空间混杂与去混杂方法]]

---

## 1. 概述

在经典因果推断中，**"稳定单元处理值假设（SUTVA）"** 是估算平均处理效应（ATE）的前提。然而，地理空间具有天然的连通性，干预不可避免地会通过物理邻接、风向平流或社会网络产生强烈的**波及或溢出效应**。

## 2. SUTVA假设

### 2.1 定义

**SUTVA（Stable Unit Treatment Value Assumption）** 包含两个子假设：

| 子假设 | 含义 | 空间情境下的违反 |
|--------|------|-----------------|
| **无干扰** | 每个个体的潜在结果独立于其他个体的干预分配 | 空间溢出导致干扰 |
| **无多重版本** | 处理只有一种版本 | 空间异质性导致处理版本不同 |

### 2.2 空间情境下的崩溃

```
SUTVA假设
├── 无干扰假设 → 空间溢出（Spillover）
│   ├── 物理邻接：相邻单元相互影响
│   ├── 扩散效应：污染物、传染病
│   └── 社会网络：信息、行为传播
└── 无多重版本 → 空间异质性
    ├── 同一处理在不同地方效果不同
    └── 环境差异导致处理异质性
```

## 3. 空间溢出效应的类型

### 3.1 外生溢出（Exogenous Spillovers）

- **定义**：干预的溢出效应不受接收者控制
- **示例**：为某村庄配置移动信号基站，邻近村庄的选民越界举报
- **特征**：溢出是干预的"副作用"

### 3.2 内生溢出（Endogenous Spillovers）

- **定义**：行为主体战略性地响应干预
- **示例**：腐败官员将舞弊行为战略性地转移至无基站监测的相邻地区
- **特征**：溢出是行为主体的"策略行为"

### 3.3 溢出效应的方向

| 方向 | 说明 | 示例 |
|------|------|------|
| **空间溢出** | 通过物理邻接传播 | 邻近区域的污染扩散 |
| **网络溢出** | 通过社会网络传播 | 朋友间的信息传播 |
| **时间溢出** | 通过时间延续 | 政策的滞后效应 |

## 4. 空间因果效应的分解

### 4.1 重新定义分析单元

基于单元网格或区域的**局部干预分配集合**，将因果目标量分解为：

### 4.2 平均直接效应（Average Direct Effect）

$$\tau_{dir} = E[Y_s(1, a_{Ns}) - Y_s(0, a_{Ns})]$$

- **含义**：在锁定邻域干预状态 $a_{Ns}$ 不变的前提下，仅改变本地干预状态 $A_s$ 所导致的本地结果变化量期望
- **解释**：干预对接受者的"直接"影响

### 4.3 平均溢出效应（Average Spillover Effect）

$$\tau_{spill} = E[Y_s(a_s, 1) - Y_s(a_s, 0)]$$

- **含义**：在维持本地干预状态不变的前提下，通过改变邻域干预状态所产生的外部结果影响
- **解释**：干预对非接受者的"间接"影响

### 4.4 总效应分解

$$\tau_{total} = \tau_{dir} + \tau_{spill}$$

## 5. 估计方法

### 5.1 断点回归设计（Spatial RDD）

- **适用**：存在空间边界的干预分配
- **方法**：利用边界处的不连续性识别因果效应
- **结合**：局部线性回归分离直接与溢出效应

### 5.2 广义倾向得分匹配

- **改进**：纳入**空间干预距离衰减权重**
- **方法**：根据与干预源的距离调整匹配权重
- **优势**：考虑溢出效应的衰减特征

### 5.3 空间差分法（Spatial DID）

- **方法**：结合空间权重矩阵的双重差分
- **适用**：政策评估中的空间溢出
- **公式**：$Y_{it} = \alpha + \beta D_{it} + \gamma \sum_j w_{ij} D_{jt} + \delta X_{it} + \epsilon_{it}$

## 6. 应用案例

### 6.1 阿富汗大选反欺诈监测

- **干预**：为村庄配置移动信号基站
- **直接效应**：降低该村庄的选举舞弊
- **溢出效应**：
  - 外生：邻近村庄选民越界举报
  - 内生：腐败官员转移舞弊行为

### 6.2 污染治理

- **干预**：某区域实施排放限制
- **直接效应**：该区域空气质量改善
- **溢出效应**：污染产业转移至邻近区域

### 6.3 传染病疫苗接种

- **干预**：某社区疫苗接种
- **直接效应**：接种者获得免疫
- **溢出效应**：区域保护效应（群体免疫）

## 7. 挑战与局限

| 挑战 | 说明 |
|------|------|
| **溢出范围不确定** | 难以确定溢出的影响半径 |
| **效应分离困难** | 直接效应与溢出效应难以完全分离 |
| **数据需求高** | 需要空间邻接关系和干预分配数据 |
| **模型复杂** | 空间溢出模型参数多、计算复杂 |
