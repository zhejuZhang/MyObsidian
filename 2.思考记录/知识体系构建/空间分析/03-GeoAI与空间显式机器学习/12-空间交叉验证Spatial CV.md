# 空间交叉验证 Spatial CV

> 上位概念：[[00-空间分析知识体系总索引]] > GeoAI与空间显式机器学习
> 相关概念：[[空间显式模型与空间表征学习]]、[[地理加权随机森林GWRF]]

---

## 1. 概述

伴随GeoAI广泛应用而来的是严峻的**模型评估偏差问题**。传统的十折随机交叉验证（Random CV）在处理存在空间自相关的地理数据时，会引发极其严重的**"空间泄漏（Spatial Leakage）"** 现象。空间交叉验证（Spatial CV）是解决这一问题的标准评估规范。

## 2. 空间泄漏问题

### 2.1 问题根源

[[地理学第一定律与空间依赖性|地理学第一定律]] 的存在导致：

- 随机划分极易导致训练集与测试集样本在物理空间上**互为邻居**
- 邻居样本具有**高度相似的环境属性**
- 模型在训练阶段已经**"提前偷看"** 了测试数据的规律

### 2.2 后果

| 问题 | 说明 |
|------|------|
| **精度虚高** | 报告的预测精度无法真实反映模型能力 |
| **泛化失真** | 无法评估模型在未见区域的泛化能力 |
| **过度乐观** | 模型选择偏向过拟合空间记忆的方案 |

### 2.3 直观示例

```
随机CV（存在空间泄漏）：
┌─────────────────────────┐
│  训练 ●  测试 ○  训练 ●  │
│  测试 ○  训练 ●  测试 ○  │  ← 训练和测试样本空间相邻
│  训练 ●  测试 ○  训练 ●  │
└─────────────────────────┘

空间CV（切断空间相邻）：
┌─────────────────────────┐
│  训练 ●  训练 ●  测试 ○  │
│  训练 ●  训练 ●  测试 ○  │  ← 测试集在独立空间区块
│  训练 ●  训练 ●  测试 ○  │
└─────────────────────────┘
```

## 3. 空间交叉验证策略

### 3.1 聚类式空间CV（Clustering-based Spatial CV）

- **方法**：利用K-Means等空间聚类算法将研究区划分为若干簇
- **流程**：每次保留一个簇作为独立测试集，其余簇作为训练集
- **优势**：自适应数据分布
- **参数**：簇数量K的选择

### 3.2 网格划分空间CV（Grid-based Spatial CV）

- **方法**：基于规则地理网格划分数据
- **适用**：大尺度遥感分析（如海洋叶绿素a浓度反演）
- **关键**：通过**空间自相关图（Correlograms）** 科学设定网格区块大小
- **目标**：确保块间**完全独立**

### 3.3 缓冲留一法（Spatial Leave-one-out CV）

- **方法**：在每次验证时，不仅剔除测试样本，还以该测试样本为中心建立一定半径的**缓冲区**
- **操作**：将缓冲区内的所有样本强制从训练集中排除
- **目的**：严格阻断局部空间自相关的影响
- **优势**：最严格的空间隔离

## 4. 空间自相关图（Correlogram）

用于科学确定空间CV的区块大小：

- **定义**：空间自相关系数随距离变化的函数图
- **用途**：确定空间自相关的**有效范围**
- **应用**：当距离超过自相关范围时，样本可视为独立

```
空间自相关系数
     ↑
  1  │●
     │ ●
     │  ●
     │   ●
     │    ●
  0  │─────────────────→ 距离
     │         ↑
     │    自相关范围（用于设定CV区块大小）
```

## 5. 空间CV的实施流程

```
1. 探索性分析
   ├── 计算空间自相关（Moran's I）
   └── 绘制空间自相关图

2. 确定CV策略
   ├── 选择空间CV类型（聚类/网格/缓冲）
   └── 确定区块大小（基于自相关范围）

3. 执行空间CV
   ├── 划分训练/测试集（确保空间隔离）
   ├── 训练模型
   └── 评估性能

4. 结果比较
   ├── 对比随机CV与空间CV的精度差异
   └── 差异越大，空间泄漏越严重
```

## 6. 评估指标

| 指标 | 适用任务 | 公式 |
|------|----------|------|
| **RMSE** | 回归 | $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$ |
| **MAE** | 回归 | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ |
| **R²** | 回归 | $1 - \frac{SS_{res}}{SS_{tot}}$ |
| **AUC** | 分类 | ROC曲线下面积 |
| **F1** | 分类 | $\frac{2 \cdot P \cdot R}{P + R}$ |

## 7. 实际意义

### 7.1 城市灾害应对

- 确保模型对**未见灾害区域**的预测可靠
- 避免因空间泄漏导致的过度乐观估计

### 7.2 大尺度生态预测

- 评估模型对**新区域**的泛化能力
- 支持可靠的置信度估计

### 7.3 模型选择

- 空间CV提供**无偏的模型性能估计**
- 避免选择过拟合空间记忆的模型

## 8. 与随机CV的对比

| 特性 | 随机CV | 空间CV |
|------|--------|--------|
| 数据划分 | 随机 | 空间隔离 |
| 空间泄漏 | 严重 | 无 |
| 精度估计 | 乐观偏差 | 无偏 |
| 泛化评估 | 不可靠 | 可靠 |
| 计算成本 | 低 | 较高 |
| 适用数据 | IID数据 | 空间数据 |
