## 知识体系全景架构

```
空间分析知识体系
├── 理论基石
│   ├── 地理学第一定律 → 空间依赖性 → Moran's I / LISA
│   └── 地理学第二定律 → 空间异质性 → Geodetector / GWR / MGWR
├── 软件生态
│   ├── UCGIS GIS&T BoK（标准化知识框架）
│   ├── GeoDa（可视化分析平台）
│   └── PySAL（Python生态系统）
├── GeoAI
│   ├── 空间显式模型（四项测试 + 位置编码器）
│   ├── GWRF / SE-KNN（空间非平稳性机器学习）
│   └── Spatial CV（对抗空间泄漏）
├── 城市应用
│   ├── 流动性与空间公平性
│   └── 气候适应与灾害响应
├── 因果推断
│   ├── 空间溢出效应（SUTVA失效 → 直接/溢出效应）
│   ├── 空间混杂（Spatial+ / 谱调整 / Deconfounder）
│   └── 因果发现（FCI / currentFCI / PAG）
└── 本体标准化
    ├── 国际：GIS&T BoK 知识图谱
    └── 国内：GB/T 42986 地理信息本体
```
