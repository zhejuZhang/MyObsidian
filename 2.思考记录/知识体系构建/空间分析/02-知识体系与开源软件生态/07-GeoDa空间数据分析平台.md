# GeoDa 空间数据分析平台

> 上位概念：[[00-空间分析知识体系总索引]] > 知识体系与开源软件生态

## 1. 概述

**GeoDa** 是由 Luc Anselin 教授（空间经济学奠基人之一）创立的**空间数据科学旗舰可视化分析平台**，脱胎于早期的 DynESDA 模块，现已独立发展并拥有超过 **63万** 全球用户。

## 2. 核心特性

### 2.1 动态链接与刷取技术

GeoDa的卓越之处在于深度整合了**动态链接与刷取技术（Dynamic Linking and Brushing）**：

- 在地图视图、散点图、直方图、平行坐标图之间**实时交互**
- 选择一个视图中的数据点，其他视图中对应点**同步高亮**
- 支持多变量的**条件探索**

### 2.2 核心功能模块

| 功能 | 说明 |
|------|------|
| **空间数据可视化** | 地图渲染、专题制图 |
| **探索性空间数据分析** | LISA热点图、Moran散点图 |
| **全局空间自相关** | Moran's I、Geary's C |
| **局部空间自相关** | LISA聚类、Gi*热点 |
| **空间回归建模** | 空间滞后模型、空间误差模型 |
| **空间权重矩阵** | 邻接、距离、K近邻 |

## 3. 空间回归模型

### 3.1 空间滞后模型（SLM）

$$y = \rho W y + X\beta + \epsilon$$

- $\rho$：空间自回归系数
- $W$：空间权重矩阵
- 捕获因变量的**空间依赖性**

### 3.2 空间误差模型（SEM）

$$y = X\beta + u, \quad u = \lambda W u + \epsilon$$

- $\lambda$：空间误差系数
- 捕获**误差项的空间依赖性**

### 3.3 估计方法

- **极大似然估计（MLE）**
- GeoDa内嵌了完整的参数估计与假设检验模块

## 6. 与PySAL的关系

| 特性 | GeoDa | PySAL |
|------|-------|-------|
| **界面** | 图形化 | 编程接口 |
| **语言** | C++ | Python |
| **定位** | 可视化分析 | 算法库与开发 |
| **用户** | 教学、实证研究 | 科研、工程开发 |
| **关系** | 概念先驱 | 功能扩展 |

两者由同一团队（Luc Anselin）主导开发，形成互补的生态系统。
