# GNSS高精度定位技术

> GNSS高精度定位技术是自动驾驶实现全局定位的基础，通过差分定位和精密单点定位实现厘米级精度。

---

## 一、基本概念

### 1.1 GNSS系统概述
全球导航卫星系统（GNSS）包括：
- **GPS**：美国系统，31颗卫星
- **BDS（北斗）**：中国系统，55颗卫星
- **GLONASS**：俄罗斯系统，24颗卫星
- **Galileo**：欧盟系统，30颗卫星

### 1.2 定位原理

#### 伪距定位
```
ρ = c × (t_receive - t_transmit) + errors
```
- **伪距**：卫星到接收机的距离测量值
- **误差源**：卫星钟差、接收机钟差、大气延迟、多路径

#### 载波相位定位
```
Φ = λ × N + φ + errors
```
- **载波相位**：更精确的距离测量
- **整周模糊度**：需要求解的整数N
- **精度**：毫米级测量精度

### 1.3 在自动驾驶中的应用

#### 全局定位
- **绝对定位**：确定车辆在全球坐标系中的位置
- **航迹推算**：提供连续的位置更新
- **地图匹配**：与高精地图匹配定位

#### 航向确定
- **双天线测航向**：通过两个天线确定航向角
- **多普勒测速**：通过多普勒频移测量速度

## 二、差分定位技术

### 2.1 差分GPS（DGPS）

#### 原理
- **基准站**：已知精确坐标的参考站
- **差分改正**：基准站计算伪距改正数
- **用户应用**：用户应用改正数提高精度

#### 精度
- **伪距差分**：亚米级精度（0.5-1m）
- **载波相位差分**：厘米级精度

#### RTK工作流程
```
基准站 → 差分数据链 → 流动站
   ↓                      ↓
已知坐标              载波相位观测
   ↓                      ↓
计算改正数            差分计算
   ↓                      ↓
发送改正数            模糊度固定
   ↓                      ↓
   └──── 实时通信 ────→ 厘米级定位
```

#### RTK精度
- **水平精度**：1-2cm
- **垂直精度**：2-3cm
- **初始化时间**：几秒到几十秒

## 四、大气延迟校正

### 4.1 电离层延迟

#### 电离层特性
- **高度**：50-1000km
- **影响**：与频率平方成反比
- **变化**：随太阳活动、地方时变化

#### 校正方法
- **双频消除**：利用双频观测量消除
- **模型改正**：Klobuchar模型、NeQuick模型
- **差分消除**：差分定位消除电离层延迟

### 4.2 对流层延迟

#### 对流层特性
- **高度**：0-50km
- **影响**：与频率无关
- **组成**：干分量（90%）和湿分量（10%）

#### 校正方法
- **模型改正**：Saastamoinen模型、Hopfield模型
- **参数估计**：估计对流层延迟参数
- **外部数据**：利用气象数据改正

### 4.3 多路径效应

#### 多路径特性
- **原因**：信号反射和散射
- **影响**：引起测量误差
- **特点**：与环境相关

#### 抑制方法
- **天线设计**：扼流圈天线、抑径板
- **信号处理**：窄相关器、多路径估计
- **后处理**：多路径建模和消除

### 6.1 定位系统架构

#### 典型架构
```
GNSS天线
    ↓
GNSS接收机
    ↓
惯性导航系统（IMU）
    ↓
惯性导航单元（INS）
    ↓
组合导航系统
    ↓
高精度定位输出
```

#### 系统组成
- **GNSS接收机**：接收卫星信号
- **IMU**：测量加速度和角速度
- **组合滤波器**：融合GNSS和INS数据
- **里程计**：提供辅助速度信息

### 6.2 组合导航

#### GNSS/INS组合
```python
class GNSSINSIntegration:
    """
    GNSS/INS组合导航
    """
    def __init__(self):
        self.gnss = GNSSReceiver()
        self.ins = INSUnit()
        self.filter = ExtendedKalmanFilter()
    
    def compute_position(self):
        # INS预测
        predicted_state = self.ins.propagate()
        # GNSS更新
        if self.gnss.has_update():
            corrected_state = self.filter.update(
                predicted_state, 
                self.gnss.get_measurement()
            )
        return corrected_state
```

#### 组合模式
- **松耦合**：GNSS和INS独立工作，结果融合
- **紧耦合**：GNSS原始观测量与INS融合
- **深耦合**：GNSS信号处理与INS深度融合

## 七、GNSS挑战与对策

### 7.1 信号遮挡

#### 城市峡谷问题
- **现象**：高楼遮挡卫星信号
- **影响**：卫星数量不足，几何分布差
- **对策**：多系统融合、惯性导航辅助

#### 隧道和地下
- **现象**：完全无GNSS信号
- **影响**：无法定位
- **对策**：惯性导航、里程计、视觉定位

### 7.2 多路径效应

#### 城市环境多路径
- **原因**：建筑物反射信号
- **影响**：定位误差增大
- **对策**：多路径抑制天线、信号处理

#### 动态多路径
- **原因**：车辆移动导致多路径变化
- **影响**：误差时变
- **对策**：动态多路径估计和消除

### 7.3 电离层扰动

#### 电离层暴
- **原因**：太阳活动剧烈
- **影响**：电离层延迟剧增
- **对策**：双频消除、模型改正

#### 极区电离层
- **特点**：电离层活动剧烈
- **影响**：定位精度下降
- **对策**：特殊改正模型
