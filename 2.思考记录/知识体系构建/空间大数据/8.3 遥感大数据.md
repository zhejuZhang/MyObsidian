# 遥感大数据

> 遥感大数据是利用卫星、航空等平台获取的对地观测数据，具有数据量大、多时相、多分辨率、多光谱等特点。

---

## 遥感数据类型

### 光学遥感

```
被动遥感: 接收地物反射的太阳辐射

特点:
- 光谱范围: 可见光、近红外、短波红外
- 分辨率: 0.3m ~ 30m
- 受云雨影响大

主要卫星:
- Landsat 系列: 30m, 16天重访
- Sentinel-2: 10m, 5天重访
- 高分系列: 亚米级
- WorldView: 0.3m
```

### 雷达遥感（SAR）

```
主动遥感: 主动发射微波并接收回波

特点:
- 全天候、全天时
- 穿透云层和植被
- 对地表粗糙度和介电常数敏感

主要卫星:
- Sentinel-1: C波段, 5-20m
- ALOS-2: L波段
- TerraSAR-X: X波段, 1m
```

### 高光谱遥感

```
连续光谱波段 (数十到数百个):

特点:
- 光谱分辨率高
- 物质精细识别能力
- 数据量大

应用:
- 矿物识别
- 植被健康监测
- 水质监测
```

### LiDAR

```
主动遥感: 发射激光脉冲测量距离

特点:
- 高精度三维点云
- 可获取植被结构
- 穿透能力有限

应用:
- 地形测量
- 森林资源调查
- 城市三维建模
```

## 遥感数据处理

### 辐射校正

```
消除传感器和大气的影响:

1. 传感器校正
   - 暗电流校正
   - 增益校正

2. 大气校正
   - 辐射传输模型 (6S, MODTRAN)
   - 基于暗目标的方法
   - 地表反射率反演
```

### 几何校正

```
消除几何畸变:

1. 系统校正
   - 利用卫星轨道参数
   - 地球自转校正

2. 精校正
   - 地面控制点 (GCP)
   - 多项式拟合
   - 正射校正 (DEM)
```

### 影像配准

```
多时相/多源影像的对齐:

方法:
1. 基于特征点的配准
   - SIFT, SURF, ORB 特征
   - 特征匹配 + 变换估计

2. 基于灰度的配准
   - 互相关
   - 互信息
```

### 影像融合

```
多分辨率影像融合:

全色 + 多光谱 → 高分辨率多光谱

方法:
- IHS 变换
- PCA 变换
- 小波变换
- 深度学习方法
```

### 深度学习分类

```python
import torch
import torch.nn as nn

class RSClassifier(nn.Module):
    """遥感影像分类 CNN"""
    def __init__(self, in_channels, num_classes):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(in_channels, 64, 3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(128, 256, 3, padding=1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.classifier = nn.Linear(256, num_classes)
    
    def forward(self, x):
        x = self.features(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x
```

## 变化检测

### 双时相变化检测

```
检测两个时间点之间的地表变化:

方法:
1. 差值法
   - 影像差值
   - 变化指数 (NDVI 差值)

2. 分类后比较
   - 分别分类
   - 比较分类结果

3. 深度学习
   - 双流网络
   - 注意力机制
```

### 时间序列变化检测

```
长时间序列的变化趋势分析:

方法:
1. 时间序列分解
   - 趋势项
   - 周期项
   - 残差项

2. 突变检测
   - BFAST 算法
   - 变点检测

3. 趋势分析
   - Mann-Kendall 检验
   - Sen's 斜率
```
