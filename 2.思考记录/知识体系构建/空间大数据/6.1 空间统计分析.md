# 空间统计分析

> 空间统计分析是研究空间数据的分布模式、关联关系和变异规律的统计方法，核心前提是空间数据具有空间自相关性。

---

## 空间自相关

### 概念

**空间自相关**（Spatial Autocorrelation）：空间上邻近的观测值倾向于相似（正相关）或不相似（负相关）。

**Tobler 地理学第一定律**："所有事物都与其他事物相关，但近处的事物比远处的事物更相关。"

### 全局空间自相关

**Moran's I 指数**：

```
I = (n / S₀) · Σᵢ Σⱼ wᵢⱼ(xᵢ - x̄)(xⱼ - x̄) / Σᵢ(xᵢ - x̄)²

其中:
- n: 观测数量
- wᵢⱼ: 空间权重矩阵元素
- S₀ = Σᵢ Σⱼ wᵢⱼ: 权重总和
- xᵢ, xⱼ: 观测值
- x̄: 均值

取值范围: [-1, 1]
- I > 0: 正空间自相关（聚集）
- I ≈ 0: 随机分布
- I < 0: 负空间自相关（离散）
```

**Geary's C 指数**：

```
C = (n-1) / (2S₀) · Σᵢ Σⱼ wᵢⱼ(xᵢ - xⱼ)² / Σᵢ(xᵢ - x̄)²

取值范围: [0, 2]
- C < 1: 正空间自相关
- C ≈ 1: 随机分布
- C > 1: 负空间自相关
```

### 局部空间自相关

**LISA（Local Indicators of Spatial Association）**：

```
局部 Moran's I:
Iᵢ = (xᵢ - x̄) / S² · Σⱼ wᵢⱼ(xⱼ - x̄)

聚类类型:
- HH (高-高): 高值被高值包围 (热点)
- LL (低-低): 低值被低值包围 (冷点)
- HL (高-低): 高值被低值包围 (异常)
- LH (低-高): 低值被高值包围 (异常)
```

**Getis-Ord Gi* 统计量**：

```
Gi* = Σⱼ wᵢⱼxⱼ / Σⱼ xⱼ

用于识别热点和冷点区域:
- Gi* > 0: 热点 (高值聚集)
- Gi* < 0: 冷点 (低值聚集)
```

## 空间权重矩阵

### 定义

空间权重矩阵 W 定义了空间对象之间的邻接关系：

```
W = [wᵢⱼ]ₙₓₙ

wᵢⱼ = 对象 i 和 j 之间的空间关系强度
```

### 构建方法

**邻接权重**：
```
二进制邻接:
wᵢⱼ = 1 如果 i 和 j 相邻
wᵢⱼ = 0 否则

邻接类型:
- Rook 邻接: 共享边
- Queen 邻接: 共享边或顶点
- Bishop 邻接: 仅共享顶点
```

**距离权重**：
```
反距离权重:
wᵢⱼ = 1 / dᵢⱼ^α

距离阈值:
wᵢⱼ = 1 如果 dᵢⱼ < d₀
wᵢⱼ = 0 否则

K 最近邻:
wᵢⱼ = 1 如果 j 是 i 的 K 个最近邻之一
```

**核权重**：
```
wᵢⱼ = K(dᵢⱼ / h)

K 为核函数，h 为带宽
常用核函数: 高斯核、Epanechnikov 核
```

## 空间插值

### 克里金法（Kriging）

基于空间自相关的最优无偏估计：

```
普通克里金 (Ordinary Kriging):

估计值: Ẑ(s₀) = Σᵢ λᵢZ(sᵢ)

权重 λᵢ 通过求解克里金方程组获得:
┌                    ┐ ┌     ┐   ┌       ┐
│ γ₁₁ γ₁₂ ... γ₁ₙ 1 │ │ λ₁  │   │ γ₁₀   │
│ γ₂₁ γ₂₂ ... γ₂ₙ 1 │ │ λ₂  │   │ γ₂₀   │
│ ...              ...│ │ ... │ = │ ...   │
│ γₙ₁ γₙ₂ ... γₙₙ 1 │ │ λₙ  │   │ γₙ₀   │
│  1   1  ...  1   0 │ │  μ  │   │  1    │
└                    ┘ └     ┘   └       ┘

γᵢⱼ: 半变异函数值
```

**半变异函数**（Semivariogram）：

```
γ(h) = 1/2N(h) · Σ[Z(sᵢ) - Z(sᵢ+h)]²

常用模型:
- 球状模型: γ(h) = c₀ + c·[1.5(h/a) - 0.5(h/a)³] for h ≤ a
- 指数模型: γ(h) = c₀ + c·[1 - exp(-h/a)]
- 高斯模型: γ(h) = c₀ + c·[1 - exp(-(h/a)²)]

参数:
- 块金值 (nugget): c₀
- 基台值 (sill): c₀ + c
- 变程 (range): a
```

### 反距离加权（IDW）

```
Ẑ(s₀) = Σᵢ [Z(sᵢ) / dᵢ₀^p] / Σᵢ [1 / dᵢ₀^p]

p: 幂参数 (通常取 2)
简单但不考虑空间自相关结构
```

### 样条函数

```
用光滑曲面拟合观测点:
- 薄板样条 (Thin Plate Spline)
- 规则样条 (Regularized Spline)
- 张力样条 (Tension Spline)
```

## 空间回归

### 空间滞后模型（SLM）

```
y = ρWy + Xβ + ε

ρ: 空间自回归系数
W: 空间权重矩阵
X: 解释变量
β: 回归系数
ε: 误差项

含义: 因变量受邻近区域因变量的影响
```

### 空间误差模型（SEM）

```
y = Xβ + u
u = λWu + ε

λ: 空间自相关系数
含义: 误差项存在空间自相关
```

### 地理加权回归（GWR）

```
允许回归系数随空间位置变化:

yᵢ = β₀(uᵢ, vᵢ) + Σₖ βₖ(uᵢ, vᵢ)xᵢₖ + εᵢ

(uᵢ, vᵢ): 位置坐标
βₖ(uᵢ, vᵢ): 位置 (uᵢ, vᵢ) 处的回归系数

局部回归，每个位置有不同的回归方程
```

## 空间点模式分析

### 点密度估计

```
核密度估计 (KDE):
λ̂(s) = Σᵢ K(s - sᵢ) / h²

K: 核函数
h: 带宽

用途: 识别点数据的聚集区域
```

### 最近邻分析

```
Clark-Evans 最近邻指数:
R = r̄ / r̄ₑ

r̄: 平均最近邻距离
r̄ₑ: 期望平均最近邻距离 (随机分布)

R < 1: 聚集分布
R ≈ 1: 随机分布
R > 1: 均匀分布
```

### Ripley's K 函数

```
K(h) = (1/λ) · E(距离 h 内的点数)

L(h) = √(K(h)/π) - h

L(h) > 0: 聚集
L(h) ≈ 0: 随机
L(h) < 0: 均匀

多尺度分析: 不同距离范围内的空间模式
```

## 空间统计在大数据中的应用

### 热点分析

```
Getis-Ord Gi* 在大数据中的应用:
1. 将数据聚合到网格
2. 计算每个网格的 Gi*
3. 识别显著的热点和冷点
4. 可视化热点分布
```

### 空间异质性分析

```
地理加权回归 (GWR) 的大数据扩展:
1. 局部回归: 每个位置独立回归
2. 带宽选择: 交叉验证
3. 并行计算: 每个位置的回归可并行
```

### 空间聚类趋势

```
Hopkins 统计量:
评估数据是否有聚类趋势

H = Σuᵢ / (Σuᵢ + Σwᵢ)

H > 0.5: 有聚类趋势
H ≈ 0.5: 随机分布
H < 0.5: 均匀分布
```
