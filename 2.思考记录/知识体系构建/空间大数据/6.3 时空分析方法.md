# 时空分析方法

> 时空分析是同时考虑空间和时间维度的数据分析方法，用于发现时空模式、预测时空演变。

---

## 时空数据模型

### 时空立方体

```
将时空数据组织为三维立方体:
- X 轴: 经度
- Y 轴: 纬度
- Z 轴: 时间

每个单元 (x, y, t) 记录属性值
支持时空切片、时空聚合等操作
```

### 时空点过程

```
时空点过程: 在时空域中随机分布的点集合

每个事件 = (位置, 时间, 类型)
示例: 犯罪事件、交通事故、疾病爆发

强度函数 λ(s, t):
时空点在位置 s 和时间 t 发生的期望率
```

### 轨迹模型

```
轨迹 = 时空点序列
T = {(s₁, t₁), (s₂, t₂), ..., (sₙ, tₙ)}

轨迹分段:
- 移动段: 持续移动
- 停留段: 在某位置停留

轨迹表示:
- 原始点序列
- 停留-移动序列
- 语义轨迹 (POI 序列)
```

## 时空统计

### 时空自相关

**时空 Moran's I**：

```
Iₛₜ = (n / S₀) · Σᵢ Σⱼ wᵢⱼ · vᵢⱼ · (xᵢ - x̄)(xⱼ - x̄) / Σᵢ(xᵢ - x̄)²

wᵢⱼ: 空间权重
vᵢⱼ: 时间权重
```

**时空 K 函数**：

```
K(s, t) = 在空间距离 s 和时间距离 t 内的期望事件数

用于检测时空聚集:
- K(s, t) > 随机期望: 时空聚集
- K(s, t) ≈ 随机期望: 时空随机
```

### 时空聚类

**SaTScan**：

```
用圆柱形窗口扫描时空域:
- 底面: 空间圆形窗口
- 高度: 时间窗口

对每个窗口计算似然比统计量
识别统计显著的时空聚类
```

**ST-DBSCAN**：

```
DBSCAN 的时空扩展:
- 空间邻域: ε_s
- 时间邻域: ε_t
- 时空密度: 同时满足空间和时间邻域条件
```

## 时空预测

### 时空克里金

```
时空克里金 (Spatiotemporal Kriging):

Ẑ(s₀, t₀) = Σᵢ λᵢ · Z(sᵢ, tᵢ)

权重 λᵢ 由时空半变异函数确定:

γ(s, t) = 1/2 · E[(Z(sᵢ, tᵢ) - Z(sᵢ+s, tᵢ+t))²]

时空半变异函数模型:
- 可分离模型: γ(s, t) = γₛ(s) · γₜ(t)
- 不可分离模型: 更复杂但更灵活
```

### 时空回归

```
地理加权回归的时间扩展 (GTWR):

yᵢ = β₀(uᵢ, vᵢ, tᵢ) + Σₖ βₖ(uᵢ, vᵢ, tᵢ)xᵢₖ + εᵢ

回归系数同时随空间和时间变化
```

### 时空序列预测

```
时空序列预测:
输入: 历史时空序列
输出: 未来时空状态

方法:
1. STARIMA (时空自回归移动平均)
   - 空间滞后 + 时间滞后
   - 考虑空间权重矩阵

2. 时空图神经网络
   - 将空间关系建模为图
   - 用 GNN 捕获空间依赖
   - 用 RNN/Transformer 捕获时间依赖

3. 时空 Transformer
   - 空间注意力: 不同位置的关联
   - 时间注意力: 不同时刻的关联
```

## 轨迹分析

### 轨迹预处理

```
1. 轨迹清洗
   - 去除噪声点 (速度异常)
   - 去除重复点
   - 插值缺失点

2. 轨迹压缩
   - Douglas-Peucker 算法
   - 垂直距离阈值
   - 保留关键形状特征

3. 轨迹分段
   - 停留点检测
   - 移动段识别
   - 语义标注
```

### 停留点检测

```
停留点: 在某位置停留超过阈值时间

方法 1: 距离阈值
  如果连续 N 个点的空间距离 < ε，则为停留点

方法 2: 时间窗口
  在时间窗口 T 内，如果所有点的空间范围 < ε，则为停留点
```

### 轨迹聚类

```
1. 轨迹距离度量
   - 欧氏距离: 对应点的距离之和
   - DTW (动态时间规整): 允许时间偏移
   - LCSS (最长公共子序列): 允许缺失
   - Hausdorff 距离: 点集间最大最小距离

2. 轨迹聚类方法
   - 层次聚类
   - DBSCAN (基于轨迹距离)
   - 轨迹聚类 (TRACLUS): 先分段再聚类
```

### 轨迹异常检测

```
轨迹异常类型:
1. 单点异常: 某个位置点异常
2. 子轨迹异常: 某段轨迹异常
3. 整条轨迹异常: 整条轨迹模式异常

检测方法:
1. 基于距离: 与其他轨迹距离远
2. 基于密度: 位于低密度区域
3. 基于预测: 预测残差大
```

## 时空模式发现

### 时空热点

```
时空热点: 在特定时间段内空间上聚集的区域

方法:
1. 时空扫描统计 (SaTScan)
2. 时空 Getis-Ord Gi*
3. 时空核密度估计

应用:
- 犯罪热点分析
- 疾病爆发检测
- 交通事故黑点
```

### 时空周期模式

```
检测时空数据中的周期性:

1. 时间周期
   - 傅里叶变换: 频域分析
   - 小波变换: 时频分析
   - 自相关函数: 延迟相关性

2. 空间周期
   - 空间自相关在不同距离的变化
   - 空间谱分析

3. 时空周期
   - 时空周期图
   - 时空小波分析
```

### 时空漂移

```
时空漂移: 空间模式随时间的变化

检测方法:
1. 滑动窗口分析
   - 在不同时间窗口内分析空间模式
   - 比较模式的变化

2. 变点检测
   - 检测空间分布发生变化的时间点

3. 时空趋势分析
   - 空间重心的移动轨迹
   - 空间扩展的方向和速度
```

## 大数据时空分析

### 分布式时空计算

```
挑战:
- 时空数据量大
- 时空计算复杂
- 数据分区困难

策略:
1. 时间分片 + 空间分区
   - 按时间分片
   - 每个时间片内按空间分区

2. 时空索引
   - 3D R-tree (空间+时间)
   - 时间分区 + 空间索引

3. 增量计算
   - 滑动窗口内增量更新
   - 避免重复计算
```

   - 实时异常检测

3. 实时时空预测
