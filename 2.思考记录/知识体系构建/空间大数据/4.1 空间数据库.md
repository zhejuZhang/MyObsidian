# 空间数据库

> 空间数据库是支持空间数据类型、空间索引和空间查询的数据库系统，是空间数据管理的核心基础设施。

---

## 概述

空间数据库在传统数据库基础上扩展了：
- **空间数据类型**：Point、LineString、Polygon 等
- **空间索引**：R-tree、Quad-tree 等
- **空间函数**：距离计算、拓扑判断、几何运算
- **空间查询**：范围查询、最近邻查询、空间连接

---

## 关系型空间数据库

### PostGIS

PostgreSQL 的空间扩展，最成熟的开源空间数据库：

```sql
-- 创建空间表
CREATE TABLE cities (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    geom GEOMETRY(Point, 4326)
);

-- 插入空间数据
INSERT INTO cities (name, geom)
VALUES ('北京', ST_SetSRID(ST_MakePoint(116.407, 39.904), 4326));

-- 空间查询：查找 100km 内的城市
SELECT name, ST_Distance(
    geom::geography,
    ST_SetSRID(ST_MakePoint(116.407, 39.904), 4326)::geography
) AS dist
FROM cities
WHERE ST_DWithin(
    geom::geography,
    ST_SetSRID(ST_MakePoint(116.407, 39.904), 4326)::geography,
    100000
);

-- 空间连接：查找某省内的所有城市
SELECT c.name, p.name AS province
FROM cities c
JOIN provinces p ON ST_Within(c.geom, p.geom);
```

**核心功能**：
- 几何类型：Point, LineString, Polygon, Multi*, GeometryCollection
- 地理类型：geography（球面计算）
- 空间索引：GiST（R-tree）
- 拓扑扩展：PostGIS Topology
- 路径规划：pgRouting

### Oracle Spatial

商业空间数据库的标杆：
- SDO_GEOMETRY 类型
- 空间索引：R-tree、Quad-tree
- 空间分析函数丰富
- 企业级性能和稳定性

### MySQL Spatial

MySQL 的空间扩展：
- 支持 OpenGIS 空间类型
- 空间索引（R-tree，仅 MyISAM/InnoDB）
- 功能相对有限

## NoSQL 空间数据库

### MongoDB

文档型数据库的原生空间支持：

```javascript
// 创建空间索引
db.places.createIndex({ location: "2dsphere" });

// 插入 GeoJSON
db.places.insert({
    name: "天安门",
    location: {
        type: "Point",
        coordinates: [116.397, 39.908]
    }
});

// 附近查询
db.places.find({
    location: {
        $near: {
            $geometry: { type: "Point", coordinates: [116.397, 39.908] },
            $maxDistance: 1000
        }
    }
});

// 范围查询
db.places.find({
    location: {
        $geoWithin: {
            $geometry: {
                type: "Polygon",
                coordinates: [[[116.3,39.8],[116.5,39.8],[116.5,40.0],[116.3,40.0],[116.3,39.8]]]
            }
        }
    }
});
```

### GeoMesa

基于分布式存储的时空数据库：

```
支持后端:
- Apache Accumulo
- Apache HBase
- Apache Cassandra
- Google Bigtable
- Redis
- Kafka (流处理)

特点:
- 分布式空间索引（Z2, XZ2, S2, H3）
- 与 GeoServer 集成
- 支持大规模时空数据
```

### Elasticsearch

搜索引擎的空间能力：

```json
// 空间查询
{
  "query": {
    "bool": {
      "must": { "match_all": {} },
      "filter": {
        "geo_distance": {
          "distance": "1km",
          "location": { "lat": 39.908, "lon": 116.397 }
        }
      }
    }
  }
}
```

## 时空数据库

### 移动对象数据库

支持连续移动对象的建模和查询：

```
数据模型:
- 轨迹: 位置的时间序列
- 移动点: 随时间连续变化的点
- 移动区域: 随时间连续变化的面

查询类型:
- 时空范围查询: 在某时间段和空间范围内的对象
- 最近邻查询: 某时刻最近的对象
- 轨迹相似性查询: 相似轨迹的检索
```

### TimescaleDB

基于 PostgreSQL 的时序数据库扩展，可与 PostGIS 结合使用。
