# 大数据概念与特征

> 大数据是指规模巨大、类型多样、处理速度快的数据集合，传统数据处理工具无法在合理时间内完成采集、存储、管理和分析。

---

## 定义

**大数据**（Big Data）：无法用常规软件工具在合理时间内进行采集、存储、管理和分析的数据集合。

关键不在于数据量本身，而在于**从数据中提取价值的能力**。

---

## 5V 特征

### Volume（大量）

数据规模从 TB 到 PB 级别：
```
1 KB = 1024 B
1 MB = 1024 KB
1 GB = 1024 MB
1 TB = 1024 GB
1 PB = 1024 TB
1 EB = 1024 PB
1 ZB = 1024 EB

全球数据量: 2025年预计达到 175 ZB
```

### Velocity（高速）

数据产生和处理的速度要求：
- **实时处理**：毫秒级响应（如金融交易）
- **准实时处理**：秒级到分钟级（如交通监控）
- **批处理**：小时级到天级（如统计报表）

### Variety（多样）

数据类型的多样性：
- **结构化数据**：关系数据库中的表格
- **半结构化数据**：JSON、XML、日志
- **非结构化数据**：文本、图像、视频、音频

### Value（价值）

数据价值密度低，需要从海量数据中挖掘有价值的信息：
```
价值密度 = 有价值的信息量 / 数据总量
```

### Veracity（真实性）

数据质量和可信度：
- 数据噪声
- 数据缺失
- 数据不一致
- 数据冗余

## 大数据的发展历程

| 阶段 | 时间 | 特征 |
|------|------|------|
| 萌芽期 | 2000 年前 | 数据仓库、商业智能 |
| 发展期 | 2000-2010 | Hadoop 生态形成 |
| 成熟期 | 2010-2020 | Spark、流计算、云原生 |
| 智能期 | 2020 至今 | AI 驱动、实时化、湖仓一体 |

## 大数据处理流程

```
数据采集 → 数据存储 → 数据处理 → 数据分析 → 数据可视化 → 决策支持

┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  数据源  │ → │ 数据湖  │ → │ 计算层  │ → │ 应用层  │
│ IoT     │   │ HDFS    │   │ Spark   │   │ BI/AI   │
│ 日志    │   │ S3      │   │ Flink   │   │ 可视化  │
│ 数据库  │   │ HBase   │   │ Hive    │   │ 报表    │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

## 大数据与空间数据的结合

空间数据天然具有大数据特征：

| 大数据特征 | 空间数据体现 |
|-----------|-------------|
| Volume | 遥感影像 PB 级、轨迹数据亿级 |
| Velocity | 实时定位流、交通流数据 |
| Variety | 矢量、栅格、点云、轨迹 |
| Value | 城市规划、灾害预警的价值 |
| Veracity | GPS 漂移、坐标偏移 |
