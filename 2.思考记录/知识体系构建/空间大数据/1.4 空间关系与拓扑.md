# 空间关系与拓扑

> 空间关系是描述空间实体之间相互联系的数学框架，是空间查询和分析的理论基础。

---

## 空间关系分类

### 1. 拓扑关系（Topological Relations）

描述空间实体之间的邻接、关联、包含等关系，在连续变换下保持不变。

**DE-9IM 模型**（Dimensionally Extended 9-Intersection Model）：

用两个几何体的内部（I）、边界（B）、外部（E）的交集来定义拓扑关系：

```
       A°  ∂A  A⁻
B°  ┌─────────────┐
∂B  │  dim(I∩I)   dim(I∩B)   dim(I∩E) │
    │  dim(B∩I)   dim(B∩B)   dim(B∩E) │
B⁻  │  dim(E∩I)   dim(E∩B)   dim(E∩E) │
    └─────────────┘

dim: -1(空), 0(点), 1(线), 2(面)
```

**九种基本拓扑关系**（面与面）：

| 关系 | DE-9IM 模式 | 含义 |
|------|-------------|------|
| 相离（Disjoint） | FF*FF**** | 无公共点 |
| 相接（Touches） | FT******* | 边界相交 |
| 交叉（Crosses） | T*T****** | 部分重叠 |
| 重叠（Overlaps） | T*T***T** | 部分覆盖 |
| 覆盖（Covers） | T*****FF* | A 完全覆盖 B |
| 包含（Contains） | T*****FF* | A 完全包含 B |
| 被覆盖（CoveredBy） | *T****T** | A 被 B 覆盖 |
| 在内部（Within） | *T****T** | A 在 B 内部 |
| 相等（Equals） | T*F**FFF* | 几何相同 |

### 2. 方向关系（Directional Relations）

描述空间实体之间的方位：

```
八方向模型:
    NW  N  NE
    W   ·   E
    SW  S  SE

锥形模型: 将空间分为若干锥形区域
投影模型: 将参考对象投影到坐标轴上
```

### 3. 距离关系（Distance Relations）

**欧氏距离**（Euclidean）：
```
d = √((x₁-x₂)² + (y₁-y₂)²)
```

**曼哈顿距离**（Manhattan）：
```
d = |x₁-x₂| + |y₁-y₂|
```

**测地距离**（Geodesic）：
```
球面上两点间的最短距离
Haversine 公式:
d = 2r · arcsin(√(sin²(Δφ/2) + cos(φ₁)cos(φ₂)sin²(Δλ/2)))
```

**闵可夫斯基距离**（Minkowski）：
```
d = (|x₁-x₂|^p + |y₁-y₂|^p)^(1/p)
p=1: 曼哈顿距离
p=2: 欧氏距离
p→∞: 切比雪夫距离
```

## 空间谓词（Spatial Predicates）

GIS 系统中常用的空间关系判断函数：

| 谓词 | 含义 | SQL 示例 |
|------|------|----------|
| ST_Intersects | 是否相交 | `WHERE ST_Intersects(a.geom, b.geom)` |
| ST_Contains | 是否包含 | `WHERE ST_Contains(a.geom, b.geom)` |
| ST_Within | 是否在内部 | `WHERE ST_Within(a.geom, b.geom)` |
| ST_Touches | 是否相接 | `WHERE ST_Touches(a.geom, b.geom)` |
| ST_Crosses | 是否交叉 | `WHERE ST_Crosses(a.geom, b.geom)` |
| ST_Overlaps | 是否重叠 | `WHERE ST_Overlaps(a.geom, b.geom)` |
| ST_Equals | 是否相等 | `WHERE ST_Equals(a.geom, b.geom)` |
| ST_Distance | 距离 | `WHERE ST_Distance(a.geom, b.geom) < 1000` |

## 空间关系的计算

### 点与点

```
距离判断: d(P₁, P₂) < ε → 相邻
相等判断: P₁.x = P₂.x ∧ P₁.y = P₂.y
```

### 点与线

```
点到线的距离: 垂距法
点在线上: d(P, L) < ε 且 P 在线段的 MBR 内
```

### 点与面

```
射线法（Ray Casting）:
从点向任意方向发射射线，计算与多边形边的交点数
奇数次 → 点在内部
偶数次 → 点在外部
```

### 线与线

```
求交: 计算两条线的所有交点
叠加: 生成新的拓扑关系网络
```

### 面与面

```
布尔运算:
- Union (并集)
- Intersection (交集)
- Difference (差集)
- Symmetric Difference (对称差)
```

## 空间关系在大数据中的挑战

1. **计算量大**：N 个实体两两判断需要 O(N²) 次运算
2. **分布式困难**：空间关系涉及跨分区的数据
3. **近似计算**：大数据场景下常使用 MBR 近似
4. **索引加速**：空间索引是高效空间关系查询的关键
