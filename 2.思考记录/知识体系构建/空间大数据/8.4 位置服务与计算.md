# 位置服务与计算

> 位置服务（LBS）是基于用户地理位置提供相关服务的技术，位置计算是支撑 LBS 的核心算法和技术。

## 概述

### LBS 架构

```
┌─────────┐   ┌─────────┐   ┌─────────┐
│ 定位层  │ → │ 数据层  │ → │ 服务层  │
│ GNSS    │   │ 位置库  │   │ POI搜索 │
│ WiFi    │   │ 地图库  │   │ 导航    │
│ 基站    │   │ 用户库  │   │ 推荐    │

```

| 技术 | 精度 | 室内 | 成本 |
|------|------|------|------|
| GNSS | 米级 | 否 | 低 |
| WiFi | 米级 | 是 | 中 |

## 地理围栏

### 概念

地理围栏（Geofence）是虚拟的地理边界，当设备进入或离开围栏区域时触发事件。

### 实现方式

```python
# 基于点在多边形内的判断
from shapely.geometry import Point, Polygon

def check_geofence(lat, lng, fence_polygon):
    point = Point(lng, lat)
    return fence_polygon.contains(point)

# 基于 GeoHash 的快速判断
def geofence_fast(lat, lng, fence_geohashes):
    geohash = encode_geohash(lat, lng, precision=7)
    return geohash in fence_geohashes or any(
        geohash.startswith(prefix) for prefix in fence_geohashes
    )
```

### 优化策略

```
大规模地理围栏优化:

1. 空间索引
   - R-tree 索引围栏
   - 快速定位候选围栏

2. GeoHash 预计算
   - 将围栏转换为 GeoHash 集合
   - O(1) 时间判断

3. 分层判断
   - 先用 MBR 快速过滤
   - 再精确判断点在多边形内

4. 批量处理
   - 批量判断多个点
   - 利用 SIMD 指令
```

## POI 搜索

### 范围搜索

```sql
-- 附近 POI 搜索
SELECT name, category, 
       ST_Distance(geom, ST_MakePoint(116.397, 39.908)::geography) AS dist
FROM pois
WHERE ST_DWithin(geom, ST_MakePoint(116.397, 39.908)::geography, 1000)
ORDER BY dist
LIMIT 20;
```

### 关键词 + 空间搜索

```sql
-- 附近的餐厅
SELECT name, rating, 
       ST_Distance(geom, user_location) AS dist
FROM pois
WHERE category = '餐厅'
  AND ST_DWithin(geom, user_location, 2000)
ORDER BY rating DESC, dist ASC
LIMIT 10;
```

### 大规模 POI 搜索

```
优化策略:

1. 空间索引
   - GeoHash 索引
   - H3 索引
   - R-tree 索引

2. 缓存
   - 热点区域缓存
   - 查询结果缓存

3. 分层搜索
   - 先搜索粗粒度网格
   - 再搜索细粒度网格

4. 预计算
   - 预计算热门区域的 POI
   - 预计算距离矩阵
```

## 地名地址解析

### 地址标准化

```
地址解析流程:

输入: "北京市海淀区中关村大街1号"
输出: {
  "province": "北京市",
  "city": "北京市",
  "district": "海淀区",
  "street": "中关村大街",
  "number": "1号",
  "location": [116.310, 39.982]
}

方法:
1. 规则匹配: 正则表达式 + 地址词典
2. 序列标注: NER (命名实体识别)
3. 深度学习: BERT + CRF
```

### 地理编码（Geocoding）

```
地址 → 坐标:

1. 精确匹配
   - 地址数据库精确查找
   
2. 模糊匹配
   - 编辑距离
   - 拼音相似度
   
3. 分词 + 匹配
   - 地址分词
   - 逐级匹配
```

### 逆地理编码（Reverse Geocoding）

```
坐标 → 地址:

1. 最近 POI
   - 找到最近的 POI
   - 返回 POI 地址

2. 行政区划
   - 判断坐标所在的行政区
   - 返回行政区名称

3. 道路匹配
   - 匹配最近的道路
   - 返回道路名称 + 距离
```

## 轨迹挖掘

### 停留点检测

```python
def detect_stay_points(trajectory, dist_threshold=200, time_threshold=1800):
    """
    检测停留点
    dist_threshold: 距离阈值 (米)
    time_threshold: 时间阈值 (秒)
    """
    stay_points = []
    i = 0
    while i < len(trajectory):
        j = i + 1
        while j < len(trajectory):
            dist = haversine(trajectory[i], trajectory[j])
            if dist > dist_threshold:
                break
            j += 1
        
        time_diff = trajectory[j-1].time - trajectory[i].time
        if time_diff > time_threshold:
            # 计算停留点中心
            center = centroid(trajectory[i:j])
            stay_points.append((center, trajectory[i].time, trajectory[j-1].time))
        
        i = j
    return stay_points
```

### 路径推荐

```
基于历史轨迹的路径推荐:

2. 路径相似度
```

## 隐私保护

### 位置隐私威胁

```
位置数据的隐私风险:
1. 位置推断: 推断居住地、工作地
2. 行为推断: 推断生活习惯
3. 身份推断: 结合其他数据识别身份
4. 关系推断: 推断社交关系
```

### 隐私保护技术

```
1. 差分隐私
   - 在位置数据中添加噪声
   - 保护个体隐私的同时保持统计特性

2. K-匿名
   - 使每个位置与至少 K-1 个其他用户不可区分

3. 位置模糊
   - 降低位置精度
   - 添加随机偏移

4. 聚合发布
   - 只发布聚合统计
   - 不发布个体轨迹
```
