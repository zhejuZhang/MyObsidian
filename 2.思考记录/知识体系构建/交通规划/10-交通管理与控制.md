## 二、交通信号控制

### 2.1 信号控制类型

| 类型 | 特征 | 适用场景 |
|------|------|----------|
| 定时控制 | 固定配时 | 流量稳定 |
| 感应控制 | 检测器触发 | 流量波动大 |
| 自适应控制 | 实时优化 | 复杂路网 |
| 协调控制 | 多交叉口联动 | 干道/区域 |

### 2.2 信号配时设计

**Webster配时公式**：
$$C_0 = \frac{1.5L + 5}{1 - \sum Y_i}$$

- $C_0$：最佳周期时长
- $L$：总损失时间
- $Y_i$：第 $i$ 相位关键流率比

**相位设计**：
```
两相位：
  相位1：南北直行+左转
  相位2：东西直行+左转

四相位：
  相位1：南北直行
  相位2：南北左转
  相位3：东西直行
  相位4：东西左转
```

**绿信比分配**：
$$g_i = \frac{Y_i}{\sum Y_i} \times (C - L)$$

### 2.3 干道绿波协调

**基本参数**：
- 带速：根据道路等级确定（40-60km/h）
- 相位差：$\theta = L / v$
- 公共周期：协调方向采用相同周期

**时间-距离图**：
```
时间
  ↑
  │    /│    /│    /│
  │   / │   / │   / │
  │  /  │  /  │  /  │   ← 绿波带
  │ /   │ /   │ /   │
  │/    │/    │/    │
  └─────┴─────┴─────→ 距离
  交叉口1  交叉口2  交叉口3
```

### 2.4 区域协调控制

**TRANSYT方法**：
- 建立路网交通流模型
- 优化信号配时参数
- 最小化总延误和停车次数

**SCOOT系统**：
- 实时检测交通流
- 在线优化配时
- 自适应调整

**SCATS系统**：
- 战略层：选择子系统
- 战术层：优化周期
- 执行层：优化相位

## 三、交通组织

### 3.1 单向交通

**设置条件**：
- 平行道路间距 ≤ 300m
- 有替代路径
- 道路宽度 ≤ 9m（可考虑）

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 提高通行能力 | 增加绕行距离 |
| 减少冲突点 | 公交运营受影响 |
| 简化交叉口 | 沿街商户受影响 |

### 3.2 禁限管理

| 措施 | 目的 | 实施方式 |
|------|------|----------|
| 货车限行 | 减少货车对城区影响 | 区域/时段限行 |
| 尾号限行 | 减少机动车使用 | 按车牌尾号轮换 |
| 摩托车限行 | 管理摩托车交通 | 区域禁行 |
| 左转限制 | 减少交叉口冲突 | 禁止左转 |

### 3.3 交叉口渠化

**渠化措施**：
- 导流岛设置
- 左转待转区
- 右转渠化岛
- 行人安全岛

## 四、交通需求管理（TDM）

### 4.1 价格手段

**拥堵收费**：
- 区域收费（伦敦、新加坡）
- 道路收费（高速公路）
- 停车收费差异化

**公共交通补贴**：
- 低票价政策
- 换乘优惠
- 月票/年票

### 4.2 行政手段

**车辆拥有管理**：
- 摇号/拍卖（北京、上海）
- 总量控制

**车辆使用管理**：
- 限行政策
- 低排放区

### 4.3 信息手段

**出行信息服务**：
- 实时路况信息
- 公交信息服务
- 停车诱导信息

**智慧出行**：
- 出行规划建议
- 多模式出行推荐
- 错峰出行引导

## 五、交通执法管理

### 5.1 电子警察系统

**功能**：
- 闯红灯检测
- 超速检测
- 违停检测
- 不按车道行驶检测
- 未系安全带检测

### 5.2 执法策略

| 类型 | 手段 | 效果 |
|------|------|------|
| 定点执法 | 固定电子警察 | 长期威慑 |
| 移动执法 | 移动测速车 | 灵活覆盖 |
| 区间测速 | 区间平均速度 | 抑制超速 |
| 视频巡检 | 监控中心 | 实时发现 |

## 六、交通事件管理

### 6.1 事件类型
- 交通事故
- 车辆故障
- 道路施工
- 特殊活动
- 恶劣天气

### 6.2 事件管理流程

```
事件检测 → 事件确认 → 响应调度 → 现场管理 → 交通恢复 → 事后分析
```

### 6.3 事件检测方法

| 方法 | 检测时间 | 准确性 |
|------|----------|--------|
| 人工报告 | 3-10分钟 | 高 |
| 视频监控 | 1-3分钟 | 中 |
| 线圈检测 | 30秒-1分钟 | 中 |
| 浮动车 | 2-5分钟 | 中 |
| 手机定位 | 1-3分钟 | 低 |
