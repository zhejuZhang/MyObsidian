# 07 - 停车设施规划

> 停车需求预测、停车场布局、停车管理政策

---

## 一、停车系统概述

### 1.1 停车设施分类

```
停车设施
├── 按位置分
│   ├── 路外停车场（地面/地下/立体）
│   └── 路内停车位
│
├── 按服务对象分
│   ├── 住宅配建停车
│   ├── 公建配建停车
│   └── 公共停车场
│
└── 按管理方式分
    ├── 自行管理
    └── 委托管理
```

### 1.2 停车设施功能
- 存放车辆，保障车辆安全
- 调节交通需求，减少寻位绕行
- 配合土地利用开发
- 作为交通需求管理工具

## 二、停车需求预测

### 2.1 需求影响因素
- 土地利用类型与强度
- 机动车保有量
- 公共交通服务水平
- 停车收费政策
- 区位条件

### 2.2 预测方法

**停车生成率法**：
$$D = \sum_{i=1}^{n} R_i \times S_i$$

- $R_i$：第 $i$ 类用地停车生成率（泊位/单位面积）
- $S_i$：第 $i$ 类用地面积

**机动车保有量法**：
$$D = V \times \alpha \times \beta$$

- $V$：区域机动车保有量
- $\alpha$：高峰停放比例
- $\beta$：周转率调整系数

**回归分析法**：
$$D = f(X_1, X_2, ..., X_n)$$

**OD推算法**：
基于交通分配结果推算各区域停车需求

### 2.3 停车配建标准

**住宅建筑配建指标**（参考值）：

| 建筑类型 | 配建标准（泊位/户） |
|----------|-------------------|
| 商品住宅 | 1.0-1.5 |
| 经济适用房 | 0.5-0.8 |
| 别墅 | 2.0 |

**公共建筑配建指标**（参考值）：

| 建筑类型 | 配建标准 |
|----------|----------|
| 办公 | 0.5-0.8 泊位/100m²建筑面积 |
| 商业 | 0.5-0.8 泊位/100m²建筑面积 |
| 医院 | 0.8-1.2 泊位/100m²建筑面积 |
| 学校 | 0.3-0.5 泊位/100名师生 |

## 三、停车场规划布局

### 3.1 布局原则
- 靠近停车需求产生源
- 与道路系统衔接良好
- 减少对道路交通的干扰
- 与公共交通枢纽结合（P+R）

### 3.2 停车场选址方法

**供需平衡法**：
- 划分停车分区
- 计算各分区停车供需缺口
- 在缺口大的区域选址

**可达性分析法**：
- 评估候选地点的交通可达性
- 考虑与主要目的地的距离
- 评估对周边交通的影响

### 3.3 停车场设计要素

| 要素 | 标准值 |
|------|--------|
| 车位宽度 | 2.5m（小型车） |
| 车位长度 | 5.3m（小型车） |
| 通道宽度 | 单向6m/双向7m |
| 坡道坡度 | ≤15% |
| 净空高度 | ≥2.2m |

### 3.4 P+R停车场规划

**设置条件**：
- 位于轨道交通站点周边
- 位于城市外围区
- 停车需求：换乘客流较大

**规模确定**：
$$N = Q \times \alpha / (1 - \beta)$$

- $Q$：高峰小时轨道换乘客流
- $\alpha$：P+R使用比例
- $\beta$：周转率

## 四、停车管理政策

### 4.1 需求管理政策

**价格调控**：
- 差别化收费政策
  - 中心区高于外围区
  - 路内高于路外
  - 高峰时段高于平峰时段

**限行限购**：
- 停车位限购政策
- 区域限行政策

### 4.2 供给管理政策

**总量控制**：
- 城市停车设施总量上限
- 中心区停车位供给控制

**结构优化**：
- 提高配建停车位比例
- 发展共享停车
- 限制路内停车

### 4.3 智慧停车

**技术手段**：
- 停车诱导系统
- 电子支付系统
- 车位预约系统
- 无人值守系统

**数据应用**：
- 停车行为分析
- 需求预测
- 动态定价
