# 11 - 智能交通系统（ITS）

> ITS架构、车路协同、自动驾驶、交通大数据

## 一、ITS概述

### 1.1 定义
智能交通系统（Intelligent Transportation Systems, ITS）是将先进的信息技术、通信技术、传感技术、控制技术和计算机技术等有效地集成运用于整个交通运输管理体系，而建立起的一种在大范围内、全方位发挥作用的实时、准确、高效的综合运输和管理系统。

### 1.2 发展历程

| 阶段 | 时间 | 特征 |
|------|------|------|
| 萌芽期 | 1960s-1980s | 电子路线引导系统 |
| 发展期 | 1990s-2000s | 系统化、标准化 |
| 成熟期 | 2010s至今 | 车联网、自动驾驶 |

### 1.3 ITS体系架构

```
智能交通系统
├── 交通管理
│   ├── 交通信号控制
│   ├── 交通监控
│   └── 事件管理
│
├── 出行者信息
│   ├── 路况信息
│   ├── 停车信息
│   └── 公交信息
│
├── 公共交通管理
│   ├── 车辆调度
│   ├── 客流监测
│   └── 电子票务
│
├── 商用车辆管理
│   ├── 车辆监控
│   └── 电子通关
│
├── 应急管理
│   ├── 紧急救援
│   └── 危险品运输
│
└── 先进车辆系统
    ├── 驾驶辅助
    └── 自动驾驶
```

## 二、交通信息采集技术

### 2.1 固定检测技术

| 技术 | 原理 | 优缺点 |
|------|------|--------|
| 感应线圈 | 电磁感应 | 成本低、需破路面 |
| 微波雷达 | 多普勒效应 | 全天候、精度中等 |
| 视频检测 | 图像处理 | 信息丰富、受天气影响 |
| 超声波 | 声波反射 | 成本低、精度较低 |
| 激光雷达 | 光学测距 | 精度高、成本高 |

### 2.2 移动检测技术

| 技术 | 数据源 | 应用 |
|------|--------|------|
| GPS浮动车 | 出租车/网约车 | 行程时间估计 |
| 手机信令 | 基站数据 | OD分析 |
| 蓝牙/WiFi | MAC地址匹配 | 行程时间 |
| ETC数据 | 收费站 | 高速公路流量 |

### 2.3 新型检测技术

- **毫米波雷达**：高精度、多目标跟踪
- **激光点云**：三维环境感知
- **AI视频分析**：深度学习目标检测
- **边缘计算**：本地实时处理

## 四、车路协同系统（V2X）

### 4.1 通信模式

| 模式 | 说明 | 标准 |
|------|------|------|
| V2V | 车与车通信 | DSRC/C-V2X |
| V2I | 车与路侧设备通信 | DSRC/C-V2X |
| V2P | 车与行人通信 | C-V2X |
| V2N | 车与网络通信 | 4G/5G |

### 4.2 应用场景

**安全类应用**：
- 前向碰撞预警
- 交叉口碰撞预警
- 盲区预警
- 紧急车辆优先

**效率类应用**：
- 车速引导
- 信号灯信息推送
- 绿波车速引导
- 交通拥堵预警

**信息服务类**：
- 道路危险提示
- 施工区预警
- 限速信息

### 4.3 技术架构

```
感知层：雷达/摄像头/激光雷达
    ↓
通信层：C-V2X / 5G
    ↓
计算层：边缘计算 / 云计算
    ↓
应用层：安全/效率/信息服务
```

## 五、自动驾驶

### 5.1 自动驾驶分级

| 级别 | 名称 | 驾驶主体 | 说明 |
|------|------|----------|------|
| L0 | 无自动化 | 人 | 完全人工驾驶 |
| L1 | 驾驶辅助 | 人+系统 | 单一功能辅助 |
| L2 | 部分自动化 | 人+系统 | 多功能协同辅助 |
| L3 | 有条件自动化 | 系统 | 特定条件下系统驾驶 |
| L4 | 高度自动化 | 系统 | 特定场景完全自动 |
| L5 | 完全自动化 | 系统 | 所有场景完全自动 |

### 5.2 关键技术

**感知技术**：
- 摄像头：图像识别
- 毫米波雷达：距离测量
- 激光雷达：三维建图
- 超声波：近距离检测

**定位技术**：
- GNSS/RTK
- 高精度地图
- 视觉里程计
- 惯性导航

**决策规划**：
- 行为决策
- 路径规划
- 运动控制

### 5.3 自动驾驶对交通规划的影响

| 影响领域 | 预期变化 |
|----------|----------|
| 道路设计 | 车道可更窄、标志标线简化 |
| 停车设施 | 需求减少、可远程停放 |
| 公共交通 | 自动驾驶公交、需求响应 |
| 交通管理 | 车队管理、协同驾驶 |
| 土地利用 | 停车用地释放、通勤距离增加 |

## 七、交通数字孪生

### 7.1 概念
交通数字孪生是物理交通系统在数字空间的映射，通过实时数据同步，实现对交通系统的监测、分析和优化。

### 7.2 核心组成
- **物理实体**：实际交通系统
- **数字模型**：虚拟交通模型
- **数据连接**：实时数据同步
- **仿真分析**：场景模拟与预测

### 7.3 应用场景
- 实时交通态势感知
- 交通方案仿真评估
- 应急事件模拟推演
- 自动驾驶测试验证
