# 02 - 交通调查与数据采集

> 交通调查的类型、方法、组织实施与数据分析

---

## 一、交通调查概述

### 1.1 调查目的
- 掌握交通系统现状运行状况
- 获取交通需求特征数据
- 为交通模型标定与验证提供基础数据
- 为规划方案编制提供依据

### 1.2 调查分类体系

```
交通调查
├── 按调查内容分
│   ├── 出行OD调查
│   ├── 交通流量调查
│   ├── 交通速度调查
│   ├── 交通设施调查
│   └── 停车调查
│
├── 按调查方法分
│   ├── 人工调查
│   ├── 机械/电子设备调查
│   └── 新技术调查
│
└── 按调查范围分
│   ├── 全样调查
│   ├── 抽样调查
│   └── 典型调查
```

## 二、出行OD调查

### 2.1 概念
OD调查（Origin-Destination Survey）是获取出行起讫点信息的调查，是交通规划最核心的数据来源。

### 2.2 调查内容
- **居民出行调查**
  - 出行目的（工作、上学、购物、休闲等）
  - 出行方式（步行、自行车、公交、小汽车等）
  - 出行时间（出发时间、到达时间、出行时耗）
  - 出行起讫点（交通小区编码）
  - 出行者属性（年龄、性别、职业、收入等）

- **流动人口出行调查**
  - 旅游出行、商务出行、通勤出行等

- **车辆出行调查**
  - 货车出行特征
  - 出租车运营特征
  - 公交客流特征

### 2.3 调查方法

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 家访调查 | 信息详细、回收率高 | 费时费力、样本量受限 | 居民出行调查 |
| 电话调查 | 效率较高 | 回收率下降、信息有限 | 辅助调查 |
| 网络调查 | 成本低、覆盖面广 | 样本偏差、数据质量不稳 | 大规模预调查 |
| 出行日志 | 连续性好 | 依赖配合度 | 长期追踪调查 |
| 手机信令 | 样本量大、连续性强 | 精度受限、出行目的难判 | OD分布估计 |
| IC卡数据 | 公交出行精确 | 仅限公交用户 | 公交OD分析 |

### 2.4 抽样设计
- **抽样率**：一般城市5%-10%，特大城市不低于3%
- **分层抽样**：按行政区、用地类型、收入水平等分层
- **样本量计算**：

$$n = \frac{Z^2 \cdot p(1-p)}{E^2} \cdot deff$$

其中：$Z$ 为置信度对应Z值，$p$ 为估计比例，$E$ 为允许误差，$deff$ 为设计效应

### 2.5 交通小区划分
- **划分原则**：
  - 用地性质一致性
  - 行政边界完整性
  - 小区面积均衡性（中心区小、外围大）
  - 与天然屏障（河流、铁路）协调
- **小区数量**：大城市一般200-500个，特大城市可达1000+
- **分区层次**：交通大区 → 交通中区 → 交通小区

## 三、交通流量调查

### 3.1 路段流量调查
- **人工计数**：在断面设置计数人员，按时段记录车辆数
- **自动计数**：
  - 气压管计数器
  - 感应线圈检测器
  - 微波/雷达检测器
  - 视频检测（AI图像识别）
- **调查时段**：一般选择工作日（周二-周四），连续12-16小时

### 3.2 交叉口流量调查
- **转向流量**：记录各进口道各转向的车辆数
- **行人/非机动车流量**：分方向记录
- **高峰小时系数**：PHF = 高峰小时流量 / (4 × 高峰15分钟流量)

### 3.3 高速公路/快速路调查
- 收费站数据（ETC数据）
- 交通量自动观测站
- 区间测速数据

### 3.4 流量统计指标

| 指标 | 定义 | 单位 |
|------|------|------|
| AADT | 年平均日交通量 | pcu/d |
| ADT | 平均日交通量 | pcu/d |
| 高峰小时流量 | 一天中最大小时流量 | pcu/h |
| 方向分布系数 | 主要方向流量/总流量 | % |
| 车型构成 | 各车型比例 | % |

## 四、交通速度调查

### 4.1 调查方法

| 方法 | 原理 | 适用场景 |
|------|------|----------|
| 牌照法 | 记录车辆通过两点的时间差 | 路段区间速度 |
| 定点测速 | 雷达/激光测速仪 | 地点速度 |
| 浮动车法 | 跟车记录行程时间 | 路网运行速度 |
| GPS轨迹法 | 车辆GPS数据分析 | 路网速度分布 |
| 手机信令法 | 信令数据推算速度 | 宏观路网速度 |

### 4.2 速度指标

- **地点速度**（Spot Speed）：车辆通过某一点的瞬时速度
- **行程速度**（Travel Speed）：路段长度 / 行程时间
- **运行速度**（Running Speed）：路段长度 / 行驶时间（不含停车）
- **设计速度**（Design Speed）：道路几何设计依据速度
- **自由流速度**（Free-Flow Speed）：交通量极小时的速度

### 4.3 服务水平评价

| 服务水平 | V/C比 | 运行状态 |
|----------|-------|----------|
| A | ≤0.35 | 自由流 |
| B | 0.35-0.55 | 稳定流 |
| C | 0.55-0.75 | 接近稳定流 |
| D | 0.75-0.90 | 接近不稳定流 |
| E | 0.90-1.00 | 不稳定流 |
| F | >1.00 | 强制流/拥堵 |

## 五、交通设施调查

### 5.1 道路设施调查
- 道路等级、长度、宽度
- 横断面形式（车道数、分隔方式）
- 交叉口类型与几何参数
- 道路路面状况
- 交通标志标线

### 5.2 公交设施调查
- 公交线路数量与走向
- 站点分布与间距
- 车辆数量与车型
- 首末站与枢纽设施
- 轨道交通线路与站点

### 5.3 停车设施调查
- 停车场位置、类型、泊位数
- 停车利用率与周转率
- 停车收费政策
- 路内停车状况

## 六、新技术数据采集

### 6.1 手机信令数据
- **数据来源**：运营商基站信令
- **信息内容**：用户位置、驻留时间、移动轨迹
- **优势**：样本量大、覆盖范围广、连续性强
- **局限**：精度受限（基站覆盖范围）、出行目的推断困难
- **应用**：OD矩阵估计、人口分布、通勤分析

### 6.2 导航/网约车轨迹数据
- **数据来源**：高德、百度、滴滴等平台
- **信息内容**：车辆GPS轨迹、路段速度、行程信息
- **优势**：精度高、实时性强
- **应用**：路网运行状态监测、出行OD分析、路径选择分析

### 6.3 社交媒体签到数据
- **数据来源**：微博、大众点评等
- **应用**：活动地点分析、出行目的推断

### 6.4 视频AI检测
- 路口全方位视频检测
- 行人/非机动车轨迹追踪
- 交通事件自动识别

### 6.5 浮动车数据（FCD）
- 出租车/网约车GPS数据
- 路段行程时间估计
- 路网可靠性分析

### 6.6 多源数据融合
- 传统调查数据 + 新技术数据
- 数据清洗、匹配、融合方法
- 交叉验证与质量控制

## 七、调查组织与实施

### 7.1 组织流程
```
制定调查方案 → 调查员培训 → 预调查/试调查 → 正式调查 → 数据录入 → 质量检验 → 数据分析
```

### 7.2 关键注意事项
- 调查时间选择：避开节假日、恶劣天气、特殊事件
- 调查表格设计：简洁明了、编码规范
- 质量控制：现场督导、抽查复核、数据逻辑检查
- 数据安全：个人信息保护、合规使用
