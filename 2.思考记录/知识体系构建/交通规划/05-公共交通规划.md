# 05 - 公共交通规划

> 公交线网规划、轨道交通、BRT、公交优先策略、MaaS

---

## 一、公共交通体系概述

### 1.1 公共交通方式层次

```
大运量 ─── 城际铁路、市域铁路
  │
中运量 ─── 城市轨道交通（地铁）、BRT、有轨电车
  │
常规运量 ── 常规公交（公共汽车）
  │
补充运量 ── 出租车、网约车、定制公交、社区巴士
```

### 1.2 各方式技术特征

| 方式 | 运能(人次/h) | 速度(km/h) | 建设成本 | 适用场景 |
|------|-------------|-----------|----------|----------|
| 地铁 | 30000-70000 | 30-40(含停站) | 极高 | 大城市骨干 |
| 轻轨 | 10000-30000 | 25-35 | 高 | 中等城市骨干 |
| BRT | 8000-20000 | 20-30 | 中 | 公交走廊 |
| 有轨电车 | 5000-15000 | 15-25 | 中 | 新区/景区 |
| 常规公交 | 3000-8000 | 15-20 | 低 | 全覆盖 |

### 1.3 公共交通评价指标

| 指标 | 计算方法 | 参考标准 |
|------|----------|----------|
| 公交分担率 | 公交出行量/总出行量 | 大城市≥35% |
| 线网密度 | 公交线路长度/建成区面积 | ≥3 km/km² |
| 站点覆盖率 | 300m/500m半径覆盖面积/总面积 | 300m≥50% |
| 线路重复系数 | 线路总长度/运营道路长度 | 1.25-2.5 |
| 万人公交车辆 | 标台数/万人 | ≥12标台/万人 |
| 准点率 | 准点班次/总班次 | ≥85% |

## 二、常规公交线网规划

### 2.1 线网层次结构

```
骨干线路 ─── 主要客流走廊，大站快车
  │
接驳线路 ─── 衔接轨道交通/BRT，填补覆盖空白
  │
社区线路 ─── 服务社区内部，短距离出行
  │
定制线路 ─── 通勤快线、旅游专线等
```

### 2.2 线网规划方法

**客流走廊识别**：
- 基于OD调查数据的客流期望线分析
- 主要走廊：单向高峰客流 ≥ 8000人次/h
- 次要走廊：单向高峰客流 3000-8000人次/h

**线路布设原则**：
- 沿主要客流方向布设
- 与轨道交通形成互补
- 减少不必要的换乘
- 线路长度控制：大城市不超过15-20km

**线网优化模型**：
$$\max Z = \sum_i w_i \cdot f(x_i) - \sum_j c_j \cdot g(y_j)$$

目标：最大化客流覆盖率，最小化运营成本

### 2.3 公交站点规划

**站距设计**：
| 区域 | 推荐站距(m) |
|------|------------|
| 市中心区 | 300-500 |
| 城区 | 500-800 |
| 郊区 | 800-1200 |
| 快线/大站快车 | 1000-2000 |

**港湾式停靠站**：
- 设置条件：道路通行能力受限时
- 渐变段长度：15-25m
- 站台长度：按同时停靠车辆数确定

## 三、轨道交通规划

### 3.1 线网规划原则

- **覆盖性**：覆盖主要客流走廊和城市核心区
- **连通性**：形成网络，便于换乘
- **可达性**：与用地开发协调（TOD）
- **经济性**：合理控制建设规模和投资

### 3.2 线网规模确定

**出行需求法**：
$$L = \frac{Q \times \alpha \times \beta}{p \times q}$$

- $Q$：规划年公交出行总量
- $\alpha$：轨道交通承担比例
- $\beta$：轨道交通负荷强度（万人次/km·日）
- $p$：线路条数
- $q$：每条线路日均客运量

**类比法**：参考同规模城市线网规模

**经济可达法**：保证核心区任意一点500m内可达站点

### 3.3 线网布局形式

| 形式 | 特征 | 优缺点 |
|------|------|--------|
| 棋盘式 | 纵横交错 | 覆盖均匀，换乘次数多 |
| 放射式 | 由中心向外辐射 | 向心性强，中心区压力大 |
| 环+放射 | 环线+放射线 | 换乘方便，投资较大 |
| 网格+对角线 | 提高斜向连通性 | 连通性好，线路复杂 |

### 3.4 换乘站规划

**换乘形式**：
| 类型 | 换乘时间 | 建设难度 | 适用场景 |
|------|----------|----------|----------|
| 站台换乘 | 最短(1-2min) | 高 | 同期建设 |
| 站厅换乘 | 较短(3-5min) | 中 | 常见形式 |
| 通道换乘 | 较长(5-10min) | 低 | 不同期建设 |
| 出站换乘 | 最长(>10min) | 最低 | 特殊情况 |

### 3.5 轨道交通站点分类

| 类型 | 功能 | 客流特征 |
|------|------|----------|
| 一般站 | 基本停靠站 | 标准客流 |
| 换乘站 | 线路换乘 | 换乘客流大 |
| 枢纽站 | 多线换乘+对外交通 | 综合客流 |
| 终点站 | 线路终端 | 折返+接驳 |

## 四、快速公交（BRT）规划

### 4.1 BRT核心要素
- **专用车道**：路中或路侧专用
- **站台设施**：封闭式站台，水平登乘
- **车辆**：大容量、低地板
- **智能系统**：信号优先、实时信息

### 4.2 BRT适用条件
- 客流走廊单向高峰客流 5000-15000 人次/h
- 道路条件：有足够的空间设置专用车道
- 投资预算不足以建设轨道交通

### 4.3 BRT车道布置

| 布置形式 | 优点 | 缺点 |
|----------|------|------|
| 路中式 | 受干扰最小 | 需中央分隔带 |
| 路侧式 | 便于上下客 | 受右转车辆干扰 |
| 单侧双向 | 节省空间 | 换向不便 |

## 五、公交优先策略

### 5.1 设施优先
- 公交专用道设置
- 交叉口公交专用进口道
- 公交信号优先

### 5.2 信号优先策略

| 策略 | 原理 | 效果 |
|------|------|------|
| 绿灯延长 | 公交到达时延长绿灯 | 减少红灯等待 |
| 绿灯早启 | 提前开启绿灯 | 减少排队延误 |
| 相位跳跃 | 公交无需求时跳过相位 | 减少空放 |

### 5.3 财政优先
- 公交补贴机制
- 票价优惠政策
- 公交发展专项资金

### 5.4 路权优先
- 公交专用道立法保障
- 违规占用公交道处罚

## 六、MaaS（Mobility as a Service）

### 6.1 概念
MaaS是一种将各种交通方式整合在一个数字平台上的服务模式，用户通过单一平台完成出行规划、预订和支付。

### 6.2 MaaS层级

```
Level 1 ─── 信息整合（出行规划）
Level 2 ─── 预订与支付整合
Level 3 ─── 服务整合（套餐制）
Level 4 ─── 政策整合（与城市交通政策协同）
```

### 6.3 核心技术
- 多模式出行规划引擎
- 统一支付系统
- 开放数据接口（GTFS、GBFS等）
- 个性化推荐算法
