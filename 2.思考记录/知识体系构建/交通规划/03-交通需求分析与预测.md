# 03 - 交通需求分析与预测

> 四阶段法、非集计模型、出行行为分析、需求预测方法

---

## 一、交通需求分析概述

### 1.1 基本概念
- **交通需求**：由社会经济活动产生的、在一定时间和空间上对交通运输服务的需要
- **交通需求预测**：基于现状数据和规划方案，预测未来交通系统的运行状态

### 1.2 需求分析框架

```
社会经济活动 → 出行产生 → 出行分布 → 方式划分 → 交通分配 → 路网流量
  (土地利用)    (Trip      (Trip       (Modal     (Traffic
                Generation) Distribution) Split)    Assignment)
```

## 二、四阶段法（Four-Step Model, FSM）

### 2.1 出行生成（Trip Generation）

#### 目的
预测各交通小区的出行产生量和出行吸引量

#### 方法

**增长率法**
$$T_f = T_0 \times (1 + \alpha)^n$$

**回归分析法**
$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + ... + \beta_n X_n$$

**交叉分类法（Category Analysis）**
- 按家庭规模、收入、车辆拥有量等分类
- 计算各类别的出行率
- 适用于土地利用变化不大的地区

**出行率法**
$$P_i = \sum_k R_k \times N_{ik}$$

其中：$R_k$ 为第 $k$ 类用地的出行率，$N_{ik}$ 为小区 $i$ 中第 $k$ 类用地的规模

#### 出行产生量与吸引量
- **产生量（Production）**：以家庭为基准，由人口特征决定
- **吸引量（Attraction）**：以用地为基准，由就业岗位等决定
- 注意：产生量之和 = 吸引量之和（平衡）

### 2.2 出行分布（Trip Distribution）

#### 增长率法（Fratar法）
$$T_{ij}^{f} = T_{ij}^{0} \times F_i \times F_j \times \frac{\sum_j T_{ij}^{0}}{\sum_j T_{ij}^{0} \times F_j}$$

#### 重力模型（Gravity Model）
$$T_{ij} = P_i \times \frac{A_j \times f(d_{ij})}{\sum_j A_j \times f(d_{ij})}$$

其中：
- $P_i$：小区 $i$ 的出行产生量
- $A_j$：小区 $j$ 的出行吸引量
- $f(d_{ij})$：阻抗函数（距离/时间的函数）

**常见阻抗函数形式**：
| 类型 | 公式 | 适用场景 |
|------|------|----------|
| 幂函数 | $f(d) = d^{-\beta}$ | 短距离出行 |
| 指数函数 | $f(d) = e^{-\lambda d}$ | 一般场景 |
| 组合函数 | $f(d) = d^{\alpha} e^{-\beta d}$ | 复杂场景 |
| Gamma函数 | $f(d) = a \cdot d^b \cdot e^{c \cdot d}$ | 最常用 |

#### 最大熵模型（Entropy Model）
- 基于信息论原理
- 在约束条件下求解最可能的OD分布
- 数学上等价于重力模型

#### 介入机会模型（Intervening Opportunities Model）
- 不以距离而以"机会"为阻抗
- 出行者依次评价可到达的机会

### 2.3 方式划分（Modal Split）

#### 影响因素
- 出行时间（含候车、换乘时间）
- 出行费用
- 舒适度与便利性
- 出行者特征（收入、年龄、车辆拥有）
- 出行目的

#### 方法

**转移曲线法（Diversion Curve）**
- 基于公交与小汽车出行时间比-分担率关系曲线

**Logit模型（最常用）**
$$P_m = \frac{e^{V_m}}{\sum_{k} e^{V_k}}$$

其中效用函数：
$$V_m = \beta_0 + \beta_1 T_m + \beta_2 C_m + \beta_3 W_m + ...$$

- $T_m$：方式 $m$ 的出行时间
- $C_m$：方式 $m$ 的出行费用
- $W_m$：方式 $m$ 的候车/换乘时间

**嵌套Logit模型（Nested Logit）**
```
出行方式选择
├── 私人交通
│   ├── 小汽车（驾驶员）
│   ├── 小汽车（乘客）
│   └── 出租车
└── 公共交通
    ├── 轨道交通
    ├── 公共汽车
    └── BRT
```

### 2.4 交通分配（Traffic Assignment）

#### 分配方法层次

| 方法 | 假设 | 适用场景 |
|------|------|----------|
| 全有全无（AON） | 所有流量走最短路 | 初步分析 |
| 容量限制分配 | 考虑通行能力约束 | 一般分析 |
| 随机分配 | 出行者对路网认知有差异 | 中等精度 |
| 用户均衡（UE） | 没有人能通过换路径减少出行时间 | 最常用 |
| 系统最优（SO） | 系统总出行时间最小 | 理论分析 |
| 随机用户均衡（SUE） | 出行者对时间认知有随机误差 | 高精度 |

#### Wardrop均衡原理

**第一原理（用户均衡，UE）**：
> 在均衡状态下，所有被使用的路径的出行时间相等，且小于等于任何未被使用路径的出行时间。

数学表达：
$$\min Z = \sum_a \int_0^{x_a} t_a(\omega) d\omega$$

约束条件：
$$\sum_k f_k^{rs} = q^{rs}, \quad \forall r,s$$
$$x_a = \sum_{r,s} \sum_k f_k^{rs} \delta_{a,k}^{rs}$$
$$f_k^{rs} \geq 0$$

**第二原理（系统最优，SO）**：
$$\min Z = \sum_a x_a \cdot t_a(x_a)$$

#### Frank-Wolfe算法
求解UE分配的经典算法：
1. 初始化（全有全无分配）
2. 求解方向搜索（找下降方向）
3. 线搜索（确定步长）
4. 更新流量
5. 收敛判断

#### BPR路阻函数
$$t_a = t_a^0 \left[1 + \alpha \left(\frac{x_a}{c_a}\right)^{\beta}\right]$$

其中：$t_a^0$ 为自由流时间，$c_a$ 为通行能力，$\alpha = 0.15$，$\beta = 4$（推荐值）

## 三、非集计模型（Disaggregate Models）

### 3.1 理论基础

**随机效用理论（Random Utility Theory）**
$$U_{in} = V_{in} + \varepsilon_{in}$$

- $U_{in}$：决策者 $n$ 对方案 $i$ 的效用
- $V_{in}$：可观测效用（确定性部分）
- $\varepsilon_{in}$：随机误差项

### 3.2 模型类型

| 模型 | 误差项分布 | 特点 |
|------|-----------|------|
| MNL（多项Logit） | Gumbel分布 | 最简单，IIA假设 |
| NL（嵌套Logit） | 广义极值分布 | 允许相关性 |
| Probit | 正态分布 | 最灵活，计算复杂 |
| Mixed Logit | 混合分布 | 随机偏好差异 |
| BLP | — | 多产品需求分析 |

### 3.3 模型估计
- **最大似然估计（MLE）**
$$L(\theta) = \prod_{n=1}^{N} \prod_{i \in C_n} P_{in}(\theta)^{y_{in}}$$

- **RP数据与SP数据融合**
  - RP（Revealed Preference）：实际选择数据
  - SP（Stated Preference）：意向调查数据

## 四、活动分析法（Activity-Based Approach）

### 4.1 核心思想
- 出行是参与活动的派生需求
- 以"活动-出行链"代替单次"出行"
- 关注一天/一周的时间利用模式

### 4.2 模型框架
```
活动模式决策（长期）
  ↓
日活动模式选择
  ↓
活动安排（时间、地点、持续时间）
  ↓
出行链生成
  ↓
方式与路径选择
```

### 4.3 代表性模型
- **CT-RAMP**（芝加哥模型）
- **ALBATROSS**（荷兰）
- **FEATHERS**（比利时）
- **TAPAS**（德国）

## 五、需求预测实践要点

### 5.1 预测流程
1. 社会经济预测（人口、GDP、车辆保有量等）
2. 土地利用预测（[[12-交通与土地利用]]）
3. 出行生成预测
4. 出行分布预测
5. 方式划分预测
6. 交通分配
7. 结果分析与校验

### 5.2 关键参数标定
- 出行率标定（基于OD调查）
- 阻抗函数标定（基于流量调查）
- Logit模型参数标定（基于SP/RP调查）
- 路阻函数标定（基于速度-流量数据）

### 5.3 模型验证
- **GOF指标**：RMSE、MAPE、R²
- **屏幕线验证**：对比调查流量与分配流量
- **关键路段验证**：重要断面流量对比
- **OD表验证**：与调查OD的结构对比

### 5.4 敏感性分析
- 关键参数变化对结果的影响
- 情景分析（高/中/低方案）
