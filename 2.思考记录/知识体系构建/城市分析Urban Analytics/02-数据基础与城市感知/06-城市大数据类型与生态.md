# 城市大数据类型与生态

## 1. 城市大数据的范式转变

城市分析正经历从**小数据统计**到**大数据驱动**的范式转变：

| 维度 | 传统数据 | 城市大数据 |
|------|----------|-----------|
| **来源** | 普查、调查、统计年鉴 | 传感器、手机、社交媒体、遥感 |
| **规模** | 万级样本 | 亿级记录 |
| **时间分辨率** | 年/季度 | 实时/分钟级 |
| **空间分辨率** | 行政区划 | 个体/建筑级 |
| **采集方式** | 主动采集 | 被动生成 |
| **更新频率** | 低频（普查每10年） | 高频（实时流） |

## 2. 城市大数据类型体系

### 2.1 兴趣点数据（POI）

**POI（Point of Interest）** 是城市功能分析的基础数据：

| 属性 | 说明 | 示例 |
|------|------|------|
| 名称 | 设施/场所名称 | "星巴克（中关村店）" |
| 坐标 | 经纬度位置 | (116.310, 39.992) |
| 类别 | 多级分类体系 | 餐饮/咖啡厅 |
| 地址 | 文本地址 | "海淀区中关村大街1号" |

**POI数据的分析价值**：
- 城市功能区识别（见[[10-城市功能区识别与语义标注]]）
- 服务设施可达性评估
- 商业选址与竞争分析
- 城市活力与多样性度量

### 2.2 轨迹数据

| 数据类型 | 来源 | 精度 | 样本量 | 特点 |
|----------|------|------|--------|------|
| **GPS轨迹** | 出租车/网约车 | 米级 | 百万级 | 精确路径 |
| **手机信令** | 基站 | 百米-千米 | 千万级 | 全人口覆盖 |
| **公交IC卡** | 刷卡记录 | 站点级 | 百万级 | 仅公交出行 |
| **共享单车** | APP | 米级 | 千万级 | 短途出行 |
| **WiFi探针** | MAC地址 | 建筑级 | 百万级 | 室内定位 |

### 2.3 社交媒体数据

| 平台 | 数据类型 | 城市分析价值 |
|------|----------|-------------|
| **微博/Twitter** | 文本+位置+时间 | 舆情、事件检测、情感分析 |
| **大众点评/Yelp** | 评论+评分+位置 | 商业服务质量评估 |
| **Flickr/Instagram** | 图像+位置+时间 | 城市景观感知 |
| **百度迁徙** | 迁徙流 | 人口流动、春运分析 |

### 2.4 遥感数据

（详见[[07-城市遥感与对地观测]]）

| 数据类型 | 分辨率 | 应用 |
|----------|--------|------|
| 高分辨率光学 | 亚米级 | 建筑提取、土地利用 |
| 夜间灯光 | ~500m | 经济活动、城市化 |
| SAR | 米级 | 形变监测、洪水制图 |
| 高光谱 | 米级 | 地表覆盖精细分类 |

### 2.5 基础地理数据

| 数据类型 | 来源 | 内容 |
|----------|------|------|
| **行政区划** | 自然资源部 | 省/市/区/街道边界 |
| **道路网络** | OpenStreetMap / 高德 | 道路等级、拓扑 |
| **建筑物轮廓** | OSM / 百度 | 建筑 footprint |
| **DEM/DSM** | 遥感/SRTM | 地形高程 |

## 3. 城市大数据生态

### 3.1 国内主要数据平台

| 平台 | 数据类型 | 特点 |
|------|----------|------|
| **高德开放平台** | POI、路径规划、实时路况 | API丰富 |
| **百度地图开放平台** | POI、轨迹、热力图 | 用户基数大 |
| **腾讯位置服务** | POI、定位、人流 | 社交数据优势 |
| **天地图** | 基础地理信息 | 官方权威 |
| **国家地球系统科学数据中心** | 遥感、社会经济 | 学术数据 |

### 3.2 国际主要数据平台

| 平台 | 数据类型 | 特点 |
|------|----------|------|
| **OpenStreetMap** | 道路、建筑、POI | 众源、全球覆盖 |
| **Google Earth Engine** | 遥感影像 | 云计算、长时间序列 |
| **US Census** | 人口、住房 | 美国普查数据 |
| **Eurostat** | 社会经济 | 欧洲统计 |
| **WorldPop** | 人口分布栅格 | 全球100m分辨率 |

### 3.3 数据融合与质量

| 挑战 | 问题 | 应对策略 |
|------|------|----------|
| **异构性** | 不同来源数据格式、语义不一致 | 本体映射、语义对齐 |
| **噪声** | 定位误差、缺失值 | 数据清洗、异常检测 |
| **偏差** | 样本不代表总体 | 加权校正、偏差建模 |
| **隐私** | 个体位置敏感 | 差分隐私、数据脱敏 |
| **时效性** | 数据快速过期 | 流式计算、增量更新 |

## 4. 城市大数据的伦理与隐私

- **知情同意**：被动采集数据的用户往往不知情
- **数据最小化**：仅收集必要的数据
- **匿名化风险**：轨迹数据的去匿名化攻击
- **算法公平**：基于大数据的决策可能加剧不平等
- **数字鸿沟**：大数据无法覆盖的人群（老年人、低收入群体）
