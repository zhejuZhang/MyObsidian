## 1. 数字孪生概念

### 1.1 定义

**数字孪生（Digital Twin）** 是物理实体在数字空间中的高保真镜像，通过实时数据连接实现双向映射。

**城市数字孪生**将这一概念扩展到城市尺度：

| 维度 | 工业数字孪生 | 城市数字孪生 |
|------|-------------|-------------|
| **对象** | 单体设备/产品 | 城市系统 |
| **尺度** | 米级 | 千米级 |
| **复杂度** | 相对封闭 | 开放复杂系统 |
| **数据源** | 传感器 | 多源异构 |
| **应用** | 预测维护 | 城市治理 |

### 1.2 城市数字孪生的层次

```
L1：几何孪生 — 三维可视化（建筑/道路/地形）
L2：物理孪生 — 物理过程模拟（交通流/热环境/能耗）
L3：逻辑孪生 — 行为规则（ABM/决策模型）
L4：数据孪生 — 数据驱动（机器学习/实时预测）
```

## 2. 三维城市建模

### 2.1 建模方法

| 方法 | 数据源 | 精度 | 应用 |
|------|--------|------|------|
| **倾斜摄影** | 多角度航拍 | 厘米级 | 实景三维 |
| **LiDAR点云** | 激光扫描 | 厘米级 | 精细建模 |
| **BIM** | 建筑设计 | 毫米级 | 建筑内部 |
| **程序化建模** | 规则生成 | 可变 | 大规模城市 |
| **NeRF/3DGS** | 图像重建 | 厘米级 | 照片级渲染 |

### 2.2 LOD（Level of Detail）层次

| LOD | 描述 | 数据来源 |
|-----|------|----------|
| **LOD0** | 二维 footprint + DEM | 遥感、OSM |
| **LOD1** | 平屋顶建筑体块 | 建筑高度 + footprint |
| **LOD2** | 带屋顶结构 | 倾斜摄影、LiDAR |
| **LOD3** | 带立面细节 | 实景建模 |
| **LOD4** | 含室内结构 | BIM |

### 2.3 BIM-GIS融合

| 融合层面 | 内容 | 挑战 |
|----------|------|------|
| **几何融合** | 坐标系统一、尺度匹配 | 坐标转换 |
| **语义融合** | IFC ↔ CityGML映射 | 本体差异 |
| **拓扑融合** | 建筑-道路-管网连接 | 拓扑一致性 |
| **应用融合** | 室内外一体化分析 | 计算效率 |

## 3. 实时数据驱动

### 3.1 数据接入架构

```
传感器/摄像头 → 边缘计算 → 数据中台 → 数字孪生平台
     ↓              ↓           ↓           ↓
   实时流        预处理      存储/计算    可视化/仿真
```

### 3.2 实时数据类型

| 数据类型 | 来源 | 更新频率 | 应用 |
|----------|------|----------|------|
| 交通流 | 地磁/视频 | 秒级 | 实时路况 |
| 环境监测 | 传感器 | 分钟级 | 空气质量 |
| 能耗数据 | 智能电表 | 15分钟 | 能源管理 |
| 人流热力 | WiFi探针 | 分钟级 | 人群监测 |
| 天气数据 | 气象站 | 小时级 | 气象影响 |

## 4. 仿真推演

### 4.1 仿真类型

| 类型 | 方法 | 应用场景 |
|------|------|----------|
| **交通仿真** | 微观仿真（VISSIM）| 信号优化 |
| **环境仿真** | CFD模拟 | 风环境、污染物扩散 |
| **灾害仿真** | 洪水/地震模拟 | 应急预案 |
| **能源仿真** | 建筑能耗模拟 | 节能优化 |
| **人流仿真** | 社会力模型 | 大型活动安保 |

### 4.2 情景推演

- **What-if分析**：改变假设条件，观察系统响应
- **政策模拟**：评估不同政策方案的效果
- **应急预案**：灾害情景下的应急响应推演
- **规划方案比选**：不同规划方案的对比评估

## 5. 城市大脑与智能决策

### 5.1 城市大脑架构

```
感知层：传感器、摄像头、物联网
    ↓
数据层：数据中台、数据湖
    ↓
计算层：AI模型、仿真引擎
    ↓
应用层：智慧交通、智慧能源、智慧安防
    ↓
决策层：辅助决策、自动控制
```

### 5.2 典型应用

| 应用 | 功能 | 技术支撑 |
|------|------|----------|
| **智慧交通** | 信号自适应、路径诱导 | 实时优化 |
| **智慧能源** | 需求响应、分布式调度 | 预测+优化 |
| **智慧安防** | 异常检测、应急响应 | 视频AI |
| **智慧环保** | 污染溯源、预警 | 扩散模型 |

## 6. 挑战与前沿

| 挑战 | 现状 | 趋势 |
|------|------|------|
| **数据融合** | 多源异构数据整合困难 | 语义互操作标准 |
| **实时性** | 大规模实时计算瓶颈 | 边缘-云协同 |
| **精度与效率** | 高精度与实时性的矛盾 | LOD自适应 |
| **隐私安全** | 大量个人数据 | 联邦学习、差分隐私 |
| **标准缺失** | 各平台互不兼容 | OGC CityGML、ISO 19650 |
