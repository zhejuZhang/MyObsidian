## 经验误差与过拟合

### 基本概念

| 概念 | 公式/定义 |
|------|----------|
| **错误率(error rate)** | $E = a/m$（$a$ 为错误样本数，$m$ 为总样本数） |
| **精度/准确率(accuracy)** | $\text{acc} = 1 - E$ |
| **训练误差/经验误差** | 模型在训练集上的误差 |
| **泛化误差** | 模型在新样本上的误差（我们真正关心的） |

### 过拟合与欠拟合

```
模型复杂度 →    低 ──────────────────→ 高

训练误差   →    高 ──────────────────→ 低
泛化误差   →    先降 ──→ 最低点 ──→ 再升
                  ↑         ↑          ↑
              欠拟合     最优       过拟合
```

| | 欠拟合(underfitting) | 过拟合(overfitting) |
|---|---|---|
| **表现** | 训练集和测试集表现都差 | 训练集表现好，测试集表现差 |
| **原因** | 模型太简单，学习能力不足 | 模型太复杂，把训练数据的噪声也学了 |
| **解决** | 增加模型复杂度、增加特征 | 正则化、early stopping、增加数据、dropout |

## 评估方法

### 留出法(Hold-out)

```
数据集 D
├── 训练集 S (70%)    → 用于训练
└── 测试集 T (30%)    → 用于评估
```

**注意**：
- 训练/测试集的划分要尽可能保持数据分布的一致性（**分层抽样**）
- 多次随机划分，取平均值（减少单次划分的偶然性）
- 常见比例：7:3 或 8:2

### 交叉验证法(Cross Validation)

**k折交叉验证（k-fold CV）**：

```
数据集 D，分为 k 份（k 份大小相近，数据分布一致）

第1轮: [测试][训练][训练]...[训练]
第2轮: [训练][测试][训练]...[训练]
...
第k轮: [训练][训练][训练]...[测试]

结果 = k 次测试结果的均值
```

- 最常用：**10折交叉验证** (10-fold CV)
- **留一法(LOO)**：k=m（样本数），训练集只少一个样本，评估结果最准确但计算开销大

### 自助法(Bootstrapping)

$$D' = \text{有放回采样 } m \text{ 次得到的训练集}$$

- 样本在 m 次采样中始终不被采到的概率：$\lim_{m \to \infty}(1-\frac{1}{m})^m = \frac{1}{e} \approx 0.368$
- 约 36.8% 的样本未出现在训练集中 → 用作测试集（**包外估计**）

**适用场景**：数据集较小，难以有效划分训练/测试集时。

## 性能度量

### 回归任务

**均方误差(Mean Squared Error, MSE)**：

$$MSE = \frac{1}{m}\sum_{i=1}^{m}(f(\mathbf{x}_i) - y_i)^2$$

更一般的 $p$ 范数形式：

$$E(f;D) = \left(\frac{1}{m}\sum_{i=1}^{m}|f(\mathbf{x}_i) - y_i|^p\right)^{1/p}$$

### 分类任务

#### 混淆矩阵(Confusion Matrix)

|  | 预测正例 | 预测负例 |
|--|---------|---------|
| **实际正例** | TP（真正例） | FN（假负例） |
| **实际负例** | FP（假正例） | TN（真负例） |

#### 常用指标

| 指标 | 公式 | 含义 |
|------|------|------|
| **准确率(Accuracy)** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体预测正确的比例 |
| **精确率(Precision)** | $\frac{TP}{TP+FP}$ | 预测为正的样本中，真正为正的比例 |
| **召回率(Recall)** | $\frac{TP}{TP+FN}$ | 真正为正的样本中，被正确预测的比例 |
| **F1分数** | $\frac{2 \times P \times R}{P + R}$ | Precision 和 Recall 的调和平均 |
| **Fβ分数** | $\frac{(1+\beta^2) \times P \times R}{\beta^2 P + R}$ | β>1偏重Recall，β<1偏重Precision |

#### P-R曲线

```
Precision
    |    ___
    |   /
    |  /
    | /
    |/_______________
            Recall
```

- 一个学习器的 P-R 曲线被另一个完全包住 → 后者优于前者
- **平衡点(BEP)**：P=R 时的取值
- **F1**：P 和 R 的调和平均，是 BEP 的一种更常用替代

#### ROC与AUC

**ROC曲线**：以 FPR 为横轴，TPR 为纵轴

$$TPR = \frac{TP}{TP+FN}, \quad FPR = \frac{FP}{TN+FP}$$

**AUC（Area Under ROC Curve）**：
- ROC 曲线下的面积
- AUC = 1.0 → 完美分类器
- AUC = 0.5 → 随机猜测
- AUC 越大越好

**AUC 的另一种理解**：

$$AUC = \frac{\sum_{i \in D^+} \text{rank}(x_i) - \frac{M(M+1)}{2}}{M \times N}$$

其中 $M$ 为正样本数，$N$ 为负样本数，$\text{rank}(x_i)$ 为样本按预测概率排序后的名次。

## 偏差与方差分解

### 泛化误差分解

$$E(f;D) = \text{bias}^2(\mathbf{x}) + \text{var}(\mathbf{x}) + \epsilon^2$$

其中：

| 分量 | 定义 | 来源 |
|------|------|------|
| **偏差(Bias)** | $\text{bias}^2 = (E[\hat{f}] - f)^2$ | 学习算法的拟合能力不足 |
| **方差(Variance)** | $\text{var} = E[(\hat{f} - E[\hat{f}])^2]$ | 数据扰动的影响 |
| **噪声(Noise)** | $\epsilon^2$ | 数据本身的固有噪声，不可消除 |

### 偏差-方差权衡

```
误差
 ↑
 |  \                    ╱
 |   \  Bias²          ╱ Variance
 |    \               ╱
 |     \     ___     ╱
 |      \   /   \  ╱
 |       \_/     \/  ← 总误差最低点
 |        ↑
 |     最优复杂度
 +──────────────────→ 模型复杂度
```

- **欠拟合**：偏差主导（模型太简单）
- **过拟合**：方差主导（模型太复杂）
- **目标**：找到偏差-方差的平衡点

## 比较检验

### 为什么需要统计检验？

- 单次实验的结果可能受随机性影响
- 需要判断性能差异是**统计显著的**还是**偶然的**

### 常用方法

| 方法 | 适用场景 | 原理 |
|------|---------|------|
| **配对 t 检验** | 两个算法在同一个数据集上的多次结果比较 | 均值差异的显著性 |
| **交叉验证 t 检验** | 交叉验证场景 | 5×2 CV 检验 |
| **McNemar 检验** | 两个分类器在同一测试集上的分类结果 | 列联表的卡方检验 |
| **Friedman + Nemenyi** | 多个算法在多个数据集上的比较 | 秩均值比较 |
