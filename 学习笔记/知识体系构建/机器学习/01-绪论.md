## 什么是机器学习

**定义（Tom Mitchell, 1997）**：对于某类任务 T 和性能度量 P，如果一个计算机程序在 T 上以 P 衡量的性能随着经验 E 而自我改善，就说这个程序**从经验 E 中学习**。

```
        经验 E
         ↓
程序 ──学习──→ 任务 T（性能 P 提升）
```

## 核心术语

### 数据相关

| 术语 | 符号 | 含义 |
|------|------|------|
| **数据集** | $D = \{(\mathbf{x}_1, y_1), ..., (\mathbf{x}_m, y_m)\}$ | 样本集合 |
| **样本/示例** | $(\mathbf{x}_i, y_i)$ | 单条数据记录 |
| **属性/特征** | $x^{(j)}$ | 描述样本的维度 |
| **属性空间/样本空间** | $\mathcal{X}$ | 所有属性张成的空间 |
| **特征向量** | $\mathbf{x}_i = (x_i^{(1)}; x_i^{(2)}; ...; x_i^{(d)})$ | 样本在属性空间中的坐标 |
| **标记** | $y_i$ | 样本的标签（监督信息） |
| **假设** | $h: \mathcal{X} \to \mathcal{Y}$ | 从输入到输出的映射 |
| **真相/真实** | $f$ | 数据本身存在的潜在规律 |
| **假设空间** | $\mathcal{H}$ | 所有候选假设构成的集合 |
| **版本空间** | VS | 与训练集一致的假设集合 |

### 学习任务分类

```
机器学习任务
├── 按是否有标签
│   ├── 监督学习(Supervised)    → 分类、回归
│   ├── 无监督学习(Unsupervised) → 聚类、降维
│   └── 半监督学习(Semi-supervised)
│
├── 按输出空间
│   ├── 分类(Classification)   → 离散输出
│   ├── 回归(Regression)       → 连续输出
│   └── 聚类(Clustering)       → 无标签分组
│
└── 按学习方式
    ├── 在线学习(Online) vs 批量学习(Batch)
    └── 主动学习(Active) vs 被动学习(Passive)
```

## 假设空间与归纳偏好

### 归纳(induction) vs 演绎(deduction)

- **归纳**：从特殊到一般（从数据中学习规律）
- **演绎**：从一般到特殊（从公理推导定理）
- 机器学习属于**归纳学习**

### 假设空间

假设空间 $\mathcal{H}$ 是所有可能假设的集合。

- 如果假设空间包含真实目标函数 → **现实问题中几乎不可能**
- 搜索策略：自顶向下（一般到特殊）、自底向上（特殊到一般）

### 归纳偏好(Inductive Bias)

> 学习算法对某种类型假设的偏好。

**奥卡姆剃刀原则**：若有多个假设与观察一致，则选最简单的那个。

```
归纳偏好的作用：
  训练集 ──→ 多个一致假设 ──(归纳偏好)──→ 唯一输出
```

**NFL定理（No Free Lunch Theorem）**：
- 脱离具体问题，所有学习算法的期望性能相同
- 没有"万能"的学习算法
- 学习算法的优劣必须在**具体问题**上讨论

## 发展历程

```
1950s  ──→  1960s  ──→  1980s     ──→  1990s      ──→  2000s+     ──→  2010s+
感知机    连接主义    符号主义       统计学习        集成学习        深度学习
(神经网络)  (统计学习)  (专家系统)    (SVM等)        (Boosting等)   (CNN/RNN等)
```

| 时期 | 代表 | 特点 |
|------|------|------|
| 1950s | 感知机 | 最早的神经网络 |
| 1980s | 符号主义 | 决策树、规则学习 |
| 1990s | 统计学习 | SVM、核方法 |
| 2000s | 集成方法 | 随机森林、GBDT |
| 2010s+ | 深度学习 | CNN、RNN、Transformer |
| 2020s+ | 大模型 | GPT、大语言模型 |

## 应用领域

- **计算机视觉**：图像分类、目标检测、语义分割
- **自然语言处理**：文本分类、机器翻译、对话系统
- **推荐系统**：协同过滤、内容推荐
- **医疗诊断**：疾病预测、影像分析
- **金融风控**：信用评估、欺诈检测
- **自动驾驶**：感知、决策、控制
- **游戏**：AlphaGo、Atari、星际争霸
