# 线性模型

> 对应西瓜书第3章

---

## 基本形式

给定 $d$ 个属性描述的样本 $\mathbf{x} = (x_1; x_2; ...; x_d)$：

$$f(\mathbf{x}) = w_1 x_1 + w_2 x_2 + ... + w_d x_d + b = \mathbf{w}^T\mathbf{x} + b$$

- $\mathbf{w}$ 为权重向量，决定各属性的重要性
- $b$ 为偏置项
- 线性模型**简单、可解释性好**，是许多非线性模型的基础

---

## 线性回归

### 问题定义

给定数据集 $D = \{(\mathbf{x}_1, y_1), ..., (\mathbf{x}_m, y_m)\}$，其中 $y_i \in \mathbb{R}$。

目标：找到 $\mathbf{w}$ 和 $b$ 使得 $f(\mathbf{x}_i) = \mathbf{w}^T\mathbf{x}_i + b \approx y_i$。

### 最小二乘法

**均方误差**作为损失函数：

$$(\mathbf{w}^*, b^*) = \arg\min_{(\mathbf{w}, b)} \sum_{i=1}^{m}(f(\mathbf{x}_i) - y_i)^2$$

求解方法：对 $\mathbf{w}$ 和 $b$ 分别求导，令导数为零。

**矩阵形式**（将 $b$ 吸收入 $\mathbf{w}$）：

$$\hat{\mathbf{w}}^* = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$

其中 $\mathbf{X}$ 为增广矩阵（每行前加一个1）。

> **注意**：$\mathbf{X}^T\mathbf{X}$ 必须可逆。若不可逆，可使用正则化（见下文岭回归）。

### 对数线性回归

$$\ln y = \mathbf{w}^T\mathbf{x} + b$$

即 $y = e^{\mathbf{w}^T\mathbf{x}+b}$，实质上是用线性模型逼近 $\ln y$。

**广义线性模型**：

$$y = g^{-1}(\mathbf{w}^T\mathbf{x} + b)$$

其中 $g(\cdot)$ 为**联系函数(link function)**。$g = \ln$ 时即为对数线性回归。

## 逻辑回归（对数几率回归）

### 为什么叫"对数几率"？

对于分类任务，我们需要将线性模型的输出映射到 $[0,1]$：

$$y = \frac{1}{1 + e^{-(\mathbf{w}^T\mathbf{x}+b)}}$$

这就是 **Sigmoid 函数**（也叫 Logistic 函数）。

**对数几率(logit)**：

$$\ln\frac{y}{1-y} = \mathbf{w}^T\mathbf{x} + b$$

- $\frac{y}{1-y}$ 是正例的相对可能性（几率，odds）
- 取对数后得到对数几率，被线性模型建模

### 参数估计

**极大似然估计(MLE)**：

$$\ell(\mathbf{w}, b) = \sum_{i=1}^{m} \ln p(y_i | \mathbf{x}_i; \mathbf{w}, b)$$

对于二分类：

$$p(y=1|\mathbf{x}) = \frac{1}{1+e^{-(\mathbf{w}^T\mathbf{x}+b)}}$$
$$p(y=0|\mathbf{x}) = \frac{e^{-(\mathbf{w}^T\mathbf{x}+b)}}{1+e^{-(\mathbf{w}^T\mathbf{x}+b)}}$$

等价于最小化**交叉熵损失**：

$$\ell(\mathbf{w}, b) = -\sum_{i=1}^{m}[y_i \ln p_i + (1-y_i)\ln(1-p_i)]$$

**求解方法**：梯度下降法、牛顿法。

## 线性判别分析(LDA)

### 基本思想

> 给定训练样例集，设法将样例投影到一条直线上，使得**同类样例的投影点尽可能近，异类样例的投影点尽可能远**。

### 数学推导

设：
- 类均值向量：$\boldsymbol{\mu}_0, \boldsymbol{\mu}_1$
- 类内散度矩阵：$\mathbf{S}_w = \sum_{\mathbf{x} \in X_0}(\mathbf{x}-\boldsymbol{\mu}_0)(\mathbf{x}-\boldsymbol{\mu}_0)^T + \sum_{\mathbf{x} \in X_1}(\mathbf{x}-\boldsymbol{\mu}_1)(\mathbf{x}-\boldsymbol{\mu}_1)^T$
- 类间散度矩阵：$\mathbf{S}_b = (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T$

**目标**（最大化类间距离，最小化类内距离）：

$$\max_{\mathbf{w}} J = \frac{\mathbf{w}^T\mathbf{S}_b\mathbf{w}}{\mathbf{w}^T\mathbf{S}_w\mathbf{w}}$$

**解**：$\mathbf{S}_w^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$ 的方向（$\mathbf{S}_w$ 非奇异时）

### 多分类推广

- $\mathbf{S}_w$：各类样本的散度矩阵之和
- $\mathbf{S}_b$：各类均值与全局均值之间的散度
- 投影到 $d' < d$ 维空间（降维）

## 多分类学习

### 基本思路

将多分类问题拆解为多个二分类问题。

### 拆分策略

| 策略 | 子任务数 | 描述 |
|------|---------|------|
| **OvR (One vs Rest)** | $N$ | 每个类 vs 其余所有类 |
| **OvO (One vs One)** | $\frac{N(N-1)}{2}$ | 每两个类之间训练一个分类器 |
| **MvM (Many vs Many)** | - | 纠错输出码(ECOC) |

**OvR vs OvO**：
- OvR：$N$ 个分类器，每个用全部数据训练，可能导致类别不平衡
- OvO：$\frac{N(N-1)}{2}$ 个分类器，每个只用两个类的数据训练，预测时投票

### 纠错输出码(ECOC)

- 编码：为每个类分配一个二进制码（如 `10101`）
- 训练：码的每一位对应一个二分类器
- 解码：用海明距离或欧氏距离找最接近的编码对应的类
- 优势：具有**纠错能力**

## 类别不平衡问题

### 问题

正负样本数量差距很大时，分类器倾向于预测多数类。

### 解决方案

| 方法 | 描述 |
|------|------|
| **欠采样(undersampling)** | 去掉部分多数类样本（如 EasyEnsemble） |
| **过采样(oversampling)** | 增加少数类样本（如 SMOTE） |
| **阈值移动(threshold-moving)** | 调整决策阈值 |

**再缩放（基于几率）**：

$$\frac{y'}{1-y'} = \frac{y}{1-y} \times \frac{m^-}{m^+}$$

其中 $m^+/m^-$ 为正/负样本数。

## 正则化

### 岭回归(Ridge Regression)

$$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_2^2$$

- L2 正则化，使权重趋向于较小但非零的值
- 闭式解：$\hat{\mathbf{w}} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}$

### Lasso回归

$$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_1$$

- L1 正则化，产生**稀疏解**（部分权重恰好为0）
- 具有特征选择的效果

### 弹性网络(Elastic Net)

$$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda_1\|\mathbf{w}\|_1 + \lambda_2\|\mathbf{w}\|_2^2$$

- L1 + L2 正则化的结合

## 算法对比

| 方法 | 类型 | 损失函数 | 正则化 | 特点 |
|------|------|---------|-------|------|
| 线性回归 | 回归 | MSE | 无/L2 | 闭式解，简单 |
| 逻辑回归 | 分类 | 交叉熵 | L1/L2 | 输出概率，可解释 |
| LDA | 分类/降维 | - | - | 基于类间/类内方差 |
| 岭回归 | 回归 | MSE | L2 | 防过拟合，不可逆时也适用 |
| Lasso | 回归 | MSE | L1 | 特征选择，稀疏解 |
