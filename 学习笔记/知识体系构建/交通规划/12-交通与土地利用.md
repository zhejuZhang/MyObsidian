# 12 - 交通与土地利用

> TOD模式、可达性、用地-交通互动模型

---

## 一、交通与土地利用关系概述

### 1.1 基本关系

```
土地利用 ←→ 交通系统
   ↑            ↓
用地性质    交通可达性
开发强度    出行需求
空间布局    交通供给
```

**核心互动机制**：
- 土地利用决定交通需求的产生和分布
- 交通可达性影响土地价值和开发模式
- 两者相互影响、动态演化

### 1.2 经典理论

**同心圆模型（Burgess）**：
- 城市围绕中心商业区呈同心圆扩展
- 交通可达性由中心向外递减

**扇形模型（Hoyt）**：
- 城市沿交通干线呈扇形扩展
- 交通走廊引导城市发展方向

**多核心模型（Harris & Ullman）**：
- 城市有多个功能中心
- 交通枢纽形成次级中心

**新城市主义**：
- 强调混合用地、步行友好
- TOD（公交导向开发）

## 二、可达性分析

### 2.1 可达性定义
可达性是指从一个地点到达其他地点的便利程度，是衡量交通与土地利用协调性的核心指标。

### 2.2 可达性度量方法

**空间距离法**：
$$A_i = \sum_{j} d_{ij}$$

**时间距离法**：
$$A_i = \sum_{j} t_{ij}$$

**机会累积法**：
$$A_i = \sum_{j: d_{ij} \leq D} O_j$$

- $O_j$：地点 $j$ 的机会数量（就业岗位等）
- $D$：时间/距离阈值

**引力模型法**：
$$A_i = \sum_{j} \frac{O_j}{f(d_{ij})}$$

**空间阻抗法**：
$$A_i = \frac{1}{\sum_{j} P_j \cdot f(d_{ij})}$$

### 2.3 可达性应用

| 应用领域 | 用途 |
|----------|------|
| 用地评价 | 评估地块开发价值 |
| 交通规划 | 识别可达性不足区域 |
| 公共服务 | 评估服务设施布局合理性 |
| 房价分析 | 研究交通对房价的影响 |

## 三、TOD模式

### 3.1 TOD定义
TOD（Transit-Oriented Development）是以公共交通站点为中心，在400-800m（步行5-10分钟）范围内进行的高密度、混合用地开发。

### 3.2 TOD核心原则

```
TOD核心原则
├── 公交优先
│   ├── 高品质公共交通服务
│   └── 公交站点作为社区中心
│
├── 高密度开发
│   ├── 站点周边最高密度
│   └── 密度随距离递减
│
├── 混合用地
│   ├── 居住+商业+办公
│   └── 功能互补
│
├── 步行友好
│   ├── 宜人的步行环境
│   └── 减少机动车依赖
│
└── 自行车友好
    ├── 完善的自行车设施
    └── 共享单车接驳
```

### 3.3 TOD类型

| 类型 | 特征 | 适用场景 |
|------|------|----------|
| 城市型TOD | 高密度、多功能 | 城市中心站点 |
| 社区型TOD | 中密度、居住为主 | 居住区站点 |
| 郊区型TOD | 中低密度、P+R | 郊区站点 |

### 3.4 TOD规划指标

| 指标 | 推荐值 |
|------|--------|
| 站点周边500m覆盖率 | ≥60% |
| 容积率（核心区） | 3.0-6.0 |
| 容积率（外围区） | 1.5-3.0 |
| 公交分担率 | ≥40% |
| 慢行分担率 | ≥30% |

### 3.5 TOD实施要点

**规划层面**：
- 将TOD纳入城市总体规划
- 制定TOD专项规划
- 调整用地规划支持TOD

**政策层面**：
- 容积率奖励政策
- 停车配建调整
- 公交补贴政策

**实施层面**：
- 站点周边一体化设计
- 分期开发策略
- 公私合作开发

## 四、用地-交通互动模型

### 4.1 模型类型

**Lowry模型**：
- 经典的用地-交通互动模型
- 将城市分为基本部门和服务部门
- 交通可达性影响就业和居住分布

**MEPLAN模型**：
- 基于一般均衡理论
- 考虑用地-交通-经济的互动
- 欧洲广泛应用

**UrbanSim模型**：
- 微观仿真模型
- 模拟家庭和企业的选址行为
- 开源软件

**TRANUS模型**：
- 综合用地-交通模型
- 支持情景分析
- 发展中国家应用较多

### 4.2 模型框架

```
经济活动预测
    ↓
用地需求预测 ← 交通可达性
    ↓
用地供给分配
    ↓
交通需求预测 ← 用地分布
    ↓
交通网络分配
    ↓
可达性计算 → 反馈至用地分配
```

### 4.3 关键参数

| 参数 | 说明 |
|------|------|
| 可达性弹性 | 交通改善对用地开发的影响程度 |
| 空间阻抗 | 距离对互动的影响 |
| 用地转化率 | 农业用地转为城市用地的速率 |
| 开发密度 | 单位面积开发强度 |

## 五、交通对土地价值的影响

### 5.1 研究方法

**特征价格法（Hedonic Price Method）**：
$$P = f(S, N, L, T)$$

- $P$：房价
- $S$：建筑特征
- $N$：邻里特征
- $L$：区位特征
- $T$：交通可达性

**双重差分法（DID）**：
- 比较交通设施建设前后的房价变化
- 控制其他因素影响

### 5.2 研究发现

- 轨道交通站点周边房价溢价：10-25%
- 影响范围：站点500-1000m
- 影响程度：中心区 > 郊区
- 时间效应：规划宣布期、建设期、运营期
