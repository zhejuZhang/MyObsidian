# 08 - 慢行交通规划

> 步行系统、自行车系统、共享单车、慢行品质提升

---

## 一、慢行交通概述

### 1.1 定义与范围
慢行交通指步行、自行车等速度低于15km/h的交通方式，是城市交通系统的重要组成部分。

### 1.2 慢行交通功能
- **交通功能**：短距离出行、接驳公共交通
- **健康功能**：促进体力活动
- **社会功能**：增强社区活力
- **环境功能**：零排放、低噪音

### 1.3 慢行出行特征

| 出行目的 | 步行比例 | 自行车比例 |
|----------|----------|------------|
| 通勤 | 15-25% | 10-20% |
| 上学 | 20-35% | 15-25% |
| 购物 | 30-45% | 10-15% |
| 休闲 | 50-70% | 5-10% |

## 二、步行系统规划

### 2.1 步行设施分类

```
步行系统
├── 人行道
│   ├── 路侧人行道
│   └── 独立步行街
│
├── 过街设施
│   ├── 平面过街（人行横道）
│   └── 立体过街（天桥/地下通道）
│
├── 步行连廊
│   ├── 室内连廊
│   └── 室外连廊
│
└── 其他设施
    ├── 步行广场
    └── 滨水步道
```

### 2.2 人行道设计标准

**宽度要求**：

| 区域类型 | 最小宽度(m) | 推荐宽度(m) |
|----------|------------|------------|
| 商业区 | 4.0 | 5.0-8.0 |
| 居住区 | 2.0 | 3.0-4.0 |
| 学校周边 | 3.0 | 4.0-5.0 |
| 医院周边 | 3.0 | 4.0-5.0 |
| 一般区域 | 1.5 | 2.5-3.5 |

**设施带要求**：
- 行进盲道：宽度250mm
- 提示盲道：长度300-600mm
- 缘石坡道：坡度≤1:12

### 2.3 过街设施规划

**平面过街设置条件**：
- 车行道宽度 ≤ 4车道
- 行人过街需求较大
- 车速 ≤ 40km/h

**立体过街设置条件**：
- 快速路/主干路
- 行人流量大、车速高
- 学校、医院等特殊区域

**过街设施间距**：
| 区域 | 最大间距(m) |
|------|------------|
| 商业区 | 150-200 |
| 居住区 | 200-300 |
| 一般区域 | 300-400 |

### 2.4 步行街区规划

**类型**：
| 类型 | 特征 | 适用场景 |
|------|------|----------|
| 全步行街 | 完全禁止车辆通行 | 核心商业区 |
| 半步行街 | 限时通行 | 次级商业区 |
| 公交步行街 | 仅允许公交通行 | 城市主街 |

## 三、自行车系统规划

### 3.1 自行车设施分类

```
自行车系统
├── 自行车道
│   ├── 路侧自行车道
│   ├── 独立自行车道
│   └── 自行车专用路
│
├── 停车设施
│   ├── 路侧停车架
│   └── 集中停放区
│
└── 辅助设施
    ├── 自行车租赁点
    └── 维修服务点
```

### 3.2 自行车道设计标准

**宽度要求**：

| 类型 | 单向宽度(m) | 双向宽度(m) |
|------|------------|------------|
| 独立自行车道 | 2.5 | 3.5-4.0 |
| 路侧自行车道 | 1.5-2.0 | 2.5-3.0 |
| 自行车专用路 | 3.0 | 4.0-5.0 |

**设计速度**：
- 一般自行车道：15-20km/h
- 电动自行车道：20-25km/h
- 自行车专用路：20-30km/h

### 3.3 自行车道隔离形式

| 形式 | 安全性 | 成本 | 适用场景 |
|------|--------|------|----------|
| 物理隔离（绿化带） | 最高 | 高 | 主干路 |
| 物理隔离（护栏） | 高 | 中 | 次干路 |
| 标线隔离 | 中 | 低 | 支路 |
| 路面标识 | 低 | 最低 | 低速道路 |

### 3.4 公共自行车系统

**站点布局**：
- 间距：300-500m
- 与公交站点结合
- 需求密集区加密

**车辆配置**：
- 每站点：20-40个锁止器
- 车辆周转率：3-5次/天

## 四、共享单车规划

### 4.1 发展现状
- 2016年起在中国快速普及
- 主要品牌：美团单车、哈啰单车、青桔单车
- 日均骑行量：大城市可达数百万次

### 4.2 管理挑战
- 车辆乱停乱放
- 过度投放
- 车辆维护不足
- 数据共享不足

### 4.3 管理对策

**总量控制**：
- 根据需求测算合理投放量
- 动态调整机制

**停放管理**：
- 电子围栏技术
- 禁停区设置
- 违停处罚

**数据监管**：
- 要求企业开放数据
- 建立监管平台
- 信用评价体系

## 五、慢行品质提升

### 5.1 品质评价指标

| 指标 | 说明 |
|------|------|
| 连续性 | 慢行通道是否中断 |
| 舒适性 | 路面平整度、遮荫率 |
| 安全性 | 机非分离程度、照明 |
| 便捷性 | 绕行距离、过街便利 |
| 愉悦性 | 景观品质、空间体验 |

### 5.2 提升策略

**空间保障**：
- 保障慢行空间不被侵占
- 拓宽人行道/自行车道
- 增加慢行专用空间

**环境提升**：
- 行道树种植
- 街道家具配置
- 夜间照明提升

**安全保障**：
- 机非物理隔离
- 交叉口安全设计
- 降速措施

**服务提升**：
- 遮阳避雨设施
- 休息座椅
- 饮水设施

### 5.3 完整街道理念

**核心原则**：
> 为所有使用者（行人、骑行者、公交乘客、机动车驾驶员）提供安全、便捷、舒适的街道空间。

**设计要点**：
- 优先考虑行人和骑行者
- 减少车道宽度和数量
- 增加绿化和公共空间
- 降低车速
