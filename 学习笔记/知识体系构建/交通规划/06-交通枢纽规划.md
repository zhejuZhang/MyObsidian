# 06 - 交通枢纽规划

> 枢纽分类、选址布局、换乘设计、一体化枢纽

---

## 一、交通枢纽概述

### 1.1 枢纽定义
交通枢纽是多种交通方式汇集、旅客进行换乘的关键节点，是交通网络的核心组成部分。

### 1.2 枢纽功能
- **集散功能**：汇集和疏散客流
- **换乘功能**：实现不同交通方式之间的转换
- **组织功能**：协调不同交通方式的运营
- **服务功能**：提供信息、商业等配套服务

### 1.3 枢纽分类体系

```
交通枢纽
├── 按交通方式分
│   ├── 对外交通枢纽（铁路、航空、公路）
│   ├── 城市交通枢纽（轨道交通、公交）
│   └── 综合交通枢纽（多种方式一体）
│
├── 按空间层次分
│   ├── 国家级枢纽
│   ├── 区域级枢纽
│   ├── 城市级枢纽
│   └── 片区级枢纽
│
└── 按功能定位分
    ├── 客运枢纽
    ├── 货运枢纽
    └── 客货综合枢纽
```

## 二、对外交通枢纽规划

### 2.1 铁路客站规划

**选址原则**：
- 靠近城市中心或副中心（大城市）
- 与城市轨道交通衔接
- 便于城市道路集散
- 考虑未来发展预留

**站房规模确定**：
$$S = Q \times k \times t / (60 \times \rho)$$

- $Q$：高峰小时客流量
- $k$：高峰系数
- $t$：旅客平均停留时间(min)
- $\rho$：允许旅客密度(人/m²)

**典型布局模式**：
| 模式 | 特征 | 适用场景 |
|------|------|----------|
| 线上式 | 站房在轨道上方 | 城市中心区 |
| 线侧式 | 站房在轨道侧面 | 郊区站 |
| 线下式 | 站房在轨道下方 | 特殊地形 |
| 高架式 | 轨道在站房上方 | 城市高架 |

### 2.2 机场交通规划

**集疏运体系**：
```
机场集疏运系统
├── 轨道交通（城际铁路/地铁/轻轨）
├── 高速公路/快速路
├── 机场大巴/公交
├── 出租车/网约车
└── 社会车辆
```

**核心指标**：
- 轨道交通分担率：国际先进水平 ≥ 30%
- 城市中心到机场时间：≤ 60分钟
- 值机前交通时间占比：≤ 总出行时间的40%

### 2.3 公路客运站规划

**分级体系**：
| 等级 | 日发送量(人次) | 适用城市 |
|------|---------------|----------|
| 一级 | ≥10000 | 省会/大城市 |
|二级 | 5000-10000 | 中等城市 |
| 三级 | 1000-5000 | 小城市 |
| 四级 | <1000 | 县城/乡镇 |

## 三、城市交通枢纽规划

### 3.1 轨道交通枢纽

**枢纽分级**：
| 级别 | 特征 | 换乘线路数 |
|------|------|-----------|
| A类 | 大型综合枢纽 | ≥3条轨道线 |
| B类 | 一般换乘站 | 2条轨道线 |
| C类 | 一般车站 | 1条轨道线 |

**换乘设计要求**：
- 换乘距离：≤ 200m（站台换乘）、≤ 300m（通道换乘）
- 换乘时间：≤ 5分钟（同层）、≤ 8分钟（跨层）
- 换乘通道宽度：按高峰小时换乘客流计算

### 3.2 公交接驳枢纽

**功能定位**：
- 轨道交通客流集散
- 常规公交与轨道交通换乘
- P+R（停车换乘）设施

**接驳设施配置**：
| 设施 | 配置标准 |
|------|----------|
| 公交首末站 | 每条线路2-3个停车位 |
| 出租车候客区 | 按高峰小时需求设置 |
| P+R停车场 | 每站点200-500泊位（郊区） |
| 非机动车停车 | 每站点50-200个车位 |
| 共享单车停放区 | 每站点50-100个车位 |

## 四、枢纽选址方法

### 4.1 定性分析法
- 城市总体规划要求
- 土地利用条件
- 工程地质条件
- 环境影响因素

### 4.2 定量分析法

**重心法**：
$$X_c = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}, \quad Y_c = \frac{\sum_{i=1}^{n} w_i y_i}{\sum_{i=1}^{n} w_i}$$

**层次分析法（AHP）**：
- 构建评价指标体系
- 确定各指标权重
- 多方案比选

**多目标优化模型**：
$$\min Z = w_1 f_1 + w_2 f_2 + ... + w_n f_n$$

## 五、枢纽内部设计

### 5.1 人行流线设计

**原则**：
- 人车分离
- 到发分离
- 换乘便捷

**流线组织**：
```
进站流线：入口 → 安检 → 候车 → 检票 → 站台
出站流线：站台 → 出站通道 → 出口
换乘流线：站台A → 换乘通道 → 站台B
```

### 5.2 导向标识系统
- 分级引导：区域引导 → 方向引导 → 目的地引导
- 多语言标识
- 无障碍标识
- 电子信息屏

### 5.3 无障碍设计
- 盲道系统
- 无障碍电梯
- 无障碍卫生间
- 低位服务设施

## 六、一体化枢纽（TOD枢纽）

### 6.1 核心理念
将交通枢纽与周边土地开发一体化规划，实现交通与城市的融合发展。

### 6.2 规划要点
- 枢纽上盖/周边综合开发
- 功能混合：交通+商业+办公+居住
- 步行友好：枢纽周边500m步行可达
- 密度梯度：越靠近枢纽密度越高

### 6.3 典型案例
- 香港九龙站（ICC+交通枢纽）
- 东京六本木（枢纽+综合体）
- 新加坡ION Orchard（地铁+商业）
