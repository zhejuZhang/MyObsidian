# 15 - 交通法规与政策

> 法律体系、规划标准、行业政策

---

## 一、交通法律体系

### 1.1 法律层次

```
交通法律体系
├── 法律
│   ├── 《道路交通安全法》
│   ├── 《城乡规划法》
│   └── 《公路法》
│
├── 行政法规
│   ├── 《道路交通安全法实施条例》
│   ├── 《城市道路管理条例》
│   └── 《公路管理条例》
│
├── 部门规章
│   ├── 《城市轨道交通运营管理规定》
│   ├── 《城市公共汽车和电车客运管理规定》
│   └── 《停车场建设和管理暂行规定》
│
└── 技术标准
    ├── 《城市道路交通规划设计规范》
    ├── 《城市综合交通体系规划标准》
    └── 各专项技术标准
```

### 1.2 主要法律

**《道路交通安全法》**：
- 道路通行规定
- 交通事故处理
- 执法监督
- 法律责任

**《城乡规划法》**：
- 规划编制与审批
- 规划实施与监督
- 违法责任

**《公路法》**：
- 公路规划与建设
- 公路养护
- 公路管理

## 二、交通规划标准

### 2.1 主要标准

| 标准编号 | 名称 | 内容 |
|----------|------|------|
| GB 50220 | 城市道路交通规划设计规范 | 道路网、公交、停车等 |
| GB/T 51328 | 城市综合交通体系规划标准 | 综合交通规划 |
| GB 50180 | 城市居住区规划设计标准 | 居住区交通 |
| GB 50157 | 地铁设计规范 | 轨道交通设计 |
| CJJ 37 | 城市道路工程设计规范 | 道路设计 |
| GB 50647 | 城市道路交叉口规划规程 | 交叉口设计 |

### 2.2 关键指标

**道路网密度**：
| 城市规模 | 路网密度(km/km²) |
|----------|-----------------|
| 大城市 | 5.4-7.1 |
| 中等城市 | 5.3-7.0 |
| 小城市 | 5.0-6.6 |

**公交覆盖率**：
- 300m半径覆盖率 ≥ 50%
- 500m半径覆盖率 ≥ 90%

**停车位供给**：
- 大城市：1.0-1.5 车位/户
- 中等城市：0.8-1.2 车位/户

## 三、交通政策

### 3.1 公交优先政策

**国家政策**：
- 《关于优先发展城市公共交通的指导意见》
- 公交都市创建示范工程

**具体措施**：
- 公交专用道建设
- 财政补贴政策
- 票价优惠政策
- 公交用地保障

### 3.2 小汽车管理政策

**拥有管理**：
| 城市 | 政策 |
|------|------|
| 北京 | 摇号 |
| 上海 | 拍卖 |
| 广州 | 摇号+拍卖 |
| 深圳 | 摇号+拍卖 |

**使用管理**：
- 尾号限行
- 区域限行
- 拥堵收费（规划中）

### 3.3 新能源汽车政策

**国家政策**：
- 购车补贴
- 免征购置税
- 充电设施建设补贴

**地方政策**：
- 不限行/不限购
- 专用牌照
- 充电优惠

### 3.4 停车政策

**国家政策**：
- 《关于加强城市停车设施建设的指导意见》
- 鼓励社会资本参与

**地方政策**：
- 差别化收费
- 路内停车管理
- 共享停车

## 四、规划审批制度

### 4.1 审批流程

```
规划编制 → 专家评审 → 公众参与 → 部门会审 → 政府审批 → 公布实施
```

### 4.2 审批主体

| 规划类型 | 审批机关 |
|----------|----------|
| 城市综合交通规划 | 城市人民政府 |
| 交通专项规划 | 建设主管部门 |
| 重大项目规划 | 国务院/省级政府 |

### 4.3 公众参与

**参与方式**：
- 公示公告
- 听证会
- 问卷调查
- 网络征集意见

**参与阶段**：
- 规划编制阶段
- 方案比选阶段
- 规划审批阶段

---

## 五、交通执法

### 5.1 执法体制

- 公安机关：道路交通安全管理
- 交通运输部门：运输市场监管
- 城管部门：市容秩序管理

### 5.2 执法手段

| 手段 | 内容 |
|------|------|
| 电子执法 | 闯红灯、超速、违停等 |
| 现场执法 | 酒驾、无证驾驶等 |
| 非现场执法 | 电子警察、视频监控 |

### 5.3 处罚措施

| 违法行为 | 处罚 |
|----------|------|
| 闯红灯 | 罚款200元，记6分 |
| 超速 | 罚款200-2000元，记3-12分 |
| 酒驾 | 罚款1000-2000元，记12分，暂扣驾照 |
| 醉驾 | 吊销驾照，5年内不得重新取得 |
