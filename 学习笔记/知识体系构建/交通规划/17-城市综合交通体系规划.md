# 17 - 城市综合交通体系规划

> 规划编制框架、指标体系、实施保障

---

## 一、规划概述

### 1.1 规划定位
城市综合交通体系规划是城市交通领域的总体规划，是城市总体规划的重要组成部分，是指导城市交通建设的纲领性文件。

### 1.2 规划层次

```
城市综合交通体系规划
├── 战略层面：发展目标、战略方针
├── 系统层面：各交通子系统规划
├── 设施层面：设施布局与规模
└── 实施层面：建设时序与投资
```

### 1.3 规划期限
- 远期：20年
- 近期：5年
- 与城市总体规划期限一致

## 二、规划编制框架

### 2.1 工作流程

```
前期准备
  ↓
现状调查与分析
  ↓
发展趋势研判
  ↓
发展目标与战略
  ↓
交通需求预测
  ↓
规划方案编制
  ├── 对外交通系统
  ├── 道路网络系统
  ├── 公共交通系统
  ├── 慢行交通系统
  ├── 停车系统
  └── 交通管理系统
  ↓
方案评价与优化
  ↓
实施计划与保障
```

### 2.2 现状分析内容

**社会经济分析**：
- 人口规模与结构
- 经济发展水平
- 城市空间结构

**交通设施分析**：
- 道路网络现状
- 公共交通现状
- 对外交通现状
- 停车设施现状

**交通运行分析**：
- 道路运行状况
- 公交服务水平
- 交通安全状况

**问题诊断**：
- 交通拥堵
- 公交分担率低
- 停车难
- 交通安全

---

## 三、发展目标与指标

### 3.1 发展目标

**总体目标**：
> 构建安全、便捷、高效、绿色、经济的综合交通体系。

**分目标**：
- **畅通**：道路运行状况良好
- **便捷**：出行时间可接受
- **高效**：交通系统效率高
- **绿色**：低碳环保
- **安全**：交通事故率低

### 3.2 指标体系

| 类别 | 指标 | 目标值 |
|------|------|--------|
| 道路 | 路网密度 | ≥8 km/km² |
| 道路 | 道路面积率 | 15-20% |
| 公交 | 公交分担率 | ≥40%（大城市） |
| 公交 | 站点500m覆盖率 | ≥90% |
| 慢行 | 慢行分担率 | ≥40% |
| 停车 | 停车位供给率 | ≥1.2车位/户 |
| 安全 | 万车事故率 | 持续下降 |
| 环境 | 交通碳排放强度 | 持续下降 |

## 六、实施保障

### 6.1 建设项目库

**项目分类**：
| 类别 | 内容 |
|------|------|
| 骨干工程 | 快速路、轨道交通等 |
| 网络完善 | 主干路、次干路等 |
| 公交提升 | 公交专用道、场站等 |
| 慢行改善 | 步行道、自行车道等 |
| 管理提升 | 信号系统、监控系统等 |

### 6.2 建设时序

**近期（1-5年）**：
- 解决当前突出问题
- 续建项目
- 投资少、见效快的项目

**中期（5-10年）**：
- 骨干网络建设
- 公交系统提升

**远期（10-20年）**：
- 系统完善
- 品质提升

### 6.3 投资估算

| 系统 | 投资占比 |
|------|----------|
| 道路系统 | 40-50% |
| 公共交通 | 30-40% |
| 慢行系统 | 5-10% |
| 停车设施 | 5-10% |
| 管理系统 | 5-10% |

### 6.4 政策保障

- 规划立法保障
- 资金保障机制
- 土地保障政策
- 人才队伍建设
