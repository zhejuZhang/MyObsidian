# 01 - 交通规划基础理论

> 交通规划的定义、发展历程、理论基础、规划层次与基本流程

---

## 一、交通规划的定义与内涵

### 1.1 定义
交通规划是指根据特定区域的社会经济发展目标，对交通运输系统的建设、运营和管理进行的**战略性、系统性、前瞻性**安排。

### 1.2 核心目标
- **效率**：最大化交通系统运输效率
- **公平**：保障各群体交通可达性与出行权利
- **安全**：减少交通事故，保障出行安全
- **可持续**：降低环境影响，节约资源能源

### 1.3 交通规划与相关概念辨析

| 概念 | 侧重点 | 时间尺度 |
|------|---------|----------|
| 交通规划 | 系统布局与建设安排 | 远期（10-20年） |
| 交通设计 | 具体设施的工程设计 | 实施阶段 |
| 交通管理 | 现有设施的运营优化 | 现状/近期 |
| 交通政策 | 制度与规则制定 | 政策周期 |

## 二、交通规划发展历程

### 2.1 国际发展脉络

| 阶段 | 时间 | 特征 | 代表事件 |
|------|------|------|----------|
| 萌芽期 | 1920s-1950s | 以道路建设为导向 | 美国州际公路计划 |
| 发展期 | 1950s-1970s | 四阶段法形成，交通建模兴起 | 芝加哥交通研究(CTS) |
| 反思期 | 1970s-1990s | 关注公共交通、环境、社会公平 | 美国《地面交通法》 |
| 转型期 | 1990s-2010s | 可持续交通、公交优先、TOD | 新城市主义运动 |
| 创新期 | 2010s至今 | 智能化、共享化、电动化、自动化 | MaaS、自动驾驶 |

### 2.2 中国发展脉络

| 阶段 | 时间 | 特征 |
|------|------|------|
| 起步期 | 1950s-1980s | 引入苏联模式，道路建设为主 |
| 发展期 | 1980s-2000s | 引入西方交通规划理论，四阶段法普及 |
| 快速发展期 | 2000s-2010s | 大规模轨道交通建设，综合交通体系规划 |
| 转型提升期 | 2010s至今 | 公交都市、交通强国、智慧交通 |

## 三、交通规划理论基础

### 3.1 系统工程理论
- 交通系统是一个由**人、车、路、环境**组成的复杂巨系统
- 系统论方法：整体性、层次性、动态性、开放性
- 规划需要统筹考虑各子系统的协调配合

### 3.2 供需平衡理论
- **交通需求**：由经济社会活动产生的出行需求
- **交通供给**：交通基础设施与服务的提供能力
- 核心矛盾：需求的无限增长与供给的有限性
- 规划策略：
  - 供给侧：增加设施容量、提升服务水平
  - 需求侧：引导和调控交通需求（TDM）
  - 供需协调：交通与土地利用一体化

### 3.3 可达性理论
- 可达性（Accessibility）是交通规划的核心评价指标
- 定义：从一个地点到达其他地点的便利程度
- 度量方法：
  - 空间距离法
  - 时间距离法
  - 机会累积法
  - 空间相互作用法（引力模型）

### 3.4 交通流理论
详见 [[16-交通模型与仿真]]

### 3.5 出行行为理论
- 出行决策过程：目的地选择 → 方式选择 → 路径选择
- 效用最大化原理
- 随机效用理论（[[03-交通需求分析与预测]]）
- 活动分析法（Activity-Based Approach）

### 3.6 城市空间结构理论
- 同心圆模型（Burgess）
- 扇形模型（Hoyt）
- 多核心模型（Harris & Ullman）
- 现代城市空间结构与交通的关系见 [[12-交通与土地利用]]

## 四、交通规划层次体系

### 4.1 按规划层次划分

```
战略层 ─── 综合交通战略规划（30-50年）
  │        · 发展目标、战略方向、政策框架
  │
规划层 ─── 综合交通体系规划（10-20年）
  │        · 网络布局、设施规模、结构优化
  │
实施层 ─── 交通专项规划 / 详细规划（5-10年）
  │        · 具体项目、建设时序、投资估算
  │
运营层 ─── 交通管理规划 / 年度计划（1-5年）
             · 日常管理、运营优化、养护维护
```

### 4.2 按空间层次划分

| 层次 | 范围 | 核心内容 |
|------|------|----------|
| 区域交通规划 | 城市群/经济带 | 综合运输通道、城际交通网络 |
| 城市交通规划 | 城市行政辖区 | 城市道路网、公交系统、停车系统 |
| 片区交通规划 | 城市分区/新区 | 片区路网、公交衔接、用地协调 |
| 地段交通规划 | 重点地段/项目 | 交通组织、出入口、微循环 |

### 4.3 按交通方式划分

- [[04-道路网络规划]]：道路系统规划
- [[05-公共交通规划]]：公交系统规划
- [[08-慢行交通规划]]：步行与自行车系统规划
- [[07-停车设施规划]]：停车系统规划
- 轨道交通线网规划
- 对外交通规划（铁路、公路、航空、水运）

## 五、交通规划基本流程

### 5.1 四步经典流程

```
┌─────────────┐
│  问题诊断    │ ← 现状调查、问题识别、目标确定
└──────┬──────┘
       ▼
┌─────────────┐
│  方案设计    │ ← 交通需求预测、方案生成
└──────┬──────┘
       ▼
┌─────────────┐
│  方案评价    │ ← 技术经济评价、环境影响评价
└──────┬──────┘
       ▼
┌─────────────┐
│  方案实施    │ ← 建设计划、投融资方案、实施保障
└─────────────┘
```

### 5.2 详细工作流程

1. **前期准备**
   - 项目立项与委托
   - 组建规划团队
   - 制定工作大纲

2. **现状调查与分析**
   - 社会经济现状（详见 [[02-交通调查与数据采集]]）
   - 交通设施现状
   - 交通运行现状
   - 问题诊断与成因分析

3. **发展目标与战略**
   - 上位规划解读
   - 发展趋势研判
   - 确定规划目标与指标

4. **交通需求预测**
   - 详见 [[03-交通需求分析与预测]]

5. **规划方案编制**
   - 方案生成与比选
   - 各子系统规划（道路、公交、停车等）
   - 方案综合与优化

6. **方案评价与决策**
   - 技术评价（服务水平、通行能力等）
   - 经济评价（[[14-交通经济学]]）
   - 环境评价（[[13-交通环境与可持续发展]]）
   - 社会评价

7. **实施计划与保障**
   - 建设项目库与时序安排
   - 投融资方案
   - 政策保障措施

## 六、交通规划核心原则

### 6.1 综合协调原则
- 交通与经济社会发展相适应
- 各交通方式之间协调发展
- 交通与土地利用相协调（[[12-交通与土地利用]]）

### 6.2 公交优先原则
- 优先发展公共交通（[[05-公共交通规划]]）
- 引导小汽车合理使用
- 保障慢行交通空间

### 6.3 可持续发展原则
- 资源节约、环境友好（[[13-交通环境与可持续发展]]）
- 低碳交通发展
- 代际公平

### 6.4 以人为本原则
- 关注出行者需求与体验
- 保障交通安全（[[09-交通安全规划]]）
- 促进交通公平
