# 地理加权随机森林 GWRF

> 上位概念：[[00-空间分析知识体系总索引]] > GeoAI与空间显式机器学习
> 前置知识：[[地理加权回归GWR与MGWR]]
> 相关概念：[[空间显式模型与空间表征学习]]、[[空间显式K近邻SE-KNN]]

---

## 1. 概述

**地理加权随机森林（Geographically Weighted Random Forest, GWRF / GRF）** 结合了随机森林的高维拟合能力与[[地理加权回归GWR与MGWR]]的局部借用（Data-borrowing）机制，实现了**非线性**和**空间非平稳性**的兼顾。

## 2. 核心思想

传统机器学习模型（如随机森林）默认数据实例在空间上是**同质的**。GWRF通过以下方式融入空间异质性：

> 针对每个地理锚点，只使用其**邻近样本**训练局部树，并赋予**距离衰减权重**。

## 3. 算法原理

### 3.1 传统随机森林 vs GWRF

| 特性 | 传统RF | GWRF |
|------|--------|------|
| 抽样方式 | 全局均匀Bootstrap | 局部空间加权抽样 |
| 空间假设 | 空间同质 | 空间异质 |
| 特征重要性 | 全局统一 | 每个位置不同 |
| 模型输出 | 单一全局模型 | 局部模型集合 |

### 3.2 局部空间加权抽样

对于每个锚点 $u_k$（数据实例所在位置）：

1. **确定邻域**：在带宽 $h$ 范围内的样本
2. **计算空间权重**：使用高斯核函数
$$w_{i,k} = \exp\left(-\frac{1}{2}\frac{\|x_i - u_k\|^2}{h^2}\right)$$
3. **加权抽样**：距离锚点越近的样本被抽中的概率越大
4. **训练局部树**：使用加权样本训练决策树

### 3.3 集成学习

- 对每个锚点，构建多棵局部决策树
- 通过投票（分类）或平均（回归）得到最终预测
- 每个锚点的模型结构可能不同

## 4. 核心优势

### 4.1 局部特征重要性

GWRF的独特优势是能够输出**每个地理网格的局部特征重要性**：

- 不同区域的关键影响因素可能不同
- 为灾害治理与空间追溯提供解释力
- 支持空间差异化的政策设计

### 4.2 SHAP事后解析

借助**SHAP（Shapley Additive exPlanations）** 方法：

- 对GWRF输出的局部非线性贡献进行事后解析
- 增强GeoAI模型的**透明度**
- 提供逐样本的特征贡献解释

$$\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!(|N|-|S|-1)!}{|N|!} [f(S \cup \{i\}) - f(S)]$$

## 5. 应用案例

### 5.1 滑坡敏感性评估

- **问题**：预测滑坡发生的敏感区域
- **优势**：局部特征重要性揭示不同区域的驱动因素
- **发现**：山区与河谷的滑坡驱动因素存在空间异质性

### 5.2 土壤重金属浓度预测

- **目标**：Cr、Pb、As、Hg的高精度预测
- **方法**：GWRF + SHAP解释
- **优势**：超越传统RF和GWR模型
- **应用**：污染源追溯与治理

## 6. 与相关方法的比较

| 方法 | 非线性 | 空间非平稳性 | 可解释性 |
|------|--------|-------------|----------|
| OLS | × | × | 高 |
| GWR | × | ✓ | 高 |
| RF | ✓ | × | 中 |
| GWRF | ✓ | ✓ | 高（局部特征重要性） |
| MGWR | × | ✓（多尺度） | 高 |

## 7. 实现工具

- **R语言**：`gwrf` 包
- **Python**：基于PySAL和scikit-learn的自定义实现
- **关键参数**：带宽选择（AICc、CV）
