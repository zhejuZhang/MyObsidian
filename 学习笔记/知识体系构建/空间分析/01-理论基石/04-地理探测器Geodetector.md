# 地理探测器 Geodetector

> 上位概念：[[00-空间分析知识体系总索引]] > 理论基石
> 前置知识：[[地理学第二定律与空间异质性]]
> 相关概念：[[地理加权回归GWR与MGWR]]

## 1. 概述

**地理探测器（Geodetector）** 由王劲峰团队提出，是专门用于**量化空间分层异质性（Spatially Stratified Heterogeneity, SSH）** 并探测其背后核心驱动因素的空间统计方法。

## 2. 核心思想

地理探测器的核心假设：

> 如果一个自变量对因变量有重要影响，那么因变量的空间分布应该与自变量的空间分布具有**相似性**。

## 3. 核心指标：q统计量

### 3.1 数学表达式

$$q = 1 - \frac{\sum_{h=1}^L N_h \sigma_h^2}{N \sigma^2}$$

| 参数 | 含义 |
|------|------|
| $L$ | 层数（分层数量） |
| $N_h$ | 第 $h$ 层的样本数 |
| $N$ | 总样本数 |
| $\sigma_h^2$ | 第 $h$ 层的因变量方差 |
| $\sigma^2$ | 全局因变量方差 |

### 3.2 q值解释

| q值范围 | 含义 |
|---------|------|
| $q = 0$ | 自变量对因变量无解释力 |
| $q = 1$ | 自变量完全解释因变量的空间分布 |
| $q$ 越大 | 自变量的解释力越强 |

**物理意义：** q统计量衡量的是层内方差（Within-strata variance）的加权总和与全局方差（Pooled variance）的比例。q值越大，说明分层变量能够解释的因变量空间变异比例越高。

## 4. 四大探测器

### 4.1 因子探测器（Factor Detector）

- **目的**：检验自变量X是否解释了因变量Y的空间分层异质性
- **统计量**：q值
- **假设检验**：
  - $H_0$：q = 0（无解释力）
  - $H_1$：q > 0（有解释力）

### 4.2 交互作用探测器（Interaction Detector）

- **目的**：检测两个自变量共同作用时的效果
- **方法**：比较 $q(X_1 \cap X_2)$ 与 $q(X_1)$ 和 $q(X_2)$ 的关系

**交互作用类型：**

| 类型 | 条件 | 含义 |
|------|------|------|
| 非线性减弱 | $q(X_1 \cap X_2) < \min(q(X_1), q(X_2))$ | 两变量交互弱于各自独立作用 |
| 单变量非线性减弱 | $\min(q(X_1), q(X_2)) < q(X_1 \cap X_2) < \max(q(X_1), q(X_2))$ | 介于两者之间 |
| 双变量增强 | $q(X_1 \cap X_2) > \max(q(X_1), q(X_2))$ | 交互强于各自独立作用 |
| 独立 | $q(X_1 \cap X_2) = q(X_1) + q(X_2)$ | 两变量独立作用 |
| 非线性增强 | $q(X_1 \cap X_2) > q(X_1) + q(X_2)$ | 协同效应 |

### 4.3 风险探测器（Risk Detector）

- **目的**：判断两个子区域间的属性均值是否存在显著差异
- **方法**：t统计量检验

### 4.4 生态探测器（Ecological Detector）

- **目的**：比较两个自变量对因变量空间分布的影响是否有显著差异
- **方法**：F统计量检验

## 5. Geodetector的优势

| 优势 | 说明 |
|------|------|
| **无线性假设** | 不要求解释变量与响应变量之间存在线性关系 |
| **物理意义清晰** | q统计量直接度量解释力 |
| **适用类型多样** | 可处理连续变量和分类变量 |
| **交互作用检测** | 能检测变量间的非线性交互 |
| **无需预设模型** | 数据驱动，不依赖先验模型设定 |

## 6. 应用案例

### 6.1 人口分布差异研究

- **案例**："秦岭-淮河"南北人口分布差异
- **方法**：以地理区域为分层变量，计算q统计量
- **发现**：地理分层对人口分布具有显著解释力

### 6.2 生态空间功能异质性

- **案例**：新疆地区"生产-生活-生态（三生）"空间功能异质性评价
- **方法**：以不同功能区为分层变量
- **发现**：不同地理阶层对生态质量的解释力不同

### 6.3 城市土地利用变化

- **案例**：地铁距离与地形交互影响土地利用
- **方法**：交互作用探测器
- **发现**：两个变量存在非线性增强交互效应

## 7. 三维扩展：3D-SHI

近期，地理探测器被扩展至**三维空间（3D-SHI）**：

- **应用场景**：海洋温度大尺度水团分布
- **创新点**：表征真三维空间分层异质性
- **方法**：将二维分层扩展为三维体素分层

## 8. 与其他方法的比较

| 方法 | 核心功能 | 与Geodetector的关系 |
|------|----------|---------------------|
| GWR/MGWR | 建模空间非平稳性 | 互补：GWR关注局域回归，Geodetector关注分层解释力 |
| Moran's I | 度量空间自相关 | 不同维度：Moran's I关注集聚，Geodetector关注异质性 |
| OLS回归 | 全局参数估计 | Geodetector无需线性假设 |
| 随机森林 | 非线性预测 | Geodetector更注重解释而非预测 |
