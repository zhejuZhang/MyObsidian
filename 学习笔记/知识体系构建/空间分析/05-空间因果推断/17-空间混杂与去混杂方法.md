# 空间混杂与去混杂方法

> 上位概念：[[00-空间分析知识体系总索引]] > 空间因果推断
> 前置知识：[[空间因果推断理论框架]]
> 相关概念：[[SUTVA假设与空间溢出效应]]、[[空间因果发现算法]]

## 1. 概述

**空间混杂（Spatial Confounding）** 指的是存在一种未被观测到、却具有明显空间结构特征的变量（如局部气象微环境、社会经济隔离地位等），它同时充当了干预变量与结果变量的**"共同原因"**，从而严重扭曲了因果效应的无偏估计。

## 2. 空间混杂的本质

### 2.1 因果图表示

```
    U（未观测空间混杂）
   ↙        ↘
  A            Y
（干预）    （结果）

U同时影响A和Y，导致A与Y的相关性 ≠ 因果效应
```

### 2.2 空间混杂的特征

| 特征 | 说明 |
|------|------|
| **未观测性** | 无法在数据中直接测量 |
| **空间结构** | 具有明显的空间模式 |
| **共同原因** | 同时影响干预和结果 |
| **普遍存在** | 几乎所有空间研究都面临 |

### 2.3 示例

| 研究领域 | 未观测混杂 | 影响 |
|----------|-----------|------|
| **环境健康** | 局部气象微环境 | 影响污染暴露和健康结果 |
| **城市研究** | 社会经济隔离地位 | 影响政策实施和居民福祉 |
| **生态学** | 微生境条件 | 影响物种分布和环境变量 |

## 3. 三大解决方案

### 3.1 Spatial+（薄板回归样条调整）

#### 理论机制

在传统具有空间随机效应的模型中，平滑的干预变量与空间残差结构会产生严重的**共线性**导致估计崩塌。

#### 算法步骤

```
1. 对干预变量拟合空间趋势
   └── 使用薄板回归样条（Thin plate splines）

2. 提取残差分量
   └── 剔除纯空间依赖后的独立非空间信息

3. 替换原始变量
   └── 将残差分量投入主模型回归
```

#### 数学表达

$$A = f(lon, lat) + \epsilon_A$$

$$\hat{A}_{residual} = A - \hat{f}(lon, lat)$$

$$Y = \beta \hat{A}_{residual} + g(lon, lat) + \epsilon$$

#### 适用条件

- 干预变量含有**非空间信息**
- 干预变量为**连续分布**
- 避免受限空间回归（RSR）的过度调整偏差

### 3.2 谱调整方法（Spectral Adjustment）

#### 理论机制

将混杂问题从**空间域**迁移至**图傅里叶变换的谱域（Spectral Domain）**。

#### 核心假设

> 未观测混杂主要支配大尺度、低频特征，而高频、微观尺度上的干预变化不易受系统性混杂影响。

#### 算法原理

基于**Matérn相干函数**数学推导证明：

1. 在因果响应均值模型中加入经过**Leroux空间自回归平滑化处理**的干预变量作为控制项
2. 等效在频域滤除低频共因偏差

#### 数学表达

空间域：$Y = \beta A + \epsilon, \quad \epsilon = \lambda W \epsilon + u$

谱域：$Y = \beta A_{high-freq} + \gamma A_{smooth} + \epsilon$

#### 适用条件

- 干预变量与混杂变量在**空间全局尺度高度相关**
- 研究者试图恢复**微观因果可识别性**

### 3.3 空间去混杂器（Spatial Deconfounder）

#### 理论机制

由 Oprescu 等人提出的深度学习双阶段框架，基于一个反直觉的绝妙洞见：

> **"空间溢出干扰"恰好为重构隐性混杂提供了"多原因信号（Multi-cause signal）"**

#### 核心思想

由于某地及其邻域的干预分配（如各邻域空气质量）均受同一**潜在气象场**支配，算法可以从邻里干预模式中逆向重构出**"替代混杂因子（Substitute confounder）"**。

#### 算法流程

```
阶段1：重构替代混杂因子
├── 输入：邻里干预模式 {A_s, A_{Ns}}
├── 模型：条件变分自编码器（CVAE）+ 空间拉普拉斯先验
└── 输出：替代混杂因子 Z

阶段2：因果效应校正
├── 输入：替代混杂因子 Z + 干预 A + 结果 Y
├── 模型：U-Net 或 GNN 结果模型
└── 输出：校正后的因果效应估计
```

#### 技术细节

**CVAE架构：**

$$q_\phi(z|a) = \mathcal{N}(\mu_\phi(a), \sigma_\phi^2(a))$$

$$p_\theta(a|z) = \text{Decoder}_\theta(z)$$

**空间拉普拉斯先验：**

$$p(z) \propto \exp\left(-\frac{1}{2} z^T L z\right)$$

其中 $L$ 是图拉普拉斯矩阵。

#### 适用条件

- 无需显式环境混杂参数模型
- 适用于**复杂非线性关联**
- 攻克"空间溢出"与"隐性未观测混杂"**两大耦合难题**

## 4. 三种方法的比较

| 方法 | 理论基础 | 适用场景 | 优势 | 局限 |
|------|----------|----------|------|------|
| **Spatial+** | 薄板样条残差分离 | 连续干预变量 | 物理意义清晰 | 需要空间趋势可分离 |
| **谱调整** | 图傅里叶变换 | 全局尺度混杂 | 理论严格 | 假设高频无混杂 |
| **Deconfounder** | 深度学习重构 | 复杂非线性 | 无需参数假设 | 计算复杂、黑箱 |

## 6. 应用案例

### 6.1 空气质量与健康

- **问题**：空气质量对居民健康的影响
- **混杂**：气象条件、社会经济地位
- **方法**：Spatial Deconfounder
- **发现**：校正后因果效应显著低于相关性估计

### 6.2 教育政策评估

- **问题**：学校质量对学生成绩的影响
- **混杂**：社区环境、家庭背景
- **方法**：Spatial+
- **发现**：局域效应存在显著空间异质性
