## 1. 空间计量经济学的学科地位

**空间计量经济学（Spatial Econometrics）** 是将空间依赖性和空间异质性纳入计量经济分析的方法论体系。在城市分析中，几乎所有涉及地理数据的回归问题都需要考虑空间效应。

### 1.1 为什么需要空间计量

经典OLS回归假设**误差项独立同分布**，但城市数据几乎总是违反这一假设：

| 违反类型 | 现象 | 后果 |
|----------|------|------|
| **空间自相关** | 相邻区域的残差相关 | 标准误偏小、t检验失效 |
| **空间异质性** | 回归系数随空间变化 | 全局模型误导 |
| **空间溢出** | X影响相邻区域的Y | 直接效应估计偏误 |

## 2. 空间权重矩阵

### 2.1 构建方法

| 方法 | 定义 | 适用场景 |
|------|------|----------|
| **Rook邻接** | 共享边界的单元为邻居 | 面状数据 |
| **Queen邻接** | 共享边或角的单元为邻居 | 面状数据 |
| **距离阈值** | 距离 < d 的单元为邻居 | 点数据 |
| **K近邻** | 最近K个单元为邻居 | 非均匀分布 |
| **核权重** | 权重随距离连续衰减 | 连续空间过程 |

### 2.2 空间权重矩阵的标准化

- **行标准化**：$w_{ij}^* = w_{ij} / \sum_j w_{ij}$
- 使空间滞后成为邻域值的加权平均
- 标准化后特征值谱有助于模型选择

## 3. 空间回归模型体系

### 3.1 空间滞后模型（SLM / SAR）

$$y = \rho W y + X\beta + \varepsilon$$

- $\rho$：空间自回归系数
- $W y$：因变量的空间滞后
- **含义**：因变量存在空间溢出效应，相邻区域的Y相互影响
- **适用**：房价溢出、经济扩散

### 3.2 空间误差模型（SEM）

$$y = X\beta + u, \quad u = \lambda W u + \varepsilon$$

- $\lambda$：空间误差自相关系数
- **含义**：遗漏变量存在空间自相关
- **适用**：未观测到的空间因素导致的残差相关

### 3.3 空间杜宾模型（SDM）

$$y = \rho W y + X\beta + WX\theta + \varepsilon$$

- 同时包含因变量和自变量的空间滞后
- **含义**：Y受本地X和邻域X共同影响
- **优势**：SLM和SEM都是SDM的特例
- **适用**：政策溢出、邻里效应

### 3.4 空间杜宾误差模型（SDEM）

$$y = X\beta + WX\theta + u, \quad u = \lambda W u + \varepsilon$$

### 3.5 通用嵌套模型（GNS / Manski模型）

$$y = \rho W y + X\beta + WX\theta + u, \quad u = \lambda W u + \varepsilon$$

- 包含所有空间效应，是所有模型的超集
- 实践中常因多重共线性而退化

## 4. 模型选择策略

### 4.1 Lagrange乘数检验（LM检验）

| 检验 | 原假设 | 备择假设 |
|------|--------|----------|
| LM-Lag | 无空间滞后 | SLM |
| LM-Error | 无空间误差 | SEM |
| Robust LM-Lag | 控制误差后无滞后 | SLM |
| Robust LM-Error | 控制滞后后无误差 | SEM |

### 4.2 信息准则与似然比检验

- **AIC / BIC**：模型拟合与复杂度的权衡
- **LR检验**：嵌套模型比较（如SDM是否退化为SLM）

### 4.3 一般到特殊策略

1. 估计SDM（最一般形式）
2. 检验是否退化为SLM或SEM
3. 如果Wald和LR检验都不能拒绝退化，则采用简化模型

## 5. 直接效应与间接效应

### 5.1 效应分解

空间模型中自变量的效应需要分解为：

| 效应类型 | 含义 | 计算 |
|----------|------|------|
| **直接效应** | X对本地Y的影响 | 包含反馈效应 |
| **间接效应（溢出效应）** | X对邻域Y的影响 | $\partial y_i / \partial x_j, j \neq i$ |
| **总效应** | 直接 + 间接 | $\partial y / \partial x_k$ |

### 5.2 效应分解的矩阵表达

对于SDM模型，总效应矩阵为：

$$\frac{\partial y}{\partial X_k} = (I - \rho W)^{-1}(\beta_k I + \theta_k W)$$

- **直接效应**：该矩阵对角线元素的均值
- **间接效应**：该矩阵非对角线元素的行和均值

## 6. 空间面板模型

### 6.1 基本形式

$$y_{it} = \rho \sum_j w_{ij} y_{jt} + X_{it}\beta + \mu_i + \nu_t + \varepsilon_{it}$$

- $\mu_i$：空间固定效应
- $\nu_t$：时间固定效应
- **双向固定效应**控制不可观测的空间和时间异质性

### 6.2 动态空间面板

$$y_{it} = \tau y_{i,t-1} + \rho \sum_j w_{ij} y_{jt} + \delta \sum_j w_{ij} y_{j,t-1} + X_{it}\beta + \varepsilon_{it}$$

- $\tau$：时间依赖（惯性）
- $\rho$：空间依赖（同期溢出）
- $\delta$：时空依赖（跨期溢出）

## 7. 城市分析中的应用场景

| 应用场景 | 推荐模型 | 原因 |
|----------|----------|------|
| 房价影响因素 | SDM | 本地和邻域特征都影响房价 |
| 经济增长收敛 | SLM/动态面板 | 经济溢出效应显著 |
| 犯罪率建模 | SEM/SLM | 遗漏变量空间相关 |
| 政策效果评估 | SDM | 政策存在空间溢出 |
| 空气污染扩散 | SLM | 污染物空间传播 |
