## 1. ABM概述

### 1.1 核心思想

**多智能体建模（Agent-Based Model, ABM）** 是一种自下而上的建模方法，通过模拟**异质主体（Agent）** 的行为及其交互来理解宏观现象的涌现机制。

与CA的区别：

| 维度 | CA | ABM |
|------|-----|-----|
| **主体** | 固定网格 | 移动智能体 |
| **状态** | 简单离散状态 | 复杂内部状态 |
| **行为** | 局部规则 | 决策逻辑 |
| **移动性** | 无 | 有 |
| **学习能力** | 无 | 可有 |
| **适用** | 空间格局 | 行为涌现 |

### 1.2 Agent的基本特征

| 特征 | 含义 | 城市Agent示例 |
|------|------|-------------|
| **自治性** | 独立决策 | 居民自主选择居住地 |
| **异质性** | 个体差异 | 不同收入/偏好 |
| **交互性** | 与环境和其他Agent交互 | 邻里效应 |
| **适应性** | 根据经验调整行为 | 学习更优通勤路线 |
| **有限理性** | 信息不完全下的决策 | 满意而非最优 |

## 2. 经典城市ABM模型

### 2.1 Schelling隔离模型

**Thomas Schelling**（1971）的隔离模型是城市ABM的经典：

- **设定**：Agent有两种类型（红/蓝），分布在棋盘上
- **规则**：如果同类邻居比例低于阈值，则迁移到满意位置
- **涌现**：即使个体偏好很弱（如仅需30%同类），也会导致**宏观完全隔离**

$$\text{满意度} = \frac{\text{同类邻居数}}{\text{总邻居数}} \geq \theta$$

**启示**：微观偏好 → 宏观隔离，无需"强歧视"即可产生严重隔离

### 2.2 居住选择模型

| 扩展维度 | 方法 | 意义 |
|----------|------|------|
| **连续空间** | 真实地理空间 | 现实化 |
| **多类型** | 多种族/收入群体 | 复杂交互 |
| **动态偏好** | 偏好随时间变化 | 适应性 |
| **经济约束** | 房价、预算 | 市场机制 |
| **社会网络** | 影响信息传播 | 扩展邻域 |

### 2.3 Bass扩散模型

**Bass扩散模型** 描述新产品/技术在城市中的扩散：

$$\frac{dN(t)}{dt} = \left(p + q\frac{N(t)}{M}\right)(M - N(t))$$

- $p$：创新系数（外部影响）
- $q$：模仿系数（内部影响/口碑）
- $M$：市场潜力
- $N(t)$：已采纳者数量

**城市应用**：共享单车扩散、新能源汽车采纳、智慧城市应用推广

## 3. ABM设计框架

### 3.1 ODD协议

**ODD（Overview, Design concepts, Details）** 是ABM描述的标准协议：

| 部分 | 内容 |
|------|------|
| **Overview** | 目的、主体、状态变量 |
| **Design concepts** | 基本原则、涌现、适应性、目标、学习、预测、交互、随机性、集体行为 |
| **Details** | 初始化、输入数据、子模型 |

### 3.2 设计要素

| 要素 | 问题 | 决策 |
|------|------|------|
| **主体定义** | 谁是Agent？ | 居民/企业/政府 |
| **行为空间** | Agent在哪里活动？ | 地理空间/社会空间 |
| **决策规则** | 如何做决策？ | 效用最大化/启发式/学习 |
| **交互机制** | 如何交互？ | 邻里效应/市场/通信 |
| **时间步长** | 多长时间一步？ | 日/月/年 |
| **环境** | 什么环境？ | 静态/动态/可消耗 |

## 4. 决策机制

### 4.1 效用最大化

$$U_i = \sum_k \beta_k x_{ik} + \varepsilon_i$$

- 离散选择模型（Logit/Probit）
- 随机效用理论

### 4.2 启发式规则

- **满意原则**：找到足够好的选项即可
- **模仿**：跟随成功者的选择
- **习惯**：重复之前的选择

### 4.3 强化学习

$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$

- Agent通过试错学习最优策略
- 适用于通勤路径选择、出行方式选择

### 4.4 BDI架构

**BDI（Belief-Desire-Intention）** 模型：

| 组件 | 含义 | 城市Agent |
|------|------|-----------|
| **Belief** | 对世界的认知 | 认为某区域房价会上涨 |
| **Desire** | 目标 | 希望住在好学区 |
| **Intention** | 行动计划 | 在目标区域寻找房源 |

## 6. ABM在城市分析中的应用

| 应用场景 | Agent类型 | 研究问题 |
|----------|----------|----------|
| **居住隔离** | 居民 | 种族/收入隔离的涌现 |
| **交通出行** | 通勤者 | 出行方式选择、拥堵形成 |
| **房地产市场** | 买方/卖方 | 房价形成、泡沫 |
| **传染病传播** | 居民 | 空间传播动态 |
| **政策评估** | 居民+政府 | 政策对行为的影响 |
| **创新扩散** | 企业/个人 | 技术采纳的时空动态 |

## 7. ABM的校准与验证

| 挑战 | 问题 | 应对 |
|------|------|------|
| **参数多** | 微观参数难以校准 | ABC（近似贝叶斯计算） |
| **随机性** | 每次运行结果不同 | 多次运行取统计量 |
| **涌现验证** | 宏观模式 ≠ 目标 | 多尺度验证 |
| **行为数据缺乏** | 微观行为数据稀缺 | 实验经济学、调查 |
