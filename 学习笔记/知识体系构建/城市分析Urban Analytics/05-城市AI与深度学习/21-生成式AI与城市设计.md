## 1. 生成式AI在城市领域的兴起

### 1.1 范式转变

| 传统方法 | 生成式AI方法 |
|----------|-------------|
| 人工设计规则 | 从数据学习模式 |
| 参数化建模 | 端到端生成 |
| 单一方案 | 多样化输出 |
| 专家经验驱动 | 数据驱动 + 条件控制 |

### 1.2 城市生成任务

| 任务 | 输入 | 输出 | 应用 |
|------|------|------|------|
| **城市形态生成** | 条件/约束 | 建筑/街区形态 | 规划方案生成 |
| **街景生成** | 文本/语义图 | 街景图像 | 可视化设计 |
| **平面图生成** | 约束条件 | 建筑平面图 | 建筑设计 |
| **地图生成** | 条件/风格 | 地图渲染 | 制图自动化 |
| **规划方案** | 场地条件 | 用地布局 | 规划辅助 |

## 2. 生成对抗网络（GAN）

### 2.1 GAN基础

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

- **生成器 G**：从噪声生成逼真数据
- **判别器 D**：区分真实和生成数据
- **对抗训练**：G和D相互博弈

### 2.2 城市GAN变体

| 模型 | 特点 | 城市应用 |
|------|------|----------|
| **pix2pix** | 图像到图像翻译 | 卫星图→地图 |
| **CycleGAN** | 无配对翻译 | 风格迁移 |
| **StyleGAN** | 风格控制生成 | 城市街景生成 |
| **SPADE** | 语义图条件生成 | 语义→街景 |
| **LayoutGAN** | 布局生成 | 建筑布局 |

### 2.3 城市形态GAN

- **FloorPlanGAN**：生成建筑平面图
- **UrbanGAN**：生成城市街区形态
- **ParcelGAN**：生成地块划分方案

## 3. 扩散模型

### 3.1 扩散模型基础

**前向过程**（加噪）：
$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)$$

**反向过程**（去噪）：
$$p_\theta(x_{t-1} | x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \Sigma_\theta(x_t, t))$$

### 3.2 扩散模型优势

| 优势 | 说明 |
|------|------|
| **生成质量** | 优于GAN的图像质量 |
| **训练稳定性** | 无模式崩溃问题 |
| **多样性** | 更好的模式覆盖 |
| **可控性** | 条件生成、引导 |

### 3.3 城市扩散模型

| 模型 | 条件 | 应用 |
|------|------|------|
| **Stable Diffusion** | 文本 | 城市设计可视化 |
| **ControlNet** | 边缘图/分割图 | 精细控制生成 |
| **DALL-E** | 文本 | 概念设计 |
| **条件扩散模型** | 规划约束 | 方案生成 |

### 3.4 文本到城市设计

```
文本描述："一个高密度混合用途街区，底层商业，上层住宅，中央有小型广场"
    ↓
文本编码器 → 条件向量
    ↓
扩散模型 → 城市设计方案图像
```

## 4. 参数化城市设计

### 4.1 形状语法（Shape Grammar）

- **规则**：用形状变换规则生成建筑形态
- **L-System**：用字符串重写规则生成分形结构
- **应用**：建筑立面生成、城市肌理生成

### 4.2 程序化建模

| 方法 | 工具 | 应用 |
|------|------|------|
| **Houdini** | 程序化3D建模 | 城市环境生成 |
| **CityEngine** | CGA形状语法 | 城市建模 |
| **Grasshopper** | 参数化设计 | 建筑形态 |
| **Blender Geometry Nodes** | 节点式建模 | 城市场景 |

### 4.3 生成式AI + 参数化设计

- **AI生成概念** → **参数化细化**：AI提供创意，参数化保证可行性
- **条件控制**：生成式AI输出作为参数化系统的输入条件

## 5. 强化学习与城市设计

### 5.1 设计优化

| 方法 | 状态空间 | 动作空间 | 奖励 |
|------|----------|----------|------|
| **布局优化** | 当前布局 | 添加/移动/删除元素 | 功能指标 |
| **参数调优** | 当前参数 | 参数调整 | 性能指标 |
| **多目标优化** | 设计状态 | 设计操作 | 多目标权衡 |

### 5.2 应用场景

- **建筑平面优化**：最大化采光、通风、空间利用率
- **用地布局优化**：最大化可达性、最小化冲突
- **交通信号优化**：最小化延误

## 6. 城市设计的AI辅助工作流

### 6.1 概念设计阶段

```
场地分析（GIS+遥感）→ AI生成概念方案 → 设计师筛选 → 参数化细化
```

### 6.2 方案评估阶段

```
生成方案 → 可达性分析 + 空间句法 + 日照分析 → AI评分 → 方案迭代
```

### 6.3 人机协作模式

| 模式 | 角色分工 | 特点 |
|------|----------|------|
| **AI生成 + 人筛选** | AI出方案，人选择 | 高效率 |
| **人设计 + AI优化** | 人定框架，AI细化 | 保创意 |
| **交互式迭代** | 人机交互迭代 | 深度协作 |

## 7. 伦理与挑战

| 挑战 | 问题 | 应对 |
|------|------|------|
| **设计同质化** | AI倾向生成常见模式 | 多样性约束 |
| **版权问题** | 生成内容的版权归属 | 法律框架 |
| **过度依赖** | 设计师能力退化 | 辅助而非替代 |
| **偏见** | 训练数据的偏见 | 多样化数据集 |
