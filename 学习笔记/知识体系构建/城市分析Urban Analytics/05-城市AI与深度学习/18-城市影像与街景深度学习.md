# 城市影像与街景深度学习

## 1. 城市影像分析的任务体系

### 1.1 遥感影像任务

| 任务 | 输入 | 输出 | 应用 |
|------|------|------|------|
| **语义分割** | 遥感影像 | 像素级分类图 | 土地利用 |
| **目标检测** | 遥感影像 | 边界框+类别 | 建筑/车辆检测 |
| **实例分割** | 遥感影像 | 像素级实例 | 单体建筑提取 |
| **变化检测** | 多时相影像 | 变化图 | 城市扩张 |
| **超分辨率** | 低分辨率影像 | 高分辨率影像 | 影像增强 |

### 1.2 街景影像任务

| 任务 | 输入 | 输出 | 应用 |
|------|------|------|------|
| **语义分割** | 街景图像 | 像素级标签 | 街道要素识别 |
| **感知评分** | 街景图像 | 安全感/活力等分数 | 城市品质评估 |
| **属性识别** | 街景图像 | 多标签分类 | 街道特征提取 |
| **图像生成** | 条件/文本 | 街景图像 | 城市设计 |

## 2. 遥感语义分割

### 2.1 经典模型

| 模型 | 架构 | 特点 |
|------|------|------|
| **U-Net** | 编码器-解码器 + 跳跃连接 | 遥感分割基准 |
| **DeepLabV3+** | 空洞空间金字塔池化 | 多尺度特征 |
| **SegFormer** | Transformer编码器 | 全局上下文 |
| **MANet** | 多尺度注意力网络 | 自适应融合 |
| **UNetFormer** | CNN+Transformer混合 | 兼顾局部和全局 |

### 2.2 遥感分割的特殊挑战

| 挑战 | 原因 | 解决方案 |
|------|------|----------|
| **大尺寸影像** | 遥感影像通常GB级 | 滑动窗口裁切 |
| **类内差异大** | 同类地物外观多样 | 多尺度特征 |
| **类间差异小** | 不同地物外观相似 | 注意力机制 |
| **标注成本高** | 专业标注昂贵 | 半监督/自监督 |

### 2.3 预训练与迁移学习

- **ImageNet预训练**：在自然图像上预训练 → 微调到遥感
- **遥感专用预训练**：SatMAE、Scale-MAE
- **自监督学习**：对比学习（SimCLR、MoCo）在遥感上的应用

## 3. 街景深度学习

### 3.1 街景语义分割

**Cityscapes数据集**是街景分割的标准benchmark：

| 类别 | 像素占比 | 难度 |
|------|----------|------|
| 道路 | 高 | 低 |
| 建筑 | 高 | 中 |
| 车辆 | 中 | 中 |
| 行人 | 低 | 高 |
| 交通标志 | 极低 | 高 |

### 3.2 街景感知评分

**Place Pulse**项目（MIT）收集了人类对城市街景的感知评分：

| 感知维度 | 含义 | 预测方法 |
|----------|------|----------|
| **安全（Safe）** | 行走安全感 | CNN回归 |
| **活力（Lively）** | 生命力 | CNN回归 |
| **美丽（Beautiful）** | 美观程度 | CNN回归 |
| **富有（Wealthy）** | 经济水平 | CNN回归 |
| **无聊（Boring）** | 乏味程度 | CNN回归 |
| **压抑（Depressing）** | 压抑感 | CNN回归 |

### 3.3 街景感知的应用

- **房价预测**：街景感知分数与房价的相关性
- **健康研究**：街道环境与居民心理健康
- **步行友好度**：街景要素与步行意愿
- **犯罪预测**：街景"破窗效应"

### 3.4 街景要素与城市品质

| 街景要素 | 城市品质关联 | 分析方法 |
|----------|-------------|----------|
| 绿视率（GVI） | 正相关：活力、美观 | 语义分割像素比 |
| 天空可视域 | 正相关：开阔感 | 语义分割 |
| 建筑密度 | 负相关：压抑感 | 语义分割 |
| 人行道宽度 | 正相关：步行友好 | 实例分割 |

## 4. 目标检测与实例分割

### 4.1 遥感目标检测

| 模型 | 特点 | 应用 |
|------|------|------|
| **YOLO系列** | 实时检测 | 车辆计数 |
| **Faster R-CNN** | 高精度 | 建筑检测 |
| **Oriented R-CNN** | 旋转检测框 | 遥感旋转目标 |
| **LSKNet** | 大选择性核 | 遥感专用 |

### 4.2 遥感实例分割

- **Mask R-CNN**：像素级实例分割
- **建筑实例分割**：单体建筑轮廓提取
- **车辆实例分割**：停车场车辆计数

## 5. 变化检测

### 5.1 方法分类

| 方法 | 原理 | 特点 |
|------|------|------|
| **Siamese Network** | 双分支特征对比 | 经典框架 |
| **Transformer变化检测** | 时相交叉注意力 | 全局对比 |
| **差异注意力** | 显式学习差异特征 | 突出变化 |

### 5.2 城市应用

- **城市扩张监测**：建设用地时空变化
- **违章建筑检测**：建筑变化与审批对比
- **灾害损失评估**：灾前灾后对比

## 6. 多模态城市感知

### 6.1 遥感 + 街景

- 遥感提供**俯视**视角（屋顶、绿地分布）
- 街景提供**平视**视角（立面、人行道）
- 融合后形成**全方位**城市感知

### 6.2 图像 + 文本

- **CLIP风格对齐**：街景图像与文本描述的语义对齐
- **视觉问答（VQA）**：对城市图像进行问答
- **图像描述生成**：自动生成城市街景描述
