# 假设检验

> 用数据判断假设是否成立，是统计推断的核心方法。

---

## 假设检验的基本框架

### 基本概念

| 概念 | 定义 | 示例 |
|------|------|------|
| **原假设 $H_0$** | 要检验的假设（默认成立） | $\mu = 100$ |
| **备择假设 $H_1$** | 与原假设对立 | $\mu \neq 100$ 或 $\mu > 100$ |
| **检验统计量** | 用于判断的统计量 | $t = \frac{\bar{x}-\mu_0}{s/\sqrt{n}}$ |
| **p值** | 在 $H_0$ 下观测到当前或更极端结果的概率 | |
| **显著性水平 $\alpha$** | 判定的阈值 | 0.05 |
| **拒绝域** | 导致拒绝 $H_0$ 的统计量取值范围 | |

### 检验步骤

```
1. 建立假设 H₀ 和 H₁
        │
2. 选择显著性水平 α（通常0.05）
        │
3. 确定检验统计量
        │
4. 计算检验统计量的观测值
        │
5. 计算p值或确定临界值
        │
6. 做出决策：p < α 则拒绝 H₀
        │
7. 得出结论
```

## 单样本检验

### 单样本t检验

**目的**：检验总体均值是否等于某个值

$$H_0: \mu = \mu_0 \quad vs \quad H_1: \mu \neq \mu_0$$

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad df = n-1$$

**条件**：
- 随机样本
- 正态总体（或n ≥ 30）

### 单样本比例检验

$$H_0: p = p_0 \quad vs \quad H_1: p \neq p_0$$

$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$$

### 单样本方差检验

$$H_0: \sigma^2 = \sigma_0^2$$

$$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2}$$

---

## 双样本检验

### 独立样本t检验

**目的**：比较两个独立总体的均值

$$H_0: \mu_1 = \mu_2 \quad vs \quad H_1: \mu_1 \neq \mu_2$$

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$

**方差齐性**：
- 方差相等：合并方差，$df = n_1 + n_2 - 2$
- 方差不等：Welch近似，$df$ 用Satterthwaite公式

### 配对样本t检验

**目的**：比较配对数据的均值差异

$$t = \frac{\bar{d}}{s_d / \sqrt{n}}, \quad df = n-1$$

其中 $d_i = x_{1i} - x_{2i}$

### 两样本比例检验

$$z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})(\frac{1}{n_1}+\frac{1}{n_2})}}$$

其中 $\hat{p} = \frac{x_1 + x_2}{n_1 + n_2}$

## p值

### 定义

在原假设为真的条件下，观测到当前或更极端结果的概率。

### 解读

| p值范围 | 含义 | 决策 |
|---------|------|------|
| p < 0.01 | 非常强的证据 | 拒绝 $H_0$ |
| 0.01 ≤ p < 0.05 | 较强的证据 | 拒绝 $H_0$ |
| 0.05 ≤ p < 0.10 | 弱证据 | 边缘显著 |
| p ≥ 0.10 | 不足的证据 | 不拒绝 $H_0$ |

> [!warning] p值不是
> - 不是 $H_0$ 为真的概率
> - 不是 $H_1$ 为真的概率
> - 不是效应大小的度量
> - 不是结果重要性的度量

### 单尾 vs 双尾检验

| 类型 | $H_1$ | p值计算 |
|------|-------|---------|
| 双尾 | $\mu \neq \mu_0$ | $P(|T| \geq |t|)$ |
| 左尾 | $\mu < \mu_0$ | $P(T \leq t)$ |
| 右尾 | $\mu > \mu_0$ | $P(T \geq t)$ |

## 两类错误

| | $H_0$ 为真 | $H_0$ 为假 |
|---|---|---|
| **拒绝 $H_0$** | 第一类错误 (α) | 正确决策 (1-β) |
| **不拒绝 $H_0$** | 正确决策 (1-α) | 第二类错误 (β) |

### 第一类错误（Type I Error）

- **定义**：$H_0$ 为真时错误地拒绝
- **概率**：$\alpha$（显著性水平）
- **控制**：设定 $\alpha$ 水平（通常0.05）

### 第二类错误（Type II Error）

- **定义**：$H_0$ 为假时未能拒绝
- **概率**：$\beta$
- **控制**：增大样本量

### 统计功效（Power）

$$\text{Power} = 1 - \beta = P(\text{拒绝} H_0 | H_1 \text{为真})$$

- 通常要求 ≥ 0.80
- 取决于：效应大小、样本量、α水平

## 效应大小

p值只告诉你差异是否显著，效应大小告诉你差异有多大。

| 检验类型 | 效应大小指标 | 小/中/大 |
|----------|-------------|----------|
| t检验 | Cohen's d | 0.2/0.5/0.8 |
| 方差分析 | η²（eta-squared） | 0.01/0.06/0.14 |
| 卡方检验 | Cramér's V | 0.1/0.3/0.5 |
| 相关 | r | 0.1/0.3/0.5 |

**Cohen's d**：

$$d = \frac{\bar{x}_1 - \bar{x}_2}{s_p}$$

## 多重检验问题

### 问题

同时进行多个检验时，第一类错误率膨胀。

进行m个独立检验，至少一个假阳性的概率：
$$P(\text{至少1个假阳性}) = 1 - (1-\alpha)^m$$

| 检验数m | α=0.05时的膨胀率 |
|---------|-----------------|
| 1 | 5% |
| 5 | 23% |
| 10 | 40% |
| 20 | 64% |

### 校正方法

| 方法 | 公式 | 特点 |
|------|------|------|
| **Bonferroni** | $\alpha' = \alpha/m$ | 最保守 |
| **Holm** | 逐步校正 | 比Bonferroni强 |
| **FDR（BH）** | 控制错误发现率 | 适用于大量检验 |

## 置信区间与假设检验的关系

- 如果 $\mu_0$ 不在95%置信区间内 ⟺ 双尾检验在α=0.05水平拒绝 $H_0$
- 置信区间提供更多信息（效应大小+精度）

## 常见误区

1. **p < 0.05就重要**：统计显著 ≠ 实际重要
2. **不拒绝 $H_0$ 就是 $H_0$ 为真**：只能说证据不足
3. **p值是效应大小**：p值受样本量影响，大样本微小差异也显著
4. **只看p值**：应结合效应大小和置信区间
5. **多重检验不校正**：大量检验需要校正
