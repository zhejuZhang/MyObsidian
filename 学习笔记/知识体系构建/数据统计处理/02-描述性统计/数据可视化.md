# 数据可视化

> 一图胜千言。选择正确的图表类型是有效传达数据信息的关键。

---

## 图表选择指南

### 按分析目的选择

| 目的 | 推荐图表 | 适用数据 |
|------|----------|----------|
| 查看分布 | 直方图、密度图、箱线图 | 单个数值变量 |
| 比较大小 | 条形图、棒棒糖图 | 分类 vs 数值 |
| 查看趋势 | 折线图、面积图 | 时间序列 |
| 查看关系 | 散点图、气泡图 | 两个数值变量 |
| 查看组成 | 饼图、堆叠条形图、树图 | 部分与整体 |
| 查看相关 | 热力图、散点矩阵 | 多个数值变量 |
| 地理数据 | 地图、等值线图 | 空间数据 |

## 单变量可视化

### 直方图（Histogram）
- **用途**：查看数值变量的分布形态
- **关键参数**：组距（bin width）
- **注意**：组距选择会影响图形外观

```
频次
 │  ┌──┐
 │  │  │ ┌──┐
 │  │  │ │  │ ┌──┐
 │  │  │ │  │ │  │
 └──┴──┴─┴──┴─┴──┴───
   值的范围
```

### 箱线图（Boxplot）
- **用途**：五数概括、异常值识别
- **变体**：小提琴图（Violin plot）、缺口箱线图

```
         ┌───┐
    ─────┤   ├─────    ← 触须
         └───┘
    │     │ │     │
   Q1   中位数  Q3
         ○         ← 异常值
```

### 条形图（Bar Chart）
- **用途**：分类变量的频次或比例
- **注意**：Y轴应从0开始，避免误导

### 密度图（Density Plot）
- **用途**：平滑版的直方图
- **优点**：不受组距影响，可叠加比较

## 双变量可视化

### 散点图（Scatter Plot）
- **用途**：两个数值变量的关系
- **增强**：颜色/大小编码第三变量、趋势线

```
y │    ·  ·
  │  ·  · · ·
  │   · · · ·
  │    · ·
  └─────────── x
```

### 分组箱线图
- **用途**：分类变量对数值变量的影响
- **优点**：同时比较分布和集中趋势

### 热力图（Heatmap）
- **用途**：两个分类变量的交叉统计
- **常见**：相关系数矩阵

### 堆叠条形图
- **用途**：分类变量的组成比较
- **变体**：百分比堆叠条形图

---

## 多变量可视化

### 散点矩阵（Scatterplot Matrix）
- **用途**：多个变量两两关系的总览
- **优点**：一次查看所有变量对

### 气泡图（Bubble Chart）
- **用途**：三个数值变量（x, y, 大小）
- **第四维**：可用颜色编码

### 平行坐标图
- **用途**：高维数据的模式发现
- **优点**：可同时查看多个变量

### 小倍数图（Small Multiples）
- **用途**：按类别分面展示
- **优点**：避免在一张图中编码太多维度

## 图表设计原则

### 数据墨水比（Data-Ink Ratio）

Edward Tufte 提出：最大化数据墨水，最小化非数据墨水。

| 原则 | 做法 |
|------|------|
| 去除不必要的网格线 | 保留主要参考线即可 |
| 去除3D效果 | 2D足以表达 |
| 去除装饰性元素 | 不用图片填充条形图 |
| 直接标注 | 标注直接放在数据点上 |

### 颜色使用

| 场景 | 配色方案 |
|------|----------|
| 分类数据 | 定性色板（不同颜色） |
| 顺序数据 | 顺序色板（单色渐变） |
| 发散数据 | 发散色板（双色渐变） |
| 色盲友好 | 使用色盲安全色板 |

### 常见误导手法

| 手法 | 问题 | 正确做法 |
|------|------|----------|
| Y轴不从0开始 | 夸大差异 | 条形图Y轴从0开始 |
| 双Y轴 | 制造假关联 | 分成两张图 |
| 3D效果 | 扭曲比例 | 使用2D |
| 不恰当的组距 | 隐藏或夸大模式 | 尝试多种组距 |
| 截断时间轴 | 误导趋势 | 展示完整时间范围 |

## 常见误区

1. **饼图的滥用**：类别超过5-6个时，条形图更清晰
2. **忽视数据墨水比**：装饰性元素分散注意力
3. **3D图表**：扭曲数据关系，几乎没有好处
4. **不标注轴标签和单位**：图表必须自解释
5. **只展示一种图表**：同一数据用多种图表可以发现不同模式
