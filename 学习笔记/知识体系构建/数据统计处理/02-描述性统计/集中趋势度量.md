# 集中趋势度量

> 数据的"中心"在哪里？三种主要度量各有适用场景。

---

## 三大集中趋势指标

### 1. 均值（Mean）

**算术平均数**，最常用的集中趋势指标。

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

**加权均值**（各数据权重不同时）：

$$\bar{x}_w = \frac{\sum_{i=1}^{n}w_i x_i}{\sum_{i=1}^{n}w_i}$$

**性质**：
- 利用全部数据信息
- 对异常值敏感（不稳健）
- $\sum(x_i - \bar{x}) = 0$（偏差之和为零）
- 适用于定距/定比数据

**示例**：收入数据 {3, 5, 6, 8, 100}，均值 = 24.4，被极端值100拉高。

### 2. 中位数（Median）

排序后位于中间位置的值。

$$\text{Median} = \begin{cases} x_{(n+1)/2} & \text{if } n \text{ is odd} \\ \frac{x_{n/2} + x_{n/2+1}}{2} & \text{if } n \text{ is even} \end{cases}$$

**性质**：
- 不受极端值影响（稳健）
- 只利用排序信息，未用全部数据
- 适用于定序及以上数据

**示例**：同一组数据 {3, 5, 6, 8, 100}，中位数 = 6，不受100影响。

### 3. 众数（Mode）

出现频率最高的值。

**性质**：
- 唯一适用于定类数据的集中趋势指标
- 可能无众数或多众数
- 不受极端值影响
- 可能不唯一

**示例**：{1, 2, 2, 3, 4} → 众数 = 2
**多众数**：{1, 1, 2, 2, 3} → 众数 = 1 和 2

## 均值、中位数、众数的关系

### 对称分布
```
    ╱╲
   ╱  ╲
  ╱    ╲
 ╱      ╲
──────────
  均值 = 中位数 = 众数
```

### 右偏分布（正偏）
```
    ╱╲
   ╱  ╲╲
  ╱    ╲╲╲
 ╱      ╲╲╲╲╲
────────────────
  众数 < 中位数 < 均值
```

### 左偏分布（负偏）
```
       ╱╲
      ╱  ╲
    ╱╱    ╲
╲╲╲╲      ╲
────────────────
  均值 < 中位数 < 众数
```

> [!tip] Pearson近似关系
> 对于轻微偏斜的单峰分布：$\text{Mean} - \text{Mode} \approx 3(\text{Mean} - \text{Median})$

## 其他集中趋势指标

### 截尾均值（Trimmed Mean）

去掉两端一定比例的数据后计算均值。

$$\bar{x}_{\text{trim}} = \frac{1}{n-2k}\sum_{i=k+1}^{n-k}x_{(i)}$$

- 常用 5% 或 10% 截尾
- 兼顾均值的信息利用和中位数的稳健性
- 体育评分中常用（去掉最高分和最低分）

### 几何均值（Geometric Mean）

$$G = \left(\prod_{i=1}^{n}x_i\right)^{1/n} = \sqrt[n]{x_1 \cdot x_2 \cdots x_n}$$

- 适用于比率数据、增长率
- 所有数据必须为正
- 总是 ≤ 算术均值（等号仅当所有值相等）

**示例**：年增长率 10%, 20%, -5%
$$G = (1.10 \times 1.20 \times 0.95)^{1/3} - 1 = 7.4\%$$

### 调和均值（Harmonic Mean）

$$H = \frac{n}{\sum_{i=1}^{n}\frac{1}{x_i}}$$

- 适用于速率、比率的平均
- 是倒数的算术均值的倒数
- $H \leq G \leq \bar{x}$（均值不等式）

**示例**：去程60km/h，回程40km/h，平均速度 = 调和均值 = 48km/h

## 选择指南

| 数据类型 | 推荐指标 | 原因 |
|----------|----------|------|
| 定类 | 众数 | 唯一可用 |
| 定序 | 中位数 | 有排序但无等距 |
| 定距（对称） | 均值 | 信息利用最充分 |
| 定距（偏斜） | 中位数 | 不受极端值影响 |
| 定比（增长率） | 几何均值 | 乘法关系 |
| 定比（速率） | 调和均值 | 倒数关系 |

## 常见误区

1. **偏斜数据用均值**：收入、房价等右偏数据应报告中位数
2. **定类数据求均值**：血型的"平均值"没有意义
3. **忽视多峰分布**：双峰分布的均值和中位数可能在两个峰之间，不代表典型值
4. **混淆平均增长率和平均增长**：应用几何均值而非算术均值
