# 判别分析

> 已知类别的情况下，找到最佳分类边界。

---

## 基本概念

### 目的

- 建立分类规则
- 降维（判别方向）
- 理解变量对分类的贡献

### 与聚类的区别

| | 聚类分析 | 判别分析 |
|---|---|---|
| 类别 | 未知 | 已知 |
| 目的 | 发现分组 | 建立分类规则 |
| 类型 | 无监督 | 有监督 |

---

## 线性判别分析（LDA）

### 核心思想

找到投影方向，使组间变异最大，组内变异最小。

### 目标函数

$$\max \frac{\mathbf{w}^T\mathbf{S}_B\mathbf{w}}{\mathbf{w}^T\mathbf{S}_W\mathbf{w}}$$

- $\mathbf{S}_B$：组间散布矩阵
- $\mathbf{S}_W$：组内散布矩阵

### 判别函数

$$\delta_k(x) = x^T\Sigma^{-1}\mu_k - \frac{1}{2}\mu_k^T\Sigma^{-1}\mu_k + \ln\pi_k$$

将x分到 $\delta_k(x)$ 最大的组。

### 假设

- 各组协方差矩阵相等
- 数据多元正态分布

---

## 二次判别分析（QDA）

### 与LDA的区别

- 不假设协方差矩阵相等
- 判别边界是二次的

### 判别函数

$$\delta_k(x) = -\frac{1}{2}\ln|\Sigma_k| - \frac{1}{2}(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k) + \ln\pi_k$$

---

## Fisher判别分析

### 核心思想

找到投影方向，最大化组间变异与组内变异的比值。

### 判别函数

$$y = \mathbf{w}^T\mathbf{x}$$

其中 $\mathbf{w} = \mathbf{S}_W^{-1}(\bar{x}_1 - \bar{x}_2)$

### 多组情况

最多可以得到 min(k-1, p) 个判别函数。

## 判别分析的评估

### 分类指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 准确率 | $(TP+TN)/N$ | 整体正确率 |
| 混淆矩阵 | 各类别的分类情况 | 详细评估 |
| 交叉验证 | 留一法或k折 | 模型泛化能力 |

### 混淆矩阵

```
              预测
            A    B    C
实际  A    50    3    2
      B     4   45    1
      C     1    2   47
```

## 变量选择

### 方法

| 方法 | 描述 |
|------|------|
| 前向选择 | 逐步加入变量 |
| 后向消除 | 逐步删除变量 |
| 逐步回归 | 结合前向和后向 |

### Wilks' Lambda

$$\Lambda = \frac{|\mathbf{W}|}{|\mathbf{T}|}$$

- $\mathbf{W}$：组内散布矩阵
- $\mathbf{T}$：总散布矩阵
- Λ越小，判别效果越好

## 与其他方法的比较

| 方法 | 特点 | 适用 |
|------|------|------|
| LDA | 线性边界，假设正态 | 正态数据 |
| QDA | 二次边界 | 协方差不等 |
| 逻辑回归 | 不假设分布 | 二分类 |
| SVM | 非线性边界 | 高维数据 |
| 决策树 | 非线性，可解释 | 混合数据 |

## 常见误区

1. **忽视假设**：LDA需要正态和等协方差假设
2. **不评估泛化能力**：应该用交叉验证
3. **变量太多**：高维时需要变量选择或正则化
4. **混淆LDA和PCA**：LDA是有监督的，PCA是无监督的
