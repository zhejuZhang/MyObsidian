## 调查设计

### 抽样方法

| 方法 | 描述 | 适用 |
|------|------|------|
| 简单随机抽样 | 等概率抽样 | 总体同质 |
| 分层抽样 | 按比例分层 | 总体有分组 |
| 整群抽样 | 抽取群组 | 地理分散 |
| 配额抽样 | 按比例分配 | 快速调查 |

### 问卷设计

| 要素 | 考虑 |
|------|------|
| 问题类型 | 单选、多选、开放 |
| 量表选择 | Likert、语义差异 |
| 问题顺序 | 先易后难 |
| 选项设计 | 互斥、穷尽 |

## 描述性分析

### 基本统计

```python
# 频次分析
df['satisfaction'].value_counts()
df['satisfaction'].value_counts(normalize=True)

# 交叉表
pd.crosstab(df['gender'], df['satisfaction'])
pd.crosstab(df['gender'], df['satisfaction'], normalize='index')
```

## 常见误区

1. **样本不具代表性**：便利抽样可能导致偏差
2. **问卷设计不当**：引导性问题影响结果
3. **忽视信效度**：应检验问卷的信度和效度
4. **过度解读**：相关不等于因果
