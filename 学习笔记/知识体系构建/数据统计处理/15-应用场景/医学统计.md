# 医学统计

> 统计学在医学研究中的应用，是循证医学的基础。

---

## 研究设计类型

### 观察性研究

| 类型 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 横断面研究 | 特定时点的调查 | 快速、便宜 | 无法推断因果 |
| 病例对照研究 | 比较患病/未患病 | 适合罕见病 | 回忆偏差 |
| 队列研究 | 跟踪暴露/未暴露 | 可推断因果 | 耗时、昂贵 |

### 实验性研究

| 类型 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 随机对照试验 | 随机分组 | 金标准 | 昂贵、伦理限制 |
| 交叉试验 | 自身对照 | 减少变异 | 洗脱期问题 |
| 非劣效试验 | 检测不差于标准 | 实用 | 非劣效界值难定 |

## 主要指标

### 生存分析

| 指标 | 描述 |
|------|------|
| 生存率 | 特定时间点的存活概率 |
| 中位生存时间 | 50%患者发生事件的时间 |
| 风险比（HR） | 两组风险的比值 |

### 诊断试验

| 指标 | 公式 | 含义 |
|------|------|------|
| 灵敏度 | $TP/(TP+FN)$ | 检出患病的能力 |
| 特异度 | $TN/(TN+FP)$ | 排除未患病的能力 |
| 阳性预测值 | $TP/(TP+FP)$ | 阳性结果中真阳性的比例 |
| 阴性预测值 | $TN/(TN+FN)$ | 阴性结果中真阴性的比例 |

### ROC曲线

```
灵敏度
  1│      ╱───
   │    ╱
   │  ╱
   │╱
  0└──────── 1-特异度
```

AUC：曲线下面积，衡量诊断准确性。

## 多重比较

### 问题

### 解决方案

## Meta分析

### 定义

**Meta分析**是系统性地合并多个研究结果的统计方法。

### 步骤

```
1. 文献检索
2. 质量评估
3. 数据提取
4. 统计分析
   ├── 固定效应模型
   └── 随机效应模型
5. 异质性检验
6. 发表偏倚检验
```

### 异质性

$$I^2 = \frac{Q - df}{Q} \times 100\%$$

| I² | 含义 |
|----|------|
| < 25% | 低异质性 |
| 25-75% | 中等异质性 |
| > 75% | 高异质性 |

## 常见误区

1. **p < 0.05就有临床意义**：统计显著不等于临床重要
2. **忽视置信区间**：应同时报告效应大小和置信区间
3. **不做ITT分析**：ITT是临床试验的标准
4. **多重比较不校正**：应控制假阳性率
