# 置换检验与Bootstrap

> 基于重抽样的统计推断方法，不依赖分布假设。

---

## 置换检验（Permutation Test）

### 核心思想

在零假设下，组标签是随机的。通过重新排列标签来构建检验统计量的分布。

### 步骤

```
1. 计算观测数据的检验统计量 T_obs
2. 随机重新排列组标签
3. 计算重新排列后的统计量 T*
4. 重复B次（如10000次）
5. p值 = P(|T*| ≥ |T_obs|)
```

### 精确置换检验

当可能的排列数较少时，可以计算所有排列。

**示例**：n₁=3, n₂=3，总排列数 = $\binom{6}{3} = 20$

### 蒙特卡洛置换检验

当排列数太大时，随机抽样排列。

### 优点

- 精确（小样本时）
- 不依赖分布假设
- 适用于任意统计量

### 缺点

- 大样本时计算量大
- 需要随机化假设

## Bootstrap方法

### 核心思想

用样本的经验分布来近似总体分布，通过重抽样估计统计量的变异性。

### 步骤

```
1. 从原始样本中有放回地抽取n个观测值
2. 计算统计量 θ*
3. 重复B次（B ≥ 1000）
4. 用B个θ*构建置信区间
```

### Bootstrap置信区间

#### 百分位法

$$CI = [\theta^*_{(\alpha/2)}, \theta^*_{(1-\alpha/2)}]$$

取Bootstrap分布的分位数。

#### BCa法（偏差校正和加速）

校正偏差和偏斜，更准确。

#### 基本法

$$CI = [2\hat{\theta} - \theta^*_{(1-\alpha/2)}, 2\hat{\theta} - \theta^*_{(\alpha/2)}]$$

### Bootstrap标准误

$$SE_{boot} = \sqrt{\frac{1}{B-1}\sum_{b=1}^{B}(\theta^*_b - \bar{\theta}^*)^2}$$

---

## Bootstrap的应用

### 均值的Bootstrap

```
原始样本: {3, 7, 2, 8, 5}
Bootstrap样本1: {5, 3, 3, 8, 7} → x̄₁ = 5.2
Bootstrap样本2: {7, 5, 2, 2, 8} → x̄₂ = 4.8
...
Bootstrap样本B: {3, 8, 5, 7, 3} → x̄_B = 5.2

Bootstrap标准误 = SD(x̄₁, x̄₂, ..., x̄_B)
```

### 中位数的Bootstrap

传统方法难以估计中位数的标准误，Bootstrap可以。

### 回归系数的Bootstrap

| 方法 | 描述 |
|------|------|
| 残差Bootstrap | 重抽样残差 |
| 配对Bootstrap | 重抽样(x,y)对 |
| 参数Bootstrap | 假设误差分布 |

---

## 置换检验 vs Bootstrap

| 维度 | 置换检验 | Bootstrap |
|------|----------|-----------|
| 目的 | 假设检验 | 参数估计/置信区间 |
| 重排方式 | 重新排列标签 | 有放回重抽样 |
| 零假设 | 需要 | 不需要 |
| p值 | 直接计算 | 需要额外步骤 |

---

## 其他重抽样方法

### Jackknife

- 每次删除一个观测值
- 计算统计量
- 用于偏差估计和标准误

$$SE_{jack} = \sqrt{\frac{n-1}{n}\sum_{i=1}^{n}(\hat{\theta}_{(i)} - \bar{\theta}_{(\cdot)})^2}$$

### 子样本方法

- 抽取较小的子样本
- 计算统计量
- 用于大规模数据

## 实际应用

### 应用场景

| 场景 | 方法 | 用途 |
|------|------|------|
| 两组比较 | 置换检验 | 假设检验 |
| 中位数CI | Bootstrap | 区间估计 |
| 回归系数CI | Bootstrap | 区间估计 |
| 复杂统计量 | Bootstrap | 标准误估计 |
| 模型比较 | 置换检验 | 显著性检验 |

### 示例：比较两组均值

```python
# 置换检验
T_obs = mean(group1) - mean(group2)
T_null = []
for i in range(10000):
    combined = shuffle(group1 + group2)
    T_null.append(mean(combined[:n1]) - mean(combined[n1:]))
p_value = mean(abs(T_null) >= abs(T_obs))
```

## 计算考虑

### Bootstrap样本量

- B ≥ 1000 用于标准误
- B ≥ 10000 用于置信区间
- B ≥ 10000 用于p值

### 置换检验的排列数

- 精确检验：计算所有排列
- 蒙特卡洛：随机抽样10000+次

## 常见误区

1. **Bootstrap=万能**：小样本时Bootstrap也不可靠
2. **置换检验=Bootstrap**：两者目的和方法不同
3. **B太小**：重抽样次数不足会导致结果不稳定
4. **忽视计算成本**：大数据时可能很慢
