# 秩次检验方法

> 用数据的秩次代替原始值进行检验，不依赖分布假设。

---

## 单样本检验

### Wilcoxon符号秩检验

**目的**：检验总体中位数是否等于某个值

**假设**：
- $H_0: M = M_0$
- $H_1: M \neq M_0$

**步骤**：
1. 计算 $d_i = x_i - M_0$
2. 排除 $d_i = 0$ 的观测
3. 对 $|d_i|$ 排秩
4. 计算正秩和 $W^+$ 和负秩和 $W^-$
5. 取较小者作为检验统计量

**适用**：对称分布的中位数检验

---

## 两样本检验

### Mann-Whitney U检验（Wilcoxon秩和检验）

**目的**：比较两个独立样本的分布

**假设**：
- $H_0$：两组分布相同
- $H_1$：一组的值系统性地大于另一组

**步骤**：
1. 合并两组数据
2. 对合并数据排秩
3. 计算各组的秩和 $R_1, R_2$
4. 计算U统计量

$$U_1 = n_1 n_2 + \frac{n_1(n_1+1)}{2} - R_1$$
$$U_2 = n_1 n_2 + \frac{n_2(n_2+1)}{2} - R_2$$

**检验统计量**：$U = \min(U_1, U_2)$

**适用**：两组独立数据的比较

### Wilcoxon符号秩检验（配对）

**目的**：比较两个配对样本

**步骤**：
1. 计算配对差值 $d_i = x_{1i} - x_{2i}$
2. 排除 $d_i = 0$
3. 对 $|d_i|$ 排秩
4. 计算正秩和与负秩和
5. 取较小者检验

**适用**：配对数据、前后比较

## 多样本检验

### Kruskal-Wallis检验

**目的**：比较多个独立样本的分布

**假设**：
- $H_0$：所有组分布相同
- $H_1$：至少有一组不同

**统计量**：

$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$

**大样本时**：$H \sim \chi^2(k-1)$

**适用**：单因素ANOVA的非参数替代

### Friedman检验

**目的**：比较多个配对/重复测量样本

**统计量**：

$$\chi^2_F = \frac{12}{nk(k+1)} \sum_{i=1}^{k} R_i^2 - 3n(k+1)$$

**适用**：重复测量ANOVA的非参数替代

## 秩次相关

### Spearman秩相关系数

$$r_s = 1 - \frac{6\sum d_i^2}{n(n^2-1)}$$

其中 $d_i$ 是两个变量秩次的差值。

**特点**：
- 衡量单调关系（不一定是线性）
- 对异常值稳健
- $-1 \leq r_s \leq 1$

### Kendall秩相关系数（τ）

$$\tau = \frac{C - D}{\binom{n}{2}}$$

其中C是和谐对数，D是非和谐对数。

**特点**：
- 衡量一致性
- 比Spearman更稳健
- 解释更直观

---

## 方法选择指南

```
数据类型？
├── 独立样本
│   ├── 两组 → Mann-Whitney U
│   └── 多组 → Kruskal-Wallis
├── 配对样本
│   ├── 两组 → Wilcoxon符号秩
│   └── 多组 → Friedman
└── 相关
    ├── 单调关系 → Spearman
    └── 一致性 → Kendall
```

## 大样本近似

| 方法 | 大样本近似 | 条件 |
|------|-----------|------|
| Mann-Whitney | 正态分布 | n₁, n₂ ≥ 10 |
| Wilcoxon | 正态分布 | n ≥ 20 |
| Kruskal-Wallis | 卡方分布 | 各组n ≥ 5 |
| Friedman | 卡方分布 | n ≥ 10 |

## 效应大小

### Mann-Whitney的效应大小

$$r = \frac{Z}{\sqrt{n}}$$

| r值 | 效应大小 |
|-----|----------|
| 0.1 | 小 |
| 0.3 | 中 |
| 0.5 | 大 |

### Kruskal-Wallis的效应大小

$$\eta^2_H = \frac{H-k+1}{n-k}$$

## 常见误区

1. **检验中位数**：Mann-Whitney检验的是分布，不只是中位数
2. **忽视结的处理**：结会影响检验统计量
3. **配对数据用独立检验**：配对数据应用Wilcoxon符号秩
4. **大样本用非参数**：大样本时参数方法更高效
