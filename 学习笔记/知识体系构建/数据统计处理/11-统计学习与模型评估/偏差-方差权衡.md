# 偏差-方差权衡

> 模型复杂度的核心问题：偏差和方差此消彼长。

---

## 数学分解

### 预测误差的分解

$$E[(Y - \hat{f}(x))^2] = [\text{Bias}(\hat{f}(x))]^2 + \text{Var}(\hat{f}(x)) + \sigma^2$$

其中：

$$\text{Bias}(\hat{f}(x)) = E[\hat{f}(x)] - f(x)$$

$$\text{Var}(\hat{f}(x)) = E[(\hat{f}(x) - E[\hat{f}(x)])^2]$$

### 各项含义

| 项 | 含义 | 来源 |
|---|---|---|
| 偏差² | 模型系统性偏离真实函数 | 模型假设错误 |
| 方差 | 模型对训练数据的敏感度 | 模型太灵活 |
| σ² | 数据本身的噪声 | 不可约误差 |

---

## 偏差与方差的来源

### 高偏差（欠拟合）

- 模型太简单
- 遗漏重要特征
- 假设过强

**示例**：用线性模型拟合非线性数据

### 高方差（过拟合）

- 模型太复杂
- 参数太多
- 训练数据中的噪声也被学习

**示例**：用高阶多项式拟合少量数据

## 控制偏差-方差权衡

### 方法

| 方法 | 降低偏差 | 降低方差 |
|------|----------|----------|
| 增加特征 | ✓ | |
| 减少特征 | | ✓ |
| 正则化 | | ✓ |
| 集成方法 | ✓ | ✓ |
| 更多数据 | | ✓ |
| 交叉验证 | | ✓ |

### 正则化

通过惩罚复杂度来降低方差。

$$\text{Loss} = \sum(y_i - \hat{y}_i)^2 + \lambda \sum \beta_j^2$$

### 集成方法

| 方法 | 降低偏差 | 降低方差 |
|------|----------|----------|
| Bagging | | ✓ |

---

## 集成方法的原理

### Bagging

对多个高方差模型取平均，降低方差。

$$\hat{f}_{bag}(x) = \frac{1}{B}\sum_{b=1}^{B}\hat{f}_b(x)$$

### Boosting

顺序拟合残差，降低偏差。

$$\hat{f}_{boost}(x) = \sum_{b=1}^{B}\lambda\hat{f}_b(x)$$

## 实践指导

### 如何判断

| 现象 | 诊断 | 解决 |
|------|------|------|
| 训练误差高 | 欠拟合（高偏差） | 增加复杂度 |
| 训练误差低，测试误差高 | 过拟合（高方差） | 减少复杂度 |
| 两者都低 | 良好 | 保持 |

### 学习曲线

```
误差
  │
  │   测试误差
  │    ╲
  │     ╲──────────
  │
  │   训练误差
  │    ──────────────
  └────────────────── 训练样本量

如果两条线接近：高偏差
如果两条线远离：高方差
```

## 常见误区

1. **只关注训练误差**：测试误差才是关键
2. **忽视学习曲线**：可以诊断偏差-方差问题
3. **过度复杂模型**：不是越复杂越好
4. **不使用正则化**：正则化是控制方差的有效方法
