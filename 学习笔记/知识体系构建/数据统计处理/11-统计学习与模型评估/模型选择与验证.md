# 模型选择与验证

> 选择合适的模型并评估其泛化能力是统计学习的核心。

---

## 训练 vs 测试

### 数据划分

```
全部数据
├── 训练集（60-80%）→ 拟合模型
├── 验证集（10-20%）→ 调参、模型选择
└── 测试集（10-20%）→ 最终评估
```

### 为什么需要划分？

- 训练误差会低估真实误差
- 模型可能过拟合训练数据
- 需要评估模型在新数据上的表现

## 交叉验证

### k折交叉验证

```
数据分为k份
第1次: [验证][训练][训练][训练][训练]
第2次: [训练][验证][训练][训练][训练]
第3次: [训练][训练][验证][训练][训练]
...
第k次: [训练][训练][训练][训练][验证]

最终误差 = k次验证误差的平均
```

### 常用变体

| 方法 | 描述 | 适用 |
|------|------|------|
| 5折CV | k=5 | 通用 |
| 10折CV | k=10 | 通用 |
| 留一法（LOO） | k=n | 小样本 |
| 重复k折 | 多次k折 | 更稳定 |
| 分层k折 | 保持类别比例 | 分类问题 |

### 时间序列交叉验证

```
第1次: [■■■□□□] → 预测□□
第2次: [■■■■□□] → 预测□□
第3次: [■■■■■□] → 预测□□
```

必须保持时间顺序，不能随机划分。

## 偏差-方差权衡

### 分解

$$E[(Y - \hat{f}(x))^2] = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$$

### 含义

| 成分 | 含义 | 模型复杂度 |
|------|------|-----------|
| 偏差 | 模型假设的误差 | 复杂度低→高偏差 |
| 方差 | 模型对训练数据的敏感度 | 复杂度高→高方差 |
| 不可约误差 | 数据本身的噪声 | 无法减少 |

### 图示

```
误差
  │ ╲         ╱  总误差
  │  ╲       ╱
  │   ╲     ╱
  │    ╲   ╱
  │     ╲ ╱
  │      ╳
  │     ╱ ╲
  │    ╱   ╲
  │   ╱     ╲
  │  ╱       ╲
  │ ╱   偏差²  ╲  方差
  └────────────────── 模型复杂度
       最佳复杂度
```

## 模型选择标准

### 信息准则

| 准则 | 公式 | 特点 |
|------|------|------|
| AIC | $-2\ln L + 2k$ | 常用 |
| BIC | $-2\ln L + k\ln n$ | 更保守 |
| AICc | AIC + 校正项 | 小样本 |

### 交叉验证误差

直接估计测试误差。

### 调整R²

$$R^2_{adj} = 1 - \frac{SSE/(n-k-1)}{SST/(n-1)}$$

## 正则化

### 目的

防止过拟合，控制模型复杂度。

### 方法

| 方法 | 惩罚项 | 效果 |
|------|--------|------|
| 岭回归（Ridge） | $\lambda\sum\beta_j^2$ | 系数收缩 |
| Lasso | $\lambda\sum|\beta_j|$ | 变量选择 |
| 弹性网络 | $\lambda_1\sum|\beta_j|+\lambda_2\sum\beta_j^2$ | 结合两者 |

### 选择λ

用交叉验证选择最优的正则化参数λ。

## 模型评估指标

### 分类

| 指标 | 公式 | 特点 |
|------|------|------|
| 准确率 | $(TP+TN)/N$ | 直观 |
| 精确率 | $TP/(TP+FP)$ | 预测为正的准确性 |
| 召回率 | $TP/(TP+FN)$ | 实际为正的覆盖率 |
| F1分数 | $2PR/(P+R)$ | 精确率和召回率的平衡 |
| AUC | ROC曲线下面积 | 综合评估 |

### 回归

| 指标 | 公式 | 特点 |
|------|------|------|
| MSE | $\frac{1}{n}\sum(y_i-\hat{y}_i)^2$ | 对大误差敏感 |
| RMSE | $\sqrt{MSE}$ | 与原始数据同单位 |
| MAE | $\frac{1}{n}\sum|y_i-\hat{y}_i|$ | 对异常值稳健 |
| R² | $1-SSE/SST$ | 解释方差比例 |

## 过拟合与欠拟合

### 过拟合

- 训练误差低，测试误差高
- 模型太复杂
- 解决：正则化、减少特征、更多数据

### 欠拟合

- 训练误差和测试误差都高
- 模型太简单
- 解决：增加特征、更复杂模型

## 常见误区

1. **用训练误差评估模型**：应该用测试误差或交叉验证
2. **不做交叉验证**：单次划分可能有偶然性
3. **忽视偏差-方差权衡**：模型不是越复杂越好
4. **数据泄露**：测试集信息不应参与训练
