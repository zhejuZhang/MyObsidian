# 条件概率与贝叶斯定理

> 贝叶斯定理是统计学中最重要的定理之一，它描述了如何用新证据更新信念。

---

## 条件概率

### 定义

在事件B已经发生的条件下，事件A发生的概率：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

### 直观理解

```
样本空间 S
┌─────────────────────────────┐
│                             │
│   ┌─────────┐              │
│   │    A    │              │
│   │   ┌─────┼──────┐      │
│   │   │ A∩B │      │      │
│   └───┼─────┘  B   │      │
│       │            │      │
│       └────────────┘      │
│                             │
└─────────────────────────────┘

P(A|B) = P(A∩B) / P(B)
       = A∩B的面积 / B的面积
```

### 乘法法则的条件概率形式

$$P(A \cap B) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)$$

---

## 贝叶斯定理

### 公式

$$P(A_i|B) = \frac{P(B|A_i) \cdot P(A_i)}{\sum_{j=1}^{n}P(B|A_j) \cdot P(A_j)}$$

**最简形式**（两个事件）：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

### 各部分的名称

| 符号 | 名称 | 含义 |
|------|------|------|
| $P(A)$ | 先验概率（Prior） | 观测到证据前的信念 |
| $P(B\|A)$ | 似然（Likelihood） | 在A下观测到B的可能性 |
| $P(A\|B)$ | 后验概率（Posterior） | 观测到证据后的信念 |
| $P(B)$ | 边际概率（Marginal） | 证据的总概率（归一化常数） |

> [!tip] 贝叶斯思维的核心
> 后验 ∝ 先验 × 似然
> 
> 新的信念 = 旧的信念 × 新证据的支持程度

## 经典案例

### 案例1：医学检测

**问题**：某疾病患病率1%，检测灵敏度99%，假阳性率5%。检测阳性时，真正患病的概率是多少？

**解**：
- 先验：$P(D) = 0.01$，$P(\bar{D}) = 0.99$
- 似然：$P(+|D) = 0.99$，$P(+|\bar{D}) = 0.05$
- 求：$P(D|+) = ?$

$$P(D|+) = \frac{P(+|D) \cdot P(D)}{P(+|D) \cdot P(D) + P(+|\bar{D}) \cdot P(\bar{D})}$$

$$= \frac{0.99 \times 0.01}{0.99 \times 0.01 + 0.05 \times 0.99} = \frac{0.0099}{0.0099 + 0.0495} = \frac{0.0099}{0.0594} \approx 16.7\%$$

> [!warning] 基础概率谬误
> 直觉上可能认为99%准确的检测，阳性就意味着高概率患病。但因为患病率很低（先验），阳性结果中真正患病的比例只有16.7%。

### 案例2：垃圾邮件过滤

- 先验：$P(\text{spam}) = 0.3$
- 似然：$P(\text{"免费"}|\text{spam}) = 0.8$
- 似然：$P(\text{"免费"}|\text{ham}) = 0.1$

$$P(\text{spam}|\text{"免费"}) = \frac{0.8 \times 0.3}{0.8 \times 0.3 + 0.1 \times 0.7} = \frac{0.24}{0.24 + 0.07} \approx 77.4\%$$

## 贝叶斯更新的迭代

贝叶斯定理可以迭代使用：上次的后验成为下次的先验。

```
先验 P(H)          后验 P(H|E₁)         后验 P(H|E₁,E₂)
   │                    │                      │
   │   × 证据E₁         │   × 证据E₂           │
   │                    │                      │
   ▼                    ▼                      ▼
 初始信念  ───→  更新信念₁  ───→  更新信念₂
```

$$P(H|E_1, E_2) = \frac{P(E_2|H, E_1) \cdot P(H|E_1)}{P(E_2|E_1)}$$

## 优势比（Odds）形式

### 优势（Odds）

$$\text{Odds}(A) = \frac{P(A)}{1-P(A)} = \frac{P(A)}{P(\bar{A})}$$

### 贝叶斯定理的优势形式

$$\text{Odds}(A|B) = \frac{P(B|A)}{P(B|\bar{A})} \times \text{Odds}(A)$$

$$\text{后验优势} = \text{似然比} \times \text{先验优势}$$

**似然比**（Likelihood Ratio）：$LR = \frac{P(B|A)}{P(B|\bar{A})}$

- LR > 1：证据支持A
- LR = 1：证据无信息量
- LR < 1：证据反对A

---

## 全概率公式

如果 $B_1, B_2, \ldots, B_n$ 是样本空间的一个划分（互斥且穷尽）：

$$P(A) = \sum_{i=1}^{n} P(A|B_i) \cdot P(B_i)$$

这是贝叶斯定理的分母，也称为**边际似然**。

## 常见误区

1. **混淆 P(A|B) 和 P(B|A)**：检测阳性患病的概率 ≠ 患病检测阳性的概率
2. **忽视先验概率**：基础概率（患病率）对结果影响巨大
3. **检验证的误用**：高灵敏度不等于高阳性预测值
4. **独立与条件独立混淆**：$P(A|B,C) \neq P(A|B)$ 一般不成立
