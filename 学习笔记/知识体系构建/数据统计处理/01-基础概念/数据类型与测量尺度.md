# 数据类型与测量尺度

> 统计分析的起点：理解你手中的数据是什么类型。

---

## 变量的基本分类

### 按性质分

| 类型 | 定义 | 示例 |
|------|------|------|
| **定性变量（分类变量）** | 描述类别或属性 | 性别、血型、学历 |
| **定量变量（数值变量）** | 描述数量大小 | 身高、体重、收入 |

### 按取值分

| 类型 | 定义 | 示例 |
|------|------|------|
| **离散变量** | 取有限个或可列个值 | 子女人数、缺陷数 |
| **连续变量** | 取任意实数值 | 温度、时间、重量 |

---

## Stevens 测量尺度（S.S. Stevens, 1946）

这是最经典的变量分类框架，由低到高四个层次：

### 1. 定类尺度（Nominal Scale）

- **定义**：仅用于分类，无顺序、无大小
- **运算**：只能判断"相等/不等"
- **集中趋势**：众数
- **示例**：性别（男/女）、血型（A/B/AB/O）、颜色、邮编

```
可做的统计：频次、百分比、卡方检验
不可做：均值、排序
```

### 2. 定序尺度（Ordinal Scale）

- **定义**：分类之间有明确的顺序/等级
- **运算**：可判断"相等、大于、小于"
- **集中趋势**：众数、中位数
- **示例**：教育程度（小学<中学<大学）、满意度（1-5分）、军衔

```
可做的统计：中位数、百分位数、秩次检验、Spearman相关
不可做：均值（间距不确定）
```

> [!warning] 定序数据的均值问题
> Likert量表（如1-5分）的间距未必相等。"满意"和"非常满意"的差距是否等于"不满意"和"一般"的差距？严格来说不应计算均值，但实践中常被放宽。

### 3. 定距尺度（Interval Scale）

- **定义**：数值之间有相等的间距，但无绝对零点
- **运算**：可加减，不可乘除（因为没有绝对零点）
- **集中趋势**：均值、中位数、众数
- **示例**：温度（摄氏/华氏）、日期、智商分数

```
可做的统计：均值、标准差、Pearson相关、线性回归
注意：不能说"20°C是10°C的两倍热"
```

### 4. 定比尺度（Ratio Scale）

- **定义**：有绝对零点，间距相等
- **运算**：可做所有四则运算
- **集中趋势**：均值、中位数、众数（全部适用）
- **示例**：身高、体重、收入、年龄、时间长度

```
可做的统计：所有统计方法均适用
可以说"200cm是100cm的两倍高"
```

## 四种尺度的对比

| 特征 | 定类 | 定序 | 定距 | 定比 |
|------|:----:|:----:|:----:|:----:|
| 分类 | ✓ | ✓ | ✓ | ✓ |
| 排序 | ✗ | ✓ | ✓ | ✓ |
| 等距 | ✗ | ✗ | ✓ | ✓ |
| 绝对零点 | ✗ | ✗ | ✗ | ✓ |
| 众数 | ✓ | ✓ | ✓ | ✓ |
| 中位数 | ✗ | ✓ | ✓ | ✓ |
| 均值 | ✗ | ✗* | ✓ | ✓ |
| 标准差 | ✗ | ✗ | ✓ | ✓ |

---

## 尺度之间的转换

```
定比 → 定距 → 定序 → 定类
（信息量递减，只能降级不能升级）

例如：
收入(定比) → 收入等级(定序) → 是否有收入(定类)
年龄(定比) → 年龄段(定序) → 成年/未成年(定类)
```

> [!tip] 实践意义
> 测量尺度决定了你能用什么统计方法。在收集数据时，尽量使用更高精度的尺度，分析时再根据需要降级。

## 常见误区

1. **把定序当定距**：满意度1-5分直接求均值——严格来说不合理，但实践中常用
2. **把定类当定序**：把颜色编号（1=红, 2=蓝）做排序——数字只是标签
3. **忽略尺度类型选错方法**：对定类数据用Pearson相关——应该用卡方检验
