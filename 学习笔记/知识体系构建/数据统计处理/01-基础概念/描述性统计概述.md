# 描述性统计概述

> 用数字和图表概括数据的特征，是统计分析的第一步。

---

## 描述性统计 vs 推断统计

| 维度 | 描述性统计 | 推断统计 |
|------|-----------|----------|
| 目标 | 描述已有的数据 | 从样本推断总体 |
| 范围 | 仅限当前数据 | 泛化到更大群体 |
| 不确定性 | 无（精确计算） | 有（概率性结论） |
| 方法 | 图表、汇总统计量 | 假设检验、置信区间 |

---

## 描述性统计的三大维度

### 1. 集中趋势（Central Tendency）
数据"中心"在哪里？
- [[集中趋势度量|均值、中位数、众数]]

### 2. 离散程度（Dispersion）
数据有多"分散"？
- [[离散程度度量|方差、标准差、极差、IQR]]

### 3. 分布形态（Distribution Shape）
数据的"形状"是什么？
- [[分布形态|偏度、峰度、正态性检验]]

## 描述性统计量汇总

### 单变量描述

| 统计量 | 类别 | 描述 | 适用尺度 |
|--------|------|------|----------|
| 众数 | 集中趋势 | 出现频率最高的值 | 定类+ |
| 中位数 | 集中趋势 | 排序后中间的值 | 定序+ |
| 均值 | 集中趋势 | 算术平均 | 定距/定比 |
| 极差 | 离散程度 | 最大值 - 最小值 | 定距/定比 |
| 四分位距 | 离散程度 | Q3 - Q1 | 定序+ |
| 方差 | 离散程度 | 偏差平方的平均 | 定距/定比 |
| 标准差 | 离散程度 | 方差的平方根 | 定距/定比 |
| 变异系数 | 离散程度 | 标准差/均值 | 定比 |
| 偏度 | 形态 | 分布的不对称程度 | 定距/定比 |
| 峰度 | 形态 | 分布的尖锐程度 | 定距/定比 |

### 双变量描述

| 统计量 | 描述 | 适用类型 |
|--------|------|----------|
| 协方差 | 两个变量的共同变化方向 | 数值-数值 |
| 相关系数 | 标准化的协方差（-1到1） | 数值-数值 |
| 交叉表 | 两个分类变量的频次分布 | 分类-分类 |
| 列联表卡方 | 分类变量间的关联性 | 分类-分类 |

## 数据探索的五数概括

Tukey提出的**五数概括法**（Five-Number Summary）：

```
最小值  Q1  中位数  Q3  最大值
  │     │    │     │    │
  ├─────┼────┼─────┼────┤
        │    │     │
        └────┴─────┘
           IQR
```

- **最小值**（Minimum）
- **第一四分位数 Q1**（25th percentile）
- **中位数**（Median, 50th percentile）
- **第三四分位数 Q3**（75th percentile）
- **最大值**（Maximum）

> [!tip] 箱线图（Boxplot）
> 五数概括的可视化形式，是探索性数据分析（EDA）的核心工具。

## 描述性统计的工作流

```
原始数据
    │
    ▼
┌─────────────┐
│ 数据清洗    │  处理缺失值、异常值、格式问题
└─────┬───────┘
      ▼
┌─────────────┐
│ 单变量描述  │  频次分布、集中趋势、离散程度
└─────┬───────┘
      ▼
┌─────────────┐
│ 可视化探索  │  直方图、箱线图、散点图
└─────┬───────┘
      ▼
┌─────────────┐
│ 双变量分析  │  相关、交叉表、分组比较
└─────┬───────┘
      ▼
┌─────────────┐
│ 汇总报告    │  表格、图表、关键发现
└─────────────┘
```

## 不同数据类型的描述策略

### 定类数据
- 频次表、百分比
- 条形图、饼图
- 众数

### 定序数据
- 频次表、累积百分比
- 条形图、箱线图
- 中位数、四分位数

### 定距/定比数据
- 全套描述统计量
- 直方图、箱线图、散点图
- 均值、标准差

## 常见误区

1. **只看均值不看分布**：Anscombe's Quartor 说明相同均值可以有完全不同的数据形态
2. **忽视异常值影响**：均值对异常值敏感，中位数更稳健
3. **过早下结论**：描述统计只能描述"是什么"，不能回答"为什么"
4. **忽略数据类型**：对定类数据计算均值是没有意义的
