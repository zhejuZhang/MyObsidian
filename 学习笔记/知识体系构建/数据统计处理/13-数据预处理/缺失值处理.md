# 缺失值处理

> 缺失值是数据科学中最常见的问题之一，处理不当会导致偏差。

---

## 缺失类型

### MCAR（完全随机缺失）

缺失与任何变量无关。

$$P(\text{Missing}|Y, X) = P(\text{Missing})$$

**示例**：数据录入错误

### MAR（随机缺失）

缺失与其他观测变量有关，与缺失值本身无关。

$$P(\text{Missing}|Y, X) = P(\text{Missing}|X)$$

**示例**：年轻人更不愿报告收入

### MNAR（非随机缺失）

缺失与缺失值本身有关。

$$P(\text{Missing}|Y, X) = P(\text{Missing}|Y_{\text{missing}})$$

**示例**：高收入者不愿报告收入

## 处理方法

### 删除

| 方法 | 描述 | 适用 |
|------|------|------|
| 列删除 | 删除缺失率高的变量 | 缺失率 > 50% |
| 行删除 | 删除有缺失的观测 | MCAR，缺失少 |
| 配对删除 | 每个分析用可用数据 | 不同分析用不同子集 |

**优点**：简单
**缺点**：损失信息，可能引入偏差

### 插补

| 方法 | 描述 | 适用 |
|------|------|------|
| 均值插补 | 用均值填充 | MCAR，数值变量 |
| 中位数插补 | 用中位数填充 | 有异常值 |
| 众数插补 | 用众数填充 | 分类变量 |
| 前向/后向填充 | 用前后值填充 | 时间序列 |
| KNN插补 | 用K近邻填充 | 结构化数据 |
| 回归插补 | 用回归预测 | 变量相关 |
| 多重插补 | 生成多个完整数据集 | 通用 |

### 多重插补

```
1. 生成m个插补数据集
2. 对每个数据集进行分析
3. 合并m个结果
```

**优点**：考虑了插补的不确定性
**缺点**：计算复杂

## 缺失率的影响

| 缺失率 | 影响 | 建议 |
|--------|------|------|
| < 5% | 影响小 | 删除或简单插补 |
| 5-20% | 中等影响 | 多重插补 |
| 20-50% | 影响大 | 谨慎处理 |
| > 50% | 严重 | 考虑删除变量 |

## 评估插补效果

| 指标 | 公式 | 含义 |
|------|------|------|
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i-\hat{y}_i)^2}$ | 插补误差 |
| 偏差 | $E[\hat{\theta}] - \theta$ | 参数偏差 |
| 覆盖率 | 置信区间包含真值的比例 | 区间估计质量 |

## 常见误区

1. **直接删除**：可能引入偏差
2. **均值插补**：低估变异性
3. **不检查缺失类型**：不同类型需要不同处理
4. **忽视缺失的不确定性**：应使用多重插补
