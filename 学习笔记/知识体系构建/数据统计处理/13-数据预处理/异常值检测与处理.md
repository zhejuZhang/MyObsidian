# 异常值检测与处理

> 异常值可能包含重要信息，也可能是数据错误。

---

## 什么是异常值

### 定义

**异常值**是与大多数数据显著不同的观测值。

### 类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 全局异常 | 整体上异常 | 年龄=200 |
| 局部异常 | 在局部区域异常 | 某地区的高收入 |
| 集体异常 | 一组数据异常 | 突然的销量下降 |

---

## 检测方法

### 统计方法

| 方法 | 公式 | 适用 |
|------|------|------|
| Z-score | $|z| > 3$ | 正态数据 |
| 修正Z-score | 基于中位数 | 稳健 |
| IQR方法 | $< Q1-1.5IQR$ 或 $> Q3+1.5IQR$ | 通用 |
| Grubbs检验 | 单个异常值 | 正态数据 |
| Dixon检验 | 小样本 | 正态数据 |

### IQR方法

```
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR

极端异常：
下界 = Q1 - 3 × IQR
上界 = Q3 + 3 × IQR
```

### 距离方法

| 方法 | 描述 | 适用 |
|------|------|------|
| KNN距离 | 到K近邻的距离 | 通用 |
| LOF | 局部密度偏差 | 局部异常 |
| DBSCAN | 密度聚类 | 噪声检测 |

### 模型方法

| 方法 | 描述 | 适用 |
|------|------|------|
| Isolation Forest | 随机分割 | 高维数据 |
| One-class SVM | 超球面 | 小数据 |
| 自编码器 | 重构误差 | 复杂数据 |

## 处理方法

### 删除

| 适用 | 不适用 |
|------|--------|
| 数据错误 | 异常值有重要意义 |
| 无法解释 | 样本量小 |
| 影响分析 | 异常值是研究焦点 |

### 保留

| 适用 | 不适用 |
|------|--------|
| 异常值真实 | 数据错误 |
| 包含重要信息 | 严重影响分析 |
| 样本量小 | 样本量大 |

### 变换

| 方法 | 描述 | 适用 |
|------|------|------|
| 对数变换 | $y = \ln(x)$ | 右偏数据 |
| 平方根变换 | $y = \sqrt{x}$ | 计数数据 |
| Winsorize | 截尾处理 | 通用 |

### 稳健方法

| 方法 | 描述 |
|------|------|
| 稳健回归 | 减少异常值影响 |
| 中位数回归 | 对异常值稳健 |
| M估计 | 稳健损失函数 |

## Winsorization

### 方法

将极端值替换为指定百分位数的值。

```
原始数据：{1, 2, 3, 4, 5, 100}
5% Winsorize：{1, 2, 3, 4, 5, 5}
```

### 常用百分位

| 百分位 | 描述 |
|--------|------|
| 5% | 替换为5th和95th百分位数 |
| 10% | 替换为10th和90th百分位数 |

## 异常值的影响

### 对统计量的影响

| 统计量 | 影响 | 稳健替代 |
|--------|------|----------|
| 均值 | 大 | 中位数 |
| 标准差 | 大 | IQR |
| 相关系数 | 大 | 秩相关 |
| 回归系数 | 大 | 稳健回归 |

### 对模型的影响

| 模型 | 影响 | 稳健替代 |
|------|------|----------|
| 线性回归 | 大 | 稳健回归 |
| K-means | 大 | DBSCAN |
| PCA | 中 | 稳健PCA |

## 实际应用

### 决策流程

```
检测到异常值
      │
      ▼
数据错误？
├── 是 → 删除/修正
└── 否
      │
      ▼
有重要意义？
├── 是 → 保留，单独分析
└── 否
      │
      ▼
样本量足够？
├── 是 → 删除或Winsorize
└── 否 → 保留，使用稳健方法
```

## 常见误区

1. **自动删除异常值**：应先检查原因
2. **不记录处理**：应记录异常值和处理方法
3. **忽视异常值信息**：异常值可能包含重要信息
4. **用均值判断**：均值本身对异常值敏感
