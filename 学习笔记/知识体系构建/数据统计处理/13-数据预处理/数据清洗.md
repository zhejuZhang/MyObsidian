# 数据清洗

> 数据质量是统计分析的基础，垃圾进垃圾出。

---

## 数据质量问题

### 常见问题

| 问题 | 描述 | 示例 |
|------|------|------|
| 缺失值 | 数据为空 | 问卷未回答 |
| 异常值 | 远离正常范围 | 年龄=200 |
| 重复值 | 重复记录 | 同一用户多次提交 |
| 不一致 | 格式不统一 | 日期格式混乱 |
| 错误值 | 明显错误 | 性别=999 |
| 类型错误 | 数据类型不对 | 数字存为字符串 |

---

## 数据清洗流程

```
1. 数据审查
   ├── 数据概览
   ├── 数据类型检查
   └── 基本统计量
        │
2. 问题识别
   ├── 缺失值
   ├── 异常值
   ├── 重复值
   └── 不一致
        │
3. 问题处理
   ├── 缺失值处理
   ├── 异常值处理
   ├── 重复值处理
   └── 格式标准化
        │
4. 验证
   ├── 处理后检查
   └── 记录变更
```

## 重复值处理

### 检测

```python
# 完全重复
df.duplicated()

# 部分重复（基于某些列）
df.duplicated(subset=['id', 'date'])
```

### 处理

| 方法 | 适用 |
|------|------|
| 删除重复 | 保留第一条/最后一条 |
| 合并 | 聚合重复记录 |
| 标记 | 保留但标记 |

## 格式标准化

### 日期格式

```
不一致：2024-01-01, 01/01/2024, 20240101
标准化：2024-01-01
```

### 字符串格式

```
不一致：New York, new york, NEW YORK
标准化：New York
```

### 数值格式

```
不一致：1000, 1,000, 1000.00
标准化：1000
```

### 常见转换

|------|------|------|

| 规则 | 示例 |

## 记录变更

### 为什么记录

- 可追溯性
- 可重复性
- 审计需求

### 记录内容

| 内容 | 示例 |
|------|------|
| 原始数据 | 保留原始文件 |
| 变更内容 | 删除了50行重复值 |
| 变更原因 | 用户ID重复 |
| 变更时间 | 2024-01-15 |
| 变更人 | 数据分析师 |

## 常见误区

1. **直接删除缺失值**：可能导致偏差
2. **不记录变更**：无法追溯和重复
3. **过度清洗**：可能丢失有用信息
4. **不做验证**：清洗后应再次检查
