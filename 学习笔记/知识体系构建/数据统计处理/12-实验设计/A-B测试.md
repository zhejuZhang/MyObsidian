# A/B测试

> 在线实验方法，用于比较两个或多个版本的效果。

---

## 基本概念

### 定义

**A/B测试**是随机对照实验的在线版本，将用户随机分配到不同版本，比较效果。

### 流程

```
1. 确定目标指标
2. 设计变体（A和B）
3. 计算样本量
4. 随机分配用户
5. 收集数据
6. 统计分析
7. 做出决策
```

---

## 关键要素

### 目标指标

| 类型 | 示例 | 特点 |
|------|------|------|
| 主要指标 | 转化率、收入 | 决策依据 |
| 护栏指标 | 跳出率、加载时间 | 安全检查 |
| 辅助指标 | 点击率、停留时间 | 辅助理解 |

### 随机化单元

| 单元 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 用户 | 通用 | 简单 | 用户间干扰 |
| 会话 | 短期效果 | 多次曝光 | 用户内相关 |
| 区域 | 地理实验 | 减少干扰 | 样本量小 |

---

## 样本量计算

### 基本公式

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot [p_A(1-p_A)+p_B(1-p_B)]}{(p_A-p_B)^2}$$

### 实际考虑

| 因素 | 影响 |
|------|------|
| 基线转化率 | 越低需要样本越大 |
| 最小可检测效应 | 越小需要样本越大 |
| 显著性水平 | 越严格需要样本越大 |
| 统计功效 | 越高需要样本越大 |

## 统计分析

### 频率学派方法

| 方法 | 适用 | 公式 |
|------|------|------|
| Z检验 | 比例比较 | $z = \frac{\hat{p}_B - \hat{p}_A}{\sqrt{\hat{p}(1-\hat{p})(1/n_A+1/n_B)}}$ |
| t检验 | 均值比较 | $t = \frac{\bar{x}_B - \bar{x}_A}{\sqrt{s_A^2/n_A+s_B^2/n_B}}$ |
| 卡方检验 | 分类变量 | $\chi^2 = \sum \frac{(O-E)^2}{E}$ |

### 贝叶斯方法

- 计算变体优于对照的概率
- 估计效应大小的后验分布
- 可以提前停止

## 多重比较

### 问题

同时测试多个变体时，假阳性率膨胀。

### 解决方案

| 方法 | 描述 |
|------|------|
| Bonferroni | α/m |
| 顺序检验 | 逐步校正 |
| 贝叶斯方法 | 不需要校正 |

---

## 提前停止

### 问题

频繁查看结果会增加假阳性。

### 解决方案

| 方法 | 描述 |
|------|------|
| 固定样本 | 不提前停止 |
| 顺序检验 | 允许提前停止 |
| 贝叶斯方法 | 基于后验概率 |

### 顺序检验

$$\text{在每次分析时比较统计量与调整后的边界}$$

## 常见陷阱

### 技术陷阱

| 陷阱 | 描述 | 解决 |
|------|------|------|
| 样本比例失衡 | 分配不均 | 检查随机化 |
| 新奇效应 | 用户因新鲜而改变行为 | 延长实验 |
| 溢出效应 | 用户间相互影响 | 集群随机化 |
| 数据污染 | 机器人、重复访问 | 数据清洗 |

### 统计陷阱

| 陷阱 | 描述 | 解决 |
|------|------|------|
| 偷看数据 | 频繁查看导致假阳性 | 顺序检验 |
| 多重测试 | 测试太多指标 | 预先确定主要指标 |
| p-hacking | 尝试不同分析直到显著 | 预注册 |

## 实际应用

### 应用场景

| 场景 | 目标 | 指标 |
|------|------|------|
| 网页设计 | 提高转化率 | 点击率、转化率 |
| 定价策略 | 优化收入 | 收入、购买率 |
| 推荐算法 | 提高参与度 | 点击率、停留时间 |
| 邮件营销 | 提高打开率 | 打开率、点击率 |

### 案例流程

```
目标：提高购买转化率
      │
变体A：原版（对照）
变体B：新按钮颜色
      │
样本量：每组10000用户
      │
结果：A转化率2.1%，B转化率2.5%
      │
p值：0.03 < 0.05
      │
决策：采用变体B
```

## 常见误区

1. **不做功效分析**：样本量不足导致功效低
2. **频繁偷看**：增加假阳性风险
3. **忽视实际意义**：统计显著不等于实际重要
4. **不做数据清洗**：机器人和异常数据影响结果
