# 全局路径规划算法

> 全局路径规划是自动驾驶决策规划的基础，为车辆提供从起点到终点的最优行驶路径。

---

## 一、基本概念

### 1.1 路径规划定义
路径规划是在给定环境中，寻找从起始状态到目标状态的最优或可行路径的过程，包括：
- **全局规划**：基于全局信息的宏观路径规划
- **局部规划**：基于局部信息的实时路径规划
- **运动规划**：考虑运动学约束的轨迹规划

### 1.2 在自动驾驶中的作用

#### 导航功能
- **路径引导**：为驾驶员或自动驾驶系统提供路径引导
- **距离估计**：估计到达目的地的距离和时间
- **路线选择**：选择最优行驶路线

#### 决策支持
- **路径可行性**：评估路径的可行性
- **风险评估**：评估路径的风险
- **能耗优化**：优化行驶能耗

### 1.3 规划问题建模

#### 状态空间
- **位置**：车辆在空间中的位置
- **速度**：车辆的速度大小和方向
- **加速度**：车辆的加速度
- **航向角**：车辆的朝向

#### 约束条件
- **几何约束**：道路边界、障碍物
- **运动学约束**：车辆运动学模型
- **动力学约束**：车辆动力学限制
- **交通规则**：交通信号、限速等

## 二、图搜索算法

### 2.1 Dijkstra算法

#### 算法原理
```python
def dijkstra(graph, start, end):
    """
    Dijkstra最短路径算法
    """
    # 初始化距离和前驱节点
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    predecessors = {node: None for node in graph}
    # 优先队列
    priority_queue = [(0, start)]
    
    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue)
        # 到达终点
        if current_node == end:
            break
        # 遍历邻居节点
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            # 更新距离
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                predecessors[neighbor] = current_node
                heapq.heappush(priority_queue, (distance, neighbor))
    
    return reconstruct_path(predecessors, start, end)
```

#### 算法特点
- **优点**：保证找到最短路径
- **缺点**：搜索范围大，效率较低
- **适用**：稠密图、非负权重

### 2.2 A*算法

#### 算法原理
```python
def a_star(graph, start, end, heuristic):
    """
    A*启发式搜索算法
    """
    # 初始化
    open_set = {start}
    came_from = {}
    g_score = {start: 0}
    f_score = {start: heuristic(start, end)}
    
    while open_set:
        # 选择f值最小的节点
        current = min(open_set, key=lambda x: f_score.get(x, float('inf')))
        if current == end:
            return reconstruct_path(came_from, current)
        
        open_set.remove(current)
        # 遍历邻居
        for neighbor in graph[current]:
            tentative_g = g_score[current] + graph[current][neighbor]
            if tentative_g < g_score.get(neighbor, float('inf')):
                came_from[neighbor] = current
                g_score[neighbor] = tentative_g
                f_score[neighbor] = g_score[neighbor] + heuristic(neighbor, end)
                open_set.add(neighbor)
    
    return None  # 无路径
```

#### 启发式函数
- **欧几里得距离**：直线距离
- **曼哈顿距离**：网格距离
- **对角线距离**：对角线距离

#### 算法特点
- **优点**：效率高，保证最优性（启发函数可容许）
- **缺点**：需要设计好的启发函数
- **适用**：路径规划、游戏AI

## 三、采样规划算法

### 3.1 快速随机树（RRT）

#### 算法原理
```python
def rrt(start, goal, obstacles, max_iterations=1000):
    """
    快速随机树算法
    """
    tree = Tree(start)
    
    for i in range(max_iterations):
        # 随机采样
        random_point = sample_random()
        # 找到最近节点
        nearest_node = tree.nearest(random_point)
        # 扩展新节点
        new_node = extend(nearest_node, random_point)
        # 碰撞检测
        if not collision_check(nearest_node, new_node):
            tree.add_node(new_node)
            # 检查是否到达目标
            if distance(new_node, goal) < threshold:
                return tree.get_path(start, goal)
    
    return None
```

#### 算法特点
- **优点**：适合高维空间，快速探索
- **缺点**：路径不光滑，不保证最优
- **适用**：复杂环境、高维规划

### 3.2 RRT*算法

#### 算法原理
```python
def rrt_star(start, goal, obstacles, max_iterations=1000):
    """
    RRT*算法：渐进最优的RRT
    """
    tree = Tree(start)
    
    for i in range(max_iterations):
        # 随机采样
        random_point = sample_random()
        # 找到最近节点
        nearest_node = tree.nearest(random_point)
        # 扩展新节点
        new_node = extend(nearest_node, random_point)
        # 碰撞检测
        if not collision_check(nearest_node, new_node):
            # 选择最优父节点
            best_parent = choose_parent(new_node, tree)
            # 重连优化
            rewire(new_node, tree)
            tree.add_node(new_node)
    
    return tree.get_path(start, goal)
```

#### 算法改进
- **渐进最优**：随着采样增加，路径逐渐优化
- **重连机制**：优化已有路径
- **Informed RRT***：启发式采样加速

### 3.3 概率路线图（PRM）

#### 算法原理
```python
class PRM:
    """
    概率路线图算法
    """
    def __init__(self):
        self.graph = Graph()
    
    def build_roadmap(self, obstacles, num_samples=1000):
        # 随机采样
        samples = self.sample_free_space(num_samples)
        # 建立连接
        for sample in samples:
            neighbors = self.find_neighbors(sample)
            for neighbor in neighbors:
                if not self.collision_check(sample, neighbor):
                    self.graph.add_edge(sample, neighbor)
        
        return self.graph
    
    def query(self, start, end):
        # 将起点终点连接到路线图
        self.connect_to_graph(start)
        self.connect_to_graph(end)
        # 图搜索
        return self.graph.search(start, end)
```

#### 算法特点
- **优点**：适合多查询问题
- **缺点**：预处理时间长
- **适用**：静态环境、多次查询

### 5.1 遗传算法（GA）

#### 算法原理
```python
def genetic_algorithm(population_size, generations):
    """
    遗传算法路径规划
    """
    # 初始化种群
    population = initialize_population(population_size)
    
    for gen in range(generations):
        # 适应度评估
        fitness = evaluate_fitness(population)
        # 选择
        selected = selection(population, fitness)
        # 交叉
        offspring = crossover(selected)
        # 变异
        mutated = mutation(offspring)
        # 更新种群
        population = update_population(population, mutated)
    
    return get_best_individual(population)
```

### 5.2 粒子群优化（PSO）

#### 算法原理
```python
def pso_optimization(num_particles, max_iterations):
    """
    粒子群优化路径规划
    """
    # 初始化粒子群
    particles = initialize_particles(num_particles)
    
    for iteration in range(max_iterations):
        for particle in particles:
            # 更新速度
            particle.velocity = update_velocity(particle)
            # 更新位置
            particle.position = update_position(particle)
            # 评估适应度
            particle.fitness = evaluate(particle.position)
            # 更新个体最优
            if particle.fitness < particle.best_fitness:
                particle.best_position = particle.position
            # 更新全局最优
            if particle.fitness < global_best_fitness:
                global_best = particle.position
    
    return global_best
```
