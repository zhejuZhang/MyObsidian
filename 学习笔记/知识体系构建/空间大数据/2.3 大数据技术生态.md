# 大数据技术生态

> 大数据技术生态是以 Hadoop 为核心的一系列开源框架的集合，覆盖数据存储、计算、管理、分析的全链路。

---

```
┌─────────────────────────────────────────────────┐
│                   应用层                         │
│   BI工具 │ 机器学习 │ 图计算 │ 实时应用         │
├─────────────────────────────────────────────────┤
│                   计算引擎层                     │
│   MapReduce │ Spark │ Flink │ Presto            │
├─────────────────────────────────────────────────┤

└─────────────────────────────────────────────────┘
```

## 存储层

### HDFS（Hadoop Distributed File System）

分布式文件系统，大数据存储的基石：

```
架构:
┌──────────┐
│ NameNode │ ← 管理元数据（文件名、块位置）
└────┬─────┘
     │
┌────┴────┬──────────┐
│         │          │
▼         ▼          ▼
DataNode₁ DataNode₂ DataNode₃ ← 存储数据块

特点:
- 数据分块: 默认 128MB/块
- 副本机制: 默认 3 副本
- 一次写入多次读取
- 流式数据访问
```

### HBase

列族存储的 NoSQL 数据库：

```
数据模型:
Row Key → Column Family₁ → Column₁: value
                        → Column₂: value
        → Column Family₂ → Column₃: value

特点:
- 基于 HDFS 存储
- 支持海量数据的随机读写
- 自动分片（Region）
- 强一致性
```

### Kafka

分布式消息队列：

```
Producer → Topic → Partition → Consumer Group

特点:
- 高吞吐量（百万级/秒）
- 持久化存储
- 消费者组并行消费
- 流式数据管道
```

## 计算引擎层

### MapReduce

批处理计算框架：

```
Input → Split → Map → Shuffle → Reduce → Output

优点: 简单、容错、可扩展
缺点: 磁盘 IO 多、不适合迭代计算
```

### Spark

内存计算引擎：

```
核心概念:
- RDD: 弹性分布式数据集
- DAG: 有向无环图执行计划
- 内存计算: 中间结果缓存在内存

生态:
├── Spark SQL    (结构化查询)
├── Spark Streaming (微批流处理)
├── MLlib        (机器学习)
└── GraphX       (图计算)
```

### Flink

流批一体计算引擎：

```
特点:
- 真正的流处理（事件驱动）
- 精确一次（exactly-once）语义
- 丰富的窗口操作
- 状态管理

适用: 实时数据处理、CEP、流式 ETL
```

## 资源管理层

### YARN

Hadoop 资源管理器：

```
┌───────────────┐
│ResourceManager│ ← 全局资源管理
└───────┬───────┘
        │
┌───────┴───────┬───────────────┐
│               │               │
▼               ▼               ▼
NodeManager₁   NodeManager₂   NodeManager₃
├── Container  ├── Container  ├── Container
└── Container  └── Container  └── Container
```

### Kubernetes

容器编排平台，逐渐替代 YARN 成为大数据平台的资源管理层。

## 数据格式

| 格式 | 类型 | 特点 | 适用场景 |
|------|------|------|----------|
| Parquet | 列式 | 压缩率高，列裁剪 | 分析查询 |
| ORC | 列式 | 索引丰富，ACID | Hive 生态 |
| Avro | 行式 | Schema 演进 | 数据交换 |
| Arrow | 列式 | 内存格式，零拷贝 | 内存计算 |

## SQL 引擎

| 引擎 | 特点 | 延迟 |
|------|------|------|
| Hive | 批处理，基于 MapReduce/Tez | 分钟级 |
| Presto/Trino | MPP，内存计算 | 秒级 |
| Spark SQL | 基于 Spark | 秒~分钟 |
| Impala | MPP，内存计算 | 秒级 |
| ClickHouse | 列式 OLAP | 亚秒级 |

## 数据仓库与数据湖

### 数据仓库（Data Warehouse）

```
特点: 结构化、Schema-on-Write、面向分析
技术: Hive, Snowflake, BigQuery
```

### 数据湖（Data Lake）

```
特点: 存储原始数据、Schema-on-Read、灵活
技术: HDFS, S3, Delta Lake, Iceberg
```

### 湖仓一体（Lakehouse）

```
融合数据仓库和数据湖的优势:
- 数据湖的灵活性
- 数据仓库的事务支持
技术: Delta Lake, Apache Iceberg, Apache Hudi
```
