# 空间数据可视化

> 空间数据可视化是将空间数据以图形方式呈现的技术，帮助人类理解空间模式、趋势和异常。

---

## 可视化基础

### 视觉变量

| 视觉变量 | 适用数据类型 | 示例 |
|----------|-------------|------|
| 位置 | 所有类型 | 点的位置 |
| 大小 | 定量 | 点的大小表示人口 |
| 颜色（色相） | 定性 | 不同颜色表示类别 |
| 颜色（亮度） | 定量 | 深浅表示密度 |
| 形状 | 定性 | 不同形状表示类型 |
| 方向 | 定量/定性 | 箭头表示流向 |
| 纹理 | 定性 | 填充图案表示类别 |
| 透明度 | 定量 | 透明度表示置信度 |

```
专题地图类型:
```

## 大规模矢量可视化

### 矢量瓦片（Vector Tiles）

```
原理:
1. 将矢量数据按瓦片金字塔切分
2. 每个瓦片是 Protobuf 编码的矢量数据
3. 客户端按需加载和渲染

瓦片坐标: z/x/y
  z: 缩放级别 (0-22)
  x: 列号
  y: 行号

优势:
- 数据量小 (仅传输几何+属性)
- 客户端可自定义样式
- 支持交互 (查询、高亮)
- 适合动态数据
```

**MVT 格式**：

```
Mapbox Vector Tile:
- Protobuf 编码
- 几何整数化 (相对瓦片的像素坐标)
- 支持多图层
- 压缩率高

工具:
- Tippecanoe: 生成矢量瓦片
- ST_AsMVT: PostGIS 生成 MVT
- Tessera: 矢量瓦片服务器
```

### 简化与聚合

```
大规模矢量数据的简化:

1. 几何简化 (Simplification)
   - Douglas-Peucker 算法
   - Visvalingam 算法 (保留面积)
   - 不同缩放级别使用不同简化程度

2. 聚合 (Aggregation)
   - 点聚合: 相邻点合并为一个
   - 面聚合: 小面合并为大面
   - 根据缩放级别动态聚合

3. LOD (Level of Detail)
   - 不同缩放级别显示不同细节
   - 远处简化，近处详细
```

## 大规模栅格可视化

### 影像金字塔

```
多分辨率影像组织:

Level 0: 全球概览 (256×256)
Level 1: 512×512
...
Level 18: 详细影像 (GB 级)
Level 22: 最高分辨率

按需加载: 只加载当前视口需要的瓦片
```

### COG（Cloud Optimized GeoTIFF）

```
云优化的 GeoTIFF:
- 内置概览 (Overview)
- 支持 HTTP Range 请求
- 按需读取任意区域
- 适合 Web 可视化

工具:
- GDAL: 创建 COG
-rio-glui: COG 可视化服务器
- MapServer: COG 发布
```

### GPU 加速渲染

```
大规模栅格的 GPU 渲染:

1. 瓦片纹理
   - 将影像瓦片作为纹理
   - GPU 加速纹理映射

2. 着色器
   - GLSL 着色器实时计算
   - 伪彩色、NDVI 等实时计算

3. WebGL
   - 浏览器端 GPU 渲染
   - Deck.gl, Mapbox GL
```

## 热力图

### 核密度热力图

```python
# 核密度估计
from scipy.stats import gaussian_kde

# 计算 KDE
kde = gaussian_kde(points.T, bw_method=0.1)
# 在网格上评估
grid_x, grid_y = np.mgrid[xmin:xmax:100j, ymin:ymax:100j]
density = kde(np.vstack([grid_x.ravel(), grid_y.ravel()]))
```

### 聚合热力图

```
基于网格聚合的热力图:

1. 将空间划分为网格
2. 统计每个网格内的点数
3. 用颜色映射表示密度

工具:
- Deck.gl: HeatmapLayer
- Mapbox: heatmap-density
- Kepler.gl: 热力图图层
```

## 时空可视化

### 动态地图

```
时空数据的动画展示:

1. 时间滑块
   - 用户拖动时间轴
   - 显示对应时刻的空间状态

2. 动画播放
   - 按时间顺序播放
   - 展示空间变化过程

3. 轨迹动画
   - 移动对象的轨迹动画
   - 尾迹效果
```

### 时空立方体

```
将时空数据可视化为三维立方体:
- X 轴: 经度
- Y 轴: 纬度
- Z 轴: 时间

可以观察:
- 空间分布随时间的变化
- 时空聚集模式
- 时空异常
```

## 交互技术

### 空间交互

```
常用空间交互:
- 缩放 (Zoom): 查看不同详细程度
- 平移 (Pan): 查看不同区域
- 选择 (Select): 选择特定要素
- 查询 (Query): 点击查询属性
- 框选 (Box Select): 选择区域内的要素
- 悬浮提示 (Tooltip): 显示属性信息
```

### 联动交互

```
多视图联动:
- 地图 + 图表联动
- 选择地图上的区域，图表显示对应数据
- 选择图表上的类别，地图高亮对应要素

工具:
- Kepler.gl: 多视图联动
- Deck.gl + 自定义图表
- Observable/D3.js
```
