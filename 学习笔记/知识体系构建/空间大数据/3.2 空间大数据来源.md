# 空间大数据来源

> 空间大数据的来源广泛，涵盖遥感、定位、传感器、社交媒体等多种渠道，每种来源的数据特征和处理方式各不相同。

---

## 遥感数据

### 光学遥感

| 卫星/传感器 | 分辨率 | 波段数 | 重访周期 |
|-------------|--------|--------|----------|
| Landsat 8/9 | 30m | 11 | 16 天 |
| Sentinel-2 | 10m | 13 | 5 天 |
| 高分二号 | 0.8m | 4 | — |
| WorldView-3 | 0.31m | 29 | 1 天 |

### 雷达遥感（SAR）

- 全天候、全天时观测
- 穿透云层和植被
- Sentinel-1、ALOS-2、TerraSAR-X

### 高光谱遥感

- 数百个连续光谱波段
- 物质精细识别能力
- EO-1、珠海一号

### 数据规模

```
全球 Landsat 数据: > 10 PB
全球 Sentinel 数据: > 20 PB
年增量: 数 PB 级别
```

## GNSS 定位数据

### 来源

- **车载 GPS**：出租车、网约车、物流车
- **手机定位**：基站定位、WiFi 定位、AGPS
- **可穿戴设备**：运动手表、智能手环
- **船舶 AIS**：船舶自动识别系统
- **航空 ADS-B**：飞机广播式自动监视

### 数据特征

```
单条轨迹点:
{
  "device_id": "vehicle_001",
  "timestamp": "2024-01-01T12:00:00Z",
  "longitude": 116.397,
  "latitude": 39.908,
  "speed": 45.2,
  "heading": 180
}

规模:
- 一辆网约车: ~10万点/天
- 一个城市出租车: ~10亿点/天
- 全国网约车: ~100亿点/天
```

### 数据质量问题

- GPS 漂移（城市峡谷、隧道）
- 采样率不均匀
- 数据缺失
- 坐标偏移（GCJ-02 等）

## 地面传感器网络

### 气象观测

- 自动气象站：温度、湿度、风速、降水
- 雷达网：天气雷达、风廓线雷达
- 数据频率：分钟级到小时级

### 环境监测

- 空气质量监测站：PM2.5、PM10、O₃
- 水质监测站：pH、溶解氧、浊度
- 噪声监测站

### 物联网传感器

```
IoT 空间数据特征:
- 海量节点: 百万~亿级
- 高频采集: 秒级
- 多源异构: 不同协议和格式
- 边缘计算: 部分计算在端侧完成
```

## 社交媒体数据

### 地理文本

- **微博/Twitter**：带位置的短文本
- **签到数据**：Foursquare、大众点评
- **评论数据**：带 POI 的用户评论

### 地理图像

- **街景图像**：Google StreetView、百度街景
- **用户上传照片**：Flickr、Instagram
- **无人机影像**：航拍、巡检

### 数据特征

```
- 非结构化为主
- 位置精度不一（GPS/基站/WiFi/文本）
- 包含丰富语义信息
- 噪声大、质量参差不齐
```

---

## 众源地理数据

### OpenStreetMap（OSM）

- 全球最大的众源地理数据库
- 包含道路、建筑、POI 等
- 数据量：> 100GB（压缩后）

### 众源测绘

- 用户贡献的地理信息
- 地名地址数据
- 实时路况信息

## 通信数据

### 手机信令数据

```
信令记录:
{
  "手机号(脱敏)": "138****1234",
  "时间": "2024-01-01 12:00:00",
  "基站ID": "BS_001",
  "经度": 116.397,
  "纬度": 39.908,
  "事件类型": "位置更新"
}

特点:
- 覆盖面广（几乎所有人）
- 采样不均匀
- 位置精度取决于基站密度
- 隐私敏感
```
