# 空间数据模型

> 空间数据模型是对现实世界空间实体及其关系的抽象表达，是空间数据组织和处理的基础。

---

## 概述

空间数据模型是将现实世界中的地理现象抽象为计算机可处理的数据结构的过程。不同的数据模型适用于不同的应用场景。

---

## 矢量数据模型

### 基本思想

用离散的几何对象（点、线、面）来表达空间实体。

### 数据结构

**简单要素模型（Simple Feature Model）**：
```
Feature = Geometry + Properties

Point:      (x, y)
LineString: [(x₁,y₁), (x₂,y₂), ...]
Polygon:    [[(x₁,y₁), ...]]  // 外环 + 可选内环(洞)
MultiPoint: [(x₁,y₁), (x₂,y₂), ...]
```

**拓扑数据模型**：
- 节点（Node）：线的端点
- 边（Edge）：连接两个节点的线段
- 面（Face）：由边围成的封闭区域

拓扑模型的优势：避免数据冗余，支持高效的空间关系查询。

### 优缺点

| 优点 | 缺点 |
|------|------|
| 精确表达几何形状 | 数据结构复杂 |
| 存储空间小 | 叠加分析计算量大 |
| 拓扑关系清晰 | 不适合连续场表达 |
| 输出美观 | 空间分析算法复杂 |

## 栅格数据模型

### 基本思想

用规则格网（Grid）覆盖空间，每个格网单元（Cell）记录一个属性值。

### 数据结构

```
栅格矩阵:
┌───┬───┬───┬───┐
│ 1 │ 1 │ 2 │ 2 │
├───┼───┼───┼───┤
│ 1 │ 2 │ 2 │ 3 │
├───┼───┼───┼───┤
│ 2 │ 2 │ 3 │ 3 │
└───┴───┴───┴───┘

元数据:
- 分辨率: cell size
- 范围: xmin, ymin, xmax, ymax
- 坐标系: CRS
```

### 关键参数

- **分辨率（Resolution）**：格网单元的边长，决定空间精度
- **波段（Band）**：每个单元可存储多个值（如遥感多波段）
- **NoData**：表示无有效数据的特殊值

### 优缺点

| 优点 | 缺点 |
|------|------|
| 数据结构简单 | 数据量大 |
| 空间分析高效 | 精度受分辨率限制 |
| 适合连续场表达 | 输出不够美观 |
| 叠加分析简单 | 难以表达拓扑关系 |

---

## 矢量-栅格混合模型

### 转换

- **矢量 → 栅格**：栅格化（Rasterization）
- **栅格 → 矢量**：矢量化（Vectorization）

### 混合策略

- 不同图层使用不同模型
- 同一图层中两种模型并存
- 中间格式（如 TIN 不规则三角网）

---

## 三维数据模型

### 体元模型（Voxel）

三维空间的栅格化表达：
```
Voxel = 3D Cell + Attribute
适用于：地质建模、大气模拟
```

### 三维边界表示（B-Rep）

用面、边、点的拓扑关系表达三维实体：
```
Solid → Shell → Face → Loop → Edge → Vertex
适用于：建筑信息模型（BIM）、城市三维建模
```

### 2.5D 模型

在二维表面上附加高程信息：
- 数字高程模型（DEM）
- 数字表面模型（DSM）
- 不规则三角网（TIN）

---

## 时空数据模型

### 快照模型

```
Time₁ → Spatial State₁
Time₂ → Spatial State₂
...
简单但存在大量数据冗余
```

### 事件模型

```
Event = (Time, Location, Type, Attributes)
记录空间状态的变化事件
```

### 轨迹模型

```
Trajectory = [(t₁, x₁, y₁), (t₂, x₂, y₂), ...]
移动对象的时空序列
```

## 数据模型对比

| 模型 | 适用场景 | 代表格式 |
|------|----------|----------|
| 矢量 | 精确几何表达 | Shapefile, GeoJSON, GML |
| 栅格 | 连续场、遥感影像 | GeoTIFF, NetCDF |
| TIN | 地形表面 | TIN |
| 体元 | 三维空间分析 | Voxel |
| 点云 | 三维扫描 | LAS, LAZ |
