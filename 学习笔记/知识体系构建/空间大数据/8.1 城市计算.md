# 城市计算

> 城市计算是利用空间大数据感知、分析和优化城市运行状态的交叉学科，旨在构建更智能、高效和可持续的城市。

---

## 概述

### 城市计算框架

```
城市感知 → 数据管理 → 数据分析 → 服务提供

┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  感知层  │ → │  数据层  │ → │  分析层  │ → │  应用层  │
│ 传感器  │   │ 存储    │   │ 挖掘    │   │ 规划    │
│ 手机    │   │ 管理    │   │ 预测    │   │ 交通    │
│ 社交媒体│   │ 融合    │   │ 推荐    │   │ 环境    │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
```

### 城市大数据来源

| 来源 | 数据类型 | 应用 |
|------|----------|------|
| 手机信令 | 位置、通信 | 人流分析、出行模式 |
| 交通卡口 | 车牌、时间 | 交通流量、路径追踪 |
| 公交地铁 | IC卡、GPS | 公共交通分析 |
| 社交媒体 | 文本、签到 | 城市情绪、热点检测 |
| 遥感影像 | 影像 | 城市扩张、土地利用 |
| POI数据 | 兴趣点 | 城市功能分析 |
| 环境监测 | 传感器 | 空气质量、噪声 |

### 基于 POI 的功能区识别

```python
# 方法 1: POI 密度聚类
from sklearn.cluster import DBSCAN

# 提取 POI 特征
features = extract_poi_features(region)  # 各类 POI 的密度

# 聚类
clustering = DBSCAN(eps=0.3, min_samples=5)
labels = clustering.fit_predict(features)

# 方法 2: 主题模型 (LDA)
# 将每个区域视为文档，POI 类型视为词

```

### 基于手机信令的功能区识别

```
1. 时空特征提取
   - 工作时段人口密度
   - 居住时段人口密度
   - 人口流入流出模式

2. 功能分类
   - 居住区: 夜间密度高，白天密度低
   - 商业区: 白天密度高，夜间密度低
   - 工业区: 工作时段密度稳定
```

### 基于深度学习的功能区识别

```
多模态融合:
1. 遥感影像 → CNN → 视觉特征
2. POI 分布 → Embedding → 语义特征
3. 人流模式 → RNN → 时序特征
4. 融合特征 → 分类器 → 功能区类型
```

## 城市人流分析

### 人口热力图

```python
# 实时人口分布
def population_heatmap(signaling_data, time_point):
    # 筛选时间点的信令数据
    data = signaling_data[signaling_data.time == time_point]
    # 按网格聚合
    grid_counts = data.groupby('grid_id').size()
    # 生成热力图
    return grid_to_heatmap(grid_counts)
```

### 出行 OD 分析

```
OD (Origin-Destination) 分析:

1. 提取出行起终点
   - 手机信令: 基站切换
   - 公交 IC 卡: 上下车
   - 出租车 GPS: 上下车点

2. OD 矩阵构建
   OD[i][j] = 从区域 i 到区域 j 的出行量

3. 可视化
   - OD 流线图
   - 弦图 (Chord Diagram)
   - 流动图 (Flow Map)
```

### 通勤模式分析

```
通勤分析:
1. 识别居住地和工作地
   - 夜间常在位置 → 居住地
   - 白天常在位置 → 工作地

2. 通勤特征提取
   - 通勤距离
   - 通勤时间
   - 通勤方向

3. 通勤模式分类
   - 短距离通勤
   - 长距离通勤
   - 跨城通勤
```

## 城市环境监测

### 空气质量分析

```
空间插值:
- 监测站点数据 → 空间插值 → 全覆盖空气质量图
- 方法: 克里金、IDW

时空预测:
- 历史数据 + 气象数据 → 模型 → 未来空气质量预测
- 方法: 时空 LSTM、ConvLSTM

污染源追踪:
- 扩散模型 + 监测数据 → 反演污染源位置
```

### 噪声地图

```
噪声空间分析:
1. 噪声数据采集
   - 固定监测站
   - 移动监测 (车载、手机)

2. 空间建模
   - 噪声传播模型
   - 机器学习预测

3. 噪声地图
   - 等值线图
   - 网格化噪声分布
```

## 城市规划支持

### 土地利用分析

```
遥感 + 深度学习:

1. 遥感影像分类
   - CNN 语义分割
   - 识别建筑、道路、绿地、水体

2. 变化检测
   - 多时相影像对比
   - 识别城市扩张

3. 规划指标提取
   - 建筑密度
   - 绿化率
   - 道路密度
```

### 公共服务设施评估

```
可达性分析:
- 服务区分析: 医院/学校/公园的覆盖范围
- 网络分析: 基于路网的可达性
- 两步移动搜索法 (2SFCA): 考虑供需关系

公平性分析:
- 不同区域的设施可达性差异
- 社会经济因素与设施分布的关系
```

### 城市模拟

```
城市增长模拟:
- 元胞自动机 (CA): 基于规则的模拟
- ABM (Agent-Based Model): 基于智能体的模拟
- 深度学习: 数据驱动的模拟

应用:
- 城市扩张预测
- 土地利用变化模拟
- 交通需求预测
```

## 城市安全

### 犯罪热点分析

```
时空犯罪分析:
1. 空间聚类: 识别犯罪热点区域
2. 时空模式: 分析犯罪的时间规律
3. 预测: 预测犯罪发生的高风险区域和时间

方法:
- 核密度估计
- 时空扫描统计
- 时空深度学习
```

   - 影响范围分析
