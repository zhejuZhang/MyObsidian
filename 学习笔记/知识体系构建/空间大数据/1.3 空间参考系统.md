# 空间参考系统

> 空间参考系统（SRS）定义了空间数据的坐标参考框架，是空间数据能够相互叠加和分析的基础。

---

## 概述

空间参考系统是一套数学规则，用于将地球表面的位置映射到坐标值。没有统一的 SRS，不同来源的空间数据无法正确叠加。

---

## 坐标系统

### 地理坐标系（Geographic Coordinate System）

用经度（λ）和纬度（φ）表示地球表面的位置：

```
经度: -180° ~ +180°（东经为正）
纬度: -90° ~ +90°（北纬为正）
```

**常用地理坐标系**：
- **WGS84**：GPS 使用的全球坐标系（EPSG:4326）
- **CGCS2000**：中国国家大地坐标系（EPSG:4490）
- **GCJ-02**：中国国测局坐标系（火星坐标系）
- **BD-09**：百度坐标系

### 投影坐标系（Projected Coordinate System）

将三维地球表面投影到二维平面：

```
投影过程:
地球椭球面 → (经度, 纬度) → 投影变换 → (x, y) 平面坐标
```

---

## 地图投影

### 投影分类

| 类型 | 特性 | 典型投影 | 适用场景 |
|------|------|----------|----------|
| 等角投影 | 保持角度不变 | 墨卡托投影 | 航海、导航 |
| 等积投影 | 保持面积不变 | 阿尔伯斯投影 | 面积统计 |
| 等距投影 | 保持特定距离不变 | 等距方位投影 | 距离分析 |
| 任意投影 | 无特定保持特性 | — | 一般用途 |

### 常用投影

**墨卡托投影（Mercator）**：
- 正轴等角圆柱投影
- 经纬线相互垂直
- 高纬度地区面积严重变形
- Web 地图的标准投影（Web Mercator, EPSG:3857）

**高斯-克吕格投影（Gauss-Kruger）**：
- 横轴等角切椭圆柱投影
- 中国大比例尺地图的标准投影
- 6° 带或 3° 带分带

**UTM 投影（Universal Transverse Mercator）**：
- 全球统一的分带投影
- 将地球分为 60 个 6° 带
- 广泛用于军事和科学领域

## 基准面与椭球体

### 参考椭球体

用于近似地球形状的数学椭球体：

| 椭球体 | 长半轴 (m) | 扁率 | 使用者 |
|--------|-----------|------|--------|
| WGS84 | 6378137 | 1/298.257 | GPS 全球 |
| GRS80 | 6378137 | 1/298.257 | CGCS2000 |
| 克拉索夫斯基 | 6378245 | 1/298.3 | 北京54 |

### 大地基准面

定义椭球体与地球的相对位置关系：
- **地心基准面**：椭球体中心与地球质心重合（WGS84、CGCS2000）
- **局部基准面**：椭球体与特定区域最佳拟合（北京54、西安80）

## 坐标转换

### 转换类型

```
相同基准面内: 投影变换 (如 WGS84 经纬度 → Web Mercator)
不同基准面间: 基准面转换 (如 WGS84 → CGCS2000)
```

### 转换方法

**三参数转换**（平移）：
```
X' = X + ΔX
Y' = Y + ΔY
Z' = Z + ΔZ
```

**七参数转换**（布尔沙-沃尔夫模型）：
- 3 个平移参数
- 3 个旋转参数
- 1 个缩放参数

**格网转换**：
- 使用预计算的偏移量格网
- 精度最高
- 中国常用：CGCS2000 ↔ WGS84 格网文件

### 中国坐标系的特殊问题

```
WGS84 (GPS原始)
  ↓ 加偏
GCJ-02 (火星坐标, 高德/腾讯)
  ↓ 再加偏
BD-09 (百度坐标)
```

注意：在中国使用空间数据时，必须注意坐标系的一致性，否则会出现几十到几百米的偏移。

常用空间参考系统的 EPSG 标识：

| EPSG | 名称 | 说明 |
|------|------|------|
| 4326 | WGS84 | GPS 全球坐标系 |
| 3857 | Web Mercator | Web 地图标准 |
| 4490 | CGCS2000 | 中国国家坐标系 |
| 4547 | CGCS2000 / 3-degree GK zone 39 | 中国 3 度带 |
