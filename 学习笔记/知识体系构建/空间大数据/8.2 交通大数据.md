# 交通大数据

> 交通大数据是利用车辆轨迹、交通检测器、公共交通等数据进行交通分析和优化的领域。

---

## 数据来源

### 浮动车数据

```
来源: 出租车、网约车、物流车的 GPS 轨迹

数据结构:
{
  "vehicle_id": "taxi_001",
  "timestamp": 1704067200,
  "longitude": 116.397,
  "latitude": 39.908,
  "speed": 45.2,
  "heading": 180,
  "status": 1  // 1=载客, 0=空载
}

规模: 大城市日均数亿条记录
```

### 交通检测器

```
类型:
- 线圈检测器: 车辆通过计数
- 视频检测器: 车牌识别、流量统计
- 微波检测器: 速度、流量
- ETC: 高速公路收费数据

数据:
- 断面流量
- 车辆速度
- 占有率
- 车型分类
```

### 公共交通数据

```
公交 IC 卡:
- 刷卡时间、站点
- 上下车记录

地铁 AFC:
- 进站时间、站点
- 出站时间、站点

公交 GPS:
- 车辆实时位置
- 到站时间
```

### 导航数据

```
来源: 高德、百度、腾讯等导航平台

数据:
- 实时路况
- 拥堵指数
- 预计到达时间
- 路径规划
```

# 基于浮动车的路段流量估计
def estimate_link_flow(trajectories, road_network):
    # 1. 地图匹配: 将 GPS 点匹配到路段

    link_flow = matched.groupby(['link_id', 'hour']).size()
    
    # 3. 扩展到全量车辆
    # 浮动车占比 → 估计全量流量
    estimated_flow = link_flow / penetration_rate

### 交通状态识别

```
交通状态分类:
- 畅通: 速度 > 40 km/h
- 缓行: 20 < 速度 ≤ 40 km/h
- 拥堵: 速度 ≤ 20 km/h

识别方法:
1. 速度阈值法
2. 聚类分析 (K-means)
3. 深度学习 (LSTM 预测)
```

### 拥堵传播分析

```
拥堵传播模型:
1. 拥堵识别
   - 识别拥堵路段和时段
2. 传播链构建
   - 拥堵从上游路段传播到下游
3. 传播规律分析
   - 传播速度
   - 传播范围
   - 消散时间
```

## 出行模式分析

### 出行 OD 分析

```
OD (Origin-Destination) 矩阵:

1. 出行起终点提取
   - 出租车: 上车点(O) → 下车点(D)
   - 公交: 上车站点(O) → 下车站点(D)
   - 手机: 基站切换

2. OD 矩阵构建
   OD[i][j] = 从区域 i 到区域 j 的出行量

3. 时空分析
   - 早高峰 OD: 居住地 → 工作地
   - 晚高峰 OD: 工作地 → 居住地
   - 周末 OD: 居住地 → 商业区/休闲区
```

### 出行链分析

```
出行链: 一天内多次出行的连接

家 → 工作地 → 餐厅 → 工作地 → 商场 → 家

分析:
- 出行链长度
- 出行方式组合
- 时空规律
```

### 出行方式识别

```
基于 GPS 轨迹的出行方式识别:

特征:
- 速度: 步行 < 自行车 < 公交 < 地铁 < 小汽车
- 加速度: 不同方式的加速度特征
- 轨迹形状: 地铁沿固定线路

方法:
1. 规则分类: 速度阈值
2. 机器学习: 随机森林、SVM
3. 深度学习: LSTM、CNN
```

## 路径规划

### 最短路径

```
经典算法:
- Dijkstra: 单源最短路径
- A*: 启发式搜索
- Floyd-Warshall: 全源最短路径

在路网上的应用:
- 节点: 交叉口
- 边: 路段
- 权重: 距离、时间、费用
```

### 时间依赖路径

```
考虑交通状况的路径规划:

时间依赖权重:
- 早高峰: 某路段通行时间 30 分钟
- 平峰: 同一路段通行时间 10 分钟

算法:
- 时间依赖 Dijkstra
- 时间依赖 A*
```

### 多目标路径

```
同时考虑多个目标:
- 时间最短
- 距离最短
- 费用最低
- 舒适度最高

方法:
- 加权和法
- Pareto 最优
- 多目标进化算法
```

## 交通预测

### 短时交通流预测

```
输入: 历史交通流数据
输出: 未来 5-60 分钟的交通流

方法:
1. 时间序列模型
   - ARIMA
   - 指数平滑

2. 机器学习
   - 随机森林
   - 梯度提升

3. 深度学习
   - LSTM: 时间依赖
   - CNN: 空间依赖
   - 图神经网络: 路网拓扑
   - 时空图网络: STGCN, DCRNN
```

### 交通需求预测

```
预测未来某区域的出行需求:

输入:
- 历史 OD 数据
- 时间特征 (时段、星期)
- 天气、事件等外部特征

方法:
- 时空图网络
- 注意力机制
- 多源数据融合
```

├── 实时计算: Flink
├── 批处理: Spark

应用层:
├── 实时路况
├── 交通预测

└── 信号优化
