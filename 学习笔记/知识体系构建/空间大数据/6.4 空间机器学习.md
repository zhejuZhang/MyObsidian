# 空间机器学习

> 空间机器学习（GeoAI）是将机器学习和深度学习方法应用于空间数据的交叉领域，解决空间预测、分类、生成等问题。

---

## 概述

空间机器学习的特殊性：
- **空间自相关**：违背传统 ML 的独立同分布假设
- **空间异质性**：不同区域的模式可能不同
- **多源数据融合**：矢量、栅格、轨迹、文本
- **几何信息**：几何形状本身包含信息

## 深度学习基础

### 卷积神经网络（CNN）

```
用于栅格数据（遥感影像）:

输入: 多波段影像 [B, C, H, W]
卷积层: 提取局部特征
池化层: 降维
全连接层: 分类/回归

空间特性:
- 局部感受野: 适合空间局部特征
- 权重共享: 减少参数
- 平移不变性: 同一特征在不同位置
```

### 循环神经网络（RNN）

```
用于序列数据（轨迹）:

输入: 时间序列 [(x₁,y₁), (x₂,y₂), ...]
LSTM/GRU: 捕获时间依赖
输出: 预测/分类

空间特性:
- 序列建模: 轨迹的时间顺序
- 长期依赖: LSTM 捕获长期模式
```

### 图神经网络（GNN）

```
用于图结构数据（空间网络）:

输入: 图结构 (节点特征, 边特征, 邻接矩阵)
图卷积: 聚合邻居信息
输出: 节点/图级别预测

空间特性:
- 非欧空间: 适合不规则空间数据
- 关系建模: 显式建模空间关系
- 消息传递: 邻居信息聚合
```

## 空间深度学习

### 遥感影像分类

```python
import torch
import torch.nn as nn

class RemoteSensingCNN(nn.Module):
    def __init__(self, in_channels, num_classes):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(in_channels, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(128, num_classes),
        )
    
    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x
```

### 时空预测

```python
class STBlock(nn.Module):
    """时空块: 空间卷积 + 时间卷积"""
    def __init__(self, in_channels, out_channels):
        super().__init__()
        # 空间卷积
        self.spatial_conv = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        # 时间卷积
        self.temporal_conv = nn.Conv1d(out_channels, out_channels, 3, padding=1)
    
    def forward(self, x):
        # x: [B, T, C, H, W]
        B, T, C, H, W = x.shape
        # 空间卷积
        x = x.view(B*T, C, H, W)
        x = self.spatial_conv(x)
        x = x.view(B, T, -1, H, W)
        # 时间卷积
        x = x.permute(0, 3, 4, 2, 1)  # [B, H, W, C, T]
        x = x.reshape(B*H*W, -1, T)
        x = self.temporal_conv(x)
        return x
```

### 图神经网络空间预测

import torch_geometric

class SpatialGNN(torch.nn.Module):
    def __init__(self, in_features, hidden_features, out_features):
        super().__init__()
        self.conv1 = torch_geometric.nn.GCNConv(in_features, hidden_features)
        self.conv2 = torch_geometric.nn.GCNConv(hidden_features, out_features)
    
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index).relu()
        x = self.conv2(x, edge_index)
        return x

# 边: 空间邻接关系

### 空间 Transformer

```python
class SpatialTransformer(nn.Module):
    """空间注意力机制"""
    def __init__(self, d_model, nhead):
        super().__init__()
        self.spatial_attn = nn.MultiheadAttention(d_model, nhead)
        self.temporal_attn = nn.MultiheadAttention(d_model, nhead)
    
    def forward(self, x):
        # 空间注意力: 不同位置之间的关联
        spatial_out = self.spatial_attn(x, x, x)
        # 时间注意力: 不同时刻之间的关联
        temporal_out = self.temporal_attn(spatial_out, spatial_out, spatial_out)
        return temporal_out
```

## 空间机器学习的挑战

### 空间交叉验证

```
传统交叉验证的问题:
- 随机划分会破坏空间自相关
- 训练集和测试集空间上邻近
- 导致过拟合和评估偏差

空间交叉验证:
1. 空间分块交叉验证
   - 按空间区域划分
   - 相邻区域不能同时在训练集和测试集

2. 空间缓冲区
   - 在训练集和测试集之间留缓冲区
   - 减少空间泄漏
```

### 可解释性

```
空间模型的可解释性:

1. 空间特征重要性
   - 哪些空间特征最重要
   - 不同区域的特征重要性是否不同

2. 空间残差分析
   - 模型残差是否有空间模式
   - 识别模型失效的区域

3. 局部可解释性
   - SHAP 值的空间分布
   - 局部特征贡献
```

### 数据不平衡

```
空间数据的不平衡问题:
- 某些区域数据密集，某些稀疏
- 空间采样偏差

解决方法:
1. 空间重采样
   - 对稀疏区域过采样
   - 对密集区域欠采样

2. 空间加权
   - 根据空间密度调整样本权重

3. 迁移学习
   - 从数据丰富区域迁移知识
```
