# 空间数据挖掘

> 空间数据挖掘是从空间数据中发现隐含的、有用的空间模式和知识的过程。

---

## 概述

空间数据挖掘在传统数据挖掘基础上考虑了空间维度的特殊性：
- **空间自相关**：邻近数据相互依赖
- **空间异质性**：不同区域的模式可能不同
- **空间关系**：拓扑、方向、距离关系
- **多尺度性**：不同尺度下的模式不同

---

## 空间聚类

### 基于密度的聚类

**DBSCAN**：

```
核心概念:
- 核心点: ε 邻域内至少有 MinPts 个点
- 边界点: 在核心点的 ε 邻域内，但自身不是核心点
- 噪声点: 既不是核心点也不是边界点

算法:
1. 选择一个未访问的点
2. 如果是核心点，创建新簇
3. 找到所有密度可达的点，加入簇
4. 重复直到所有点被访问

优点: 不需要预设簇数，能发现任意形状的簇
缺点: 对参数 ε 和 MinPts 敏感
```

**HDBSCAN**：

```
DBSCAN 的层次化扩展:
1. 构建核心距离图
2. 构建最小生成树
3. 层次化聚类
4. 提取稳定的簇

优点:
- 自动确定簇数
- 不需要固定 ε 参数
- 能处理不同密度的簇
```

**ST-DBSCAN**（时空 DBSCAN）：

```
扩展 DBSCAN 支持时空数据:
- 空间邻域: ε_s (空间距离)
- 时间邻域: ε_t (时间距离)
- 时空密度: 同时考虑空间和时间邻域
```

### 基于网格的聚类

**STING**（Statistical Information Grid）：

```
层次化网格结构:
1. 将空间划分为不同分辨率的网格
2. 计算每个网格的统计信息
3. 自顶向下查询，利用统计信息过滤
4. 在满足条件的网格内聚类

优点: 查询速度快，并行性好
```

**CLIQUE**：

```
基于网格和密度的聚类:
1. 将每个维度划分为等宽区间
2. 识别密集单元
3. 连接相邻密集单元形成簇
4. 为每个簇生成最小描述

优点: 自动发现子空间中的簇
```

### 基于层次的聚类

**BIRCH**（Balanced Iterative Reducing and Clustering using Hierarchies）：

```
核心数据结构: CF 树 (Clustering Feature Tree)

CF = (N, LS, SS)
- N: 点数
- LS: 线性和
- SS: 平方和

算法:
1. 构建 CF 树 (增量插入)
2. 全局聚类 (在 CF 上聚类)
3. 可选: 精炼阶段
```

## 空间分类

### 空间决策树

```
考虑空间特征的决策树:

空间特征:
- 几何属性: 面积、周长、形状指数
- 邻域属性: 邻近对象的统计特征
- 位置属性: 坐标、高程

空间自相关处理:
- 在分裂准则中考虑空间自相关
- 使用空间滞后变量
- 局部决策树 (每个区域独立建模)
```

### 空间随机森林

```
随机森林 + 空间特征:

1. 特征工程:
   - 原始属性特征
   - 空间邻域特征 (邻近对象的属性统计)
   - 空间关系特征 (距离、方向)
   - 位置特征 (坐标、GeoHash)

2. 训练:
   - 随机采样 + 随机特征选择
   - 构建多棵决策树
   - 投票/平均得到最终结果
```

### 空间贝叶斯

```
贝叶斯分类器 + 空间先验:

P(C|X) ∝ P(X|C) · P(C)

空间先验 P(C):
- 考虑邻近区域的类别
- 空间平滑: 邻近区域倾向同类
- 马尔可夫随机场 (MRF) 建模
```

## 空间关联规则挖掘

### 概念

```
空间关联规则:
A → B (support, confidence)

A, B 是空间谓词的组合:
- near(A, B): A 靠近 B
- inside(A, B): A 在 B 内部
- adjacent(A, B): A 与 B 相邻

示例:
near(hospital, school) → near(park, school)
(支持度=0.3, 置信度=0.8)
```

### 挖掘方法

```
1. 空间关系计算
   计算所有对象对之间的空间关系
   构建空间关系事务表

2. 频繁项集挖掘
   Apriori 算法或 FP-Growth 算法
   在空间关系事务表上挖掘频繁项集

3. 规则生成
   从频繁项集生成关联规则
   计算支持度和置信度
```

## 异常检测

### 空间异常

```
空间异常 (Spatial Outlier):
在空间上与其邻域显著不同的观测

检测方法:
1. 基于邻域统计
   - 计算每个点与其邻域的差异
   - 差异超过阈值则为异常

2. Moran 散点图
   - 绘制观测值 vs 邻域均值
   - 象限 HL 和 LH 为异常

3. 局部 Moran's I
   - 计算每个点的局部 I
   - 统计显著的为异常
```

### 时空异常

```
时空异常 (Spatiotemporal Outlier):
在时空上与其邻域显著不同的观测

检测方法:
1. 时空邻域定义
   - 空间邻域: 距离或邻接
   - 时间邻域: 时间窗口

2. 时空统计
   - 计算时空邻域的统计量
   - 与观测值比较

3. 深度学习方法
   - 时空自编码器
   - 预测残差异常检测
```

## 空间模式发现

### 空间同位模式

```
空间同位 (Co-location):
空间上频繁共现的特征类型集合

示例:
- 咖啡店与书店经常共现
- 医院与药店经常共存

挖掘方法:
1. 构建空间邻近图
2. 生成候选同位模式
3. 计算参与率和参与度
4. 提取频繁同位模式
```

### 空间序列模式

```
空间序列模式:
具有空间约束的序列模式

示例:
用户访问 POI 的序列:
商场 → 餐厅 → 电影院

挖掘方法:
1. 空间序列化
   将空间轨迹转换为 POI 序列
2. 序列模式挖掘
   PrefixSpan, GSP 算法
3. 空间约束过滤
   考虑空间距离和方向约束
```

## 大数据环境下的空间挖掘

### 并行化策略

```
1. 数据并行
   - 将数据分区到多个节点
   - 每个节点独立挖掘
   - 合并结果

2. 任务并行
   - 将挖掘任务分解为子任务
   - 多个子任务并行执行
   - 合并结果

3. 流式挖掘
   - 增量更新挖掘结果
   - 滑动窗口内挖掘
   - 近似算法
```

### 近似挖掘

```
1. 采样
   - 随机采样减少数据量
   - 分层采样保持分布
   - 结果有统计误差

2. 概率数据结构
   - Bloom Filter: 集合成员判断
   - HyperLogLog: 去重计数
   - Count-Min Sketch: 频率估计

3. 增量更新
   - 维护挖掘结果的增量版本
   - 新数据到达时更新而非重算
```
