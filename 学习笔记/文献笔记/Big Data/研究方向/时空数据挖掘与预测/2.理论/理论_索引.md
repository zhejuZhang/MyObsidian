# 时空数据挖掘与预测 — 理论

## 核心理论框架

### 统计方法
- ARIMA / SARIMA：经典时间序列
- STARIMA：ARIMA + 空间权重矩阵
- Kriging：空间插值（普通克里格、协同克里格）
- GWR / MGWR：地理加权回归

### 深度学习方法
- 基于网格：ConvLSTM → ST-ResNet → PredRNN
- 基于图：STGCN → DCRNN → Graph WaveNet → MTGNN
- 基于 Transformer：ASTGCN → GMAN → STAEFormer
- 基于 Neural ODE：ST-GODE、GRAND-ODE

### 基础模型
- 时空大模型：UrbanGPT、STLLM、UniST
- 跨域迁移：预训练 + 微调范式
