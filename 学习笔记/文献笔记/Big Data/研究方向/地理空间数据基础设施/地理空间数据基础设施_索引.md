# 地理空间数据基础设施

> Geospatial Data Infrastructure — 空间数据的存储、索引、查询、共享与服务化的技术体系。

## 核心主题

- 分布式空间数据库（PostGIS、GeoMesa、Apache Sedona）
- 空间索引与查询优化（R-tree、GeoHash、S2）
- OGC 标准（WMS、WFS、WCS）
- 空间数据存储与管理（矢量、栅格）
- 云原生 GIS 与微服务架构
