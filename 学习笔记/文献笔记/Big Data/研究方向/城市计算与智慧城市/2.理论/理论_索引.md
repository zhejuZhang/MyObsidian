# 城市计算与智慧城市 — 理论

## 核心理论框架

### 城市计算框架
- 郑宇城市计算四层架构：城市感知 → 数据管理 → 数据分析 → 服务提供
- 多源异构数据融合方法

### 智能交通建模
- 时空图神经网络（ST-GCN、DCRNN、Graph WaveNet）
- 出行需求预测模型（ConvLSTM、Multi-task Learning）
- 交通流理论与元胞自动机

### 城市功能区识别
- 基于 POI 的主题模型（LDA）
- 基于手机信令的人群活动模式
- 深度学习多源融合（Stacked Auto-Encoder）

### 城市数字孪生
- 数字孪生概念：虚拟镜像、实时同步、预测仿真
- CIM-to-UDT过渡路径：数据基础设施 → 3D建模 → 仿真平台 → 决策支持
- 生成式AI赋能：GAN/VAE/GPT/Diffusion在城市数据生成中的应用
