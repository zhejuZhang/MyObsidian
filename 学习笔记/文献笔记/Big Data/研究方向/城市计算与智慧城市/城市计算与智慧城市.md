# 城市计算与智慧城市

> Urban Computing & Smart City — 利用大数据技术感知、分析和优化城市系统的运行状态。

---

## 1. 概述

城市计算（Urban Computing）是由微软研究院郑宇等人系统提出的概念，指通过采集城市中多源异构数据（交通、环境、经济、社会等），利用数据挖掘和机器学习技术，解决城市中的实际问题，提升城市运行效率和居民生活质量。

智慧城市（Smart City）是城市计算的工程化落地，强调物联网（IoT）、云计算、大数据等技术在城市管理中的综合应用。

---

## 2. 核心研究方向

### 2.1 智能交通

| 研究问题 | 典型方法 | 应用场景 |
|----------|----------|----------|
| 交通流量预测 | ST-GCN、DCRNN、Graph WaveNet | 信号灯优化、拥堵预警 |
| 出行需求预测 | ConvLSTM、Multi-task Learning | 网约车调度、公共交通规划 |
| 路线规划 | 强化学习、图搜索算法 | 导航避堵、物流配送优化 |
| 交通事故检测 | 轨迹异常检测、社交媒体挖掘 | 实时事故预警 |
| 停车位预测 | 时空序列模型 | 智慧停车系统 |

**代表性数据集**：
- TaxiBJ：北京出租车 GPS 轨迹
- METR-LA / PEMS-BAY：洛杉矶/旧金山高速公路传感器数据
- NYC Taxi Trip：纽约出租车出行记录

### 2.2 城市功能区划分

目标：根据区域内的 POI 分布、人流模式、交通特征等，自动识别城市功能区（商业区、住宅区、工业区等）。

**典型方法**：
- 基于 POI 语义的聚类分析（LDA 主题模型）
- 基于手机信令数据的人群活动模式挖掘
- 基于深度学习的多源数据融合分类（如 Stacked Auto-Encoder）

### 2.3 人口流动与城市活力

- **数据源**：手机信令、公交刷卡、社交媒体签到
- **分析内容**：
  - 通勤 OD（Origin-Destination）矩阵构建
  - 城市活力时空分布特征
  - 城市群联系强度与结构识别
  - 突发事件（疫情、灾害）对人口流动的影响

### 2.4 环境监测与治理

- **空气质量预测**：结合气象数据、交通排放、工业分布的 PM2.5/PM10 预测
- **噪声地图构建**：基于传感器网络和众包数据的城市噪声时空分布
- **城市热岛效应**：遥感数据与地面观测融合分析
- **碳排放估算**：交通流数据结合排放模型

### 2.5 城市事件检测与应急响应

- 社交媒体实时流中的突发事件检测（地震、火灾、恐怖袭击）
- 基于多源数据的城市异常状态识别
- 应急资源调度与疏散路径规划

### 2.6 城市规划与模拟

- 基于智能体（Agent-based）的城市增长模拟
- 土地利用变化预测（CA-Markov、深度学习）
- 城市扩张对交通、环境的影响评估

## 3. 关键技术

### 3.1 数据采集

| 数据类型 | 来源 | 特点 |
|----------|------|------|
| 轨迹数据 | 出租车 GPS、共享单车 | 连续性强、采样率不均 |
| 手机信令 | 基站定位 | 覆盖广、精度较低 |
| 社交媒体 | 微博、Twitter、Foursquare | 语义丰富、偏倚明显 |
| 传感器 | IoT 设备、交通摄像头 | 实时性强、需设备部署 |
| 遥感影像 | 卫星、无人机 | 覆盖广、更新周期长 |
| POI 数据 | 高德、百度地图 | 语义明确、更新及时 |

### 3.2 数据融合

- 时空对齐：不同数据源的时间分辨率和空间分辨率统一
- 多模态融合：结构化数据（表格）与非结构化数据（文本、图像）联合建模
- 图像-轨迹-文本联合表示学习

### 3.3 城市知识图谱

- 构建城市实体（道路、建筑、区域）之间的语义关系
- 支持城市问答、推荐、推理等下游任务

## 5. 挑战与前沿

- **数据偏倚与代表性**：社交媒体数据存在人群和区域偏倚
- **隐私保护**：轨迹数据和位置信息的隐私风险（差分隐私、联邦学习）
- **跨城市迁移**：在一个城市训练的模型如何迁移到另一个城市（Domain Adaptation）
- **实时性**：大规模流数据的在线处理与实时决策
- **可解释性**：城市决策需要模型提供可理解的依据
- **数字孪生**：构建城市级别的数字孪生体，实现仿真与决策支持
