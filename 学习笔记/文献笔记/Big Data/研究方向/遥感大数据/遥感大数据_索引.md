# 遥感大数据

> Remote Sensing Big Data — 大规模遥感影像的采集、处理、分析与应用。

## 核心主题

- 高分辨率/高光遥感影像分类
- 多源遥感数据融合（光学、SAR、LiDAR）
- 深度学习地物识别（CNN、U-Net、Transformer）
- 变化检测与动态监测
- 大规模遥感影像分布式处理
- Google Earth Engine 云计算平台
