# 大数据与地理信息研究

> 大数据技术与地理信息科学（GIScience）的交叉领域，涵盖空间数据的采集、存储、分析与可视化。

---

## 1. 空间大数据分析

- **轨迹数据挖掘**：出租车 GPS、手机信令、社交媒体签到等移动对象轨迹的模式发现
- **空间聚类与异常检测**：DBSCAN、OPTICS 等算法在大规模空间数据上的应用
- **热点分析**：Getis-Ord Gi*、核密度估计等方法识别空间聚集区域

## 2. 遥感大数据

- 高分辨率/高光谱遥感影像的自动化处理与分类
- 多源遥感数据融合（光学、SAR、LiDAR）
- 基于深度学习（CNN、U-Net、Transformer）的地物识别与变化检测
- 大规模遥感影像的分布式处理框架

## 3. 地理空间数据基础设施

- **分布式空间数据库**：PostGIS、GeoMesa、Apache Sedona
- **空间索引与查询优化**：R-tree、Quadtree、GeoHash、S2 Geometry
- **空间数据存储与检索**：矢量数据、栅格数据的高效管理
- **OGC 标准**：WMS、WFS、WCS 等 Web 服务规范

## 4. 城市计算与智慧城市

- 交通流量预测与路线优化
- 城市功能区划分与土地利用分析
- 人口流动分析与城市活力评估
- 城市事件检测与应急响应

## 5. 时空数据挖掘与预测

- 时空序列预测（PM2.5 扩散、犯罪预测、传染病传播）
- **时空图神经网络**（ST-GNN）：结合图结构与时序特征的深度学习方法
- 地理加权回归（GWR）等空间统计方法
- 时空异常检测与因果推断

## 6. 社交媒体地理信息

- 带地理标签的文本/图像挖掘
- 基于社交媒体的灾害监测与应急响应
- **地理命名实体识别**（Geoparsing）与地理解析
- 情感地理学：空间维度下的情感分析

## 7. 位置服务（LBS）与推荐

- 基于位置的 POI（兴趣点）推荐
- 地理社交网络分析
- 用户移动性建模与预测

## 8. 环境与气候大数据

- 气候模型的高性能计算与降尺度
- 地理空间数据的可视化与模拟
- 生态环境监测与评估

## 常用技术栈

| 技术 | 用途 |
|------|------|
| Apache Sedona (GeoSpark) | 分布式空间计算 |
| Hadoop / Spark | 大规模数据处理 |
| GeoMesa | 时空数据库 |
| PostGIS | 空间关系型数据库 |
| Kepler.gl / Deck.gl | 大规模地理可视化 |
| PyTorch / TensorFlow | 深度学习（遥感、轨迹） |
| GDAL / Rasterio | 地理空间数据读写 |
| GeoPandas | Python 空间数据处理 |
