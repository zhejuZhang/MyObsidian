## 研究框架概览

### 核心研究问题
城市建成环境的视觉特征如何影响居民的步行、跑步和骑行路线选择？这种影响是否存在因果关系？

### 研究创新点
从传统相关性分析转向因果推断，引入GFCI、LvLiNGAM等高级因果发现算法，结合特征向量空间滤波（ESF）处理空间自相关问题。

### 研究框架流程
```
数据采集层
├─ 街景影像 (Google Street View API)
├─ 运动轨迹 (Strava/共享单车GPS)
├─ 路网拓扑 (OpenStreetMap)
└─ 兴趣点 (POI数据)

预处理层
├─ 语义分割 (DeepLab/ViT) → GVI, SVF, BVI
├─ 地图匹配 (HMM/FMM) → 路网流量统计
└─ 空间聚合 → 路段级特征矩阵

因果分析层
├─ ESF空间去依赖 → 消除空间自相关
├─ GFCI骨架构建 → 识别因果网络结构
└─ LvLiNGAM定向 → 确定因果方向

输出层
├─ 因果图谱 (PAG)
├─ 效应量化 (因果系数)
└─ 政策建议 (干预优先级)
```
