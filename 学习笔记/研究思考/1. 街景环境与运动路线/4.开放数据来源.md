# 开放数据来源

> 获取高质量的开放数据是开展因果推断研究最关键的”源头活水”。特别是当您想要使用 GFCI 或 LiNGAM 等进阶因果模型时，充足且细粒度的数据能够极大地提升模型识别隐变量和因果方向的准确性。

> 关联文档：[[2.主流研究+创新方向]], [[5.1.城市环境与微观运动路线：基于多源空间数据与混合因果模型的路径选择机制研究]]

针对”城市环境与人们运动路线”这一研究方向，我为您梳理了目前学术界最常用、质量最高的几类开放数据来源，涵盖了从微观步行到宏观车流的不同尺度：

### 1. 共享单车轨迹数据 (微观/中观尺度)

共享单车数据非常适合研究街道环境（如绿化、路面开阔度、自行车道配置）对非机动车骑行路线的因果影响。

- **NYC Citi Bike System Data（纽约花旗单车开放数据）：**
    
    - **特点：** 这是全球最成熟的开放单车数据集之一，记录了每一次骑行的起点、终点、时间戳以及用户类型。
        
    - **优势：** 如果您想延续之前那篇纽约曼哈顿论文的研究区域，将 Citi Bike 数据与曼哈顿的街景和 POI 结合，可以直接无缝对接。
        
- **国内单车开源数据集（如摩拜、哈啰）：**
    
    - **特点：** 国内的数据通常不直接设立长期开放门户，但经常通过数据科学比赛（如阿里天池平台、Kaggle）或学术合作计划释放。
        
    - **获取途径：** 可以在天池大数据竞赛平台搜索“共享单车轨迹”，或者申请高校相关的开放实验室数据集。
        

### 2. 个人步行/跑步/骑行运动轨迹 (微观尺度)

这类数据是研究“环境感知”（如安全性、舒适度、美观度）对微观路径选择影响的绝佳素材。

- **Strava Metro：**
    
    - **特点：** Strava 是全球最大的运动轨迹追踪 App。Strava Metro 将这些海量的匿名化步行、跑步和骑行轨迹数据汇总。
        
    - **获取途径：** 重点是，它对**学术研究人员和城市规划者是免费开放申请**的。您可以直接在其官网上提交研究计划来获取城市级别的热力图和路段流量数据。
        
- **Microsoft GeoLife Trajectory Dataset：**
    
    - **特点：** 微软亚洲研究院发布的一个经典数据集，记录了上百名用户在数年内的连续 GPS 轨迹，绝大部分数据集中在北京。
        
    - **优势：** 精度极高，甚至包含了用户的出行模式（如步行、公交、驾车）标注，非常适合做小样本、深度的微观因果机制挖掘。
        

### 3. 出租车/网约车 GPS 数据 (宏观尺度)

如果您更关注城市宏观设施（如大型商业体、交通枢纽）如何作为“发生点”和“吸引点”重塑城市交通流，车辆轨迹数据是首选。

- **纽约市 TLC (Taxi & Limousine Commission) 记录：**
    
    - **特点：** 包含了十多年来纽约市所有的黄色/绿色出租车、以及 Uber/Lyft 的行程记录（包含上下车经纬度、时间、费用等）。这是城市计算领域被引用最多的开源数据集。
        
- **滴滴盖亚数据开放计划 (DiDi GAIA Initiative)：**
    
    - **特点：** 滴滴出行面向学术界开放的真实网约车轨迹数据，包含了成都、西安等城市的脱敏轨迹点。
        
    - **获取途径：** 需要以高校研究人员的身份在盖亚平台上提交申请即可下载。
        
- **芝加哥数据门户 (Chicago Data Portal - Transportation)：**
    
    - **特点：** 提供极其详尽的网约车（TNC）和出租车行程数据，且数据字段经过良好清洗，对隐私保护和空间聚合做得很好。
        

### 4. 城市环境特征数据 (自变量数据)

为了构建因果图，您还需要获取建成环境数据来与轨迹数据进行空间匹配：

- **POI 与 路网：** **OpenStreetMap (OSM)** 是目前最强大、最自由的全球地理空间开源数据，可以获取极其详细的道路等级和兴趣点。您可以使用 Python 的 `osmnx` 库直接一键下载所需城市的街道网络。
    
- **街景影像 (SVI)：** 虽然 Google 街景和百度街景的商业 API 收费，但它们通常为学术研究提供**免费额度或学术授权**。此外，像 **Mapillary** 这样的众包街景平台，其图像和提取的语义数据对非商业用途是完全开放的。
    

不同尺度的数据决定了您能讲出怎样的“因果故事”。考虑到您希望探索环境特征对路线选择的影响，您目前是更想聚焦于**微观尺度下行人/骑行者的路径偏好**，还是倾向于研究**宏观尺度下城市设施与大规模车流之间的因果关系**呢？
