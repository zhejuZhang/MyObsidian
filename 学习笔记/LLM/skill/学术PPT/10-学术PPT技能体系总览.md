## 学术PPT核心原则

### 内容原则
```
1. 一页一观点 — 每页只传达一个核心信息
2. 倒金字塔 — 结论先行，细节后置
3. 故事线 — 问题→方法→结果→结论
4. 视觉优先 — 图表>要点>段落
5. 少即是多 — 删除一切不必要的元素
```

### 结构模板
```
学术报告结构 (15-20分钟)
├── 封面页 (标题、作者、单位、日期)
├── 背景/动机 (1-2页)
├── 研究问题 (1页)
├── 方法 (2-4页)
├── 结果 (3-5页)
├── 讨论 (1-2页)
├── 总结 (1页)
└── 致谢/Q&A (1页)

比例分配:
├── 背景: 15%
├── 方法: 25%
├── 结果: 40%
└── 讨论+总结: 20%
```
