# 版本控制与代码管理

## Git核心操作

### 基础命令
```bash
# 初始化仓库
git init
git clone <url>

# 配置
git config --global user.name "Your Name"
git config --global user.email "your@email.com"

# 状态查看
git status
git log --oneline --graph
git diff
```

### 分支管理
```bash
# 创建分支
git branch feature/new-analysis
git checkout -b feature/new-analysis  # 创建并切换

# 切换分支
git checkout main
git switch main  # Git 2.23+

# 合并分支
git merge feature/new-analysis

# 删除分支
git branch -d feature/new-analysis  # 已合并
git branch -D feature/new-analysis  # 强制删除

# 变基
git checkout feature/new-analysis
git rebase main
```

### 提交规范
```bash
# Conventional Commits格式
git commit -m "feat: 添加新分析方法"
git commit -m "fix: 修复数据加载错误"
git commit -m "docs: 更新README"
git commit -m "refactor: 重构数据处理模块"
git commit -m "test: 添加单元测试"
git commit -m "chore: 更新依赖"

# 提交类型
feat:     新功能
fix:      修复bug
docs:     文档变更
style:    代码格式（不影响功能）
refactor: 重构
test:     添加测试
chore:    构建过程或辅助工具变更
```

### 暂存与恢复
```bash
# 暂存工作区
git stash
git stash save "描述信息"

# 查看暂存列表
git stash list

# 恢复暂存
git stash pop  # 恢复并删除
git stash apply  # 恢复但保留

# 恢复文件
git checkout -- <file>  # 恢复到上次提交
git restore <file>  # Git 2.23+

# 撤销提交
git reset HEAD~1  # 撤销上次提交，保留更改
git reset --soft HEAD~1  # 撤销提交，保留更改在暂存区
git reset --hard HEAD~1  # 撤销提交，丢弃更改（危险）
```

## Git高级技巧

### 交互式变基
```bash
# 压缩最近3个提交
git rebase -i HEAD~3

# 编辑器中选择：
pick abc1234 第一次提交
squash def5678 第二次提交
squash ghi9012 第三次提交
```

### Cherry-pick
```bash
# 选择性合并提交
git cherry-pick <commit-hash>

# 合并多个提交
git cherry-pick A..B
```

### 二分查找bug
```bash
# 开始二分查找
git bisect start

# 标记当前版本有bug
git bisect bad

# 标记某个版本无bug
git bisect good v1.0

# Git会自动切换版本，测试后标记
# 测试通过：
git bisect good
# 测试失败：
git bisect bad

# 结束查找
git bisect reset
```

### 子模块
```bash
# 添加子模块
git submodule add https://github.com/user/repo.git path/to/submodule

# 克隆包含子模块的仓库
git clone --recursive <url>
# 或
git submodule init
git submodule update

# 更新子模块
git submodule update --remote
```

## Git工作流

### GitHub Flow（推荐）
```
1. 从main创建分支
   git checkout -b feature/xxx

2. 开发并提交
   git add .
   git commit -m "feat: xxx"

3. 推送并创建PR
   git push origin feature/xxx
   gh pr create

4. 代码审查和讨论

5. 合并到main
   gh pr merge --squash

6. 删除分支
   git branch -d feature/xxx
```

### Git Flow
```
分支类型:
├── main        # 生产环境
├── develop     # 开发主线
├── feature/*   # 功能分支
├── release/*   # 发布分支
└── hotfix/*    # 热修复

流程:
1. develop创建feature分支
2. 完成后合并回develop
3. 发布时从develop创建release
4. release完成后合并到main和develop
5. 紧急修复从main创建hotfix
```

## 测试

### pytest基础
```python
# tests/test_analysis.py
import pytest
from src.analysis import calculate_mean

def test_calculate_mean():
    assert calculate_mean([1, 2, 3]) == 2.0

def test_calculate_mean_empty():
    with pytest.raises(ValueError):
        calculate_mean([])

# 参数化测试
@pytest.mark.parametrize("input,expected", [
    ([1, 2, 3], 2.0),
    ([0, 0, 0], 0.0),
    ([1], 1.0),
])
def test_calculate_mean_parametrize(input, expected):
    assert calculate_mean(input) == expected
```

## 容器化

### Dockerfile
```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "main.py"]
```

### docker-compose.yml
```yaml
version: '3.8'

services:
  app:
    build: .
    volumes:
      - .:/app
      - ./data:/app/data
    environment:
      - PYTHONPATH=/app
    command: python main.py
  
  jupyter:
    build: .
    ports:
      - "8888:8888"
    volumes:
      - .:/app
    command: jupyter lab --ip=0.0.0.0 --allow-root --no-browser
```

## 环境管理

### conda
```bash
# 创建环境
conda create -n research python=3.9

# 激活环境
conda activate research

# 安装包
conda install numpy pandas scikit-learn
conda install -c conda-forge pytorch

# 导出环境
conda env export > environment.yml

# 从文件创建环境
conda env create -f environment.yml
```

### pip + venv
```bash
# 创建虚拟环境
python -m venv .venv

# 激活
source .venv/bin/activate  # Linux/Mac
.venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt

# 生成requirements.txt
pip freeze > requirements.txt
```

### pyenv
```bash
# 安装pyenv
curl https://pyenv.run | bash

# 安装Python版本
pyenv install 3.9.16
pyenv install 3.10.11

# 设置全局/本地版本
pyenv global 3.10.11
pyenv local 3.9.16
```
