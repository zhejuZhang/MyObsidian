# Small talk 总结
1. 主动打招呼
   Hi, hello, you all right?
2. 体积对方近期关键词
   从life school office interests入手
3. 好事：congratulations
   That sound so fun/good
4. 坏事：oh no I'm so sorry.
   That's horrible
   That must be so sad
5. 结束对话：
   找借口：I'am going that way
   万能结尾：we'll catch up soon
   we'll meet up soon
